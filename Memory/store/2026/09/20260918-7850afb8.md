왜 : 절차 정본의 8단계 판정은 「남이 켜서 설명 없이 끝까지 해 본다」인데, 켜 볼 남이 없어 그대로는 못 한다.
무엇을 : 사용자가 2026-09-18 에 판정을 「사용자가 직접 켜서 하루치를 끝까지 해 본다」로 바꿨다. 설명 없이 되는지는 사용자 스스로 보는 셈이라, 미뤄 둔 물음(손맛·연출·화면 알아보기)에 예/아니오를 적는 것으로 대신한다.
다음에 : 세로 조각 설계 문서에 이 판정 기준을 적고, 놀고 난 뒤 결과 기록을 남긴다. 사람 시험자가 생기면 그때 남이 해 보는 판정을 추가한다.
