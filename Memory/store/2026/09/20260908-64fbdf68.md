무엇 : q2 2판 프로토(Prototypes/2026-09-08-q2-골드고리2판) 소단계 4~6. 짝 구매 1·2단계 150·750 (buyPrice·buy 가 종 key 를 받는다, 3단계·변종 안 팜) · CORE.judge(s,extra) 로 q2-1 ①~④·q2-2 ①~③ 자동 판정 표와 JSON `판정` 키 · node 봇 두 정책(가 짝 구매 우선 · 나 번식만) 씨앗 20 × 30분.
봇 결과 30분 : q2-1 ① 남은÷번 골드 12% 통과 · ③ 2칸 이상 동시 비율 18% 로 0/20 (30분엔 2칸까지만 산다, 60분이면 59%) · q2-2 ① 짝까지 4.6분(짝 구매) / 7.1분(없음) · ② 짝 구매 비율 10% 로 20~40% 밖 · ③ 늘 통과.
어긋남 : ③ 은 30분 기준이 불가 (후보 : 60분 기준 · 칸 값 낮춤 · 빈 칸 대기 시간으로 바꿈). ② 는 눈금상 불가 (후보 : 5~20% · 분모를 합성 골드로 · 새 종마다 짝 구매 비율). 눈금은 안 고쳤다, 사용자 판단.
확인 : node --check 통과 · 봇 4판 다 돌았다 · 브라우저는 직접 안 열어 봤다. 공수 예상 90분 · 실제 약 20분.
