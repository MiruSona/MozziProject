2026-09-07 실측. WebFetch 로 팬카페 주소를 열면 unable to fetch from cafe.naver.com 오류가 난다.
보통 세션에서는 ToolSearch 로 chrome·browser 를 찾아도 크롬 도구가 하나도 없다.
1. 로그인이 필요한 페이지를 볼 일이면 세션을 claude --chrome 으로 새로 연다.
2. 세션 시작 뒤 ToolSearch 로 chrome 도구가 떴는지 먼저 확인하고 나서 일을 시작한다.
3. 안 떴으면 WebFetch 로 시간 쓰지 말고 바로 사용자에게 알린다.

2026-09-07 추가 실측. claude --chrome 세션에서 navigate 로 cafe.naver.com 을 열면
"This site is not allowed due to safety restrictions" 가 난다. 사용자가 직접 연 탭도 "This site is blocked" 로 못 읽는다.
확장 Permissions 화면(사이트별 Ask/Allow, Blocked sites)으로는 못 푼다 — Anthropic 쪽 안전 목록이다.
4. 팬카페 글은 사용자가 캡처해 Docs/Reference/ 에 넣어 주면 Read 도구로 그림을 읽는다.
