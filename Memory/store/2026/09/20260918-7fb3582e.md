왜 : 절차는 「코드가 수치표를 읽게 한다」만 있고 장치가 없었다. 사용자는 관리 프로그램 / 실제 데이터 / Unity 임포트 세 층을 원했다. 값이 임시이고 표 모양이 세로 조각 중에 바뀌므로 편집기를 먼저 만들면 따라 고치게 된다.
무엇을 : 세로 조각 동안은 층 둘만 만든다. 데이터 폴더에 표 하나당 JSON 하나를 두고 Resources 로 읽는다. 읽는 클래스는 키로 행 찾기만 하고 값 해석은 안 한다. JSON 이 값의 정본이고 수치표 문서는 근거만 남긴다. 관리 프로그램은 Officina 툴킷 쪽에서 나중에 정식 조사와 설계로 만든다(사용자 2026-09-18 결정). 네임스페이스는 Mozzi.
다음에 : 이 저장소에는 JSON 형식과 폴더 규칙만 문서로 남겨 나중에 툴이 붙게 한다.
