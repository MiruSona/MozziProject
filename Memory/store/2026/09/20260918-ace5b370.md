왜 : 수치표는 재료별 상한을 미정으로 두었고 q3 프로토는 종당 60 으로 놀았다. Unity 로 옮기며 값 하나로 굳혀야 했다.
무엇을 : 사용자가 2026-09-18 에 종마다 100 으로 정했다. 옛 농장기획의 합계 60 과 프로토의 종당 60 은 안 쓴다. 어긋난 다른 값 셋(개수 계수 ×1.5/×2/×3 · N 강화 300/800/2,000/5,000 · 영구 단축 200/400/800/1,600/3,200)은 프로토 값으로 수치표를 고친다.
다음에 : 04-수치표.md 와 JSON 데이터에 100 을 적는다. 세로 조각 판정 뒤 다시 본다.
