2026-09-20 사용자 결정. 포물선 움직임은 코드가 계산하고, 납작·길쭉한 모양은 그린 프레임 4장(hop0 기본 · hop1 납작 · hop2 길쭉 · hop3 내려옴)이 맡고, 프레임 재생은 Unity Animator 가 한다.
값 : 뜀 0.35초 + 쉼 0.15초 · 높이 12px. 걸을 때만 뛴다.
클립·컨트롤러는 12종이 한 벌을 같이 쓴다 : Assets/_Project/Art/Anim/MozziIdle.anim · MozziHop.anim · Mozzi.controller.
시계는 코드 하나다 — Animator.speed = 0 으로 세우고 코드가 프레임을 몬다. 배속·방치와 어긋나지 않게 하려는 것이다.
클립을 손으로 안 고친다 : MozziAnimBuild 의 상수 표를 고쳐 메뉴 Tools/찹쌀이/애니 다시 굽기 로 굽는다. 프리팹은 Tools/찹쌀이/프리팹 다시 짜기.
