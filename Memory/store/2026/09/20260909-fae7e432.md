무엇을 했나 : q2 2판을 사용자가 실제 16분(게임 235분) 놀아 q2-1·q2-2 둘 다 통과시켰다. 눈금 둘을 바꿨고(q2-1 ③ 게임 60분 기준, q2-2 ② 짝 산 비율·합성 대비 30%), 판정 결과를 01-코어루프.md·03-시스템-합성소.md 에 반영했다. 00-컨셉.md 를 92줄에서 57줄로 접고, stage next 둘로 6단계에서 7단계 「기능 자르기」로 넘겼다.
어긋난 것 : 로컬 Flash-Next 한 판이 3~10분 걸려 예상보다 느렸다(프롬프트 27K). mem 본문을 1줄로 쓰면 body-thin 관문이 거절해서 다시 썼다. 골드 25% 기준은 235분 기준으로 불통 — 96분에 칸·단축을 다 사면 소비처가 합성뿐이라 고인다. 도감 15칸도 230분에 다 찼다(컨텐츠 양 문제).
다음에 할 것 : 7단계에서 흩어진 아이디어를 모아 Docs/Design/02-기능목록.md 에 MoSCoW 표로 늘어놓는다. Won't 칸은 필수, Must 는 열 개 안. 최종 칸은 사용자가 정한다.
