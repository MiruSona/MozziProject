사용자가 손님을 「익명이와 지금 캐릭터의 중간」으로 가자고 해서 조사했다.
익명이는 카카오 이모티콘 캐릭터이고 작가는 라부다. 12판 넘게 나왔다. 이모티콘 그림 12장을 받아 눈으로 봤다 — 흰 달걀 한 덩어리에 손그림 검정 윤곽선, 점눈 두 개, 작게 벌린 입, 분홍 볼이다. 팔은 짧은 혹이고 다리는 거의 없다.
핵심은 익명이와 손님 v2 의 차이가 등신(1.2 대 2.0)이 아니라 덩어리 수(1 대 4)였다는 것이다. v2 가 어색했던 까닭이 여기 있다 — 사람 뼈대를 줄여 놔서 「작은 사람」으로 읽혔다.
중간 후보 셋을 냈다 : 가(달걀 한 덩어리 + 혹 팔 + 발, 키 48) · 나(눈사람 두 덩어리, 키 52) · 다(물방울 + 가는 팔, 키 50). 안 가를 권했다 — 얼굴이 16~18px 로 넓어 표정이 갈리고 찹쌀이 대비 1.37배라 주인공이 안 밀린다.
윤곽선은 아트규칙 7번(외곽선 없음)이 있어 없음 유지를 제안했다. 다음은 사용자가 안을 고르면 draw_customer_v3.py 로 바로 그린다.
