왜 : 사용자가 2026-09-20 농장 타일 작업을 마치고 새 세션으로 넘어가기 전에 다음 아트 일의 순서를 정했다.
무엇을 : 재료 그림(팥·콩·쑥·깨·잣·대추 등 재료 아이콘)을 먼저 그린다. 그림요청목록의 재료 아이콘 항목이 해당한다.
다음에 : 새 세션에서 조사 → 설계 → 작업 순으로 연다. 그림을 받을 코드 자리(PileObject)는 세로 조각 세션 몫이라 순서를 맞춘다. 작은 아이콘은 PixelLab 의 item_descriptions 묶음 생성이 후보다.
