사용자가 2026-09-07 에 컨셉 물음에 다 답해서 Docs/Design/00-컨셉.md 를 1판으로 썼다.

무엇을 : 인터넷 방송인 고차비 님의 무료 팬게임이다. 주인공은 팬 캐릭터 찹쌀이(왕관 쓴 찹쌀떡)이고, 계열은 기존 합성 설계(잔디·물·용암·늪)를 그대로 쓴다. 대상은 20~30대 팬, 남길 기분은 힐링, 재밌는 순간은 찹쌀이 도감과 레시피 도감 둘이다. 화면은 모바일 세로 기준이고 PC·안드로이드로 낸다.

기둥 넷 : ① 켜지 않아도 농장은 굴러간다 ② 새 찹쌀이·새 찹쌀떡을 만나는 순간이 제일 즐겁다 ③ 힐링이 먼저다 ④ 원작 찹쌀이를 보면 바로 알아본다.

왜 : 빚·마감 같은 압박 목표는 힐링과 부딪혀서 뺐고, 유료 판매·공식 그림 사용은 권리가 소속사에 있어 뺐다.

다음에 : 2차 창작 규정을 팬카페 공지에서 확인해야 하고, 01-코어루프.md 를 쓴다.
