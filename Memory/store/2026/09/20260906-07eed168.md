Docs/Design/ 아래 기획서는 날짜 없이 번호 이름을 쓴다. 00-컨셉.md, 01-코어루프.md, 02-기능목록.md, 03-시스템-<이름>.md, 04-수치표.md, 05-진행과튜토리얼.md 순이다.
기획서는 계속 고쳐 쓰는 문서라 날짜를 붙이면 이름이 금방 낡기 때문이다. 조사·기록 문서는 YYYY-MM-DD-주제.md 그대로다.
이 예외를 doc-writing 스킬의 「어디에 두나」 절에 한 줄 적어 두었다.
이미 있던 2026-09-06-찹쌀이합성설계.md 는 git mv 로 03-시스템-합성소.md 로 옮겼고, 가리키던 진행상황.md 와 필요프로토타입가늠.md 의 경로도 고쳤다.
