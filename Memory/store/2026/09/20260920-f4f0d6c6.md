찹쌀이 레이어 애니를 코드가 몰려고 실측했다 (2026-09-20, Unity 6000.3.23f1, 에디터 모드 eval).

- Play(hash, 0, 0.75f) 만 하고 바로 값을 읽으면 0 이다 — 반영이 안 된다.
- Play 뒤 animator.Update(0f) 를 부르면 그 시각의 커브 값이 들어온다.
- speed 가 0 이니 Update(0.4f) 처럼 시간을 줘도 값이 안 흐른다 — 시계는 코드가 갖는다.

MozziVisual.PlayState 가 Play + Update(0f) 를 묶어 두었다.
