왜 : 2026-09-12 에 로컬 Flash-Next 하네스로 문서 반영 3판을 돌리다 두 가지에 걸렸다. 하나는 실행기가 아예 안 뜨는 것, 하나는 게이트가 오탐으로 실패해 재시도 판이 헛도는 것이다.

1. 키를 먼저 꺼내 export 한다. 실행기는 `ANTHROPIC_BASE_URL` 과 `ANTHROPIC_AUTH_TOKEN` 환경 변수가 없으면 「Not logged in」을 찍고 종료 코드 4 로 죽는다. 키는 `ssh minipc` 로 꺼내 두 변수에 넣은 뒤 하네스를 돌린다.
2. 하네스 판은 다른 갈래가 없을 때 돌린다. 서브에이전트나 `mem index` 가 같은 시간에 저장소 파일을 바꾸면 G1 범위 게이트가 「범위 밖 파일을 건드렸다」로 오탐해 실패하고, 재시도 판이 멀쩡한 산출물을 두고 헛돈다.
3. 판정은 항목 단위로 본다. 이번 3판 9항목은 전부 1판에 통과했으니, 실패가 뜨면 모델을 의심하기 전에 위 둘을 먼저 본다.

다음에 : 하네스를 띄우기 전에 (가) 두 환경 변수가 있는지 (나) 다른 갈래가 도는지 두 줄만 확인한다. 두 갈래를 꼭 같이 돌려야 하면 게이트 범위를 갈래별로 나눠 잡는다.
