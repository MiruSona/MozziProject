2026-09-20 사용자 판정으로 농장 바닥·담장 그림 8장의 결을 확정했다. 판정이 세 판 걸렸다.

1판(AI 색·무늬만 받아 PIL 로 짠 것)은 「둘 다 너무 밋밋하다. 담장은 나무 느낌을 더 내고 굵어져도 된다. 변종 무늬를 더 세게. 옆 담장은 앞으로」였다.
2판(풀밭 얼룩 + 풀뭉치 22~26개, 굵은 기둥·5px 판자·나뭇결·옹이·못·그림자)은 「풀밭이 너무 야생 같다 — 밋밋한 것으로 되돌리되 약간만 잔디 자란 느낌. 담장은 마음에 든다. 옆 담장만 다시」였다. 메인 세션도 옆 담장이 사다리처럼 보이고 모서리와 기둥 x 자리가 3px 어긋난 것을 잡았다.
3판에서 바닥은 1판 바탕(#8AC35E + 잔 점)에 옅은 풀 뭉치를 타일당 4~5개만 얹고, 꽃·돌은 2판 그대로 두고, 옆 담장과 모서리 둘은 기둥 x15~23 + 가는 띠 2줄로 다시 그렸다.

확정된 것 : 풀밭은 차분한 바탕 + 옅은 풀 포기 · 담장은 굵은 나무 울타리 · 옆 담장은 기둥과 가는 띠 · 변종 무늬는 2판 세기 · 변종 비율 82/10/8 그대로 · 위 담장 위로 풀 띠가 보이는 것과 위아래 담장이 비슷해 보이는 것은 당장 괜찮다. 사용자 최종 판정은 「오 좋아」였다.
