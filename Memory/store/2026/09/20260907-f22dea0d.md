무엇 : q1-1 골드 고리 프로토(Prototypes/2026-09-07-q1-1-골드고리)를 만들고 node 봇으로 게임 시간 30분·씨앗 20개를 돌렸다.
결과 : 시작 2마리를 바로 합성하는 봇은 1회로 끝난다(혼자 남아 번식 불가, 끝 골드 827). 번식 짝 2마리를 지키고 남는 골드로 1단계를 사는 봇은 3.4회(3~5), 끝 골드 2,332, 9.7마리. 골드 0 멈춤은 첫 7초뿐. 60분이면 6.0회·골드 11,000.
읽은 것 : 병목은 골드가 아니라 합성소 1칸·5분 대기와 「시작 2마리를 다 쓰면 번식이 멈춘다」다. 골드는 남아돈다.
가정 : 바닥·설비·보관함·농장 상한 없음, 한 농장. 가루 주기에 단계 배수 없음. 같은 계열 다른 단계 합성은 낮은 단계+1.
다음 : 사용자가 30분 놀고 결과.md 에 ①~④ 를 쓴다. 눈금(합성 대기·떡 값)은 그 뒤 사용자가 정한다.
