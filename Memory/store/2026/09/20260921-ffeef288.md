왜 : 2026-09-21 에 손님 시안 v1(살색 몸에 옷·헤어 겹)은 어깨가 넓고 몸이 사각이라 물렸다.
v2(휴먼 폴 플랫·메챠 카멜레온·SD 비율을 참고한 흰 사람 2등신)도 사용자가 「이건 아닌 듯」으로 물렸다.
무엇을 정했나 : 사용자가 레퍼런스를 직접 준다. 남녀 구분은 하지 않는다.
손님은 가볍게 가고, 제대로 만들 인물은 나중의 고차비(이 팬게임의 대상) 캐릭터 하나다.
아직 살아 있는 것 : 캔버스 48x64 와 전신 구도. 손님 칸은 가로 68px 이 한계라 세로로 키운다.
주문 떡 자리는 말풍선이 가장 또렷했고, 볼은 분홍이 노랑보다 나았고, 팔은 48px 급에서 2~3px 이 맞다.
다음에 뭘 : 레퍼런스를 받으면 Docs/Reference/Art/손님/ 의 v2 스크립트 뼈대와 미리보기 함수를 다시 써서 v3 를 그린다.
Unity 쪽은 아직 아무것도 안 건드렸다. 손님이 끝나면 진열대 칸 UI 다.
눈금 : 조사·시안 서브에이전트 한 판은 실행 기록으로 6~9분이었다. 예상은 10분 안팎으로 잡는다.
