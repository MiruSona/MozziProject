왜 : 농장 바닥·담장 그림을 만들기 전에 지금 코드가 무엇으로 그리는지와 PixelLab 선택지를 알아야 했다.

무엇을 : 바닥은 FarmViewManager.CreateGround 가 만드는 흰 네모 하나이고 Tilemap 도 격자도 없다. 담장은 오브젝트 자체가 없고 코드의 FenceMax 20 은 마릿수 상한일 뿐이다. 바닥 자리는 화면 y 136~560 의 360x424px 라 타일 32 로 11.25 x 13.25 칸이 되어 가로 세로 둘 다 안 떨어진다. 임포트 설정은 MozziArtImport 가 Resources/Art 폴더 전체에 걸려 있어 손댈 것이 없고, com.unity.2d.tilemap.extras 6.0.3 이 이미 깔려 있어 Rule Tile 까지 패키지 추가 승인이 필요 없다. PixelLab 잔액은 4976/5000 generations 로 넉넉하다. 참고 그림은 바닥 12장 담장 6장이 이미 저장소에 있다.

다음에 : 설계에서 정할 것 9개를 사용자와 답한다. 바닥 자리를 타일 배수로 맞출지, 바닥 몇 종, 담장 조각 몇 장, 어느 PixelLab 도구로 뽑을지, Unity 에 어떻게 넣을지가 앞의 다섯이다. FarmViewManager.cs 와 SpriteKeys.cs 는 세로 조각 세션과 겹치는 자리라 누가 언제 고치는지 먼저 정한다.
