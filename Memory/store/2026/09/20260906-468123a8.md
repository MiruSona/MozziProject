왜 : 필드를 빼고 합성으로 바꾼 뒤 첫 설계가 필요했다. 사용자와 네 토막으로 나눠 확인하며 정했다.
무엇 : 합성 1차 설계를 Docs/Design 에 남겼다. 계열 4×단계 3 = 12종 + 변종 24칸, 결과 세 갈래 75/20/5(임시), 골드+시간 비용, 번식·도감 구매, 보관함, 화면 흐름. 공수는 조사 약 15분 + 설계 대화 약 30분 + 문서화 약 10분.
다음 : 가판대 설계(골드 수입 눈금) → 농장 설계 다시 쓰기(번식 주기·보관함·늪 계열) → 합성 눈금 확정.
