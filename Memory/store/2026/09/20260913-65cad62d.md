왜 : 사용자가 q3 를 놀아 보고 「재료 수급 전제가 이상하다」고 했다. 원인은 찹쌀이 번식을 통째로 뺀 것.
무엇 : CONST 에 BREED_PERIOD 180(q2 그대로)·FARM_MAX 20·FLOOR_CAP 60·PAIR_PRICE 150 을 넣고 breed()·buyPair()·재료 상한 생산 정지를 붙였다. 새 찹쌀이 얻기(다음 종 1마리)는 그대로 두고 옆에 짝 사기를 두어 「새 종은 짝을 사야 번식」 흐름을 재현했다. 기록·JSON 에 번식·짝구매·비운 동안 태어난 마리 수를 더했다.
확인 : node 헤드리스로 팥 2마리가 게임 10분 뒤 5마리(번식 3회)·창고 60 에서 생산 정지·농장 20 에서 번식·구매 정지를 봤다. 브라우저는 안 띄웠다.
다음 : 사용자가 다시 놀고 결과.md 판정 표를 채운다. 재료가 60 에 금방 차니(10분에 가득) FLOOR_CAP 이 병목이면 눈금을 다시 본다.
