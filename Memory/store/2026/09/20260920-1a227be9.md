왜 : 폰으로 받다가 끊기고 아티팩트가 파일당 15MB 를 넘기면 못 올린다.

무엇을 : 셋을 했다. 하나. ONEMobilePOP SDF 의 폴백에서 Dynamic 자산을 뺐다 — 그 자산이 원본 ttf 3.8MB 를 끌고 왔다. 먼저 게임이 띄우는 글자 343자를 정적 아틀라스 2484자와 대조해 다 있는 것을 보고 끊었다. 둘. Renderer2D 의 PostProcessData 를 None 으로 하고 URP 전역 설정의 포스트프로세싱 변종 버리기를 켰다 — FilmGrain 텍스처 열 장이 빠졌다. 셋. TMP 기본 자료(LiberationSans SDF · EmojiOne)를 Resources 밖 Unused 폴더로 옮기고 TMP Settings 의 기본 스프라이트를 비웠다.

결과 : 자료 7,103,356 → 4,211,322 바이트, 전체 16,071,807 → 13,575,250 바이트. 사용자 에셋은 18.1 → 9.4MB 다. Play 로 농장·가판대 화면을 360x640 으로 찍어 네모 글자 없음과 색 그대로를 봤다.

다음에 : 남은 큰 것은 Unity 스플래시 2.7MB (Personal 라이선스라 못 끈다) 와 엔진 wasm 9.2MB 다.
