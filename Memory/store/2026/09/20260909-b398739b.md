왜 : 2026-09-09 심층 조사(문서 2-1 절)에서 독립 실사용 후기가 0건이었다. 공식 홈 후기 5개는 이름·직함만 있고 링크가 없어 광고문으로 봤다. API·MCP·Unity/Aseprite 플러그인이 전부 없어 24종을 규칙적으로 뽑아 굽는 자동화에 못 꽂는다. 정가 토큰표·약관·갤러리가 로그인 벽 뒤라 토큰 1개로 무엇이 몇 개 나오는지도 모른다. 스프라이트 권장 조건이 단색 배경·오른쪽 보기·물체 하나라 8방향 회전은 기대하기 어렵다. 유일한 강점인 리스킨(애니 구조 유지·겉만 교체)은 ArtTool 의 팔레트 치환으로 공짜로 대신된다.
무엇 : 사용자가 「없던 일로」 결정했다. 소액 시험(₩4,900 첫 팩)도 하지 않는다. 생성 AI 는 PixelLab 을 1차로 두고, UI·배경도 PixelLab MCP 로 먼저 시험하며, 부족할 때 SpriteCook 만 2차로 본다.
뒤집는 조건 : 에테르AI 가 공개 API 나 MCP 를 내놓거나, 독립 실사용 후기에서 픽셀 격자 정확도가 확인되면 다시 본다.
