왜 : 오프라인 검증에서 save.json 의 savedAtUtcTicks 를 N초 전으로 옮기려고 PowerShell 로 600*10000000 을 뺐더니 int 곱이 넘쳐 double 이 되고 파일에 6.39E+17 로 써졌다.
무엇을 : Set-Content 전에 [long]600*[long]10000000 처럼 양쪽에 [long] 을 붙여 계산하고, 쓴 뒤 정규식으로 값이 정수인지 다시 읽어 확인한다.
다음에 : 세이브 시각을 손으로 옮기는 검증(a~e 같은 것)은 스크래치패드 .ps1 한 장으로 묶어 두면 같은 실수를 안 한다.
