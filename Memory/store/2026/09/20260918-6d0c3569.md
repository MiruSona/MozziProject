왜 : unity command delete_asset asset=Assets/Scripts confirm=true 로 치면 '매개변수가 아닙니다. 대신 --asset <value>' 오류가 난다.
무엇 : 인자는 전부 --이름 값 꼴이다. 인자 목록은 unity command --query <이름> --detail full 로 본다 (--help 는 일반 도움말만 준다).
다음 : delete_asset 은 --dry_run true 로 먼저 보고 --confirm true 로 지운다. 폴더와 .meta 가 같이 지워진다.
