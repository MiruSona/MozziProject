왜 : CakeIconSetup 이 Icon 을 MakeIcon 으로 마지막 자식에 붙여, 패널 전체를 덮는 흰 섬광(MadeFlash) 위에 떡만 남아 떠 보였다. 글자들은 흰색이라 섬광에 묻히는데 떡만 도드라졌다.

무엇을 : 프리팹의 MadePanel 안 Icon 을 sibling index 5 에서 0 으로 옮겼다(Unity CLI eval). CakeIconSetup 에도 SetAsFirstSibling() 한 줄을 넣어 다시 돌려도 같은 자리가 되게 했다.

다음에 : UGUI 는 형제 순서가 그리는 순서다. 덮개(섬광·암전) 아래에 둘 것은 덮개보다 앞 형제로 둔다. Play 로 알파 1(떡 가려짐)·알파 0(떡 보임) 두 장을 캡처해 확인했다.
