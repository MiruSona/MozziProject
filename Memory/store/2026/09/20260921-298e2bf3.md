왜 : 떡 아이콘 시안을 20분으로 잡았는데 8판을 돌아 40분이 걸렸다. 참고 그림이 하나도 없는 새 갈래라 구도를 여섯 번 바꿨다 (물든 몸 → 흰 몸+고물 → 반달 → 반 가르기 → 기울이기 → 돌리기 → 기운 반쪽 → 같은 크기 두 알).
무엇을 : 시안은 예상 20분 · 실제 약 40분(8판)이고, 배선은 예상 60분 · 실제 약 15분이었다. 이 값은 EffortTool 실측이 아니라 서브에이전트 실행 시간 합이다 — 작업이 도는 중이라 effort 로 못 쟀다.
다음에 : 참고 그림 없는 새 아이콘 갈래는 시안 3~4판 × 판당 5~7분에 사용자 판정 왕복을 더해 잡는다. 반대로 훅이 이미 있는 배선은 예상을 크게 잡을 필요가 없다 — 표에 열 하나 더하고 화면 넷을 잇는 일은 15분쯤이다.
