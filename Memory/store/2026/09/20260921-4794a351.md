왜 : 「검사에서 나온 것 고치고 빌드해 올리기」 꼴의 눈금이 없었다.

무엇을 : 고칠 자리가 경로·줄까지 지목된 상태로 넘어와 고치기 4건이 4분, Play 확인 4분, WebGL 빌드 5분(빌드 자체 305초), 뒷정리 2분이었다. 서브에이전트 한 판 약 14분에 메인 세션의 검토·게시 5분을 더해 19분이다. 예상은 사람 눈금 55분이었다.

다음에 : 같은 꼴(지목된 고침 몇 건 + 빌드 + 게시)은 25분으로 잡는다. 빌드 8분 동안은 다른 Unity 명령이 막히니 그 시간에 기억·피드백을 쓴다. EffortTool 의 estimate 는 이 꼴에 1분 안팎을 내놓아 그대로 못 썼다 — 시각을 직접 적었다.
