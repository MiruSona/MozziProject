왜 : 세로 조각 판정을 설치 없이 링크로 하려고 WebGL 빌드를 아티팩트에 올렸다. 09-20 에 사용자가 아티팩트에서 잘 돈다고 확인했다.
1. unity command eval_file 로 Mozzi.Editor.WebGlBuild.Build() 를 부른다. CLI 는 5초 상한으로 실패처럼 돌아오지만 빌드는 돈다. Editor.log 의 WebGlBuild 결과 줄로 끝을 본다 (약 11분, 12.3MB).
2. 아티팩트는 unityweb 확장자를 거절한다. data · framework · wasm 세 파일을 wasm 이름으로 올린다. framework 는 Brotli 바이너리라 js 이름으로도 거절된다.
3. 페이지의 로더 config 에서 dataUrl · frameworkUrl · codeUrl 을 새 이름으로 바꾼다. 로더는 내용으로 압축을 알아봐서 그대로 풀린다.
다음에 : 같은 주소로 갱신하려면 Artifact 에 url 을 넘긴다. APK 는 15MB 상한과 확장자 때문에 못 올린다.
