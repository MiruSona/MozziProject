2026-09-07 GamedesignTool 1판을 끝내고 게임 저장소에 붙였다.
정본은 Docs/Todo/기획상태.json (지금 1단계·1판). 설정은 Docs/Todo/기획설정.json 에 코드폴더 한 칸만 덮었다.
.claude/settings.json 에 SessionStart show --hook, PreToolUse lint --hook (순서·모양이 어긋나면 쓰기를 막는다), Stop done --hook (판 끝 할 일 경고만) 셋을 걸었다.
bin/ 은 gitignore 라 새로 받으면 Tools/GamedesignTool 안에서 go build 를 한 번 친다.
훅이 실제 세션에서 도는지는 다음 세션 첫 화면에 「지금 1단계 컨셉」이 뜨는지로 확인한다.
