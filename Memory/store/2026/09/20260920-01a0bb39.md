왜 : 그림요청목록 1번이 「Resources/Art/Mozzi/<id>.png 한 장을 넣으면 코드 수정 없이 뜬다 · 새로 8장」이라고 적혀 있었는데 코드와 달랐다.
무엇을 : MozziSpecies.json 24종의 spriteKey 가 전부 Mozzi/body 이고 MozziArtKeys.BodyHop 이 _hop0~_hop3 을 붙여 찾는다. 지금은 흰 몸 한 벌에 MozziObject 가 colorHex 를 곱해 종을 구분한다. 09-20 에 그림요청목록 1번과 진행상황 아트 절을 이 사실대로 고쳤다.
다음에 : 종별 몸은 8종 x 4프레임 = 32장을 <spriteKey>_hop0~3 이름으로 넣고 MozziSpecies.json 의 spriteKey 를 종마다 바꾼다. 색으로 그린 몸은 colorHex 곱하기가 덮으니 그 처리는 코드 일로 따로 잡는다.
