왜 : 03-시스템-농장.md 가 없어 세로 조각 코드를 못 쓰는 상태였다. 사용자가 정한 것(재료 상한 종마다 100 · 1판 범위 · JSON 정본) 밖의 빈 자리를 AI 가 제안으로 채워야 했다.
무엇을 : 제안 딱지로 채운 것 — 재료 상한 100 은 바닥 재료 기준이고 창고는 상한 없음 · 바닥 더미를 탭하면 그 종 전부 줍기 · 번식과 짝 구매 결과는 농장에 바로 놓이고 담장이 차면 멈춤 · 합성 결과만 보관함으로 · 보관함 상한 없음(1판) · 일괄 팔기는 종 단위 · 오프라인은 1초 걸음으로 생산→번식 순서 계산 · 번식 단계 배수는 생산과 같은 ×1/×1.5/×2. 04-수치표.md 는 프로토 값 넷으로 고치고 3-1 농장 절을 더했다.
다음에 : 사용자가 제안을 확인하면 보류를 푼다. 세로 조각 판정 뒤 상한 100 과 바닥 기준이 맞는지 다시 본다.
