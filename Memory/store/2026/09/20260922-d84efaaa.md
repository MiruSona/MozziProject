왜 : 세로 조각 판정을 남에게 시키려고 링크 공유가 필요했다. 아티팩트는 v9 가 12.62MB 로 16MB 상한에 가깝고 Content-Encoding 헤더를 못 만져 한 파일 우회를 계속해야 한다. 구글 드라이브는 HTML 호스팅이 없어 다운로드만 되고 file:// 에서는 wasm 이 안 돈다. NAS 는 집 망을 밖에 여는 일이라 물렸다.
무엇을 : itch.io 에 HTML 프로젝트로 zip 을 올린다. Brotli + Decompression Fallback 이면 헤더 없이 돈다. Visibility 는 Restricted(비밀 링크). 트래픽은 12MB×100명=1.2GB 라 무료 구간 안이다.
다음에 : 새 판을 올릴 때 zip 뿌리에 index.html 이 바로 있어야 한다. 아티팩트 판(WebGLArtifact/)은 그대로 둔다.
