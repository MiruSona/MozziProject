왜 : ResourcePool 루트가 DontDestroyOnLoad 라 DeleteAndRestart 로 씬을 다시 열면 같은 화면 인스턴스가 다시 빌려진다. _bound 가 남아 Bind 가 바로 return 하면 닫기 버튼이 옛 UiManager 를, 허브 필드가 폐기된 Manager 를 가리킨다.
무엇을 : OverlayScreen · FarmScreen · DebugPanel · OfflinePopup 의 OnReturn 에서 _bound=false, UiBindUtil.UnbindAllButtons 로 리스너 전부 떼기, 목록·허브 비우기를 한다.
다음에 : 풀에서 빌리는 화면을 새로 더하면 UnbindChildren 을 꼭 채운다. 재시작 검증은 디버그 「세이브 지우기」 뒤 닫기 버튼과 골드 머리글로 본다.
