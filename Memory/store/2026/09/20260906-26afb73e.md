uloop 저장소 README 는 Claude Code 의 명령 샌드박스가 네트워크와 명명 파이프 연결을 막아서 uloop 가 켜진 Unity 에디터에 붙지 못하는 오류가 난다고 적고 있다. 에디터가 잘 돌고 있어도 연결 순간에 실패한다.

해결은 Claude Code 사용자 설정의 sandbox 예외 목록에 uloop 명령 전체를 넣는 것이다. 자세한 설정 값과 근거 문서 위치는 조사 문서에 적어 두었다.

공식 unity CLI 도 로컬 포트로 에디터에 붙으니 같은 문제가 날 수 있다는 것은 아직 추측이다. 이번 조사에서는 Bash 도구로 공식 CLI 의 에디터 상태 명령이 문제없이 돌았다. uloop 를 실제로 깔고 나서 다시 확인해야 한다.
