검증 중 onClick.Invoke 로 덮개 뒤 토글을 누르니 떡메가 다른 재료로 다시 시작됐다.
실제 손가락은 덮개 Image 가 raycast 를 먹어 안 닿지만, 코드 호출 · 키 입력 · 자동화는 뚫는다.
OnToggle · OnExpMake · OnMakeRow 첫 줄에서 _pound.IsRunning 이면 돌아간다. 덮개형 연출을 새로 만들면 같은 가드를 둔다.
