왜 : 파이프라인 서버가 authoring root(Assets) 기준으로 경로를 검사하고 바로 임포트한다. 스크래치패드 경로는 400 으로 거절된다.
무엇을 : Assets/Temp/cap/ 같은 임시 폴더에 찍고 스크래치패드로 복사한 뒤 AssetDatabase.DeleteAsset 으로 지운다. 세로 화면은 --width 405 --height 720 을 같이 준다.
다음에 : Game 뷰 9:16 은 eval 로 GameViewSizes 에 AspectRatio 9:16 을 더하고 selectedSizeIndex 를 바꾸면 된다 (scratchpad eval_gameview916.cs 꼴).
