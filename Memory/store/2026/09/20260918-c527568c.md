## 왜
- WebGL 빌드의 Application.persistentDataPath 는 Emscripten IDBFS 다.
- File.WriteAllText · File.Delete 는 메모리 파일계에만 적힌다. FS.syncfs(false, cb) 를 불러야 IndexedDB 에 내려간다.
- 안 부르면 30초 자동저장이 돌아도 탭을 닫는 순간 다 사라진다.

## 무엇을
- Plugins/WebGL/MozziFs.jslib 에 MozziSyncFs 를 두고 Save/WebGlFsUtil.Sync() 로 감쌌다.
- SaveManager 는 SaveNow 의 쓰기 뒤와 DeleteAndRestart 의 지우기 뒤에 Sync() 를 부른다.
- 에디터 · 다른 플랫폼에서는 UNITY_WEBGL && !UNITY_EDITOR 가 아니라 빈 함수다.
- 디버그 패널(DebugPanel · UiManager)은 UNITY_EDITOR || MOZZI_DEBUG 로 묶었고, Editor/WebGlBuild.Build() 가 WebGL 정의에 MOZZI_DEBUG 를 넣는다.

## 다음에
- WebGL 빌드가 나오면 브라우저에서 저장 → 탭 닫기 → 다시 열기로 세이브가 남는지 눈으로 본다.
- 세이브 지우기 뒤 씬 다시 열기(GameMaster.RequestScene)가 브라우저에서도 도는지 같이 본다.
