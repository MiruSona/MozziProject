2026-09-07 새벽. Opus 서브에이전트 한 판으로 설계 6분, 구현 21분(시험 47개·명령 9개·검사 L1~L8·대시보드), 게임 저장소 연결 3분. 메인 검토를 더해 약 1시간.
툴 할일 문서의 눈금은 반나절이었다. 설계 문서를 먼저 받아 메인이 실제 저장소 사정(옛 문서·하위 폴더·단계별 막기)을 고친 뒤 같은 에이전트가 이어서 구현한 것이 효과가 컸다.
구현 중 잡은 결함 둘 : Go flag 가 첫 인자에서 옵션 읽기를 멈춰 재정렬이 필요했고, 훅이 준 상대 경로가 cwd 기준으로 풀려 검사가 조용히 통과했다.
다음 툴 1판 눈금은 설계 20분 + 구현 30분 + 연결 15분으로 잡아도 된다.
