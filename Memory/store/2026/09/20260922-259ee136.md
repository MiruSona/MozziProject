2026-09-22 itch.io 에 올릴 WebGL v10 빌드를 굽고 zip 으로 묶었다. 결과 Succeeded · 322초 · 오류 0 · 경고 2.
왜 : 남에게 링크로 돌리려고 itch.io 로 정했다(20260922-d84efaaa). 기존 스크립트가 Brotli + Decompression Fallback + Default 템플릿이라 그대로 맞아 코드는 안 고쳤다.
무엇을 : eval_file --detach 로 빌드를 걸고 Editor.log 로 끝을 봤다. 파일은 data 4,229,286 · framework 76,650 · loader 110,344 · wasm 8,801,577 바이트, 합계 13,217,857(12.61MB). zip 은 Build/itch/ProjectMozzi-webgl-v10.zip 12,934,572 바이트, 뿌리에 index.html · Build/ · TemplateData/ 17항목. ProjectSettings 는 원복돼 git 이 깨끗했다.
못 한 것 : itch.io 에 올려 브라우저에서 돌려 보지는 않았다. MOZZI_DEBUG 정의가 들어 있어 D 버튼 디버그 패널이 뜬다.
다음에 : 같은 꼴(검사 없이 빌드 + zip)은 서브 7분 + 검토 3분으로 잡는다. itch 뷰포트는 405×765 쯤(캔버스 720 + 아래 띠 약 45px)으로 둔다.
