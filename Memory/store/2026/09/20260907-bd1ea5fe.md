왜 : 틀은 다음 게임에서도 쓰므로 툴 저장소가 정본이어야 한다. 게임 저장소에 두면 두 벌이 되어 어긋난다.
무엇 : 정본 281줄 — 게임 낱말·다른 툴 이름·개인 일정 표현을 빼고 확정 값은 기본값 표로. 게임 저장소는 확정 값·문서 뼈대·툴 결정·근거 조사만 68줄.
함정 : 게임 저장소 금칙어 목록에 두 툴 이름이 다 있어 서브모듈이 자기 이름으로 자기 README 를 못 커밋했다. public_guard.self 파일로 자기 이름을 뺀다.
다음 : GamedesignTool 1판(상태 파일·stage CLI·훅·상태 탭) → ProtoTool 1판. 기획 1~3단계(컨셉·기둥·코어 루프)는 사용자와 같이.
공수 : 문서 이동 18분 · 검사기 보강 8분 · 검토·커밋 15분
