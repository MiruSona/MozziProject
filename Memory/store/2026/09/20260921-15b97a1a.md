Get-Command 로 직접 확인했다 (2026-09-21). effort · stage · arttool · soundtool 은 PATH 에 안 잡힌다. mem 만 C:\Users\USER\.aimemory\bin\mem.exe 로, localharness 는 ~/.localharness/bin 으로 잡힌다.

개발환경.md 의 「effort 는 홈 아래에 깔려 PATH 에 있다」 는 틀린 글이었다. ~/.effort/ 에는 cache 와 rules 만 있다.

이제 Docs/Guide/개발환경.md 의 「툴 exe」 절에 어느 툴을 어느 경로로 부르는지 표로 적어 뒀다.
