왜 : PPU 32 로 넣은 140x64 그림은 그 자체로 4.375x2.0 유닛이다. 예전처럼 부모 scale 을 (4.375, 2.0) 으로 두면 그림이 두 배로 커진다.
무엇을 : Setup(kind, sprite, position) 으로 넓혔다. 그림이면 scale 1, sprite 가 null 이면 예전처럼 흰 네모를 늘려 동작을 보존한다. Label·Badge·BoxCollider2D 는 localW = w/scaleX 로 몸 크기를 local 단위로 바꿔 두 갈래가 같은 셈법으로 돈다.
이름표는 그림일 때만 LayoutConst.BuildingLabelBelowPx(23px = 0.72유닛) 만큼 내린다. 그림 아래 18px 이 이름 띠로 비어 있기 때문이다. 네모일 때는 예전처럼 한가운데다.
키는 데이터 표가 없어 SpriteKeys.BuildingSynthesis · BuildingStall 상수 둘로 뒀고 FarmViewManager 가 GetSprite 로 찾아 넘긴다.
다음 : 떡·손님·UI 틀도 같은 꼴(Manager 가 찾아 Setup 에 넘기기)로 넓히면 된다.
