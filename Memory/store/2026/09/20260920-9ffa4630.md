왜 : 09-20 WebGL 첫 빌드에서 UI 글씨가 하나도 안 보였다. Text 365개와 TextMesh 2개가 모두 내장 폰트(fileID 10102)를 썼고 에디터에서는 윈도우 폰트로 보여서 몰랐다.
무엇을 : TMP 로 옮겼다. 폰트 자산은 TmpFontBake.Bake() 로 굽는다 (Static 2048 · 샘플링 34 · 2484자 · 약 30초). 프리팹은 TmpConvert.ConvertAll() 로 바꿨다. 임시 폰트는 ONE Mobile POP 이고 이 폰트에는 en dash · em dash · bullet 글리프가 없다.
다음에 : 글씨가 든 기능은 에디터가 아니라 WebGL 빌드에서 확인한다. CreateFontAsset 으로 만든 자산은 fallbackFontAssetTable 이 null 이라 새 List 를 넣고 Add 한다. 긴 unity eval 은 try catch 와 Debug.LogError 로 감싼다. 5초 상한 뒤의 예외는 로그에 안 찍힌다.
