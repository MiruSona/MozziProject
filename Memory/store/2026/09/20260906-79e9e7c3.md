기획 9단계 루프를 한눈에 보는 웹 대시보드를 조사했다. 출처 35곳.

기성품(HacknPlan 무료~7.5유로, Machinations, Codecks, articy, Notion)은 정본 데이터가 저장소 밖 클라우드에 있어 AI 가 못 읽고 git 에 안 남는다. Obsidian+Dataview 가 가장 가깝지만 앱 설치와 플러그인 묶임이 걸린다. 기획 단계 자체를 상태로 다루는 제품은 못 찾았다.

그래서 만든다 : 상태는 Docs/Todo/기획상태.json 하나, 조절은 CLI(stage next/check), 보기는 stage dash 가 굽는 정적 HTML 한 장. 웹에서 눌러 고치는 것은 File System Access API 가 Firefox·Safari 에 없어 1판에서는 뺀다. 그리기는 순수 CSS + Mermaid stateDiagram-v2 로 충분하고 D3·Cytoscape 는 과하다. 화면은 6덩어리를 넘기지 않는다.

다음 : 기획절차 틀이 확정된 뒤 반나절 안에 만든다. 프로토타입 갤러리·수치 대시보드와 뼈대가 같아 툴 하나에 페이지 셋으로 합칠 수 있다.
