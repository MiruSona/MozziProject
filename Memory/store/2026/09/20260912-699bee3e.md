왜 : 하네스 툴이 git 밖 개인용(~/.localharness/)으로 바뀌었다. 툴 저장소에 두면 공개 반출과 서브모듈 두 번 커밋이 따라온다.

무엇을 : 이 저장소는 실행 파일(PATH 의 localharness)과 계정 스킬 localharness-usage 만 쓴다. Tools/ 서브모듈로 안 붙인다. 규칙은 두 겹 — 저장소에 .claude/local/rules.md 가 있으면 그걸 쓰고 없으면 홈 기본 규칙이다. .claude/local/ 은 .gitignore 에 넣었고 지금은 만들지 않았다 (홈 기본 규칙으로 시작).

다음에 : 하네스 판은 --bare 라 훅을 안 탄다. 판이 끝나면 메인 세션이 Tools/GamedesignTool/bin/stage.exe lint <고친 파일> 을 직접 돌려 종료 0 을 확인한다. Unity C# 규칙이 필요해지면 그때 .claude/local/rules.md 를 만든다.
