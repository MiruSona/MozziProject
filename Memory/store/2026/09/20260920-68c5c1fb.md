64 캔버스 안에서 몸(왕관 포함)은 45x39px 이고 사방에 여백이 있다.
LayoutConst 의 40/48/56px 을 캔버스 전체에 맞추면 몸이 28px 로 작아진다.
그래서 그림이 있을 때만 scale = size / (native * MozziBodyHeightPx / MozziCanvasPx) 로 나눈다.
실측 배율은 1단계 1.0256 · 2단계 1.2308 · 3단계 1.4359 다. 폴백(흰 네모) 경로는 예전 그대로다.
변종 테두리는 같은 divisor 를 되곱해야 몸 밖에 남는다.

## 덧붙임 2026-09-20

레이어로 나눈 뒤 몸 그림에서 왕관이 빠져 실제 몸이 작아졌다.
body_hop0.png 의 불투명 bbox 는 x 11~52 · y 16~50 으로 42x35px 이다 (왕관은 acc_crown 으로 따로 그린다).
그래서 LayoutConst.MozziBodyHeightPx 를 39 에서 35 로 바꿔 쓴다.
scale = size / (native * 35 / 64) 라 실측 배율은 1단계 1.143 · 2단계 1.371 · 3단계 1.600 이다.
흰 네모 폴백은 MozziSpriteSet.HasBody 가 false 일 때 divisor 1 로 예전 그대로 둔다.
