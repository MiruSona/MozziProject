왜 : AGENTS.md 10절은 「인스펙터에서만 알 수 있는 배선」 을 막는 것이지 프리팹을 막는 것이 아니다. UI 를 전부 코드로 만들면 모양 고치기가 힘들고, 프리팹에 배선을 두면 AI 가 못 본다. 그래서 둘을 나눴다.
무엇을 : 화면 프리팹은 Assets/_Project/Prefabs/UI/ 에 화면마다 하나. 프리팹은 모양(레이아웃 · 위치 · 크기 · 색 · 자식 이름)만 갖는다. Manager 참조 · UnityEvent 인스펙터 연결은 넣지 않는다. UiManager 가 ResourceService 로 빌려 Canvas 에 붙이고, UiNames 상수 한 곳의 자식 이름으로 찾아 버튼→Manager 호출 · 값 넣기를 코드로 배선한다. 프리팹은 Unity CLI(create_prefab 등)로 만든다. 씬에는 카메라 · EventSystem · InGameMaster 셋만, Manager 11 순서, Hub 직접 호출 / EventBus, JSON 은 Assets/_Project/Resources/Data/ + JsonUtility 는 옛 기억 그대로다.
다음에 : 소단계 1(CodeTool install.ps1 -Namespace Mozzi)부터 시작한다. 그림이 오면 프리팹의 스프라이트만 바꾼다.
