Unity 공식 CLI(unity 명령) 와 hatayama 의 Unity CLI Loop(uloop) 를 조사했다. 자세한 내용은 Docs/Research/2026-09-06-Unity조작CLI조사.md.

확인한 것 : 공식 CLI 는 이 컴퓨터에 이미 깔려 있고 로그인돼 있다. 프로젝트에 파이프라인 패키지도 이미 들어 있어 켜진 에디터와 연결이 된다 (editor_status 성공). 남은 것은 Claude Code 스킬 설치 한 줄이며 MCP 는 선택이다.
uloop 는 옛 uLoopMCP 가 이름을 바꾼 것으로, V3 부터 MCP 를 뺐고 CLI 와 스킬만 있다. Unity 2022.3 이상을 지원하니 Unity 6 도 된다. 아직 안 깔았다.
추천 : 공식 CLI 를 기본으로 쓰고, 핫리로드·일시정지점·플레이모드 입력 재생이 필요할 때 uloop 를 얹는다.
공수 : 예상 15분, 실제 약 30분 (문서 페이지 본문이 안 읽혀 --help 와 외부 글로 채우느라 늦었다).
