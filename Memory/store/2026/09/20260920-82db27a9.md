왜 : 사용자가 09-20 에 세로 조각이 색 네모뿐이라 사람이 하기엔 아무것도 없다고 했다. 아트 세션에 넘길 목록을 문서로 썼다.
무엇을 : 우선순위는 찹쌀이 일반 8장, 농장 바닥과 담장, 건물 2채, 재료 6, 떡 10, 손님, 떡메와 결과 상자, UI 틀 순이다. 스프라이트 훅은 찹쌀이 한 갈래에만 이어져 있다.
다음에 : 2번부터는 spriteKey 열과 Setup 의 sprite 인자를 먼저 넓힌다. 누가 할지는 미정이다. 같은 파일을 두 세션이 동시에 고치지 않는다.
