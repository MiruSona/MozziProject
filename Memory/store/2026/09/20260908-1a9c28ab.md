왜 : 아트 경험 없는 1인 개발이라 코드처럼 단계별 구조가 아트에도 있는지 알아야 PixelLab·ArtTool 준비를 시작할 수 있다.
무엇 : 표준 파이프라인 10단계를 방향(조사)·규칙(설계)·제작(작업) 세 단계로 줄여 제안했다. 규칙 단계 끝 기준은 흰찹쌀이 한 마리가 PixelLab→Aseprite→ArtTool→Unity 를 끝까지 통과하는 것. 24종은 베이스 12 + 팔레트 바꾸기 12. PixelLab MCP 는 원격 HTTP 서버이고 도구 이름·비용 눈금은 공식 문서에서 확인했다.
다음 : 사용자가 해상도·시점·크기·팔레트·외곽선·방향 수·애니 최소 등 11개 결정을 내린 뒤 06-아트규칙 문서와 ArtTool 프로필을 쓴다. 공수 : 웹조사·문서 약 20분.
