왜 : 사용자가 손님이 원하는 떡을 만들어 파는 테이크아웃 가게 안을 냈다. 초반 손 제작에 할 일이 생기고 못 찾은 떡 주문이 레시피 목표가 되어 기둥 2 에 맞는다. 그러나 시간 제한·별 5개 평가는 기둥 3(힐링) 과, 영업시간은 기둥 1(방치) 과 부딪힌다.
무엇을 : 부드러운 안을 02-기능목록 Should 에 한 줄(61) 로 넣고 「전부」 버튼(43) 을 여기에 합쳤다. 시간 제한·별점·영업시간은 Won't(62). 손님은 기다려 주고 줄은 몇 명까지, 없는 떡은 평범한 떡으로 값만 낮게, 맞는 떡은 골드 보너스, 가게는 늘 열려 있고 안 켠 동안은 자동 판매.
다음에 : 가판대 설계(⑥) 때 프로토 한 판으로 「손님 주문이 재미있나」 를 판정한다. 아직 안 재 본 것이라 Must 에는 안 올린다.
