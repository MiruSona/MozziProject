5단계 거친 프로토타입은 브라우저에서 바로 도는 HTML 한 파일로만 만든다. Unity 로 버릴 씬을 만드는 방식은 쓰지 않는다.
까닭은 둘이다. Unity 에디터가 하나뿐이라 프로토타입 여러 개를 동시에 못 만들고, 컴파일과 .meta 생성을 기다리는 시간이 길다. 한 판에 2~4개를 평일에 만들어 두는 방식과 맞지 않는다.
웹으로 답이 안 나는 물음 — 손맛, 연출, 화면 알아보기 — 은 프로토타입으로 만들지 않고 8단계 세로 조각에서 실제 화면으로 본다.
그래서 4단계 물음 표에 「웹으로 답이 나나」 칸을 두었다. 기본값은 예이고, 아니오면 8단계로 미룬다.
