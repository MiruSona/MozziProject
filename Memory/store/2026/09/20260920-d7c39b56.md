무엇이 문제인가 : SpriteRenderer 의 localScale 은 스프라이트 원래 크기에 곱해진다. 지금까지 쓰던 흰 네모(SpriteUtil.White)는 1유닛이라 scale 이 곧 유닛 크기였지만, 64px 그림을 PPU 32 로 넣으면 2유닛이라 같은 scale 을 주면 두 배로 커진다.

어떻게 풀었나 : MozziObject.Setup 이 native = sprite.bounds.size.y 를 구해 localScale = 목표유닛 / native 로 잡는다. 흰 네모는 native=1 이라 예전 동작 그대로다.

함정 : 변종 테두리 자식 Border 는 1×1 흰 네모라 부모 scale 에 그대로 곱해진다. 부모 scale 이 절반이 되면 테두리가 몸 안으로 들어가 안 보인다. SetupBorder 에서 ShinyBorderScale * native 로 되곱해야 한다.

다음에 볼 것 : Radius(충돌·배회 반지름)는 목표 크기 기준을 그대로 둔다 — 그림 크기가 아니라 게임 규칙 값이다. PileObject·BuildingObject 를 같은 방식으로 바꿀 때 이 셋을 똑같이 본다.
