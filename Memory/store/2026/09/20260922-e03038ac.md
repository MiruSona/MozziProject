왜 : 진열대가 글자 한 줄이라 쌓인 양이 안 보인다 (사용자 결정 20260922-ec7fcb9b).
무엇 : 칸 40×40·사이 3·8×3 을 ShelfText 자리(8,-60)에 두면 구역 126px. 머리글을 칸 위에 두면 아래가 ButtonStrip 을 2px 넘쳐 StatusText 끝에 붙였다. QueueCell 부터 ExpMakeButton 까지 86px 내리면 16px 남는다. unit 은 올림 (ShelfMax+5)/6 — 한 종류가 상한까지 차도 6칸 이하. 종류 11 최악은 11+floor((M-11)/unit) 로 30→14 · 120→16.
다음 : UiNames·LayoutConstUi 상수 → ShelfCellSetup(QueueCell 도 내림, ShelfCell_0 있으면 멱등) → ShelfCellView → StallScreen 배선. 코드는 아직 안 고쳤고 기획서 반영·버리기·상한 업그레이드는 뒤로.
