왜 : q3 프로토 2판에서 점원을 두고 5분 자리 비우기를 3번 했는데 팔린 떡이 9·9·19 로 그날 남은 손님 수(N 10→20)에 딱 묶였다. 밤이 되면 「다음날로」를 사람이 눌러야 해서 나머지 시간엔 한 명도 안 온다.
무엇 : 방치 게임이 되려면 점원이 밤을 넘기거나(자동 다음날) 방치 중 하루가 저절로 넘어가야 한다. 03-시스템-가판대.md 의 자리 비우기·점원 절에 넣을 것. 하루 N 강화가 곧 방치 수입 상한이라는 뜻이라 수치표 N 값도 이 눈으로 다시 본다.
다음 : 가판대 설계 고칠 때 자동 다음날 규칙(잠 → 아침) 을 정하고 q3 프로토에도 넣어 한 번 더 잰다.
