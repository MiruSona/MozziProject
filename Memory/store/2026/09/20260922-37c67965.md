팔은 어깨 바깥선에 딱 붙이고 아래로 2px 벌리며 끝에 손 덩어리(r=2.5)를 달았다. 길이 14 → 12, 폭 3 → 4.
다리는 틈 2 → 0, 길이 14 → 7 로 줄이고 둥근 발로 만들었다. 줄인 만큼 몸통을 y52 → y57 까지 내려 아랫도리가 둥글다. 발 사이는 가운데 한 줄만 어둡게(ramp[3]) 해 두 짝으로 읽히게 했다.
몸통 명암 겹을 4 → 2 로 줄였다. v2 는 4겹이라 가운데가 배 주름처럼 뭉쳤다. 머리는 26x25(1.04) 로 둥글게 하고 superellipse n 을 2.4 → 2.15 로 낮췄다 (2.4 는 식빵 모양으로 읽혔다).
몸 색은 속 색 하나에서 HSV 로 명도를 내리고 채도를 올려 5단을 만든다. 명도 배율은 찹쌀이 흰 5단에서 잰 값(1.0/0.882/0.783/0.717/0.654) 그대로다. 흰 손님은 찹쌀이(#FEFDFC)와 갈리게 크림흰(#F5F1E8)으로 띄웠다.
표정 시무룩은 눈 안쪽 끝 1px 을 올린다. 바깥을 올리면 화난 얼굴이 됐다.
