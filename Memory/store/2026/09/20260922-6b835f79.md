effort estimate 의 본줄 예상에 서브에이전트가 도는 시간을 5~10배로 따로 어림해 공수 표에 둘 다 적는다.
왜 : 2026-09-22 진열대 칸 판에서 예상 합 15분 대 본줄 실제 4분, 서브 참고 18분이었다. 본줄만 적으면 표가 안 맞는다.
1. `Tools/EffortTool/bin/effort.exe estimate 조사:M 구현:L …` 로 본줄 예상을 뽑는다.
2. 소단계마다 서브 참고값을 조사 4~7분 · 설계서 5분 · 구현+Play 실측 10분 눈금으로 어림해 「본줄 N분 · 서브 약 M분」 으로 적는다.
3. 끝나면 `effort scan` 뒤 `effort show <id>` 의 서브 칸으로 실제를 채운다. 세 판 더 맞으면 effort rules 반영을 제안한다.
