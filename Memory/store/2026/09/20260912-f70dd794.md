무엇을 : Docs/Guide/개발환경.md 「툴 exe」 절은 mem·effort·localharness 가 PATH 에 잡혀 있다고 적었는데, effort 만 실제로 안 잡힌다.

사용자 PATH 실측 (2026-09-12, [Environment]::GetEnvironmentVariable("Path","User")) :
- mem -> %USERPROFILE%\.aimemory\bin — 등록됨
- localharness -> %USERPROFILE%\.localharness\bin — **오늘 등록됨.** 문서가 맞다
- effort -> 등록 안 됨. EffortTool bin 이 사용자 PATH 에 없다

할 일은 effort 하나다. EffortTool bin 을 사용자 PATH 에 넣는다.

함정 (이번에 밟았다) : 돌고 있는 셸은 세션 시작 때의 PATH 를 물려받는다. 그래서 오늘 등록한 localharness 가 Get-Command 로는 '없음' 으로 보였다. 새로 등록한 PATH 를 확인할 때는 현재 셸의 Get-Command 를 믿지 말고 [Environment]::GetEnvironmentVariable("Path","User") 를 직접 읽거나 새 터미널에서 본다.

주의 : PATH 수정은 분류기가 막아 AI 가 못 한다. 사용자가 '! <명령>' 으로 직접 넣는다.
