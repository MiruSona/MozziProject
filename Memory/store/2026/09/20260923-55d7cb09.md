2026-09-22 itch.io 에 WebGL v10 이 올라가 비밀 링크로 공유가 됐다.
왜 : 세로 조각 판정을 남에게 시키려면 링크가 필요했다(20260922-d84efaaa).
무엇을 : 사용자가 itch.io 에 Build/itch/ProjectMozzi-webgl-v10.zip 을 HTML 프로젝트로 올려 브라우저에서 뜨는 것을 봤고, Visibility 를 Restricted 로 저장해 Secret URL 을 받았다. Secret URL 은 Restricted 로 저장한 뒤에만 Edit 화면 맨 아래에 나온다 — 대시보드에는 안 보인다.
다음에 : 새 판을 올릴 때는 같은 프로젝트의 Uploads 에서 zip 만 바꾼다. 링크는 그대로다. MOZZI_DEBUG 디버그 패널이 든 판이라 테스터에게 D 버튼 이야기를 해 두거나 다음 판에서 뺀다.
