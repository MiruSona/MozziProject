지금은 둘 다 확인용 임시다.
1) 왕관 : 확인용으로 전 종이 쓴다. 누가 왕관을 쓰나(대표 종만? 3단계만?)를 기획에서 정해야 한다. 왕관 자리 판정은 따로 대기 중이다 (20260920-f7a7af3b).
2) 표정 : 표정 10종은 사용자가 다 마음에 든다고 했고 「나중에 적용」이다. 지금은 확인용으로 찹쌀이 id 에 따라 랜덤하게 끼운다 — MozziArtKeys.DebugRandomFace = true. 언제 어떤 표정을 쓰나가 기획에서 정해지면 이 값을 false 로 끈다.
