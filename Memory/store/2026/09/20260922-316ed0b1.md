1. 쓴 도구는 create_image_pro_flash 하나다. width 48 · height 64 커스텀 크기(4의 배수)가 받아들여지고 한 장에 5 generations 만 든다 — create_1_direction_object(20~40회)보다 훨씬 싸다. 걸린 시간은 한 장에 35~156초이고 같이 띄우면 대기열에 밀려 늘어난다. 열 장 중 한 장이 서버 사정으로 실패해 같은 인자로 다시 돌리니 통했다.
2. 화풍을 묶는 길은 style_image 에 source_image_id 를 주는 것이다. 첫 판을 찹쌀이 그림(48×64 로 맞춘 것)으로 뽑고, 그 결과의 source_image_id 를 나머지 석 장의 style_image 로 되먹이니 몸 크기·외곽선·볼 위치가 거의 같게 나왔다. 참고 그림 없이 뽑은 것은 26~28px 로 작고 색이 탁했다 — 참고를 주는 쪽이 확실히 낫다.
3. 안 된 것 둘이다. 첫째, 방향을 못 고른다 — 글로 「왼쪽 3/4」 을 아무리 적어도 전부 정면(south)으로 나온다. 둘째, 색이 500개 넘게 나온다(±2 씩 흔들린 잡색). 미디언컷으로 14색으로 줄이면 볼 분홍과 눈이 통째로 사라지니, 가까운 색끼리만 묶는 방식으로 줄여야 원본 꼴이 남는다. 크기도 목표(동물 46·사람 44)보다 커서 50~59px 로 나오는데, 줄이면 1px 눈·입이 뭉개진다.
