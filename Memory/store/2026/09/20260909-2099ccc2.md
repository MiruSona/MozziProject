왜 : 베이스·템플릿·배경·UI 기반 이미지를 그려 줄 AI 와 오픈소스를 비교하려고 네 갈래(유료 AI 서비스 · 오픈소스·로컬 모델 · ArtTool 보충 · AI 조작 편집툴)로 웹조사했다.
무엇 : PixelLab 을 기준선으로 유지한다. 공식 MCP 문서에서 create_ui_asset·create_font·create_map_object·create_image_*·image_to_pixelart·correct_pixelart·reduce_colors 를 확인해 UI·배경도 PixelLab 으로 먼저 시험한다. 2차 후보는 SpriteCook(모든 요금제 API·MCP, 무료 40크레딧, 격자 미확인). UI 패널·지형 타일은 ArtTool 코드가 이미 하고, 아이콘·폰트는 CC0·OFL(물마루) 기성품, 캐릭터 베이스·배경 그림만 AI 몫이다. 손질은 Aseprite MCP(diivi, MIT, 툴 104개)로 AI 가 일부 대신할 수 있다. 값은 판정에 안 넣었다(사용자 : 유료 OK).
함정 : ArtTool 의 pixellab·local 제공자는 dry-run 이 아니면 예외를 던지는 껍데기다. 새 AI 를 고르기 전에 pixellab 실제 호출부터 붙여야 한다.
다음 : 사용자가 후보 8개(PixelLab 호출 붙이기 · 팔레트 변종 배치 · UI 를 CC0+프레임 생성기로 닫기 · SpriteCook 격자 확인 · Aseprite MCP 손질 시험 등) 중 고른다. 공수 : 웹조사 4갈래 + 문서 약 45분.
