20260920-ca7f4400 의 뒤집는 조건 가운데 크기 쪽은 이것으로 닫혔다.
남은 조건 : 타일 바닥이 들어올 때 다시 판단한다 — 밝은 바닥 위에서 배경과 붙어 보이는지는 아직 못 봤다. 그때 붙어 보이면 색 1px 외곽선으로 바꾼다.
곁들여 : 크기 기준은 캔버스가 아니라 몸 높이 35px 이다 (20260920-e069e6d8).
