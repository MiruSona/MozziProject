왜 : screenshot --view game 은 카메라만 그려 Screen Space Overlay 의 덮개 화면(가판대 등)이 통째로 안 보인다.
무엇을 : capture_game_view --source screen 이 합성된 게임 뷰(Overlay UI 포함)를 찍는다. 단 save_path 가 프로젝트 상대라 Assets/Temp/ 에 png 와 .meta 가 생긴다.
다음에 : 스크래치패드로 복사한 뒤 Assets/Temp 폴더와 Temp.meta 를 지운다. git status 에 Temp.meta 가 남으면 잊은 것이다.
덤 : eval 에서 InGameHub 는 Mozzi.Game 네임스페이스다(Mozzi.Hubs 아님). Play 중 화면을 새로 그리려면 IUiHub.CloseAll() 뒤 OpenStall() 이 가장 쉽다.
