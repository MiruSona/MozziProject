왜 : 어느 화면에서도 생산·합성·손님 시계가 돌아야 하고 Hub 는 하나여야 해서 씬을 나눌 이유가 없다. 인스펙터 배선 금지라 UI 연결은 어차피 코드에 있어야 하고 1판은 그림 없는 네모라 프리팹이 주는 것이 없다. Newtonsoft 는 패키지 추가라 승인이 필요해 JsonUtility 로 시작한다.
무엇을 : AI 제안(2026-09-18, 사용자 확인 전). 씬에는 카메라·EventSystem·InGameMaster 셋만. Manager 순서 StaticData→Save→Clock→Wallet→Inventory→Farm→Storage→Codex→Synthesis→Stall→Ui. 화면→Manager 는 Hub 직접 호출, Manager→화면은 EventBus. 오프라인 진행은 PostInit 에서 ClockManager.OfflineSeconds 를 읽어 각자 진행. 세이브는 persistentDataPath/save.json 한 파일. JSON 자리는 Resources.Load 제약으로 Assets/_Project/Resources/Data/.
다음에 : 사용자가 확인하면 promote 하고, 그림이 오면 UI 프리팹 전환을 2판에서 다시 본다.
