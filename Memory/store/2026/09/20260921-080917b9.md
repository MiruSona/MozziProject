확정(사용자 승인) : 떡 아이콘 11종(Recipe.json 10종 + plain_cake)은 32x32 픽셀아트 한 벌이다. 정본 스크립트는 Docs/Reference/Art/떡아이콘/draw_cake_v5.py, 그림은 setG_32/ 11장, 한눈에 보는 장은 final_cake_sheet.png 다.
구도 : 같은 크기 두 알(19x14). 뒤 알은 온전한 떡이고 밑칠을 한 톤 어둡게(그늘색) 깔아 앞뒤를 가른다. 앞 알은 세로로 갈라 자른 면이 정면을 본다 — 피 테두리 2px -> 떡살(명암 없음) -> 소 13x7. 앞 알은 가로 11 · 세로 4 어긋난 자리다.
재료 자리 : 팥·잣 = 소 / 쑥·대추 = 피 / 콩·깨 = 고물. 콩은 피 전체를 인절미 색으로 바꾼다.
색 : 장당 3~7색 · 알파 0/255 · 외곽선 없음 · 빛 왼쪽 위. 깨 #8A5A2C(어두운 피 위에서는 가로 2x1), 잣 소 #DEC27E + 크림 잣알 #F4EACC 셋.
마지막 손질 : 잣 소 위 아치 하이라이트 + 아래 점이 웃는 얼굴(식빵)로 보여 아치를 없애고 2x3 물방울 낱알 셋을 층계로 흩었다. 팥소 아치는 그대로 둔다 — 팥은 색 차가 커서 얼굴로 안 읽힌다.
