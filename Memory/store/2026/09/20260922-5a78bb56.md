왜 : 2026-09-22 손님 시안을 v1~v9 아홉 판 손으로 그렸다. 동물 방향(v7~v9)은 통과했지만 화질이 「뭉개진 찰흙」이었다. 뭉툭한 슈퍼타원 덩어리 + 한 단 명암이 PIL 로는 한계였다.
무엇 : 방향(동물 4종 · 왼쪽 3/4 · 40~50px)은 두고 도구를 PixelLab MCP 로 바꿔 시험한다. 사람 손님도 PixelLab 로 같이 한 번 더 뽑는다.
다음 : PixelLab 산출을 손그림 v9 와 나란히 놓고 사용자 판정. 눈금 : 손그림 시안 한 판은 서브에이전트 4~9분, 아홉 판 합계 약 50분이었다.
