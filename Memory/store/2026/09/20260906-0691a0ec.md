왜 : 웹 프로토타입 툴(ProtoTool)에 어떤 부품이 필요한지 가늠하려고 옛 농장 기획과 최근 합성 설계를 훑었다.

무엇을 : 게임 시스템 13개를 옛 기획 그대로/최근 고침/미정/빠짐 으로 나눈 표, 프로토타입으로 답할 물음 17개(판정 기준은 숫자·예/아니오), 프로토타입 종류 넷(숫자 경제 시뮬 · 시간 흐르는 방치 화면 · 확률 뽑기 시뮬 · 배치 격자), ProtoTool 부품 12개를 1판/2판/나중으로 나눈 표를 문서로 남겼다.

핵심 : 물음 17개 중 15개는 웹으로 답이 나고 둘(화면 알아보기·손맛)만 Unity 세로 조각으로 미룬다. ProtoTool 1판은 HTML 뼈대 한 장 · 틱 엔진과 빨리 감기 · 기록과 JSON 내보내기 · 목록 페이지 넷이면 되고 눈금은 5~9시간(의견)이다. 격자 캔버스 헬퍼는 값이 비싸고 물음이 둘뿐이라 뒤로 미뤘다.

다음에 : 기획절차 4단계에서 사용자가 물음 묶음을 확정한다. 첫 판 제안은 Q1(경제 고리가 닫히나) · Q2(합성 대기 5분이 지루한가) · Q3(3단계까지 평균 몇 번)이며, Q1 은 가판대 설계가 먼저 나와야 눈금이 잡힌다.
