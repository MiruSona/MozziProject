2026-09-20 사용자 결정. 왜 : 악세사리와 표정을 나중에 코드로 갈아 끼우려는 것이다. 종 색은 몸에만 곱하면 되니 12종이 그림 한 벌을 같이 쓴다.
자리 : ProjectMozziUnity/Assets/_Project/Resources/Art/Mozzi/ 한 폴더.
몸 body_hop0~3 (64x64 · 흰색으로 그린다 · 왕관·볼·표정을 안 넣는다) · 볼터치 cheek (11x11 한 장을 좌우로, 오른쪽은 코드가 flipX) · 표정 face_01~10 (64 캔버스에 표정 픽셀만) · 악세사리 acc_crown (64 캔버스에 왕관만).
임포트 값(PPU 32 · Point · 무압축 · Mip 끔 · pivot 가운데)은 에디터 스크립트 MozziArtImport 가 자동으로 건다.
프리팹 : 루트(콜라이더·SortingGroup) > Visual(Animator) > Body · 볼 앵커 L/R · 표정 앵커 · 악세 앵커. 앵커는 두 겹이다 — XxxAnchor 는 코드가 잡는 기준 자리, XxxOffset 은 애니 클립이 움직이는 자리.
새 종을 그릴 때 그리는 것은 몸 4장뿐이다. 새 표정은 face_11 처럼 번호를 잇고, 새 악세는 acc_<이름> 으로 넣는다.
