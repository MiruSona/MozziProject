사용자가 2026-09-21 에 다섯을 정했다.

1. 손님은 사람이고 모양은 단순하게 간다.
2. 찹쌀이처럼 겹을 나눈다 - 몸은 하나로 같고 헤어·모자·표정을 갈아 끼워 5종을 만든다.
3. 구도는 전신 서 있는 모습이다. 나중에 가판대를 카페 화면으로 바꿀 때 그대로 세우려는 것이다.
4. 참고 그림이 없어 웹 조사를 먼저 했다.
5. 크기는 크게 그려도 된다. 지금 손님 칸 66x56 에 맞출 필요가 없고 칸과 UI 를 그림에 맞춰 키운다.

캔버스·겹 구성·그리는 수단은 아직 안 정했다. 조사 문서 5~8절에 제안만 있다.
