MozziObject 루트에서 SpriteRenderer 를 떼고 Visual(Animator+MozziVisual) 자식이 그리게 배선했다.
WanderAgent.IsMoving 을 더해 걸을 때만 뜨고, sortingOrder 는 SortingGroup 에 MozziSortBase - y*32 로 넣는다.
MozziSpecies.json 24줄의 spriteKey 를 전부 Mozzi/body 로 바꿔 한 벌 그림을 종 색으로 물들인다.
실측 : 몸 bbox 42x35px · 뜀 높이 12px(유닛 0.375, 부모 배율만큼 커진다) · 뜀 0.35초 + 쉼 0.15초.
확인 : 콜라이더 어긋남 0 · 탭 빗나감 0 · 컨트롤러 한 벌 · 볼/표정/왕관 흰색 유지 · 풀 재사용 잔상 0 · 콘솔 경고 0.
남은 눈 : 왕관 그림이 64 캔버스 x42~55 로 오른쪽 위에 치우쳐 머리에 안 얹혀 보인다.
