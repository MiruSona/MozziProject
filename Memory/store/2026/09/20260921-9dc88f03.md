무엇을 정했나 : 떡 그림도 부재료 그림이 간 길을 그대로 탄다. Recipe.json 에 spriteKey("Cake/<id>") 를 넣고 RecipeRow 가 받아, IResourceHub.GetSprite 로 찾아 Image.sprite 에 꽂는다. 표에 줄이 없는 평범한 떡만 건물처럼 SpriteKeys.CakePlain 코드 상수다.

자리와 크기 : 원본 32px 의 배수로 잡았다. 레시피 도감 칸(172x98) 왼쪽 64px, 발견 연출 96px, 만들기 줄(170x27) 왼쪽 24px, 손님 주문 칸(66x56) 위쪽 32px.

폴백 : sprite 가 null 이면 Icon 을 꺼 두고 예전 글자가 그대로 나온다. 도감의 미발견 칸은 같은 그림을 Image.color #1E1E24 로 물들여 검은 실루엣으로 보여 준다 — 알파는 그림 것을 쓰므로 모양만 남는다.

글자 비키기 : 만들기 줄과 손님 칸은 TMP margin 으로 코드에서 민다(재료 토글과 같은 셈법). 도감 칸은 글자 셋의 rect 자체를 에디터 스크립트로 옮겼다(x 6→72, 폭 160→94).
