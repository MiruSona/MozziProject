왜 : B벌 1판을 눈으로 보니 고물 셋이 안 읽혔다.
무엇을 : 팥 세 알을 가깝게 놓으니 덩어리 하나로 뭉갰다 — 2px 넘게 떼고 알을 작게 잡아 고쳤다. 비슷한 잎 둘을 V 로 놓으니 체크 표시로 읽혀 쑥은 큰 잎 하나 + 잎맥 + 작은 조각으로 바꿨다. 잣은 크림색이라 흰 몸 위에서 사라져 밑색을 그늘색으로 내리고 갈색 꼭지를 키웠다.
또 : 장당 3~6색 규칙 때문에 고물에 하이라이트를 못 주는 자리가 생긴다 (쑥이 7색이 돼 잎 하이라이트를 뺐다). x1 에서는 팥·쑥·대추만 읽히고 깨·콩·잣은 점으로 보인다 — UI 는 x2 이상으로 쓴다.
