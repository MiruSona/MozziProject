왜 : 툴은 툴킷 저장소에서 따로 만들고 게임 저장소는 가져다 쓰기만 한다. 그래야 툴 고침이 게임 이력에 섞이지 않는다.

무엇을 : 툴 여섯(DiagramTool·ArtTool·SoundTool·CodeTool·EffortTool·AIMemoryTool)을 Tools 아래 git 서브모듈로 붙였다. Unity 프로젝트는 ProjectMozziUnity 폴더 하나에만 두고, gitignore 의 Unity 규칙도 그 접두어를 붙였다. 규칙 문서 AGENTS.md·CLAUDE.md 와 스킬 셋(doc-writing·mem-usage·report-format)은 툴킷 저장소 것을 게임 저장소 관점으로 다시 썼다. mem scope 는 game·design·art·sound·code 다섯으로 정했다.

다음에 : 사용자가 Unity 를 깔고 ProjectMozziUnity 를 만들면 CodeTool 구조 템플릿을 적용한다. 툴 개선 요청은 이 저장소가 아니라 그 툴 저장소 Docs/Todo 에 적는다.
