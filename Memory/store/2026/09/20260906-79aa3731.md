기획을 돕는 툴을 둘로 나눈다. ProtoTool 은 프로토타입 뼈대·틱·기록·목록을 주고 저장소는 officina-game-prototype-tool 이다. GamedesignTool(소문자 d) 은 단계 관문 CLI 와 대시보드를 주고 저장소는 officina-game-design-tool 이다.
둘 다 툴킷 쪽 저장소로 따로 만들어 이 게임 저장소의 Tools/ 아래 git 서브모듈로 붙인다.
툴 코드에는 게임 낱말을 넣지 않는다. 찹쌀이·합성소 같은 이름이 툴에 들어가면 다음 게임에서 못 쓴다.
프로토타입 파일과 단계 상태 파일은 게임 저장소에 남는다. 툴은 만들고 읽기만 한다.
만드는 차례는 GamedesignTool 관문+상태 탭(반나절) → ProtoTool 1판(5~9시간) → 대시보드 밸런스 탭(8단계에서) 이다.
