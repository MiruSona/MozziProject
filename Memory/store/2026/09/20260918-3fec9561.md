왜 : 8단계 산출물이 「게임 속 하루 한 번」 세로 조각이라 범위를 한 바퀴로 못 박아야 한다. 하루의 뜻이 코어루프(접속 3~4번)와 가판대(열기→밤→다음날)로 둘이라 뒤쪽으로 잡았다.
무엇을 : 넣는 것 = 농장·합성소·가판대 화면, 도감 둘, 번식·짝 구매·합성 칸·영구 단축, 점원, 오프라인 진행 계산, 농장 20마리 화면. 빼는 것 = 수수가루·늪·변종 특제, 2·3개 레시피 10칸, 찜기, N 강화, 진열 상한 업그레이드, 튜토리얼, 소리. 부재료는 프로토대로 6종(팥·콩·쑥·깨·잣·대추). 사용자 2026-09-18 결정.
다음에 : 세로 조각 설계 문서와 03-시스템-농장.md 를 이 범위로 쓴다. 판정은 사용자가 직접 + Q16·Q17·발견 연출 예/아니오.
