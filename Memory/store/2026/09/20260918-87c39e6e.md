왜 : 09-13 에 그림 갈래·시점·AI 비중을 가결한 뒤 남은 규격을 비교판(폰 시뮬·외곽선×명암 9종·빛 3종)과 레퍼런스 판을 보고 정하기로 했다. 에셋이 아직 없어 뒤집는 값이 0 이라 지금 정했다.
무엇 : 2026-09-18 사용자가 답했다 — 기준 해상도 360×640(같은 폰을 ×3 으로 채움) · 찹쌀이 48(타일 한 칸 반, PixelLab 기본) · 타일 32(PPU 32) · 외곽선 없음 + 명암 평면 · 빛 왼쪽 위. AI 는 찹쌀이 64 초안을 48 로 권했고 사용자가 48 로 바꿨다. 외곽선 없음·평면은 밝은 바닥에서 배경과 붙어 보일 수 있다고 짚었지만 사용자가 그대로 가결했다.
남은 것 : 팔레트 · 방향 수 · 애니 최소는 계열 수·이동·동작이 기획에서 아직 늘고 있어 기획 뒤로 미룬 상태 그대로다. 찹쌀이 원본 색값 확인(todo 20260909-ddb748e2)이 팔레트 앞에 있다.
뒤집는 조건 : B 단계 첫 한 마리(흰찹쌀이)를 360×640 폰 시뮬 위 밝은 바닥에 놓았을 때 배경과 붙어 보이면 외곽선을 색 1px 로 바꾼다. 찹쌀이 48 이 세로 화면에 여러 마리 놓아도 좁지 않은지 그때 같이 본다.
다음에 : B 단계 — Docs/Design/06-아트규칙.md · 팔레트 JSON · ArtTool 프로필(canvas.frame 48 · tiles.size 32). PixelLab 토큰·Aseprite·ArtTool venv 는 사용자 준비다.
