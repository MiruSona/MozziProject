왜 : 2026-09-21 에 건물 2채 그림만 넣고 배선은 손대지 않기로 사용자가 정했다. 같은 파일을 두 세션이 동시에 고치면 안 되기 때문이다.
무엇을 : 넘긴 것은 다섯이다. ① 프리팹 자식 Label 을 건물 정중앙에서 아래 18px 띠 가운데(중심에서 아래로 0.72유닛)로 내린다. ② SpriteKeys 에 건물 상수 둘을 더한다. ③ BuildingObject.Setup 이 색 네모 대신 sprite 를 받게 하고 localScale 을 1로 돌린다. ④ Badge 자리 계산이 스케일에 묶여 있으니 ③ 과 같이 고친다. ⑤ BoxCollider2D 도 스케일에 업혀 있어 size 를 직접 4.375×2.0 으로 준다. 자세한 까닭은 그림요청목록의 「3번 — 건물 2채」 절에 있다.
다음에 : 배선 세션이 이 다섯을 끝내면 건물이 네모 대신 그림으로 뜬다. 끝나면 이 할 일을 done 으로 닫는다.
