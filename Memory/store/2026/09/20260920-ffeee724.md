설계 2·3절대로 LayoutConst 에 칸 수·시드·층 정렬을 넣고 FarmBottomPx 를 552 로 내렸다. FarmViewManager 는 painter 인터페이스만 안다.
그림이 아직 없어 바닥은 흰 네모+풀색 폴백으로 깔리고 담장 칸은 건너뛴다. 캡처로 바닥이 136~552 를 채우고 찹쌀이가 담장 안쪽 범위에서 도는 것을 봤다.
칸 종류 셈은 에디터에서 재서 위 10·아래 10·옆 22·모서리 4·안쪽 110 으로 설계와 같았고, TileFlags.None 을 준 Tile 에 SetTransformMatrix 가 m00=-1 로 먹는 것도 확인했다.
