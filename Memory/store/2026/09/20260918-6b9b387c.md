왜 : Git Bash(MSYS) 는 슬래시로 시작하는 인자를 Windows 경로로 고쳐 넘긴다. hierarchyPath 가 /이름 꼴이라 그대로 걸린다.
무엇 : export MSYS_NO_PATHCONV=1 뒤에 unity command 를 치면 그대로 간다. PowerShell 도구에서는 안 일어난다.
다음 : find_gameobjects 는 DontDestroyOnLoad 씬을 안 본다. 거기 있는 것은 eval 로 GameObject.Find 해서 확인한다.
