capture_game_view --width/--height 는 저장 크기만 정하고 카메라 aspect 는 Game 뷰 창을 따른다.
Free Aspect 가로 창에서는 aspect 1.78 로 찍혀 농장이 화면 가운데 3분의 1만 차지한다.
UnityEditor.GameViewSizes 에 고정 360x640 을 넣고 GameView.SizeSelectionCallback 으로 고르면 aspect 0.5625 가 된다.
Game 뷰 크기는 에디터 공용 설정이라 다른 세션과 같이 쓰면 끝낸 뒤 원래대로 되돌린다.
