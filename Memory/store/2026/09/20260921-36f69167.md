왜 : 3판(20260921-9acfa073)을 본 사용자가 「뒤에 온전한 알, 오른쪽 앞에 45도 돌린 반쪽」 구도를 냈다. 「45도」가 두 가지로 읽혀 둘 다 그렸다 — setE_tilt(화면 안에서 기울임)와 setF_turn(세로축으로 돌린 3/4 시점).
기울기 각도 : 시계 40도로 재 보니 뒤 알과 이어져 하나의 긴 초승달로 보였다. 여섯 각도를 견줘 140도로 정했다 — 잘린 면이 왼쪽 위를 보고 덩어리가 동글게 뭉친다. 겹치는 자리도 셋을 재 13.4 로 정했다(12.8 은 두 덩이가 한 덩어리로 붙는다).
3판 약점 셋을 같이 고쳤다 : 깨를 거의 검은 갈색(#4A3520)으로 내려 쑥 피 위에서도 보이게 했고, 흰 피 그늘을 #D8C9B2 에서 #C9BCA6 으로 내리고 그늘 폭을 아래로 한 칸 넓혔고, 잣 소를 #EFE2BE 에서 #E8D49A 로 노릇하게 했다.
다음 : 사용자가 compare_cake_v3.png 로 구도를 고르면 Resources 에 넣고 배선한다. 재료 자리 규칙과 11종 id 는 3판 그대로다.
