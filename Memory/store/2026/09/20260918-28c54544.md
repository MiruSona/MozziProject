왜 : 에디터 정지 때 파괴 순서가 Manager 보다 앞서서 Return 의 Component == null 검사에 걸린다.
무엇을 : Rent 한 Object 를 들고 있는 Manager 는 Dispose 에서 Unity 의 == null 로 살아 있는지 본 뒤에만 Return 한다 (FarmViewManager.ReturnIfAlive).
다음에 : 4·5단계 화면 Manager 도 같은 꼴로 쓴다. 3a 순수 C# Manager 는 해당 없다.
