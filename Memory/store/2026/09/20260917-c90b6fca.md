왜 : 1판(2026-09-17)에서 재료 합계 60 상한이라 팥만 쌓여 다른 재료가 못 들어와 아무것도 못 만들었다. 진열대에 팥떡만 쌓여 막혔고 상한 업그레이드도 없었다.
무엇 : 재료 상한을 합계 60 에서 종마다 60 으로 (코어루프 2판의 재료별 상한 결정을 합계로 잘못 옮겼던 것). 진열대 한 줄 버리기·전체 비우기 버튼 (골드 안 돌려줌, 버린 수는 기록 JSON 버린떡). 진열 상한 30→50→80→120, 값 200·500·1200 (임시), 설비 상점에서 buyN 과 같은 꼴로 산다.
다음 : 고친 판으로 순서 2~5 를 이어 논다. 진열 상한 값과 단계는 판정 뒤 수치표에 옮길지 정한다.
