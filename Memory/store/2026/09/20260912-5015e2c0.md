무엇을 : 게임 저장소 .claude/hooks/public_guard.words 의 옛 이름 GateTool 을 LocalHarnessTool 로 바꿨다. 소문자 localharness 는 넣지 않는다.

왜 : public_guard.py 의 낱말 검사는 'word in line.lower()' — 대소문자를 안 가리는 그냥 부분 문자열이고 낱말 경계가 없다. 목록에 localharness 를 넣으면 CLAUDE.md 에 정당하게 적힌 localharness 명령·localharness-usage 스킬 이름까지 다 걸린다(5줄). 반대로 LocalHarnessTool(소문자화 localharnesstool)은 localharness·localharness-usage 안에 부분 문자열로 들어가지 않아 안전하다.

확인 : 툴 저장소 안에서 --all 실행 — GamedesignTool·ProtoTool 둘 다 종료 0. localharness 문장만 있는 파일 통과(0), LocalHarnessTool 있는 파일 차단(2), 옛 이름 GateTool 은 이제 안 걸림(0).

주의 : 이 검사기는 Tools/<툴>/ 공개 저장소 안에서 도는 것이다(그 저장소의 .githooks/pre-commit 과 PreToolUse 훅). 게임 저장소 루트에서 돌리면 게임 낱말이 다 걸려 방향이 거꾸로다.
