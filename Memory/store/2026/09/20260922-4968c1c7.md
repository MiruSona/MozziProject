그림 작업은 레퍼런스 조사 → PIL 프로토타입 → 사용자 확인 → PixelLab 베이스 → PIL 겹 나누기 → 필요하면 ArtTool 순서로 간다 (사용자 결정 2026-09-22).
왜 : 09-21~22 에 PIL 프로토 없이 바로 그리면 시안이 8~9판 갔고, PixelLab 결과는 겹으로 갈라야 배선이 쉬웠다 (손님 겹 넷, Docs/Reference/Art/손님/pixellab/layers/bake_palette.py).
무엇 : ① 레퍼런스 조사(분위기 한 줄, 없으면 웹) ② PIL 프로토타입 두 벌 ③ 사용자 확인 ④ PixelLab 베이스 ⑤ PIL 로 겹 나누기·팔레트 미리 굽기 ⑥ 필요하면 ArtTool 로 불리기(normalize·check·bake). Aseprite 는 필수가 아니다.
다음 : Docs/Design/06-아트규칙.md 파이프라인 절을 이 순서로 고치고 Tools/ArtTool/Docs/Todo 에 피드백을 남긴다. 찹쌀이 몸·손님 머리 추가는 이 순서로 간다.
