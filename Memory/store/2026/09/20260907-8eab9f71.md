2026-09-07 게임 저장소 연결 때 밟았다.
파이썬으로 settings.json 과 기획절차.md 를 고치면서 Windows 경로를 일반 문자열로 적어 '\bin' 의 앞 두 글자가 백스페이스 제어문자가 됐다. 파일에서 bin 이 두 자리 사라졌다.
다음에는 raw 문자열이나 슬래시 경로를 쓰고, 고친 뒤 grep -P '[\x00-\x08]' 로 제어문자를 한 번 훑는다.
