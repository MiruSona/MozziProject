왜 : AI 가 03-시스템-농장.md 에 「바닥 기준」 을 제안했으나, 사용자가 세로 조각 설계를 확인하며 프로토 q3 와 같은 창고 기준으로 정했다. 창고가 찬 종은 떡을 만들어 재료를 써야 다시 도니 가판대와 농장이 한 고리로 묶인다.
무엇을 : 주워 온 부재료가 종마다 창고 100 에서 멈춘다. 창고가 100 인 종은 생산이 멈춘다. 바닥 더미는 상한이 없고 주우면 창고로 들어가되 창고가 100 이면 100 에서 잘린다. 오프라인 생산분도 바닥 더미로 쌓이고 주울 때 잘린다. 옛 기억 146879a8 의 나머지 제안(더미 탭 줍기 · 번식 농장 직행 · 보관함 상한 없음 · 오프라인 1초 걸음)은 그대로다.
다음에 : 세로 조각 판정 뒤 「안 주우면 바닥에 쌓이기만 한다」 가 문제면 더미 표시 상한을 둘지 본다.
