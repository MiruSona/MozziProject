무엇 : JsonUtility 용 { rows: [] } 꼴 + 제네릭 DataTableJson<T> 로 읽었고 잘 읽힌다. 모든 표에 문자열 id 를 뒀다(SynthesisRule tier1 · Growth slot2/shortcut1/pair1 · Stall/Farm default). 변종 24행 대신 12행(isShiny 전부 false). 부재료는 팥콩쑥 1단계(10) · 깨잣대추 2단계(30).
