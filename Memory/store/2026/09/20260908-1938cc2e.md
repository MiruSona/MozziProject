무엇 : q1-1 프로토를 복사해 2판 프로토(Prototypes/2026-09-08-q2-골드고리2판) 소단계 1~3 을 만들었다. 합성소 칸 1~4(s.synth 가 칸 배열, buySlot) · 영구 단축 5단계(s.speedLevel, buySpeed, 새 합성부터 적용) · 변종 15%. 기록에 칸 구매·단축 구매·합성·짝 구매 골드와 2칸 이상 동시 가동 게임 초를 더했다.
확인 : script 둘 node --check 통과. 봇(씨앗 5개·게임 30분·60분)에서 안 죽었다. 30분 봇은 남은÷번 골드 10~19%(1판 40%), 2칸 이상 비율 0~20%, 60분은 58%.
남은 것 : 소단계 4 짝 구매 2단계(150·750) · 5 자동 판정 표 7개 · 6 봇 실측. REC.pending 과 buildRecord() 에 자리를 남겼다. 브라우저 화면은 직접 안 열어 봤다.
공수 : 예상 70분 · 실제 약 25분 (뼈대가 있어 복사·확장이 빨랐다).
