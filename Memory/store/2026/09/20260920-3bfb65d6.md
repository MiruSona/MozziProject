무엇을 정했나 : 스프라이트도 프리팹과 똑같은 짜임으로 넣는다. ISpriteSource 가 가져오는 곳을 가리고, ResourcesSpriteSource 가 Resources.Load<Sprite>(SpriteKeys.Root + key) 를 부른다. SpriteKeys.Root 는 "Art/" 라 표의 spriteKey "Mozzi/grass1" 이 Resources/Art/Mozzi/grass1 이 된다.

프리팹과 다른 점 : 프리팹은 없으면 예외지만 스프라이트는 아직 안 그린 종이 있는 것이 정상이라 null 을 준다. ResourceService.GetSprite 가 Dictionary<string, Sprite> 로 캐시하는데 null 결과도 담아 매번 다시 찾지 않게 하고, 못 찾았다는 경고도 키마다 한 번만 뜬다. Dispose 에서 캐시를 비운다.

배선 자리 : 그림을 찾는 것은 FarmViewManager 몫이고 MozziObject 는 Setup 인자로 받아쓰기만 한다. 규칙 그대로 흐름 배선은 Manager 에 둔다.

그림이 없을 때 : sprite 가 null 이면 예전처럼 SpriteUtil.White + 종 colorHex 로 그린다. grass1 흰색 특례도 그대로 남겼다 — 그림 로드가 실패해 네모로 떨어질 때 흰찹쌀이 색을 지킨다.
