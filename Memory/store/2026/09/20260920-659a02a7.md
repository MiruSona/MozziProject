unity command eval_file 에 준 .cs 는 PipelineEval_xxxx.Execute() 의 몸통이 된다.
파일 맨 위에 using 을 적거나 class 를 선언하면 'Identifier expected' 로 깨진다.
System.Reflection.BindingFlags 처럼 전부 풀이름으로 쓰고 마지막에 return 한 줄을 둔다.
