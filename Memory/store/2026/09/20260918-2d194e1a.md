SynthesisScreen.OnStart 가 필드 _needs 를 돌며 storage.TakeFromFarm 을 불렀다.
TakeFromFarm 이 MozziRemovedEvent 를 내고, UiManager 가 받아 Refresh → HasEnough → CollectNeeds 가 _needs 를 Clear 해 'Collection was modified' 가 났다.
EventBus 는 동기라 버튼 처리 도중에 같은 화면의 Refresh 가 끼어든다. 화면에서 순회할 컬렉션은 필드로 재사용하지 말고 호출마다 새 List 로 만든다.
Manager 를 부르는 줄 앞에서 순회를 끝내는 것도 방법이다.
