왜 : 범위 결정이 기획서의 2·3개 레시피 10칸(조합 미정)을 뺐는데 1개짜리만 두면 손님 힌트 주문과 떡메 발견 연출을 볼 조합이 없다. 부재료는 6종으로 정해졌는데 늪을 뺀 종은 9종이라 하나씩 못 준다.
무엇을 : AI 제안(2026-09-18, 사용자 확인 전). 레시피는 q3 프로토 임시 조합(1개 6·2개 3·3개 1). 재료 짝은 1단계 셋→팥·콩·쑥, 2단계 셋→깨·잣·대추, 3단계는 같은 계열 2단계 재료. 늪 6칸은 도감에 ??? 로만 보인다.
다음에 : 사용자가 아니라고 하면 2단계까지만 넣는다. 판정 뒤 가판대 문서의 10칸 조합을 정할 때 다시 본다.
