아티팩트를 새로 만들면 로딩 고침이 사라진다. 그래서 2026-09-20 에 폰에서 통한 v10 페이지를 저장소에 떠 뒀다.
자리는 ProjectMozziUnity/WebGLArtifact/ 다. Assets 밖이라 Unity 재임포트를 안 건드린다.

새 빌드를 올릴 때 손 흐름이다.

1. 빌드를 내고 Build/WebGL/Build/ 의 네 파일을 확인한다.
2. 페이지의 BASE 한 줄에서 판 번호를 올린다. 주소 다섯 곳이 여기를 따라간다.
3. PARTS 의 크기 세 값과 TOTAL 을 새 파일 크기로 고친다. 진행 표시에만 쓴다.
4. 세 바이너리를 .wasm 이름으로, contentType 을 application/wasm 으로 올린다.

Brotli 와 decompressionFallback 은 한 짝이다. 아티팩트가 Content-Encoding 을 안 주니 폴백을 끄면 깨진 파일로 실패한다.
왜 이런 페이지가 필요한지와 건드리면 안 되는 것은 같은 폴더 README.md 에 적었다. 실측 내력은 20260920-f5fe6235, 올리는 손 흐름은 20260920-39d7aa99 다.
