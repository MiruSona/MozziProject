Tools\setup.ps1 을 새로 넣었다. 인자 없이 부르면 Tools\*\ 를 돌며 setup.ps1 이 있으면 그것을, 없으면 build.ps1 을 인자 없이 부른다. CodeTool 은 이름으로 건너뛴다 (install.ps1 은 템플릿 복사용이라 부르면 안 된다). 하나가 실패해도 나머지는 계속하고 끝에 표를 찍고 종료 1 이다.

-Check 는 아무것도 안 만들고 낡은 것만 표로 찍으며 언제나 종료 0 이다 (세션 시작 훅에 걸 것이라 세션을 막으면 안 된다). 실측 0.29초.

수정 시각으로 견주는 까닭 : git checkout 은 바뀐 파일만 새 시각으로 쓰므로 서브모듈 갱신이 곧 「소스가 exe 보다 새것」 으로 잡히고, 문서만 고친 커밋에는 안 울린다.

전역 mem 교체만은 스크립트가 못 한다 — 사용자가 Tools\AIMemoryTool\build.ps1 -Install 을 직접 돌려야 한다.
