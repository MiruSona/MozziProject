왜 : 담장 20마리가 차면 보관함 「농장에 놓기」가 꺼지고 번식도 멈춰 새 찹쌀이를 농장에 못 놓았다.
무엇 : 보관함 화면에 「담장 늘리기 {값}G」 버튼. 값은 합성 칸 확장 값을 그대로 빌린 임시값이다. rate 는 더해지는 마리 수(누적)라 FenceMax = 20 + rate(level).
무엇 : 농장 찹쌀이를 탭하면 팝업(종 이름 · 보관함으로 · 닫기). 「보관함으로」 는 IStorageHub.TakeFromFarm.
정한 것 : 짝 구매는 코드대로 보관함으로 들어온다 — 문서의 「농장에 바로」 를 코드에 맞춰 고쳤다 (코드가 정본 · 사용자 09-23).
다음 : 세로 조각 판정 뒤 담장 값과 번식 속도 업그레이드를 정한다.
