왜 : PowerShell 5.1 이 네이티브 exe 에 넘길 때 안쪽 큰따옴표를 지워 --code 뒤가 여러 인자로 갈라진다.
무엇을 : 검증 C# 은 스크래치패드에 파일로 쓰고 unity command eval_file --file <경로> 로 돌린다. 반환값은 result 필드에 문자열로 온다.
다음에 : 정지 뒤 콘솔은 unity command console --format json 을 정규식으로 걸러 Manager 로그만 뽑는다.
