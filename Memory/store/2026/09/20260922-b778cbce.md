2026-09-22 itch.io 용 WebGL zip 을 Compress-Archive 로 만들었더니 항목 이름이 역슬래시였다.
왜 : Windows PowerShell 5.1 의 Compress-Archive 와 .NET Framework 의 ZipFile.CreateFromDirectory 는 알려진 문제로 구분자를 역슬래시로 쓴다. Linux 쪽 서버는 그것을 한 파일 이름으로 본다.
무엇을 : System.IO.Compression.ZipArchive 를 열어 CreateEntryFromFile 에 슬래시 경로를 직접 주는 스크립트로 다시 만들었다. python zipfile 로 항목 목록을 찍어 역슬래시 0 · testzip None 을 봤다.
다음에 : 웹에 올릴 zip 은 Compress-Archive 를 쓰지 말고 ZipArchive 직접 쓰기나 python zipfile 로 만든다. 만든 뒤 항목 목록에 역슬래시가 없는지 본다.
