2026-09-07 사용자가 팬카페(cafe.naver.com/chabii) 공지를 직접 읽었다. 2차 창작·팬게임 규정은 없었고, 있는 것은 카페 글을 외부로 공유하지 말라는 것 하나뿐이다.
결정 : 무료 팬게임을 만들고, 만드는 과정과 게임 공유는 카페 안에서 한다. 문제가 생기면 사용자가 감수한다.
기존 방침 유지 : 상업 이용 안 함, 공식 그림 안 쓰고 새로 그림. 표기 문구는 정해진 게 없어 「고차비 님 팬게임입니다」 식으로 우리가 붙인다 (안, 확정 아님).
카페 글은 민감해 보여 캡처를 저장소에 넣지 않았다.
