저장소 뿌리에서 UNITY_NO_BANNER=1 unity skill install claude-code --local --yes --non-interactive 를 돌려 .claude/skills/unity-cli/ (SKILL.md, SECURITY.md, CHANGELOG.md, references/ 8개) 가 생겼다.
unity status · unity command editor_status --json · unity command eval 세 개 모두 ready 상태의 에디터(6000.3.23f1, 포트 7800)에 붙는 것을 확인했다.
스킬 폴더 안에 사용자 홈 경로나 실제 토큰은 없다 (grep 결과는 전부 토큰 플래그 설명 문서).
.claude/settings.local.json 에 permissions.allow 로 Bash(unity *) 를 넣었다 (gitignore 대상). 공수: 예상 5분, 실제 약 4분.
