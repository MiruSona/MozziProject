왜 : 반복 02 에서 합성소 배경 6장 중 정면은 1장뿐이었고 병이 계속 나왔다.
1. create_image_pixflux 360x400, view=side, lineless, basic shading. 글머리에 flat 2D side-scroller game background, flat elevation of one back wall only, no side walls, no ceiling, no perspective 를 넣는다.
2. 후보 3장을 한꺼번에 걸고 wait_for_jobs 로 기다린 뒤 눈으로 고른다.
3. 빼고 싶은 소품(병 등)이 남으면 inpaint_image 에 download URL 과 사각 마스크를 주고 넣을 것을 적는다 (약 40 generation).
4. PIL 로 위 120px 은 맨 윗줄 색, 아래 280px 은 바닥을 이어 360x800 을 만든다. 원본은 y 120~520 에 놓인다.
씨앗 : 가판대 2003, 합성소 3212, 합성 기계 1013.
다음에 : 차양처럼 벽 소품을 가리는 것은 글에 높이를 적어 처음부터 작게 뽑는다.
