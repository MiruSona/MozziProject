왜 : 전용 화면 시안은 270×480 을 ×2 해서 도트가 2px 이고 메인 화면은 1px 이라 두 굵기가 섞였다. 사용자가 「1px로 일단 맞춰줘」 라고 했다 (2026-10-03).
무엇을 : 전용 화면(가판대 · 합성소 · 주방)의 정식 그림은 메인 화면과 같은 1px 도트로 그린다. 지금 v5 · v6 시안은 2px 그대로이고 구도 판정용이다.
다음에 : 정식 그림을 뽑을 때 540×960 캔버스 1px 굵기로 배경 · 손님 · 주인을 다시 뽑는다. 잔디 한 장 대 타일은 아직 대기다.
