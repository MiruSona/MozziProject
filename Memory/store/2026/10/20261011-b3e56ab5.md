왜 : 10-11 변천사 영상에서 HTML 프로토를 세로 540x1200 으로 녹화하려 resize_window 를 불렀더니 성공이라 했지만 창 크기가 그대로였다.
무엇을 : 페이지를 -90도 돌린 iframe 에 1.5배로 넣어 가로 화면을 다 쓰고, 찍은 뒤 영상에서 바로 세웠다.
다음에 : 녹화 전 window.innerWidth·innerHeight 를 읽어 실제 크기부터 확인한다. 첫 녹화는 해상도가 낮아 두 번 다시 찍었다.
