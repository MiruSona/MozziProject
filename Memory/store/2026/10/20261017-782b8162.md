증상 : 저장소를 C:\Mirusona 에서 D:\Project 로 옮긴 뒤, 저장소 뿌리에서 `unity projects info ProjectMozziUnity` 를 치면 옛 C: 경로에서 ProjectVersion.txt 를 못 찾는다며 실패했다. 셸 현재 폴더는 D: 였다.
원인 : CLI 는 이름 인자를 Hub 등록 목록에서 먼저 찾는다. 그 목록은 %APPDATA%\UnityHub\hub.db (SQLite, -wal 포함) 에 있고, 이미 D: 로 고친 projects-v1.json 과는 따로 옛 C: 항목을 쥐고 있었다.
고친 법 : `unity projects remove <옛 C: 경로> --force` 하고 `unity projects add <D: 절대 경로>`. hub.db 와 hub.db-wal 은 .bak-20261017 로 먼저 백업했다. 다른 항목은 건드리지 않았다. 그 뒤 상대 경로 info 가 D: 로 성공했다.
덤 : %APPDATA%\UnityHub\cli-skill-installs.json 의 basePath 도 아직 옛 C: 경로다 (손대지 않음).
