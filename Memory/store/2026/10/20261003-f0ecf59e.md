현상 : unity command simulate_pointer 나 InputSystem.QueueStateEvent 로 넣은 누름은 Pointer.press.isPressed 가 참인데도 wasPressedThisFrame 이 FarmViewManager.ReadTap 에서 거짓이었다 (실측 2026-10-03, 드래그 phase 가 None 그대로). 한 프레임에 입력 갱신이 두 번 돌면 '이번 프레임' 표시가 먼저 꺼지는 것으로 보인다.
처치 : ReadTap 이 _pressWasDown 과 isPressed 를 견줘 누름 가장자리를 직접 잡는다. 실제 마우스에서도 똑같이 동작한다.
시험 주의 : simulate_pointer 는 한 번 누르면 다음 프레임에 풀리는 펄스라 누른 채 끄는 드래그 시험에는 못 쓴다. eval 로 InputSystem.QueueStateEvent(Mouse.current, new MouseState{...}.WithButton(Left, true)) 를 몇 번 넣거나 BeginDrag·DragTo·EndDrag·OnFarmMozziDropped 를 직접 부른다.
또 : capture_game_view 는 Assets/Temp 에 떨어지니 끝나면 지운다.
