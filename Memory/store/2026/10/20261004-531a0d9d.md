1. 메인 화면 기계 png(135×144)를 pro_flash style_image 에 크기 그대로 넣는다 (캔버스보다 작으면 가운데에 놓인다).
2. 캔버스 224×240 · no_background=true · 「The exact same … machine as the style image, redrawn bigger … at rest」 로 부탁한다. 9회.
3. 그림 칸만 잘라 쓴다 (177×194 · 29색 · 바탕 투명으로 옴). 보기 : Docs/Reference/Art/정식/합성소/build_synthesis.py (2026-10-04).
