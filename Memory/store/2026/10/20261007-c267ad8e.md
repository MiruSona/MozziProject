떡메를 손 자리(자루 끝) 둘레로 돌릴 때 들기 장은 PIL rotate 각도를 음수(-16/-32/-42)로 줘야 머리가 손보다 위에 온다.
양수로 주면 손이 머리 위로 가서 머리가 처져 보인다 (pound14 첫 판에서 밟음).
절구를 뒷벽/앞 테두리로 가를 때 반죽 밑은 구멍 아래 끝(y435)보다 5~11px 아래에 둬야 앞 테두리가 반죽 밑을 가려 안 떠 보인다.
다음 정식 배선 때 숫자는 pound14 README 의 장별 표를 그대로 읽는다.
