결론 : 캔버스 배율과 카메라를 ScreenFitUtil 한 자리에서 안전 영역 기준 360×640 내용 칸에 맞춘다 (반복 02 피드백 7).
까닭 : 높이 맞춤(match 1)이라 9:20 폰에서 캔버스 가로가 288 로 줄어 UI 양옆이 잘렸다.
규칙 : CanvasScaler 는 ConstantPixelSize 로 두고 scaleFactor = min(안전폭/360, 안전높이/640). 화면 프리팹은 Canvas 밑 ContentRoot(안전 영역 안 360 폭, 가운데)에 붙인다. 팝업의 어두운 막만 Canvas 에 바로 붙어 화면 끝까지 덮는다.
월드 : UiToWorldPx 1.5 는 어느 비율에서도 같다. 카메라 orthographicSize 는 이제 고정 15 가 아니라 FarmViewManager.FitCamera 가 화면마다 계산하고, 월드 위끝을 내용 칸 위끝에 붙인다. 길쭉한 폰에서 남는 세로는 농장 아래 풀밭 줄(FarmFillRowsBelow 24)로 채우고, 넓적한 화면은 양옆이 카메라 배경색이다.
띠 : 자원바·아래 띠는 FarmScreen.ExtendBar 가 뒤판(배경색)과 덧띠(띠 색)를 코드로 붙여 안전 영역 밖까지 잇는다 (BarBleedLength 200).
시험 : 에디터에서 ScreenFitUtil.EditorSafeInsetPx 로 카메라 구멍을 흉내 낸다. 1080×1920 · 2340 · 2400 · 1536×2048 넷을 Play 모드로 봤다.
