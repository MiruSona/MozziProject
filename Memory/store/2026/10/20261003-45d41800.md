왜 : 반복 01 피드백 10 (공통 서비스 코드 미리 파악) 의 조사 결과다. 코드는 안 썼다.
무엇을 : GameMaster/GlobalHub 서비스 층, InGameMaster/InGameHub Manager 층, ResourceService 풀, EventBus, SaveManager, StaticDataManager, DebugPanel 은 이미 돌아간다. AudioService·VfxManager·세이브 칸별 version migration·CutsceneManager 가 없다.
WebGL 제약 : 소리는 첫 탭 뒤에만, AudioMixer 는 볼륨만, Streaming 불가, VFX Graph 불가, Addressables 는 비동기만. 외부 패키지 후보는 PrimeTween 과 DataTool 둘뿐이고 지금은 안 쓴다.
다음 : 컷씬은 Timeline 대신 단계 JSON + 코드 실행기 권장. 만드는 순서는 세이브 판 올리기 → 소리 → VFX → 입력 잠금 → 컷씬. 갈림길 6개는 문서 5절.
