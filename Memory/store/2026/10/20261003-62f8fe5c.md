전용 화면 둘은 실내이고 사람을 크게, 건물과 기계는 단순하게 그린다 (사용자, 2026-10-03).
확정 : 작은 주인 = v11 3번(72×88) · 잔디와 울타리 = 가 벌(256 풀밭 + 통나무 울타리).
전용 화면은 270×480 으로 짜서 ×2 한다. 한 화면의 도트 굵기를 하나로 맞추려는 것이다.
가판대 v3 는 계산대 안쪽에서 손님을 마주 본다. 맨 앞 손님은 새로 뽑은 큰 그림(78×146)이고 주인은 10차 A(128×160)다. 손님 크기 안은 메인 세션이 임시로 고른 것이다.
건물 단순화는 pro_flash 의 detail 을 끄고 뽑았다. 가게 80색 → 38색, 기계 71색 → 28색. 메인 v5 의 후보 1 둘은 임시로 고른 것이다.
