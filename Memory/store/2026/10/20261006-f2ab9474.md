사용자가 2026-10-06 에 구성 시안 3안 견줌판(Docs/Reference/Art/시안/반복09-v1/00_견줌판.png)을 보고 1안 현대 카페 주방을 골랐다.
왜 : 지금 기구(전통 나무 · 무쇠 솥 풍)가 새 배경과 안 어울린다. 있는 기구 그림을 조리대 위에 늘어놓는 식이 아니라 피자 가게 운영 게임 주방처럼 작업 상황에 맞게 다 다시 그려야 한다고 했다.
무엇을 : 분위기 = 1안(흰 타일 벽 · 윗벽장 · 선반 · 밝은 조리대). 기구 = 전부 새로. 앞선 결정 20261006-efb3d4ac 의 「지금 기구 그림을 그대로 올린다」는 이 결정으로 바뀐다.
다음에 : 장면 구조안 2~3개(화면 고정 / 단계마다 넘어감 등)를 조사해 사용자가 고른 뒤, 배경 정식 → 그 배경을 스타일 참고로 기구 시안 → 고르기 → 정식 → 배선 순서로 간다.
