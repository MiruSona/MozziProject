왜 : 확정한 주인 10차 A 는 128x160 이라 손님 64x80 의 두 배였고, 그냥 절반으로 줄이면 얼굴이 뭉개졌다.
1. 큰 그림을 PIL 최근접으로 줄인다 (0.5배 64x80, 0.55배 72x88, 0.625배 80x100). 캔버스는 4의 배수다.
2. 줄인 그림을 image_base64 로 넣고 edit_image_pro_flash method=text 에 blurry down-scaled sprite, redraw as clean crisp pixel art 로 시작하는 글을 준다. 한 장 5~6회다.
3. 손님 비율에 꼭 맞추려면 바탕을 손님 그림으로, 참고를 줄인 주인으로 한 method=reference 편집을 쓴다. 얼굴은 덜 닮는다.
4. create_image_pro_flash 는 80x96 을 시켜도 캐릭터가 47x77 로 와서 큰 판을 못 만든다.
5. 볼 다이아는 2x2 덩어리로 오거나 빠져서 PIL 로 FA6270 더하기 꼴 5픽셀을 찍었다.
다음 : 사용자가 후보(추천 3번 72x88)를 고르면 Idle 을 만든다. 프롬프트 전문은 시안 README 의 가판대 주인 v11 소절.
