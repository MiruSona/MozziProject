왜 : 사용자가 처음 판을 「거의 근접, 꽉 채우면 좋겠다」고 했고 섞임 3장은 「너무 공처럼 보인다」고 버렸다.
무엇 : 60x60 겹 셋(a·b 회색 255·220·180 곱하기용, top 외곽선 #3A2E25 + 흰 반짝이) 8프레임 그대로, 창 원 안 빈 칸 0. 다시 뽑은 판은 구슬처럼 보일 수 있어 정본에서 뺐다. 앞 기억 20261005-cfedd962 의 「섞임 3장」은 이제 안 쓴다.
다음에 : 사용자가 다시 뽑은 판을 고르면 build_swirl.py 의 CANON 을 regen 으로 바꿔 돌린다. 검사는 mozzi_prop 프로필(mozzi_fx 는 흰 1색 한도라 실패).
