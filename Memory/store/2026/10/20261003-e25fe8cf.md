원본 : ProjectMozziUnity/GameData/schema.json + 표 7장(farm growth ingredient mozzi_species recipe stall synthesis_rule). 표·열 이름은 소문자 밑줄, 값은 옛 JSON 과 451칸 같음을 에디터에서 대조했다.
구운 파일 : Assets/_Project/Resources/Data/gamedata.bytes (MessagePack). StreamingAssets 는 안드로이드·WebGL 에서 File 로 못 읽어 안 쓴다.
생성 코드 : Assets/_Project/Scripts/Data/Generated (네임스페이스·asmdef Mozzi.Data). Mozzi.Runtime 과 Mozzi.Editor asmdef 가 Mozzi.Data 를 참조한다.
DataTable<TRow> 는 얇은 어댑터로 남겨 _data.Species.Get(id) 꼴을 지켰고, 행 필드는 PascalCase 속성(row.Tier)으로 바뀌었다. Recipe.IngredientIds 는 string[] 이다.
굽기는 Unity 메뉴 Mozzi/Data/Validate+Export+Gen 이 한다.
