왜 : 10-11 변천사 영상에서 옛 판 v9 를 크롬으로 녹화하려 했는데 빌드 폴더에 띄울 index.html 이 없었다.
무엇을 : v10 zip 의 index.html 을 가져오고 code.wasm 을 WebGL.wasm.unityweb 식으로 v10 이름에 맞춰 바꿨더니 떴다.
다음에 : 옛 WebGL 판을 다시 띄울 때는 바로 다음 판의 템플릿과 파일 이름부터 견준다.
