사용자가 2026-10-03 반복 03 에서 정한 그림 기준이다 (그림풍 레퍼런스 조사 7절의 1·6·7번 답).
- 기준 해상도 : 540×960 하나. 지금은 농장 540×960 · UI/가판대 360×640 두 굵기가 섞여 있다. UI 캔버스도 540 으로 올린다.
- UI 재질 : 종이 + 나무 계열.
- 글꼴 : 둥근 글꼴. 안 어울리면 픽셀 글꼴. 게임이 쓰는 ONEMobilePOP.ttf 가 둥근 글꼴이라 목업은 그것으로 얹었다.
- 화풍 중심 : 순검정 아닌 어두운 색 외곽선 1px · 명암 3단 · 낮은 채도 · 안티에일리어싱 없음 (같은 갈래의 탑다운 생활 게임을 자로 삼음).
- 메인 화면 배치는 아직 안 정했다 — 「가」(한 화면 고정)를 생각 중이고 가·나 시안을 보고 고른다.
- 아트규칙 문서(06)의 360×640 · 「외곽선 없음 기본」은 아직 안 고쳤다. 배치가 정해지면 같이 고친다.
