왜 : 지금은 바닥 재료에 상한이 없어 수량이 150만까지 불어났다 (반복 06 판정 ①). 사용자가 반복 07 을 시작하며 값을 정했다.
무엇을 : 더미 하나의 수량 상한은 5개다. 바닥 전체 합계 상한은 50개이고 닿으면 찹쌀이가 더 떨구지 않는다. 농장 업글로 갯수를 늘리거나 회수기가 회수하면 다시 떨군다.
