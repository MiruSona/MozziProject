왜 : 사용자의 메인 시험기가 폰이다. 컨셉의 기기도 처음부터 PC 와 안드로이드 둘이었고, WebGL 은 링크로 돌리려고 쓰던 임시 길이었다.
무엇을 : WebGL 빌드와 zip 을 그만둔다. 반복 판은 Build/itch/ProjectMozzi-android-vNN.apk 로 낸다(IL2CPP · ARM64 · 세로 고정). Windows 빌드는 나중에 만든다.
다음에 : itch.io 에 올리는 것 자체는 그대로다 — 올리는 것이 WebGL zip 에서 APK 로 바뀌었다. 사용자가 올리거나 폰에 직접 옮겨 설치한다. 옛 결정(웹 빌드는 itch.io zip)은 이 결정이 덮는다.
조사 문서의 WebGL 제약 절은 참고용이 됐다. 소리·VFX 설계는 PC·안드로이드 기준으로 다시 본다.
