1. 세이브 폴더(LocalLow/DefaultCompany/ProjectMozziUnity)를 스크래치에 백업한다.
2. unity open 뒤 unity status 가 ready 가 될 때까지 기다린다 (실측 44초).
3. Bash 에서 eval 로 SetGameViewSize · TouchSaveTime · Arm 을 차례로 부른다.
4. capture_log.txt 가 생기면 끝이다 (840장 26초 · 실제 33fps). Play 는 저절로 꺼진다.
5. 세이브를 되돌리고 EditorApplication.Exit(0) 로 닫는다. 데모 드라이버는 v17 전용이라 옛 판에는 VideoCapture.cs 만 복사한다.
