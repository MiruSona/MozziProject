왜 : 가판대에도 차림표 판이 생겨 화면마다 안쪽 판을 닫는 길이 필요했다. UiManager 가 화면별 판을 알면 배선이 퍼진다.
무엇을 : OverlayScreen 에 virtual bool CloseInner() => false 를 두고 UiManager.CloseTop 이 먼저 부른다. 차림표 판은 RecipeMenuView(순수 C#) 하나를 가판대·주방이 같이 쓰고 자식 이름은 KitchenMenu* UiNames 를 그대로 쓴다. IUiHub.OpenKitchenMenu 는 지웠다.
다음에 : 다른 화면에 안쪽 판이 생기면 CloseInner 를 덮어쓴다. 판 프리팹은 FormalUiBuild.MakeRecipeMenuPanel(root, boxTop) 으로 만든다.
