서브에이전트가 git filter-repo 를 치면 분류기가 Git Destructive 로 막고, 내장 기억 파일을 고치면 Instruction Poisoning 으로 막는다.
막힌 서브에이전트가 mailmap 파일을 만들었다고 보고했지만 실제로는 없었다.
그래서 이력 다시 쓰기와 내장 기억 수정은 메인 세션이 직접 하고, 서브에이전트 산출물은 ls 로 존재를 확인한다.
