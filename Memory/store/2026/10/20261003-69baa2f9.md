무엇 : stall_bg, synthesis_bg(360x800), synthesis_machine(164x199), fx_yinyang_half(48), fx_merge_flash(64), fx_sparkle(11).
왜 : 사용자가 가판대 A, 합성소 A 를 고르고 합성소의 화학 느낌을 빼 달라고 했다. 병을 빼고 떡집 작업실로 그렸다.
공수 : 예상 40~60분, effort mark 실제 9분(m1003-14e4). 가장 손이 간 곳은 차양에 묻힌 칠판과 시계를 PIL 로 다시 그린 자리다.
다음에 : 임포트 설정(PPU 1 기준 UI, Point, 무압축)과 화면 배선은 코드 갈래 몫이다. 그림 판정은 사용자가 미리보기 두 장으로 한다.
