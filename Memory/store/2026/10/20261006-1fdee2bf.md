사용자가 시안 v2~v5 견줌판을 보고 번호로 골랐다 (2026-10-06).
구조 : B — 칸1 준비(재료 선반 + 쟁반 + 믹서기) / 칸2 치기(흰 돌 절구 크게) / 칸3 마무리(대리석 빚기 판 + 전기 찜기 + 벽 결과 자리). 버튼 줄과 돈 표시는 고정.
재료 선반 : S1 — 6x3 = 18병, 화살표로 넘김 (찹쌀이 24종 이상 대비).
갈기 G1 믹서기 · 치기 P3 흰 돌 절구 + 나무 떡메 · 찌기 T1 전기 찜기 · 천장 W2 원근 널 + 몰딩 (C2 는 바닥처럼 보여 버림).
정식 때 고칠 것 : 도트 굵기 1배 통일 · 보는 각도 통일 · 천장은 곧게 선 판(칸 경계 꺾임 없게) · W2 가 어두우니 등이 묻히지 않게.
