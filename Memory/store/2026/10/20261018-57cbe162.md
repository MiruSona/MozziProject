저장소가 2026-10-18 공개 GitHub 로 바뀌어 개인정보가 새면 되돌리기 어렵다.
commit-prep 가드는 꼴이 있는 것(토큰·홈 경로·메일·공인 IP)만 자동으로 잡고, 꼴이 없는 개인 식별자(계정 이름·SSH 별칭·기기 이름·본명)는 git 밖 목록 ~/.claude/private.words 나 .claude/local/private.words 에 적어야 잡는다.
문서·보고·커밋 메시지에는 저장소 상대 경로만 쓰고 스크래치패드 전체 경로를 적지 않는다. 서브에이전트 프롬프트에도 이 규칙을 넣는다.
큰 정리 뒤에는 /prep all 로 추적 파일 전부를 한 번 훑는다. 10-18 기준 남은 거짓 경보는 조사 문서의 버전 글 1건뿐이다.
