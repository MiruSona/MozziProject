메인 화면은 v3 배치로 가고 잔디·울타리만 건물 화풍으로 새로 그린다. 가판대·합성소는 건물을 누르면 넘어가는 전용 화면이다 (사용자, 2026-10-03).
왜 : 잔디와 울타리가 건물·캐릭터·주인과 화풍이 달랐다. UI 로 다 처리하면 게임이 아니라 시뮬레이터 같다고 했다.
무엇을 : 합성 칸 수만큼 기계가 선다 (1~4대). 기능은 진열장·칠판·문패·바구니·절구 같은 화면 속 물건으로 옮긴다. 주인은 손님 크기로 새로 뽑는다.
다음에 : 시안은 Docs/Reference/Art/시안/ 의 메인화면-나-v4 · 가판대화면-v2 · 합성소화면-v2 다. 이때 미확정이던 잔디 벌(가)과 작은 주인 v11 3번은 같은 날 확정됐다 (20261003-62f8fe5c).
