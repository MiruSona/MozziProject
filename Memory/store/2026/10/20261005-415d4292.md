왜 : Stage 가 내용 칸 아래끝에 붙어 9:16 이면 위 240 줄이 안 보이는데, 가판대 판 위끝 96 은 고정값이라 위가 잘렸다. 화면 비율은 실행해야 알아 고정값으로는 못 맞춘다.
무엇을 : RecipeMenuView 생성자에 boxTop(가판대 96 · 주방 596)을 받고, Open 때 화면 뿌리 rect.height 로 보이는 위끝을 구해 Box 의 anchoredPosition.y 를 고친다. 여백은 KitchenLayout.MenuVisibleMargin=8. 9:16 가판대는 위끝 248 · 아래끝 704 로 진열장을 조금 덮는다(닫으면 보인다). 주방은 596 그대로다.
다음에 : 판 크기를 바꾸면 Box 높이를 rect 에서 읽으니 따로 고칠 것은 없다.
