왜 : 2026-10-18 사용자가 이 저장소를 공개 GitHub 저장소(MiruSona/MozziProject)로 옮기기로 했다. 09-07 의 「만드는 과정과 게임 공유는 팬카페 안에서」 결정과 정면으로 부딪혀 덮는다.
무엇을 : 무료·비상업·새 그림 방침은 그대로다. 대신 원작 원본(아바타 캡처·카페 색표 캡처·공식 이모티콘 시트)과 카페 설정표를 옮겨 적은 신상 부분, 출처·라이선스가 불확실한 남의 그림 61장, ONE 모바일 POP 원본 사본 2개를 저장소에서 뺐다. 색값 표는 남겼다.
다음에 : 새 참고 그림을 넣을 때는 라이선스가 CC0·CC-BY 처럼 재배포가 되는 것만 넣고, 원작·카페 자료는 로컬(gitignore)에만 둔다. 이력 정리(filter-repo)는 따로 한다.
