왜 : 홈으로 나간 뒤 OS 가 앱을 안 죽이면 Unity 가 deltaTime 을 0.33초로 잘라 몇 시간이 0.33초가 됐다.
그 뒤 30초 자동 저장이 savedAtUtcTicks 를 덮어 그 시간은 영영 사라졌다.
무엇을 : GameRunner.SetBackground 가 뒤로 갈 때 UTC 틱과 Update 로 돈 초를 적어 둔다.
돌아올 때 실제 흐른 초에서 돈 초를 뺀 값을 AppForegroundEvent 로 낸다 (PC 는 포커스 잃어도 돌 수 있어 두 번 안 세려고).
Farm·Synthesis·Stall 은 PostInit 에서 구독해 Skip 하고 UiManager 는 30초 이상이면 부팅 때와 같은 오프라인 팝업을 띄운다.
확인 : EditMode 시험으로 농장 번식 따라잡기만 봤다. 기기에서는 안 봤다.
