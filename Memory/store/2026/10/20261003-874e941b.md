결론 : save.json 의 version 이 판 번호이고 지금 CurrentVersion 은 2 다. 꼴을 바꾸면 판을 올리고 단계 클래스 하나를 SaveMigrator.CreateSteps 에 더한다.
판 번호 : version 글자가 없는 옛 파일은 1판으로 읽는다. 1→2 는 설정 구역(settings · 볼륨 둘)만 생겼고 진행 칸은 그대로다 (SaveMigrationV1ToV2).
읽을 때 : 옛 판이면 save.json.bak 한 장을 남기고 한 판씩 올린다. 깨졌거나 이 앱보다 새 판이면 save.json.unreadable.bak 로 남기고 새 게임이다.
단계 : ISaveMigration(FromVersion · Apply). 단계가 SaveFile.FindEntry 로 자기 칸 JSON 만 고치면 된다.
앱 판과 세이브 판(1·2)은 다른 숫자다.
확인 : 1판·version 없음·2판·99판·0판·깨진 것·빈 파일·없음 여덟 경우를 eval 로 돌려 봤다 (2026-10-03).
