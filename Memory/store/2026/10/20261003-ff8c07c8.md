왜 : DOTween Pro 를 git 저장소에 넣을 수 없어 대체 트윈 라이브러리의 라이선스 원문을 직접 열어 보았다.
무엇을 : LitMotion 은 MIT 라 공개 저장소에 소스·git 참조 모두 된다. PrimeTween 은 자체 라이선스로 NPM 설치일 때만 공개 저장소에 쓸 수 있다. DOTween 무료판은 고치지 않은 원본만 재배포된다. DOTween Pro 는 사람마다 라이선스가 필요해 못 넣는다.
다음에 : 권장은 LitMotion v2.0.2 git 주소 설치, 차선은 DOTween 무료판이다. 우리 배속은 GameMaster.TimeScale 자체 값이라 수동 tick(ManualMotionDispatcher)이 필요하다. 안드로이드 IL2CPP 실행은 아직 안 돌려 봤다.
