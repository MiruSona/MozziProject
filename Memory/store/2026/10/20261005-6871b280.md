capture_game_view save_path 는 프로젝트 뿌리 밖이면 거절되니 Assets/Temp 에 받고 옮긴 뒤 폴더를 지운다.
증상 : Docs/ 아래 전체 경로를 주면 'is outside the project root' 로 실패하고 콘솔 오류 1건이 남는다.
피하기 : Assets/Temp/<이름>.png 로 받고 mv 로 옮긴다. 그러면 Unity 가 만든 .meta 만 남아 장마다 경고 1건이 쌓인다.
끝에 Assets/Temp 폴더와 Temp.meta 를 지우고 AssetDatabase.Refresh 뒤 clear_console 하면 경고 0 으로 돌아온다.
