왜 : 저장소가 공개되어 PC·안드로이드 빌드를 GitHub Release 로 돌리기 시작했다. 판 번호가 파일 이름·태그·Release 제목에 같이 쓰인다.
무엇을 : 프로토타입→알파→베타→정식처럼 단계가 바뀔 때만 첫자리를 올린다. 안드로이드 versionCode 는 정수라 따로 1씩 올린다 (v17 APK 다음은 18).
다음에 : 어느 자리를 올릴지 묻지 말고 갱신 크기로 고른다. 애매하면 0.0.1.
