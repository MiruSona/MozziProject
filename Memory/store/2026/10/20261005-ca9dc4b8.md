왜 : editor_pause 중에는 Game 뷰가 다시 안 그려져 capture_game_view 가 멈추기 전 화면을 그대로 준다. RepaintAllViews 도 안 듣는다.
무엇을 : 연출 프레임을 찍을 때는 일시정지하지 말고 VfxManager._ui 디스패처를 새것으로 바꿔 끼워 멈춘 뒤 원래 것을 Update(dt) 로 손수 돌린다. 농장은 GameMaster.TimeScale=0 으로 멈추고 FarmViewManager.Process(dt) 를 부른다.
다음에 : TimeScale 0 이면 FarmScreen 재료 칸 bump 처럼 게임 시간으로 도는 UI 도 멈춰 커진 채 찍힌다 — 버그로 착각하지 않는다.
