왜 : 2026-10-03 에 최종 플랫폼을 PC + 안드로이드로 정하고 WebGL 을 뺐다. v12 는 APK 만 돌린다.
무엇을 : unity command eval_file 로 Mozzi.Editor.AndroidBuild.SwitchPlatform(); 을 부르고 전환 뒤 Build(); 를 --detach 로 부른다.
설정은 스크립트가 넣는다 — 패키지 com.mirusona.projectmozzi · 판 12 · 최소 API 25 · 디버그 키 서명 · MOZZI_DEBUG 는 빌드 때만 켠다.
잰 값 : 플랫폼 전환 1분쯤 · 빌드 404초 · apk 39,981,030 바이트. aapt 로 패키지·versionCode 12·arm64-v8a 를 확인했다.
다음에 : 판을 올릴 때는 Version 상수만 고친다. 실제 폰 실행은 아직 안 봤다.
