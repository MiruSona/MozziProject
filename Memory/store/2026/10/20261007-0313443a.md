왜: 사용자 피드백 — 넘침이 흰 귀 두 개처럼 가만히 붙어 있어 역동적이지 않았다.
무엇: build_pound15.py 의 splash_spill 이 1·2단계 5장 터짐(덩어리+방울 6개+머리 둘레 조각), 6장 내려옴(처짐, 방울 작아짐), 7장 벽 타고 흘러내림, t12 0·1장 잔방울을 그린다. 2단계는 0.6배·방울 절반, 3단계·쉼 장은 없음.
옛 규칙(절구 윤곽 안만, 5·6장만)은 이걸로 덮는다. 숫자는 README 넘침 규칙 표.
다음: Unity 캡처로 크림 벽 위 방울이 보이는지 사용자 판단을 받는다.
