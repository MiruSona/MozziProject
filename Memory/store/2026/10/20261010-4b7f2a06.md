1. mem review --kind held,retired,expired,gone,conflict,contradict,merge,value --ids --all 로 큐·규칙별 건수를 파일에 남긴다.
2. mem gc --retired 로 미리 보고, 전부 superseded_by 가 달린 것이면 mem gc --retired --apply 로 접는다. 첫 정리 때 39건을 접었다. 되돌리기는 mem gc --restore.
3. gone 의 dead-path 는 git log 로 옮김·지움을 보고 옮겼으면 새 경로, 지웠으면 commit:<마지막 sha> 로 머리말 sources 를 고친다. mem set 에는 --sources 가 없다.
4. 덮음은 mem set <옛id> --by <새id> 뒤 꼭 mem index 를 친다. 큐에만 들어가고 파일에 안 붙은 적이 있다.
5. 접은 뒤 lint 오류가 접힌 본문 탓에 늘고 contradict 에 접힌 기억이 남는다. 툴 피드백 문서에 적었다. conflict·contradict 큐는 오탐이 많아 손검사만 한다.
