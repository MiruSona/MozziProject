1. UI 입력 : 화면 안 Button 을 이름(UiNames)으로 찾아 onClick.Invoke() 한다. 뒤로는 IUiHub.CloseTop(). 팝업(Offline · Mozzi)은 CloseAll 로 안 닫히니 제 버튼을 누른다.
2. 농장 입력 : (FarmViewManager)InGameHub.Get<IFarmViewHub>() 로 꺼내 TapAtWorld · SweepFloor · OnFarmMozziDropped 를 부른다. 끌기는 MozziObject.BeginDrag → DragTo → OnFarmMozziDropped 이다. 보관함 꺼내기는 BeginPlaceDrag 뒤 _drag 의 Clear 를 부르고 OnPlaceGhostDropped 를 부른다.
3. 시간 : 떡메 연타처럼 실제 초를 보는 판정은 eval 한 번 안에서 System.Threading.Thread.Sleep(ms) 를 끼워 잰다.
4. 파일 : 한국어 경로가 든 .cs · .ps1 은 UTF-8 BOM 으로 저장한다 (PS 5.1). eval_file 인수는 --file 이다.
