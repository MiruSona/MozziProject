왜 : 10-11 변천사 영상용 HTML 프로토 녹화에서 클릭 뒤 바뀐 화면이 gif 에서 빠질 수 있었다.
까닭 : gif_creator 는 도구 동작(클릭·스크린샷 같은 것)이 일어날 때만 프레임을 잡는다. 동작 없이 흐르는 화면은 안 담긴다.
다음에 : 녹화가 끝나면 gif 를 열어 클릭 뒤 화면이 들어 있는지부터 본다.
