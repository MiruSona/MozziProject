화면 연출은 IVfxHub.Ui 스케줄러에 걸고, 게임 진행에 묶인 연출만 IVfxHub.Game 에 건다.
왜 : 디버그 배속(GameMaster.TimeScale)이나 멈춤에 UI 연출이 같이 빨라지거나 멈추면 손맛을 못 본다. 대기 시간 같은 진행은 게임 시계 그대로다.
무엇을 : VfxManager.Process 가 Game 은 dt, Ui 는 Time.unscaledDeltaTime 으로 ManualMotionDispatcher.Update 를 부른다. 모션은 WithScheduler(vfx.Ui).Bind(상태, static 함수) 로 걸고 핸들은 CompositeMotionHandle 에 모아 화면 닫기·칸 바꾸기 때 Cancel 한다.
다음에 : 폰(IL2CPP·Burst)에서 LitMotion 이 도는지는 아직 못 봤다. APK 에서 합성 시작 연출이 도는지 본다.
