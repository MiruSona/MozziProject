왜 : Artifact 15MB · Chrome file_upload 10MB · SendUserFile 30MiB 라 셋 다 막힌다. OneDrive 「링크 복사」 는 계정 기본 권한이 「특정 사용자」 라 남에게 「링크 없음」 으로 보였다(10-09). Google Drive MCP 와 Drive 데스크톱은 PC 앞에서 OAuth 동의가 한 번 필요하다.
1. AndroidBuild.cs 의 Version 을 올려 빌드한다 (Build/android/ProjectMozzi-android-vNN.apk).
2. Release 만들기는 공개 게시라 사용자가 직접 한다. AI 는 명령 한 줄을 준다 : gh release create apk-vNN Build/android/ProjectMozzi-android-vNN.apk --repo MiruSona/officina-game-prototype-tool --prerelease --title "ProjectMozzi 시험용 APK vNN" --notes "…" (Bash 에서 치니 경로는 슬래시).
3. 올라간 뒤 gh release view 와 curl -sIL 로 다운로드 링크가 로그인 없이 200 이고 바이트 수가 같은지 본다.
4. 링크 꼴 : https://github.com/MiruSona/officina-game-prototype-tool/releases/download/apk-vNN/ProjectMozzi-android-vNN.apk
다음에 : 툴 저장소와 관계없는 임시 자리다. 쌓이면 옛 Release 를 지우거나 전용 공개 저장소로 옮긴다.
