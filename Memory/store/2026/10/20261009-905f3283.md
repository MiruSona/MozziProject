왜 : Artifact 자산 15MB · Chrome file_upload 10MB · SendUserFile 30MiB 라 42MB APK 는 셋 다 막힌다. Chrome 확장은 PC 앞에서 아이콘을 눌러야 붙어 원격으론 못 쓴다.
1. OneDrive 앱을 켠다 : %LOCALAPPDATA%\Microsoft\OneDrive\OneDrive.exe /background
2. APK 를 %USERPROFILE%\OneDrive\테스트apk\ 에 복사한다. 10초 안에 파일 속성에 ReparsePoint 가 붙으면 올라간 것이다.
3. PowerShell 에서 Shell.Application 의 NameSpace(폴더).ParseName(파일).Verbs() 중 이름이 「링크 복사」 인 것을 DoIt() 한다.
4. 6초쯤 뒤 Get-Clipboard -Raw 로 1drv.ms 링크를 읽는다.
다음에 : 남이 열리는지는 curl 로 못 본다(onedrive.live.com 이 403). 사용자가 폰에서 확인한다. Google Drive 로 바로 넣으려면 Drive 데스크톱이 필요하다.
