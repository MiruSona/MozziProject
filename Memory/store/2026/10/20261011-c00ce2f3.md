왜 : 10-11 v17 첫 캡처 600장 전부에 101시간 방치 팝업이 떴다.
무엇을 : TouchSaveTime(파일, 칸) 으로 세이브 시각만 지금으로 바꾸고 바로 Arm 한다. 데모 드라이버도 OfflinePopup.Hide 를 안전장치로 부른다.
PowerShell 5.1 에서 eval 에 큰따옴표 문자열을 넘기면 따옴표가 빠져 컴파일 오류가 난다.
다음에 : 옛 판은 세이브 칸 이름이 다를 수 있다. false 가 오면 save.json 을 열어 시각 칸 이름부터 찾는다.
