왜 : EventSystem 드래그는 보관함 화면을 닫는 순간 끊긴다. 월드 쪽이 포인터를 직접 읽으면 UI 가 닫혀도 이어진다.
무엇을 : 누른 채 8 UI px(LayoutConstUi.DragThresholdPx, 화면 높이 비로 환산) 넘기면 드래그, 안 넘기고 떼면 탭이다. 탭은 랜덤 표정 1.5초(LayoutConst.FaceHoldSec) + 팝업, 드래그는 들리는 순간 랜덤 표정을 끝까지 들고 sortingOrder 700 으로 띄운다.
보관함 : 농장 마리를 보관함 버튼 Rect(FarmScreen.IsOverStorageButton) 에 놓으면 IStorageHub.TakeFromFarm. 보관함 줄은 코드가 AddComponent 한 UiDragSource(IBeginDragHandler)가 시작만 알리고 IUiHub.CloseAll → IFarmViewHub.BeginPlaceDrag 가 id -1 임시 마리를 띄운다. 담장 안에 놓으면 PlaceToFarm(놓은 자리에서 시작), 밖이면 보관함 화면으로 돌아간다.
다음에 : 기존 버튼 UI(농장에 놓기·보관함 보내기)는 그대로 둔다. 보관함 줄의 EventSystem 드래그 시작은 실제 손가락으로는 아직 못 봤다.
