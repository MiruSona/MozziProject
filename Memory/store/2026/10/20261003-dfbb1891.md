생성 코드의 GameDataTables.SchemaHash 와 구운 파일 _meta.schemaHash 가 다르면 Load 가 바로 던진다.
열을 더하거나 빼거나 타입을 바꾸면 Unity 메뉴 Mozzi/Data/Validate+Export+Gen 으로 셋을 한 번에 돌린다.
값만 고쳤을 때도 export 를 안 하면 게임은 옛 값을 읽는다 — 원본 JSON 은 빌드에 안 들어간다.
gen 은 옛 생성 파일을 안 지운다. 표를 없앴으면 Generated 의 그 Row.cs 를 사람이 지운다.
