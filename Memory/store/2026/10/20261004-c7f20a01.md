왜 : DataTool 스키마 검사가 enum 값에 ^[a-z][a-z0-9_]*$ 를 건다 (README 에는 안 적혀 있다).
무엇 : FarmDecor 의 layer 열을 back/front 로 적었다. 구운 값은 문자열, C# 은 DecorLayer.Back/Front 와 LayerName 속성이 같이 나온다.
다음에 : 새 enum 을 만들 때 값은 소문자 snake 로 적는다.
