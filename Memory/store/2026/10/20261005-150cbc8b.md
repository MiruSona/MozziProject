왜 : 사용자가 빈틈 채운 판(가)과 다시 뽑은 판(나)을 나란히 보고 「나가 좋아」라고 골랐다 (2026-10-05).
무엇을 : build_swirl.py 의 CANON 을 regen 으로 바꿔 out/Fx 를 다시 뽑은 판으로 채웠다. 60x60 겹 셋(a · b 는 회색 곱하기용, top 은 외곽선 + 반짝이) × 8장 = 낱장 24장이다. 창 원 안 빈 칸은 0 이다.
게임에 : Resources/Art/Fx/fx_swirl_{a,b,top}_{0~7}.png 24장을 이 판으로 바꿨다 (원본과 바이트 같음).
다른 판 : 빈틈 채운 판은 out/alt/fill_near, 처음 판은 out/alt/gap 에 남겼다. 섞임 단계 그림은 안 쓰고 색을 코드가 35% 까지 물들인다.
