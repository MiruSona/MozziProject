왜 : 반복 05 에서 미룬 피드백 3 · 7 · 13 과 주방 갈아엎기(순서 2), v15 피드백 2~5(순서 3)를 사용자가 한 세션에 이어서 하자고 했다 (2026-10-05).
무엇을 : 손님 왼쪽 한 줄 + 계산대 585x122 · 칠판을 누르면 차림표 판에서 바로 1개 만들기 · 합성 창 안에서 찹쌀이 둘이 엉켜 돌며 색이 35% 까지 물듦 · 주방 네 단계(고르기 → 찌기 → 치기 → 빚기) 단색 상자 판 · 궤짝에 폴짝 들어가기 · 발 y 기준 앞뒤 · 무작위 자리 시작 · 바닥 재료 낱개/꾸러미 줍기(화면만의 표현, 세이브에 안 넣음).
확인 : 컴파일 오류 0 · 경고 0 · EditMode 시험 29/29 · Unity Play 캡처 97장. APK 는 안 구웠고 판 번호는 v16 그대로다. 폰 실기 확인은 없다.
다음에 : 사용자가 주방 상자 판을 놀아 보고 단계 수 · 배치를 판정 → 주방 정식 그림. 농장 강화(수집기 · 먹이 공급기 · 창고 넓히기). 사용자가 보고 정할 것 여덟. 그 뒤 순서 4(메인 화면) · 5(손님 옷) · 6(찹쌀이 모션 · 표정).
공수 : 갈래 넷을 병렬로 돌렸다. 서브 mark 구간이 7~13분으로 찍혔으나 메인 문맥 압축 탓에 실제보다 짧게 잡혔을 수 있다 (줍기 갈래는 못 쟀다). Play 확인 한 판은 34분 (예상 55분).
