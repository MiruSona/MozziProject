Exit 을 delayCall 로 걸면 백그라운드 Editor 에서 안 닫히니 EditorApplication.Exit(0) 을 직접 부른다.
1. eval 로 delayCall += Exit(0) 을 걸면 Editor 가 백그라운드라 틱이 없어 안 닫힌다. Exit(0) 을 직접 부르면 닫힌다 (eval 응답은 success=false 로 온다).
2. 드라이버가 ui.OpenX 를 부른 프레임의 png 는 옛 화면이다. 화면 바꾼 새 화면은 다음 장부터 찍힌다. 구간표는 로그 frame + 1 로 잡는다.
3. captureFramerate 30 인데 실제로는 33~37fps 로 찍혀, 실제 초 연출(떡메·찜기)은 30fps 영상에서 0.8~0.9배로 느려 보인다. 판마다 실제 fps 가 달라 같은 드라이버도 구간 길이가 15프레임쯤 흔들린다.
