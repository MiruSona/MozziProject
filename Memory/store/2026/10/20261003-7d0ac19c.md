왜 : 반복 방식은 세션마다 되풀이되니 순서를 스킬로 고정해 두면 새 세션도 같은 길로 간다.
무엇을 : 진행상황 문서에 버릴 것·남길 것·추가할 것 세 표와 반복 색인 표, 기획절차 문서에 9단계 뒤 절, 반복 기록 틀 파일, iteration 스킬(8단계 순서·서브 프롬프트 틀·빌드와 zip 명령), 툴 저장소 할 일 폴더에 반복 단계 제안 문서. lint 전부 종료 0.
다음에 : 사용자가 v11 을 한 판 놀고 피드백을 던지면 iteration 스킬로 1회를 시작한다. 툴 저장소 피드백은 서브모듈 커밋 두 번이 남았다. 같은 꼴(문서 넷+스킬 하나)은 메인 5분+서브 2분으로 잡는다.
