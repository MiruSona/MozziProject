왜 : MozziSpriteSet.Load 가 전 종에 acc_crown 을 끼워 기본 흰찹쌀이도 왕관을 썼다. 어느 종이 무엇을 쓰나는 수치라 코드 분기보다 데이터 통(표)에 둔다.
무엇을 : MozziSpeciesRow.accessoryId 를 더하고 Load 가 acc_<accessoryId> 를 읽는다. 비어 있으면 MozziArtKeys.NoneId(none)로 본다. acc_none.png 는 64×64 투명 그림이라 겹은 있되 안 보인다.
결과 : Play 에서 grass1 23마리 전부 acc_none, 나머지 17마리 acc_crown 을 확인했다.
다음에 : 「왕관 찹쌀이」를 어느 종(새 종인지 기존 종인지)으로 둘지는 기획 미정이라 안 건드렸다. 정해지면 표의 accessoryId 만 고치면 된다.
