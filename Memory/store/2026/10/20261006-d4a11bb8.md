왜 : 수집기는 창고가 찬 재료를 건너뛰어 swept 0 이 나왔다.
무엇을 : eval 로 TimeScale 0 → _piles[pinenut]=3 등 → view.Process(0) 로 바닥에 깔기 → _collectorClock=period-0.01 → farm.Process(0.02) → view.Process(0.3) 뒤 캡처.
함께 : PowerShell 에서 unity command eval 은 따옴표·괄호가 인수로 깨지니 eval_file --file 로 돌린다. 끝나면 세이브를 백업본으로 되돌린다.
