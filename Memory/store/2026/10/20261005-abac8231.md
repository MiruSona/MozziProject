왜 : 정식 그림이 갈래마다 따로 들어와 외곽선 색 · 떡 아래 빈칸 · 서랍 배율이 흔들렸다 (20261005-d39e7431).
무엇을 : 갈래 0(프로필 · 팔레트 · 기준선) · A(떡 · 재료 아이콘 꼴 ①) · B(가판대 · 진열장 떡 그림 수 · 메뉴 세움판 뺌) · C(농장 장식 · 울타리) · D(합성소 서랍 ×1 · 찹쌀이 선 #5E5048 · 코드 좌표) · E(뒷정리 · 재검사). 고친 그림 41장 + ui_badge_alert 새로. 재검사는 Docs/Reference/Art/점검/2026-10-05/check_after/ — 새로 생긴 것 0, 알고 두는 것 88 (실패 7 · 경고 81). 프로필 mozzi_prop 색 수 표를 설계에 맞춰 경고 8 을 한 번에 풀었다. APK 는 안 굽고 Unity 로 확인 (v16 그대로).
공수 눈금 : 서브 갈래 예상 합 약 6~7시간, 실제 약 1시간 50분. 그림 갈래 한 판 예상을 너무 크게 잡았다 — 다음엔 그림 갈래 하나를 20~30분으로 잡는다.
다음에 : 진열장 유리 꼴 · 「한 종류 = 접시 하나」 는 사용자 확인 대기. 다음 판은 피드백 3 · 7 · 13. 남은 경고는 Docs/Reference/Art/화풍/README.md 「알고 두는 경고 · 실패」.
