왜 : 찹쌀이 몸 선은 차가운 회색 #6E6E6E(10-03 사용자 「짙은 쪽」)이라 갈색 선 건물과 어긋났고, 합성소 서랍 찹쌀이는 코드 OutletScale 0.5 로 몸이 약 21x17 까지 줄었다 (v16 피드백 14). 사용자 답 4 「시안먼저」 · 7 「권장대로」 (2026-10-05).
무엇을 : 찹쌀이 선 색은 지금 회색과 따뜻한 회갈색 후보를 몸 4장 x 종 색 x 잔디 위로 나란히 놓은 시안을 본 뒤 사용자가 고른다 (그때까지 회색 110 유지). 서랍 찹쌀이는 OutletScale 을 1 로 올리고 몸 아래끝을 서랍 바닥(y 194)에 맞춰 위로 5줄 「고개 내민」 꼴로 먼저 본다. 모자라면 그때 서랍 그림을 다시 뽑는다.
다음에 : 갈래 C 가 C-1 시안을 내고, 코드 갈래 D 가 OutletScale · 「?」 글자 크기를 고친 뒤 Play 캡처를 보인다.
