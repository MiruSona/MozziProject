왜 : 바탕 한 장에 얼룩·꽃·풀포기를 그려 넣으면 256 마다 같은 무늬가 되풀이되어 눈에 띈다 (사용자, 2026-10-03). 09-20 의 타일 12x13 + Tilemap 짜임을 덮는다.
무엇을 : 정식 그림 out/grass_base.png(256, 네 변 이어짐) + decor_00~10(32 칸) + 통나무 울타리 32 마디 셋을 만들었다. 토끼풀 둘은 얼룩처럼 보여 뺐다.
다음에 : 코드 갈래가 SpriteRenderer Tiled 로 바탕을 깔고 장식을 32 칸에 씨앗 고정으로 흩는다. 바탕 밝기·밋밋함은 판정 그림을 사용자가 본다.
