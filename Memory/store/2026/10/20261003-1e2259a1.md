왜 : UI 프리팹이 왼쪽 위 절대 앵커(0,1)라 CanvasScaler 기준을 올리면 레이아웃이 깨진다. 월드 쪽만 키우면 UI 는 손대지 않아도 된다.
무엇을 : LayoutConst 의 ScreenWidthPx/HeightPx 를 540×960(32 PPU)로, 카메라 orthographicSize 15 는 FarmViewManager.Init 이 코드로 넣는다. UI px → 월드 px 는 UiToWorldPx=1.5 로 환산해 건물·자원바·건물 띠 높이를 맞춘다. 농장 타일은 17×20.
결과 : 찹쌀이 크기(40/48/56 월드 px)는 그대로라 화면에서 작아 보이고 칸이 더 보인다. 건물은 ×1.5 라 화면 크기 그대로다.
다음에 : 씬 Farm.unity 의 카메라 size 는 아직 10 이다(런타임이 15 로 덮음). 씬 값도 맞추려면 set_component_properties 로 고치고 save_scene.
