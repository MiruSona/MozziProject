왜 : v13 을 놀고 「프로토타입 UI 같다 · 그림체를 통일해 게임처럼」 피드백이 나와 그림체 통일과 화면 배치를 다시 했다. 버그 수정은 v14, 메인 화면 새 그림은 v15 로 나눴다.
무엇을 : 시안 확정 뒤 메인 화면 정식 그림(하늘 · 건물 셋 · 궤짝 보관함 · 잔디 b1 + 장식 36 · 통나무 울타리 · 아이콘 셋 · 찹쌀이 뛰는 그림 4장)을 넣고, UI 540 · Tilemap 걷음 · 건물 누르면 전용 화면 · 오른쪽 아래 메뉴를 코드로 넣었다. v15 APK(Build/android/, 40,645,156 바이트)를 사용자가 폰에서 열두 항목 확인했다. 기록 Docs/History/반복/03-2026-10-03.md.
다음에 : 반복 04 = 전용 화면(가판대 · 주방 · 합성소 실내, 버튼 아래 정렬) → v16. 그 다음 반복에서 v15 피드백 2~6.
공수 눈금 : 서브 한 판 벽시계 14~21분 · APK 빌드 123초(앞 판 404초) · EffortTool mark 는 체감(벽시계)보다 짧게 잡힌다 — 실제 칸은 mark 와 벽시계를 같이 적는다.
