왜: 그림은 PPU 32 로 들이고 Canvas referencePixelsPerUnit 은 100 이다. 그냥 두면 9-slice 테두리가 약 3배로 그려진다.
무엇: FormalLayout.SliceMultiplier = 100f/32f 를 FormalUiBuild.MakeSliced 가 넣는다. spriteBorder 는 Vector4(왼,아래,오른,위) 순서라 README 의 위·아래 값을 바꿔 적지 않게 본다 (MozziArtImport.BorderFor).
다음: 새 9-slice 그림(ui_button·ui_bubble 말고)은 BorderFor 에 줄을 더한다.
