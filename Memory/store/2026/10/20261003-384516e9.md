Scene 은 SceneAnchorY 1(위끝)에 붙이고 아래 판은 StallPanelHeight 200 · SynthesisPanelHeight 176 고정으로 바닥에 붙인다.
왜 : 가운데 정렬이면 9:20 에서 합성소 위에 어두운 들보 띠가 40px 더 보이고, 판이 늘어나면 가판대 아래 판 가운데가 빈다. 위끝 정렬은 360×640 과 같은 윗모습을 지키고 남는 세로를 마루·가게 바닥으로 돌린다.
무엇을 : 배경 360×800 은 그림 좌표 y 720 까지 있어 가판대는 내용 칸 높이 920, 합성소는 896 까지 그림이 닿는다. 그 너머는 SceneFillBottom 끝색이다.
말풍선 : 손님 머리 위 OrderBubble 은 네모 조각(BubbleEdge_n 테두리 · BubbleFill_n 바탕)으로 둥근 꼴과 꼬리를 만든다. 찾은 떡은 그림만(폭 30), 아무거나·못 찾은 떡은 글자(폭 60). 색은 OrderBubbleView.SetColor 가 Fill 조각에만 넣는다.
옛 손질기 : CakeIconSetup · CustomerLayerSetup · ShelfCellSetup 은 지웠다. Icon · 손님 겹 · 진열 칸 자식은 프리팹에 이미 있고 FormalScreenSetup 은 자리만 놓는다 — 프리팹을 처음부터 다시 만들 일이 생기면 git 기록(1c571dd 이전)에서 꺼낸다.
다음에 : 자리를 고치려면 LayoutConstUi 정식 화면 구역을 고치고 메뉴 「Mozzi/정식 화면 배치」를 다시 돌린다.
