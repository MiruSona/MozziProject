왜 : 반복 03 피드백 5, 6번(정식 UI, 메인 화면 배치)에 답하려고 사용자가 고른 게임 여섯과 농장 경영 도트 게임 넷을 훑었다.
무엇을 : 스팀 공개 스크린샷의 픽셀 격자를 PIL 로 재고 색을 뽑았다. 그림은 저장소에 안 넣었다.
결과 : 우리 게임은 월드 540×960(1080 폰에서 2배)과 UI 360×640(3배)으로 픽셀 굵기가 둘이다. 540×960 하나로 맞추면 주인 128×160 을 줄이지 않고 쓴다(화면 높이의 13퍼센트로 지금 64×80 과 같은 크기).
메인 화면은 하늘 띠, 먼 숲 띠, 건물 줄, 농장 순서의 한 화면 고정을 권했다. 하늘 띠가 남는 세로를 받는다.
못 한 것 : 오른쪽 세로 메뉴 본보기는 못 찾았다. 캐릭터 크기는 눈대중이다. PixelLab 화풍 낱말은 안 뽑아 봤다.
다음 : 사용자가 문서 7절의 11가지를 정하면 PIL 프로토 한 장(메인 화면 540×960)을 만든다. 공수는 조사와 문서로 약 40분.
