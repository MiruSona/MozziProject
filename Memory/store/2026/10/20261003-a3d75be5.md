왜 : 사용자가 v12 를 폰에서 놀고 시안 판정 4건·플레이 피드백 3건·기타 2건·덧붙임 1건을 던졌다. UI 가 폰 화면 밖으로 나간 것이 가장 급했다.
무엇을 : 가판대 A안(현대 카페)·합성소 A안(귀여운 기계, 배경은 떡집 내부)을 정식 화면으로 넣고 합성 때 음양 연출을 붙였다. 끄는 중 표정은 face_05 고정, 놓으면 바로 기본. 안전 영역 안 360×640 내용 칸으로 가로가 늘 다 보인다. 세이브는 2판으로 올렸고 연출 뼈대(LitMotion 디스패처 둘)를 깔았다. 옛 손질기 셋은 사용자 승인 뒤 지웠다.
빌드 : Build/itch/ProjectMozzi-android-v13.apk · 40,566,234 바이트 · Succeeded · 오류 0 · 253초.
안 넣은 것 : 가판대 주인(고차비 캐릭터)은 시안 v3 까지만 — Won't 47(권리 확인 전)이라 사용자가 시안을 보고 정한다. 농장 여러 개는 방향만(스와이프 + 한 화면 2개쯤 + 농장마다 타입 하나).
공수 : 서브 실제 코드1 21분·그림 11분·주인 시안 약 15분·코드2 21분·정리+빌드 15분. 예상은 50·50·40·60·40분이라 2~4배 넉넉했다. 까닭 : 서브 예상을 본줄의 10배로 잡은 것이 과했고 첫 판에서 컴파일·그림이 바로 통과했다.
다음에 : 떡메 치기 게임 화면(사용자가 다음 반복으로 미룸) · 가판대 주인 넣을지 · 소리(AudioService) · 농장 여러 개 설계. 폰에서 연출·안전 영역·글자 말풍선을 아직 못 봤다.
