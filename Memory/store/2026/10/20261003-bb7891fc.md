왜 : 흰찹쌀이가 표에는 초록(#7BC96F)이고 농장 코드만 예외로 흰색을 써서, UI(합성소 입구·음양·결과 네모·도감)에서는 초록으로 나왔다.
무엇을 : grass1 의 color_hex 를 #FFFFFF 로 고쳐 다시 굽고, 예외 상수를 지운 뒤 MozziArtKeys.BodyColorOf 한 함수로 모았다.
다음에 : 종 색을 바꿀 때는 표만 고치고 datatool export 를 돌린다. 코드에 종 id 예외를 두지 않는다.
