왜: 반복 03(v15)에서 메인 화면에 정식 그림을 넣었고, 건물을 눌러 여는 전용 화면 셋이 남아 있었다. v15 피드백 1(버튼이 위에 몰림)도 전용 화면부터 아래 줄로 반영했다.
무엇을: 가판대 배경 B·갈색 계산대·줄인 주인·소품, 옆모습 손님 3차d(파츠 따로 + 턱·입 손수정), 합성소 기계실(기계 넷·상태 다섯·표/서랍/세움판/깔때기 누르기), 만들기·실험을 가판대에서 떼어 임시 주방으로, 닫기는 한 겹씩 되돌아감(_returnStack), 죽은 파일 둘 지움, AndroidBuild.Version 16. 기록 Docs/History/반복/04-2026-10-04.md.
다음에: APK v16 빌드·폰 시험·손님 3차d 판정 → 반복 05 주방 갈아엎기(mem 20261004-80fc4a14) → v15 피드백 2~6.
눈금: 코드 판 넷 예상 190분 / 실제 약 74분(판당 18~23분), 손님 그림 판 넷 예상 80분 / 실제 약 48분. 설계안이 파일 단위까지 정해져 있고 앞 판의 공용 도구(FormalUiBuild)를 뒤 판이 그대로 써서 짧았다. EffortTool mark 가 문맥 압축 전 구간을 빼먹었을 수 있다.
