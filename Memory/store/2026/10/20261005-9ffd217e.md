주방 v3 그림 34장 배선과 연출을 한 판에 끝냈고 예상(30~40분)보다 짧은 약 18분(mark 실측 합)이 걸렸다.
무엇을 : FormalArtCopy 표를 v3 로, SpriteKeys 키, Setup 이 틀 · 칸 · 그릇 · 찜기 · 빚기판을 그림으로 굽고 김 · 빚기 자리를 더함. KitchenMortarView 는 단계 묶음 셋, 새 KitchenOnceView 가 김 · 빚기 한 바퀴. PlateY = BoardTop + 14. 시험 52/52 · 경고 0 · check_all 새로 생긴 것 0.
어긋난 까닭 : 그림 갈래 README 「코드에 넘길 것」 표가 자리 · 피벗 · 시간을 다 줘서 Unity 에서 다듬을 값이 없었다. Play 확인은 TimeScale 0 + KitchenScreen.Process 손 돌리기로 프레임 중간 장을 바로 찍었다.
다음에 : 정식 그림 배선은 넘김 표가 있으면 15~20분 눈금으로 잡는다. 그릇 자리(가운데 240 vs 견줌판 왼쪽 240)는 놀아 보고 정한다.
