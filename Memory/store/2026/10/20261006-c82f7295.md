왜: get_image 는 그림을 대화에 올려 문맥을 쓰고, 다운로드 주소는 인증 없이 열린다.
1. job id 표를 스크립트에 두고 없는 파일만 urllib 로 받는다.
2. 받을 때 크기 · bbox · 색 수를 찍어 잘림 · 빈 그림을 바로 본다.
3. 미리보기 시트 한 장만 Read 로 열어 눈으로 본다.
다음에: 시안 판은 wait_for_jobs → 받기 스크립트 → 시트 한 장으로 끝낸다 (반복08-v1/README 참고).
