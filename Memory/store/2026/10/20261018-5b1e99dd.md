로컬 저장소를 file:// 주소로 clone 하면 git-lfs 가 원격을 못 찾아 큰 파일이 포인터 그대로 남는다.
그 상태로 filter-repo 를 돌리고 push 하면 lfs fsck 가 openError 를 낸다.
원본의 .git/lfs/objects 폴더를 새 clone 에 통째로 복사하고 git lfs checkout 을 치면 fsck 가 통과한다.
새 원격에는 git lfs push --all 로 객체를 따로 밀어야 한다.
