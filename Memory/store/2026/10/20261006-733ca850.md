왜 : 반복 07 판을 놀던 사용자가 「순서상 찜기가 마지막 아냐? 재료 갈기가 첫 순서로 추가되면 좋겠어」, 「찜기 애니 너무 짧아」라고 했다 (2026-10-06, 피드백 13 · 15).
무엇을 : 단계는 고르기 → 갈기 → 치기 → 빚기 → 찌기. 갈기는 맷돌을 치기처럼 누름 3번. 찌기는 누를 것 없이 2.5초 기다리면 김이 오르다 끝난다. 찌기가 마지막이니 찜기 뚜껑이 열리며 찜기 위에 떡 · 이름 · NEW 가 뜨고, 결과 접시와 도마 위 결과는 뺀다. 해 본 조합은 지금처럼 짧게 바로 만들기.
다음에 : 다음 세션 반복 08 에서 KitchenFlowAgent · KitchenStep 흐름 규칙 자체를 고친다 (반복 07 까지는 흐름 규칙은 그대로였다). 맷돌 그림은 시안부터 뽑는다. 03-시스템-가판대.md 의 주방 단계 절은 고친 뒤에 적는다.
