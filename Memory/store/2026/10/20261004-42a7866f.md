1. 벽 540x440 : 프롬프트에 맨 위 crown molding 과 맨 아래 baseboard 를 곧게 요구해 이을 자리를 만든다.
2. 천장 540x360 : style_image_url 에 벽 download 주소, ONLY the top part 와 Nothing else 목록.
3. 마루 540x420 : fills the whole canvas edge to edge.
4. PIL 로 몰딩·걸레받이 줄에서 쌓는다. 높이가 모자라면 마루를 어두운 널 이음 줄에서 잘라 한 구간을 한 번 더 잇는다. 세로 널 계산대는 한 줄을 되풀이해 키를 키운다.
