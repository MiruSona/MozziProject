왜 : 창고 상한(Cap)은 InventoryManager 가 셈한다. 단계를 FarmManager 에 두면 Inventory 가 Farm 을 봐야 해 Farm → Inventory 와 맞물려 고리가 생긴다.
무엇을 : InventoryManager 가 IWalletHub 로 값을 내고 StorageLevel · NextStoragePrice · BuyStorage 를 가진다. Cap = 표 cap + storage 행 rate. 사면 StorageUpgradedEvent 를 내고 UiManager 가 자원바를 다시 읽는다.
나머지 셋(바닥 넓히기 · 수집기 · 공급기)은 FarmManager 가 kind 하나로 받는 UpgradeLevel · NextUpgradePrice · BuyUpgrade 로 판다. 담장은 옛 BuyFence 그대로다.
