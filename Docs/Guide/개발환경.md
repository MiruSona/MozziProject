# 개발 환경

> 환경이 바뀌면 이 문서를 고친다. 규칙 문서(`AGENTS.md`)에는 환경 이야기를 적지 않는다.

## 기본 환경

| 항목 | 값 |
| --- | --- |
| OS | Windows 11 |
| 기본 셸 | PowerShell |
| 게임 엔진 | **Unity — 버전 미정.** 2D URP 로 갈 생각이다 |
| 주 언어 | C# |
| VCS | Git + **Git LFS** |
| Unity 프로젝트 자리 | `ProjectMozziUnity/` (아직 없다) |

## 셸 주의사항

- PowerShell 5.1 기준이라 `&&`, `||`, 삼항 연산자를 쓸 수 없다. `;` 와 `if ($?) { }` 를 대신 쓴다.
- 경로에 공백이 있으면 큰따옴표로 감싼다.
- Bash 를 쓸 때는 Git Bash(POSIX) 문법으로 작성한다.

## Git LFS

그림·소리·영상은 LFS 로 잡는다. 잡는 확장자는 `.gitattributes` 에 있다.

- 저장소를 처음 받으면 **`git lfs install` 을 한 번 돌린다.** 안 하면 파일 대신 짧은 글자만 들어온다.
- 새 종류의 큰 파일(예 `.psd`)을 넣기 전에 `.gitattributes` 에 그 확장자가 있는지 본다. 없으면 먼저 더한다.
- **이미 LFS 없이 커밋한 큰 파일을 뒤늦게 LFS 로 옮기는 것은 이력을 고쳐야 해서 아프다.** 넣기 전에 확인한다.

## Unity 주의사항

- `.meta` 파일은 대상 파일과 **항상 함께** 커밋한다. 빠지면 다른 사람 환경에서 연결이 깨진다.
- `Library/`, `Temp/`, `Logs/`, `Build/` 는 커밋하지 않는다 (`.gitignore` 에 걸어 뒀다).
- 씬(`.unity`)과 프리팹(`.prefab`)은 합칠 때 충돌을 풀기 어렵다. 같은 파일을 동시에 고치지 않는다.
- Unity 조작 도구(배치 모드·CLI)는 프로젝트를 만든 뒤에 필요해지면 그때 검토한다.

## 툴 exe

`mem` · `effort` · `gate` 는 **사용자 홈 아래**에 깔려 있고 PATH 에 잡혀 있다.
저장소 안에 exe 를 두지 않는다 (`.gitignore` 가 `mem.exe` 를 막는다).

- 있는지 보려면 : `mem status` · `effort --help`
- 없으면 각 툴 저장소(`Tools/AIMemoryTool` · `Tools/EffortTool`) README 의 설치 절차를 따른다.

## 로컬 AI 작업기 (미니PC)

무거운 반복 작업(그림·소리 생성, 로컬 LLM)은 미니PC 에서 돌린다.
**주소·사양·접속 절차는 툴킷 저장소(ProjectOfficina) 쪽 로컬 문서**에 있다 (git 에 안 올린다).
