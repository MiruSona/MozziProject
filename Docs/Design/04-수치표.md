## 2. 떡 값 (규칙은 `03-시스템-가판대.md` 7절)

떡 값 = 부재료 값 합 × 개수 계수 × 특제 배율 × 주문 계수. 가루 값은 더한다.

| 항목 | 값 | 임시/제안 | 어디서 왔나 |
| --- | --- | --- | --- |
| 부재료 값 (1·2·3단계) | 10 / 30 / 90 골드 | 임시 | q2 프로토 CONST |
| 찹쌀가루 값 | 0 | 확정 | mem 20260912-7151c951 |
| 수수가루 값 (덧셈) | +30 골드 | **제안** | 2단계 부재료와 같은 무게로 |
| 개수 계수 (1·2·3개) | ×1.0 / ×1.5 / ×2.2 | **제안** | 3개짜리가 「두 배 넘게」 되게 |
| 특제 배율 | ×2.0 | **제안** | 변종이 12종 중 절반 아래라 두 배 |
| 주문 맞춤 배율 | ×1.5 | 임시 | mem 20260912-01b50d85 |
