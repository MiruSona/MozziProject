# 컨셉

> 이 게임이 무슨 게임이고, 누구를 위한 것이고, 무엇을 안 할지를 정한 문서.
> 마지막 고침 2026-09-07 · 정한 사람 사용자 + AI · 상태 1판 초안 — 사용자 확인 전

## 1. 한 줄 컨셉

**물려받은 농장에서 찹쌀이를 키우고 둘씩 합성해 새 종을 만들어, 그 재료로 찹쌀떡 레시피를 찾아 파는 2D 방치형 힐링 농장 게임.**

- 인터넷 방송인 **고차비 님의 팬게임**이다. 개발자가 팬심으로 만드는 **무료** 게임이고 상업 이용은 없다.
- 주인공은 원작 팬 캐릭터 **찹쌀이**(왕관 쓴 찹쌀떡)다. 생김새는 떡으로 가되, 계열(잔디·물·용암·늪)은 이미 정한 합성 설계를 그대로 쓴다.

## 2. 대상과 노는 상황

- **20~30대**, 1순위는 고차비 팬(호군단)이다.
- 출퇴근길에 가볍게. 또는 PC 한쪽에 작은 세로 창을 띄워 두고 방치한다.
- 방치 세기는 **껐다 켜면 쌓여 있는 쪽**이다. 켜 놓고 계속 누르는 게임이 아니다.

## 3. 남는 기분과 제일 재밌는 순간

남기고 싶은 기분은 **힐링**이다. 편안함에 「모으는 재미」를 얹는다.

제일 재밌는 순간은 둘이고, **도감도 둘**이다.

1. 새 찹쌀이를 얻어 **찹쌀이 도감** 한 칸이 열릴 때
2. 새 재료로 새 레시피를 찾아 찹쌀떡을 만들어 팔 때 — **레시피 도감**

가판대는 요리 타이쿤의 한 축이다. 흐름은 **찹쌀이 재료 → 레시피 발견·제작 → 찹쌀떡 판매**다. 만드는 과정 상세는 시스템 문서에서 정한다.

## 4. 스토리

가볍게 배경만 깐다. **찹쌀이 농장을 물려받아 → 키우다 → 찹쌀떡 가게까지 운영하게 된다.**

- **빚·마감 같은 압박 목표는 안 넣는다.** 힐링과 부딪힌다.

## 기둥

| # | 기둥 | 뜻 |
| --- | --- | --- |
| 1 | 켜지 않아도 농장은 굴러간다 | 방치가 기본. 접속을 강요하는 장치를 안 만든다 |
| 2 | 새 찹쌀이·새 찹쌀떡을 만나는 순간이 제일 즐겁다 | 두 도감이 목표이자 보상. 연출·소리는 이 순간에 몰아 준다 |
| 3 | 힐링이 먼저다 | 빚·마감·실패 벌칙처럼 조급하게 만드는 것은 안 넣는다 |
| 4 | 원작 찹쌀이를 보면 바로 알아본다 | 팬이 첫 화면에서 「아, 고차비다」 해야 한다. 원작에 없는 설정을 원작인 척하지 않는다 |

## 5. 안 할 것

| 안 하는 것 | 왜 |
| --- | --- |
| 전투 | 힐링과 안 맞고 만들 것만 늘어난다 |
| 멀티플레이 | 혼자 만드는 규모를 넘는다 |
| 랭킹 | 남과 비교하면 편안하지 않다 |
| 빚·마감 같은 압박 목표 | 기둥 3과 정면으로 부딪힌다 |
| 유료 판매·광고 | 굿즈 권리가 소속사에 있다. 무료 팬게임으로 못 박는다 |
| 공식 이모티콘 그림 그대로 쓰기 | 저작권이 본인·소속사에 있다. 새로 그린다 |
| 본인 자캐를 조작 캐릭터로 | 실존 인물의 아바타다. 주인공은 찹쌀이로 충분하다 |
| 신상·사생활 소재 | 본인이 싫어한다 |
| 합방 상대 스트리머를 캐릭터로 | 그쪽 허락이 또 필요하고 범위만 커진다 |
| 농장·합성·가판대 밖의 새 시스템 | 축 셋으로 끝낸다. 늘리면 첫 판을 못 낸다 |

## 6. 플랫폼과 한 판 길이

- **모바일 세로 기준**이다. 기기는 PC(Windows)와 안드로이드 둘.
- PC 에서는 작은 세로 창을 화면 왼쪽에 띄워 두고 곁눈질하는 그림이다.
- 한 판 길이는 첫 세팅 때 1시간쯤, 자리 잡히면 접속당 30분 이내다.

## 7. 원작과의 관계

| 가져올 것 | 안 가져올 것 |
| --- | --- |
| 찹쌀이 = 왕관 쓴 흰 떡 | 공식 이모티콘 그림 그대로 쓰기 |
| 원작 색표(분홍 `#F8BBC0`·보라 눈·볼 다이아 `#FA6270`·짙은 남색) 중심, 둥글고 귀여운 형태 | 본인 자캐를 조작 캐릭터로 |
| 소품으로 변형을 나누는 방식 (원작 이모티콘이 이미 그렇다) | 신상·사생활 소재 |
| 대왕찹쌀이 같은 「오래 본 사람만 아는」 표식 | 합방 상대 스트리머 |

- 그림은 **공식 것을 안 쓰고 새로 그린다.**
- 팬카페 공지에 **팬게임 규정은 없다.** 있는 것은 「카페 글 외부 공유 금지」 하나다 (2026-09-07 사용자 확인).
- 무료·비상업·새 그림으로 만들고, 만드는 과정과 게임 공유는 **카페 안에서** 한다. 문제가 생기면 사용자가 감수한다.
- 자세한 조사는 `Docs/Research/2026-09-07-고차비조사.md`.
- 나중에 볼 것 : 가판대에 고차비 님 SD 캐릭터를 두는 아이디어. **확정 아니다.**
