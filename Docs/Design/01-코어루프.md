# 코어 루프

> 이 게임이 1~3분 · 하루 · 며칠 단위로 어떻게 도는지, 자원이 어디서 생겨 어디로 없어지는지, 이번 판에서 무엇을 물을지를 정한 문서.
> 마지막 고침 2026-09-09 · 정한 사람 사용자 + AI · 상태 2판 통과 (1판은 q1-1 불통으로 5단계에서 되돌아옴 · 2판은 2026-09-09 사람 판으로 통과, 6단계)

## 1. 한 줄 요약

「쌓인 재료 줍기 → 떡 만들어 팔기 → 골드로 합성 걸기(칸 여러 개) · 짝 구매 · 합성소 강화」가 코어 고리, 「새 찹쌀이 → 짝 구매 → 번식 → 새 재료 → 새 떡 레시피 → 도감 한 칸」이 하루 고리, 「새 계열 → 3단계 → 늪 → 변종 → 도감 24칸」이 메타 고리다. 셋 다 닫힌다 (메타는 24칸이 끝).

## 1-1. 1판에서 2판으로 — 왜 바꿨나

1판을 q1-1 프로토로 논 결과 **고리는 닫히는데 돌릴 이유가 없어** 불통이었다 (`Prototypes/2026-09-07-q1-1-골드고리/결과.md` · mem `20260908-26980bf2`).
기록 : 실제 16분에 5분 건너뛰기 70회 · 번 골드 15,180 중 6,130 남음(40%) · 마릿수 462 · 합성 21회 · 10분에 질림.

| # | 원인 | 고친 것 (2판) |
| --- | --- | --- |
| 1 | 골드가 고인다 — 배수구가 합성 21회 · 구매 15회뿐 | 계속 사는 소비처 셋 : 합성소 칸 확장 · 영구 대기 단축 · 도감 짝 구매. 값은 지수로 오른다 |
| 2 | 합성소 1칸이라 대기가 곧 정지 | 합성소 칸 1→4 로 중간 시계를 여러 개 두고, 떡 레시피 찾기(느린 시계)를 같은 판에 둔다 |
| 3 | 새 종이 1마리라 번식이 안 된다 | 도감 짝 구매를 1·2단계 일반 종까지 연다 (3단계·변종은 안 판다) |

근거는 `Docs/Research/2026-09-08-골드소비처와합성병목조사.md` (안 가 「합성소 성장 + 짝 구매」 채택, mem `20260908-f4838ff4`).
「합성 결과 2마리」「재료 안 소모」는 안 쓴다 — 찹쌀이 배수구가 사라진다.

## 2. 3층 루프

| 층 | 시간 | 고리 | 닫히나 | 플레이어가 느끼는 것 |
| --- | --- | --- | --- | --- |
| 코어 | 한 번 접속 1~3분. 한 접속에 여러 번 돈다 | 켠다 → 쌓인 재료 줍기 → 합성 결과 받기 → 재료로 찹쌀떡 만들기 → 팔아서 골드 → 골드로 합성 걸기(칸 1~4 동시) · 짝 구매 · 합성소 강화 중 하나(또는 설비 하나) → 끈다 → 시간 흐름 → 켠다 | 닫힌다 | 「쌓였네, 챙겼다」 편안한 수확 |
| 하루 | 한 판 = 접속 3~4번 | 합성 걸기 → 새 찹쌀이 → 짝 구매 → 번식 → 농장 배치 → 새 재료 나옴 → 새 조합으로 떡 레시피 시도 → 도감 한 칸 → 다음 합성 목표 → 합성 걸기 | 닫힌다 | 「오늘 한 칸 열었다」 |
| 메타 | 며칠~몇 주 | 다른 계열 갈래로 새 계열 씨앗 → 바닥 깔기·농장 확장 → 그 계열 3단계 → 잔디+물 교차로 늪 발견 → 3단계끼리 합성 = 변종 뽑기 → 두 도감 채우기 → 다음 계열·레시피 묶음 | 반만 닫힌다 — 도감 24칸 다 차면 끝 | 「다 모았다」 |

- **방치 시간이 자원이 되는 길** : 농장 바닥에 재료가 쌓이고(상한은 미정, 옛 기획은 60개), 합성 시계·번식 시계가 돈다. 골드로 시간을 못 사니(즉시 완료 없음) 시간이 진짜 비용이자 원천이다.
- 코어의 「1~3분」과 컨셉의 「접속당 30분 이내」는 층이 다르다. 한 접속에 코어 고리를 여러 번 돈다.
- 메타 끝(24칸 완성) 뒤에 무엇이 있는지는 미정이다. 힐링 게임이라 끝이 있어도 된다.

### 시계 겹치기

「항상 작은 할 일 하나가 있게」 주기가 다른 시계를 같은 판에 겹친다. 1판(q1-1)은 중간 시계가 하나뿐이고 느린 시계가 없어서 대기가 곧 정지였다.

| 시계 | 무엇 | 주기 (임시) | 1판에 있었나 |
| --- | --- | --- | --- |
| 빠른 | 재료 줍기 → 떡 만들기 → 팔기 | 15~30초 | 있었다. 「전부」 버튼이라 1초에 끝 |
| 중간 | 합성 완료 (칸 1~4) · 번식 | 3~5분 | 있었다. 합성소 1칸이라 하나뿐 |
| 느린 | 떡 레시피 찾기 (새 부재료가 생길 때) | 새 종마다 | **없었다** (q1-2 에 따로) |
| 목표 | 도감 24칸 · 레시피 도감 | 며칠 | 있었다 |

## 3. 자원 흐름

| 자원 | 원천 | 변환 | 배수구 |
| --- | --- | --- | --- |
| 찹쌀이 | 시작 2마리 · 번식(공짜 + 시간) · 합성 결과 · 도감 짝 구매(1·2단계 일반 종, 골드) | 합성 재료 2 → 1 | 합성 · **보관함에서 팔기·일괄 팔기** (골드. 값은 떡보다 훨씬 낮게) |
| 재료 (찹쌀가루 + 부재료) | 찹쌀가루는 모든 찹쌀이가 기본으로 뱉음 · 부재료는 계열별 찹쌀이가 뱉음 (단계 높을수록 희귀하고 느림) | 찹쌀떡 | 떡 제작에 소모 · 바닥 상한을 넘으면 생산이 멈춤 |
| 찹쌀떡 | 재료 + 떡 레시피 → 제작 | 골드 | 가판대 판매. 초반은 손, 설비를 사면 자동 |
| 골드 | 찹쌀떡 판매 · 잉여 찹쌀이 팔기 | — | 합성 비용 × 칸 · 합성소 칸 확장(1→4, 300 · 1,000 · 3,000 임시) · 영구 대기 단축(5단계, 값 지수 임시) · 도감 짝 구매(150 / 750 임시) · 설비(담장·바닥·수집기·먹이 공급기·제작·판매 자동화 설비) · 농장 확장 · 바닥 깔기 |
| 찹쌀이 도감 · 떡 레시피 도감 | 처음 얻을 때 / 처음 만들 때 열림 | 목표이자 보상. 열리면 1·2단계 일반 종 구매 가능 / 떡 제작 가능 | 없음 — 진행표라 배수구가 없어도 된다. 24칸이 상한이자 끝 |
| 시간(방치) | 접속 안 한 시간 | 재료 · 합성 완료 · 번식 | 재료 상한에 닿으면 이후 시간은 버려짐 |

- 「먹이」는 자원이 아니다. 먹이 공급기라는 설비만 있다 (2026-09-07 사용자 결정. 축 셋에 맞춘다).
- 찹쌀이가 넘치면 보관함에 두고, 보관함에서 팔기와 일괄 팔기를 한다 (2026-09-07 사용자 결정). 보관함 상한·UI 는 농장 설계 때 정한다.
- 재료는 찹쌀가루(바탕)와 부재료(소·고물)로 나눈다 (2026-09-07 사용자 결정). 가루를 거쳐 가는 변환 단계로 두지 않는다 — 코어 고리가 한 칸 늘고 조합 정보가 사라진다.
- 떡 제작·판매는 초반엔 손으로, 골드가 모이면 설비를 사서 자동화한다 (2026-09-07 사용자 결정). 자동화 뒤에도 합성 걸기와 떡 레시피 발견은 손으로 남는다. 자동화 시점은 물음 1 결과 뒤에 정한다.
- 계속 사는 골드 소비처는 합성소(칸·영구 단축)와 도감 짝 구매에 몬다 (2026-09-08 사용자 결정). 즉시 완료·광고·소모품은 안 쓴다. 상세는 `03-시스템-합성소.md` 5·6절.
- 재료 상한은 전체 합이 아니라 **재료별**로 둔다. 찹쌀가루는 모든 찹쌀이가 뱉으니 상한을 부재료보다 훨씬 크게 잡는다 (2026-09-09 사용자 결정. q2 프로토의 상한 60 이 전체 합이라 개별 상한으로 오해했다).
- 부재료 이름은 계열 이름이 아니라 **식재료답게** 짓는다 — 뜨거운 지역 찹쌀이는 매운·뜨거운 재료, 물 지역은 차가운 재료 같은 식 (2026-09-09 사용자 아이디어. 재료 종류표는 가판대 설계에서 정한다).
- 칸 4·단축 5단계를 다 사면(사람 판에서 게임 96분) 골드 소비처가 합성뿐이라 다시 고인다 (q2 2판 · mem `20260909-84384f61`). 그 뒤 소비처 후보 : 농장 업그레이드(번식 속도·수용 상한) · 가판대 강화 · 농장 확장·바닥. 값 눈금은 가판대 설계 뒤에 정한다.

### 함정 검사

| # | 검사 | 결과 |
| --- | --- | --- |
| 1 | 찹쌀이 배수구 | 합성 + 보관함 팔기 둘. **통과** |
| 2 | 재료 배수구 | 찹쌀가루는 모든 레시피에 쓰이니 안 고인다. 검사할 것은 부재료뿐 — 레시피 설계에서 「모든 부재료가 최소 한 레시피에 쓰인다」 규칙이 필요하다. 안 그러면 안 쓰이는 부재료가 고인다. 가판대는 아직 미정 |
| 3 | 성격 같은 원천 둘 — 찹쌀이 얻기 : 번식(공짜) vs 도감 짝 구매(골드) | 구매는 「새 종 짝 맞추기(1마리 → 2마리) + 마지막 2마리를 다 썼을 때 구제」로 역할을 못 박는다. 그러면 함정이 아니다 |
| 4 | 골드 원천이 판매 하나 (잉여 찹쌀이 팔기는 보조) | 가판대 눈금 하나가 경제 전부를 좌우한다. 물음 1 이 그 위에 선다. 자동화 설비가 큰 덩어리 배수구다 |
| 5 | 재료 상한에 닿으면 손해 | 기둥 「접속 강요 안 함」과 살짝 부딪힌다. 수집기가 있으면 풀리는데 수집기가 모은 재료의 상한은 미정. 물음 후보 Q8 로 다음 판에 잰다 |
| 6 | 골드 고임 (1판에서 40% 남음) | 계속 사는 소비처 셋(칸·단축·짝)을 넣었다. 값이 지수라 상한에 닿기 전까지 고이지 않는지 5단계에서 잰다 |
| 7 | 짝 구매가 합성을 시시하게 하나 | 값은 그 단계 합성비 ×1.5 · 3단계와 변종은 안 판다 · 「처음 얻기」는 여전히 합성뿐. 기준 「구매 횟수 ≤ 합성 횟수」로 5단계에서 잰다 |
| 8 | 소비처를 다 산 뒤 골드 고임 | q2 2판 사람 판에서 확인 (게임 235분에 25% 남음). 농장 업그레이드·가판대 강화를 다음 소비처로 둔다. 눈금은 가판대 설계 뒤 |

## 4. 합성과 떡 레시피 발견 — 두 축

| | 합성 | 떡 레시피 발견 |
| --- | --- | --- |
| 무엇 | 찹쌀이 2마리 → 새 찹쌀이 | 찹쌀가루에 부재료를 골라 넣어 「어떤 조합이 어떤 찹쌀떡이 되나」를 알아낸다 |
| 표 | 합성표는 도감에 다 보인다 (안 숨김) | 떡 레시피는 숨긴다 |
| 운 | 확률 있음 + 대기 시간 | 확률 없음, 즉시 결과 |
| 재미 | 「기다렸다 열어 보는 뽑기 + 계열 트리 오르기」. 운과 시간 | 「생각해서 맞히기」. 지식과 재료 |

- **방식** (2026-09-07 사용자 결정) : 조합을 시도한다. 실패하면 「평범한 떡」이 나온다 — 팔 수는 있으니 벌칙이 아니다. 힌트는 이번 판엔 안 둔다.
- **루프 위치** : 코어에서 「재료 줍기 → 떡 만들기」 사이 한 칸. 하루에서 「새 찹쌀이 → 새 재료 → 새 레시피 시도 → 도감」으로 하루 고리를 닫는 마지막 칸. 메타에서 떡 레시피 도감 완성.
- **둘은 맞물린다** : 합성이 열쇠(새 재료)를 주고 레시피가 자물쇠(새 떡)다. 합성만 있으면 「찹쌀이 얻고 끝」, 레시피만 있으면 「재료가 안 늘어 금방 바닥」이라 같은 무게로 둔다.
- **낱말** : 「합성표」(찹쌀이, 안 숨김)와 「떡 레시피」(찹쌀떡, 숨김)로 가른다. `03-시스템-합성소.md` 의 「레시피를 숨기지 않는다」는 합성표 이야기다.

## 5. 1판 물음 결과와 2판 물음

### 1판 물음 (2026-09-07 사용자가 셋을 골랐다 · 2026-09-08 판정)

| 물음 | 판정 기준 | 판정 |
| --- | --- | --- |
| 1. 재료 → 골드 → 합성 → 재료 고리가 닫히나 | ① 30분 플레이에서 골드 0 에 붙어 멈춘 시간 3분 이하 ② 「다음에 뭐 하지」 하고 멈춘 횟수 2회 이하 ③ 30분 안에 합성 3회 이상 걸었다 ④ 끝나고 한 판 더 생각이 든다 (예/아니오) | **불통** (q1-1). ①③ 통과 · ②④ 불통. 고리는 닫히지만 돌릴 이유가 없다 → 1-1 절 |
| 2. 재료 조합으로 떡 레시피를 찾는 것이 재미인가 노가다인가 | ① 찹쌀가루 + 부재료 4종으로 10분 안에 새 레시피 2~4개 찾는다 ② 같은 실패 조합을 3번 넘게 반복하지 않는다 ③ 「힌트가 있어야겠다」 (예/아니오) ④ 끝나고 「하나 더 찾고 싶다」 (예/아니오) | **통과** (q1-2). 부재료 4종은 1.5분에 6개가 다 찾혀 너무 쉽다. 다음 판 조건 : 부재료 6종 이상 · 해 본 조합 표시 · 3재료 힌트 |
| 3. 「다른 계열 20%」로 3단계까지 평균 몇 번 합성하나 | ① 1000회 시뮬 평균 12회 이하 ② 늪 첫 마리까지 평균 횟수를 잰다 (숫자) ③ 60분 눈금에서 변종 1~3마리 | **통과** (q1-3). ③ 을 위해 변종 5% → 15% |

- **왜 이 셋이었나** : 1 은 코어 고리 그 자체다 (가판대 눈금이 없어 골드 수입은 임시 숫자로 박고 구조만 본다. 손 제작·손 판매만으로 만든다). 2 는 새 축인데 검증된 것이 0 이다 (골드는 빼서 1 과 안 얽힌다). 3 은 메타 루프 길이다 (씨앗 난수만 있으면 되니 가장 싸다).
- 셋은 코어·하루·메타 층에 하나씩이고, 종류도 경제·발견·뽑기로 갈린다. 서로 얽히지 않는다.
- 「아니오」 물음은 없다. 화면 알아보기·손맛 물음은 8단계 세로 조각으로 미룬다.
- **q1-2·q1-3 은 다시 안 잰다.** 2판에서 다시 재는 것은 q1-1 자리(고리) 뿐이다.

### 2판 물음 초안 (4단계에서 확정)

기준은 느낌이 아니라 **기록으로 재는 것**으로 둔다 (1판 기준 ② 는 느낌 5회와 화면 근사 70회가 너무 달랐다).

| 물음 | 기준 초안 (기록으로 재는 것) |
| --- | --- |
| 골드가 고이지 않나 | 30분 뒤 「남은 골드 ÷ 번 골드」 20% 이하 (q1-1 은 40%) |
| 대기가 정지가 아닌가 | 30분에 5분 건너뛰기 20회 이하 (q1-1 은 16분에 70회) · 합성 2칸 이상 동시에 돈 시간 비율 50% 이상 |
| 새 종이 병목이 아닌가 | 새 종을 얻고 짝(2마리째)까지 게임 시간 10분 이하 · 짝 구매가 골드 유출의 20~40% |
| 짝 구매가 합성을 시시하게 만들지 않나 | 구매 횟수 ≤ 합성 횟수 |
| 한 판 더 | 예/아니오 · 질린 시점(분) |

- **2판 판정 (2026-09-09, 사람 판)** : 두 물음 다 **통과**. 눈금 둘을 바꿨다 — 「합성 2칸 이상 동시 50%」는 게임 **60분** 시점으로, 「짝 구매가 골드 유출의 20~40%」는 「새 종 중 짝 산 비율 50% 이상 · 짝 구매 골드 ≤ 합성 골드의 30%」로. 기록은 `Prototypes/2026-09-08-q2-골드고리2판/결과.md`.
- 「한 판 더」는 **아니오** — 도감 15칸을 다 채워서다. 고리가 멈춘 것이 아니라 컨텐츠 양이 다한 것이라 6단계로 넘겼다. 컨텐츠 늘리기 후보는 `03-시스템-합성소.md` 11절.

- **다음 판 후보** (1판에서 이어짐) : Q8 하루에 몇 번 들어오게 만드는 게임인가 · Q2 합성 대기 5분이 한 번 접속과 맞나 · Q5 번식이 합성 소모를 따라잡나 (Q5 는 물음 1 과 얽혀 따로 프로토를 만들어야 한다).
