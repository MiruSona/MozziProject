# 찹쌀이 합성 설계

> 찹쌀이를 어떻게 합성해서 새 종을 얻는지, 종은 몇 가지이고 마릿수는 어떻게 늘리는지를 정한 문서.
> 날짜 2026-09-06 · 마지막 고침 2026-09-09 (컨텐츠 늘리기 후보) · 정한 사람 사용자 + AI · 상태 1차 설계

## 1. 한 줄 요약

찹쌀이 2마리를 합성소에 넣고 골드와 시간을 쓰면 새 찹쌀이 1마리가 나온다. 결과는 「정해진 종 · 다른 계열 · 빛나는 변종」 세 갈래 가운데 하나이고, 실패는 없다. 종은 4계열 × 3단계 = 12종에 변종을 더해 도감 24칸이다.

## 2. 왜 이렇게 정했나

이 게임은 2D 방치형 농장 게임이다. 「찹쌀이」라는 왕관 쓴 떡을 키워 재료를 얻고, 가판대에서 찹쌀떡을 팔아 골드를 번다.

옛 기획(`Docs/Design/농장기획/농장 시스템.md`)에서는 찹쌀이를 **필드에서 잡아왔다.** 이번에 필드 파트를 통째로 빼고 **합성**으로 바꿨다. 혼자 만드는 규모로 줄이려는 결정이다.

합성은 메인 콘텐츠다. 그래서 농장 설비 하나로 두지 않고 **별도 건물 「합성소」**로 뺀다.

몬스터 합성 게임들을 조사한 결과(`Docs/Research/2026-09-06-몬스터합성조사.md`)에서 가져온 것과 버린 것은 아래와 같다.

| 가져온 것 | 버린 것 |
| --- | --- |
| 결과 종은 고정 레시피 | 실패하면 재료를 잃는다 |
| | 10단계 깊이 · 수백 종 규모 |
| | 별도 소모 아이템 |

## 3. 찹쌀이 종 격자

계열 3 × 단계 3 = 9종에, 숨은 교차 계열 「늪」 3종을 더해 **12종**이다. 종마다 「빛나는 변종」이 하나씩 있어 도감은 **24칸**이다.

| 계열 | 바닥 | 1단계 | 2단계 | 3단계 |
| --- | --- | --- | --- | --- |
| 잔디 | 잔디 | 흰찹쌀이 | 풀찹쌀이 | 나무찹쌀이 |
| 물 | 물 | 물찹쌀이 | 파도찹쌀이 | 상어찹쌀이 |
| 용암 | 뜨거운 바닥 | 불찹쌀이 | 용암찹쌀이 | 화산찹쌀이 |
| 늪 (숨은) | 늪 | 늪찹쌀이 | 이끼찹쌀이 | 악어찹쌀이 |

- 이름은 전부 **자리표시**다. 나중에 바꾼다.
- 단계가 오를수록 더 희귀한 재료를 뱉고, 생산 주기가 길어진다. 옛 기획의 「희귀할수록 느리다」를 단계에 얹은 것이다.
- 첫 판은 이 규모로 간다. 재미있으면 계열을 늘린다.

## 4. 합성 규칙

### 재료

- 찹쌀이 **2마리**.
- 슬롯 순서는 한 곳에서만 영향을 준다 — 계열이 다른 둘을 넣을 때 ① 정해진 종의 계열은 **첫 슬롯**을 따른다 (「교차 합성」 절). 순서마다 다른 종이 나오는 레시피는 종 수가 두 배로 늘어서 넣지 않는다.
- **실패 없음.** 재료는 항상 소모되고, 결과는 항상 1마리 나온다.

### 결과 세 갈래

| 갈래 | 무엇이 나오나 | 눈금 (임시) |
| --- | --- | --- |
| ① 정해진 종 | 레시피대로. 같은 계열 같은 단계 2마리 → 그 계열 다음 단계 | 65% |
| ② 다른 계열 | 재료와 다른 계열의 **1단계**. 열린 계열 가운데 랜덤 | 20% |
| ③ 빛나는 변종 | ①과 같은 종의 빛나는 변종 | 15% |

눈금은 임시다. 프로토타입에서 「3단계까지 평균 몇 번 합성하나」를 재고 조정한다.
변종 확률은 2026-09-08 q1-3 시뮬 뒤 5% → 15% 로 올렸다 (임시값). 근거는 `Prototypes/2026-09-07-q1-3-합성횟수/결과.md`.

- **②가 1단계인 이유** : 새 계열의 씨앗 한 마리를 주는 것이 목적이다. 키우려면 그 계열 바닥과 농장이 필요하니 확장 동기가 된다. 같은 단계로 주면 새 계열 트리를 건너뛰게 된다.
- **②의 「열린 계열」** : 처음엔 잔디·물·용암 셋이다. 늪은 ②로 나오지 않고 교차 합성으로만 처음 열린다. 한 번 열리면 ② 후보에 늪도 들어간다. 숨은 계열이 뽑기가 아니라 **발견**이 되게 하려는 것이다.
- **3단계 2마리 합성** : 다음 단계가 없으니 ② 또는 ③만 나온다. 눈금은 임시로 60 / 40. 3단계끼리 합성이 「변종 뽑기」 역할을 한다.

### 교차 합성

계열이 다른 둘을 넣으면 ①의 정해진 종이 아래 표대로 바뀐다. ②·③ 갈래는 그대로다.

| 조합 | 정해진 종 |
| --- | --- |
| 잔디 + 물 (둘 다 2단계 이상) | 늪 1단계 |
| 그 밖의 다른 계열 조합 | 첫 슬롯 계열의 다음 단계 |

### 시작 상태

- 흰찹쌀이 2마리, 잔디 농장 1개, 합성소는 처음부터 열려 있다.
- 물·용암 바닥은 골드로 깔 수 있지만, 그 계열의 첫 찹쌀이는 ② 갈림으로만 처음 얻는다.
- 시작 2마리로 첫 합성을 하면 65% 풀찹쌀이, 20% 물찹쌀이 또는 불찹쌀이가 나온다. 바로 「다른 바닥이 필요하다」를 보여준다.
- 튜토리얼에서 **합성 전에 번식으로 늘려 두는 것이 유리하다**고 알린다.

## 5. 비용과 시간 · 합성소 성장

### 비용

- 골드 + 대기 시간 **둘 다** 쓴다.
- 값은 **재료 단계**로 정한다. 결과 종 단계가 아니다. 교차든 같은 계열이든 재료가 같으면 값도 같다. 단계가 섞이면 낮은 쪽 기준이다.
- 눈금은 전부 **임시**다. 가판대·농장 설계에서 시간당 골드 수입이 나오면 그때 확정한다 (사용자 결정 2026-09-06).

| 재료 단계 | 골드 (임시) | 대기 시간 (임시) |
| --- | --- | --- |
| 1단계 2마리 | 100 | 5분 |
| 2단계 2마리 | 500 | 30분 |
| 3단계 2마리 | 2,000 | 2시간 |

- 합성소는 기본 1칸이고, 칸을 사면 최대 4칸이 동시에 돈다 (아래). 농장은 평소대로 돈다.
- 골드로 즉시 완료는 없다. 과금이 없으니 시간이 진짜 비용이다.

### 합성소 업그레이드

축은 「동시 합성 칸」과 「영구 대기 단축」 둘이고, 따로따로 골드로 산다. 둘 다 **계속 사는 골드 소비처**다 — q1-1 에서 골드가 40% 고인 것을 풀려고 2026-09-08 에 이렇게 바꿨다 (근거 `Docs/Research/2026-09-08-골드소비처와합성병목조사.md`). 값은 전부 임시다.

| 칸 확장 | 값 (임시, ×3) |
| --- | --- |
| 1칸 (기본) | — |
| 2칸 | 300 |
| 3칸 | 1,000 |
| 4칸 | 3,000 |

| 영구 단축 단계 | 대기 시간 | 값 |
| --- | --- | --- |
| 0 (기본) | 100% | — |
| 1 ~ 5 | 90% → 80% → 70% → 60% → 50% | 단계마다 지수로 오른다 (눈금 미정, 임시) |

- 단축은 합성 칸 전부에 걸린다. 50% 가 상한이다.
- 옛 1차 설계(3단계 · 칸 3 · 대기 75%/50%)는 이것으로 덮는다.
- **레어 확률 업그레이드는 없다.** 확률이 성장 축이 되면 「업그레이드 전엔 합성 말자」가 되어 초반이 지루해진다.
- **다시 볼 것 (2026-09-09)** : 사용자가 「합성소 업그레이드에 변종 확률 증가」를 냈다. 위 이유와 부딪히니, 넣는다면 단축 5단계를 다 산 뒤에 열리는 마지막 축으로 두어 초반 「합성 말자」를 피하는 안이 있다. 확정 아니다.

## 6. 마릿수가 늘어나는 통로

합성은 2마리 → 1마리라 마릿수가 줄어든다. 늘어나는 통로는 둘이다.

### 번식

- 같은 농장에 같은 종이 2마리 이상이면 번식 시계가 돈다. 차면 그 종 1마리가 태어난다.
- 종마다 주기가 다르고, 단계가 오를수록 길다. 눈금은 농장 설계 때 정한다.
- 빛나는 변종끼리는 번식하지 않는다. 변종 + 일반 = 일반. 변종은 **합성으로만** 얻게 해 도감 가치를 지킨다.
- 농장 수용 상한(담장 10~20마리)에 닿으면 멈춘다.
- 한 농장에 여러 종이 섞이면 종마다 따로 센다.

### 가판대 구매 (도감 짝 구매)

- 도감에 열린 **1·2단계 일반 종**을 골드로 산다. 값은 그 단계 합성비 ×1.5 = 1단계 150 · 2단계 750 (임시).
- **3단계와 변종은 팔지 않는다** (2026-09-08 결정, mem `20260908-f4838ff4`). 옛 결정 「1단계만 판다」를 덮었다. 이유 : q1-1 에서 합성으로 얻은 새 종이 1마리라 2단계조차 짝을 못 모아 번식이 막혔다.
- 늪 계열도 열린 뒤에는 같은 규칙으로 산다.
- 「사는 것보다 번식·합성이 싸다」를 지킨다. 「처음 얻기」는 여전히 합성뿐이라 도감 재미는 그대로다. 값이 싸서 합성이 시시해지지 않는지는 5단계에서 「구매 횟수 ≤ 합성 횟수」로 잰다.

### 첫 마리를 얻는 길

| 종 | 첫 마리를 얻는 길 |
| --- | --- |
| 잔디 1단계 | 시작 지급 |
| 물 · 용암 1단계 | 합성 ② 갈래 |
| 늪 1단계 | 잔디 2단계 + 물 2단계 교차 합성 |
| 각 계열 2 · 3단계 | 같은 계열 같은 단계 합성 |
| 빛나는 변종 | 합성 ③ 갈래만 |

## 7. 도감

- 24칸. 처음 얻는 순간 열린다.
- 열린 칸에는 그림 · 이름 · 뱉는 재료 · 번식 주기 · 레시피가 보인다.
- **레시피를 숨기지 않는다.** 숨은 것은 늪 계열의 존재뿐이고, 늪 첫 마리를 얻는 순간 레시피가 드러난다.
- 도감 완성률이 장기 목표다. 옛 기획에 없던 「끝」이다.

## 8. 합성소 화면 흐름

1. 합성소 건물을 누른다 → 합성 화면이 열린다.
2. 슬롯 두 개에 찹쌀이를 고른다. 목록은 농장별로 묶고, 합성 가능한 것만 밝게 보인다.
3. 「나올 수 있는 결과」 미리보기. 세 갈래를 확률과 같이 보여준다. 확률은 감추지 않는다. **단 도감에 안 열린 종은 그림·이름을 ??? 로 감춘다** (발견 재미).
4. 골드를 내고 시작한다. 재료가 빠지고 시계가 돈다.
5. 차면 건물 위에 알림이 뜬다. 누르면 결과 연출 → 새 찹쌀이가 「보관함」에 들어간다.
6. 보관함에서 농장으로 옮긴다. 맞는 바닥 농장이 없으면 「물 바닥이 필요해요」 안내를 띄운다.

### 보관함

- 농장에 못 넣은 찹쌀이가 머무는 곳. 재료를 뱉지 않고 번식도 하지 않는다.
- **상한 · UI · 옮기는 방식은 아직 안 정했다.** 농장 설계 때 같이 정한다 (mem todo 20260906-592f5268).

## 9. 위험과 대비

| 위험 | 대비 |
| --- | --- |
| 재료 2마리를 다 써 농장이 빈다 | 합성 화면에서 「이 농장 마지막 2마리예요」 경고. 튜토리얼에서 번식 먼저 |
| ② 다른 계열이 너무 자주 나와 원하는 단계가 안 오른다 | 20% 는 임시. 프로토타입에서 「3단계까지 평균 몇 번」을 재고 조정 |
| 3단계 이후 할 일이 없다 | 3단계끼리 합성 = 변종 뽑기. 도감 완성이 끝 |
| 그림 24장 + 4계열 설비 | 변종은 팔레트만 바꾼다. 늪 계열 설비 3종은 뒤로 미룰 수 있다 |
