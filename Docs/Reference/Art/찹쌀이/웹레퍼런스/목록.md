# 찹쌀이 웹 레퍼런스 목록

**이 폴더는 읽기 자료다. 게임에 그대로 넣지 않는다.** 생김새·색 나누기·동작 타이밍을 보고 찹쌀이를 새로 그린다.

- 모은 날 : 2026-09-08
- 찹쌀이 확정 모습 : 왕관 쓴 흰 찹쌀떡 (`../Front.png`). 종 표는 `Docs/Design/03-시스템-합성소.md` 3절.

- 라이선스는 **참고용이라 상관없지만** 페이지에서 확인한 것만 적었다. 못 본 것은 「모름」.

## 4. 못 찾은 것

- **합성 연출**(둘이 합쳐져 하나 되는 GIF) — 무료 에셋으로는 없었다. `슬라임_탑다운_통에들어가기` 가 가장 가깝다. 머지 계열 모바일 게임 스토어 화면을 따로 봐야 한다.
- **빛나는(샤이니) 변종** 표현 — 무료 에셋으로 못 찾았다. 포켓몬 색차 변종처럼 「같은 모양·다른 팔레트 + 반짝이 파티클」로 가면 될 듯.
- **먹기·자기** 동작 — 슬라임 에셋은 대부분 공격·죽음 위주라 없었다.
- **모찌·떡 캐릭터** 자체는 무료 에셋이 없고 벡터 스톡·AI 생성물뿐이라 뺐다.
