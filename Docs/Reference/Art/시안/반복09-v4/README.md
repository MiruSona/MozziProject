## 짜는 법 (`build_mock.py`)

- v3 `build_mock.py` 의 함수(바탕 · 칸 · UI)를 불러 쓰고 천장만 덮는다. 새로 칠한 것은 없다 — 자르기 · 되풀이 · 배치 · 정수배 확대 · 글자뿐.
- 천장 바탕은 2배, 등은 3배로 키웠다. 천장 아래 끝은 윗벽장 위 끝(y 250)에 맞췄다.
- 등은 칸마다 x 120 · 270 · 420 에 둔다. 칸 경계(540 · 1080)에서 잘리지 않는다.
- C3 은 덕트 · 크림 띠(조각의 윗부분)만 쓰고, 그 아래는 **지금 벽 타일**을 위로 이어 깔았다. 타일 크기가 벽과 똑같다.

## 흠

1. **돈 표시 뒤에 옛 자주색 천장이 비친다.** 캡처에서 오려 붙인 반투명 판이라 그렇다. 게임에서는 새 천장이 비친다.
2. 조각 둘레에 흰 여백이 있어 그림 부분만 오려 썼다. 2배로는 높이가 모자라 C1 은 민무늬 줄을, C2 는 널 한 장을 한 번 더 쌓았다.
3. 바탕은 거울 되풀이(약 450~480px 주기)로 이었다. C2 의 옹이 · C3 의 덕트 받침쇠가 좌우 대칭으로 되풀이된다. 정식에서는 540 폭에 맞춰 다시 뽑는 것이 좋다.
4. 도트 배율이 섞였다 (천장 2배 · 등 3배 · 벽 1배). 앞 판부터 있던 흠이다.
5. 스타일 참고 그림은 넣지 않고 글로만 색 · 선을 맞췄다. C2 널이 윗벽장보다 한 톤 짙다.
6. C3 은 등 줄이 덕트 앞을 지난다. 등 갓도 다른 둘보다 작다.

## 함정

- `create_image_pro_flash` 에 `no_background=false` 로 바탕 조각을 뽑아도 **둘레 7~16px 가 흰 여백**으로 나온다. 256×128 을 시켜도 쓸 수 있는 그림은 240×100 쯤이다. 그대로 깔면 천장과 윗벽장 사이에 흰 줄이 생긴다 — 줄 · 열 밝기를 재서 오려 쓴다.
- 256×128 조각 둘의 예상 대기가 450초로 떴지만 실제로는 30초 안에 끝났다.
