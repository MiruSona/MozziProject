## 알고 있는 흠

- **스타일 참고 그림을 안 넣었다.** 우리 배경을 참고로 넣지 않고 글로만 뽑아, 선 굵기와 색이 기구 그림과 조금 다르다. 정식 판에서는 우리 그림을 참고로 넣어 다시 뽑는다.
- **벽 · 조리대는 256 너비 조각을 좌우로 뒤집어 이은 것이다.** 같은 무늬가 거울처럼 되풀이된다. 정식 판은 한 장으로 그려야 한다.
- 벽 아래쪽은 조각의 띠를 세로로 되풀이해 채웠다. 2안은 기둥 줄이 어긋나 보인다.
- 1 · 2안의 서랍장은 다리 달린 그림을 벽에 올려 떠 보인다. 고르면 받침 선반을 그리거나 서랍장을 조리대 위에 세우는 판을 다시 본다.
- 화덕은 따로 안 그렸다. 찜기 그림에 붙은 검은 솥이 화덕 노릇을 한다.
- 그릇(`kitchen_bowl`)과 빚는 떡(`kitchen_shape_*`)은 올리지 않았다. 서랍장 칸의 재료 그림도 없다(코드가 그리는 것이라).
- 색 수 검사는 안 돌렸다. 한 장에 1,350~1,440 색이라 통과 못 한다.
- `__pycache__/` 는 스크립트를 돌리다 생긴 것이다. 지워도 된다.
