## 알고 있는 흠

1. **스타일 참고는 그림 크기가 캔버스보다 크면 안 받는다.** 256 벽을 128 기구의 참고로 넣었더니 여덟 장이 다 거절됐다. 그래서 기구는 같은 색 · 선 낱말(짙은 갈색 1px 선 · 따뜻한 크림 · 밝은 나무)만 되풀이했다. 정식 때는 참고 그림을 128 로 잘라 넣는다.
2. A · B 는 조리대와 기구가 **2배(절구는 B 에서 3배) 확대**라 도트가 2~3px 이다. 벽은 1배라 굵기가 섞여 보인다. 정식에서는 제 크기로 그린다.
3. 벽 타일은 아래 48px 띠를 되풀이해 채웠고, 벽 · 조리대는 거울로 이어 붙였다. 가까이 보면 되풀이가 보인다.
4. 안내 글은 지금 것(「서랍에서 재료를…」) 그대로다. 단계에 맞게 안 바꿨다.
5. A 의 작업면 흰 테는 「여기가 작업면」을 알리는 표시다. 게임에 들어갈 그림이 아니다.
6. 견줌판의 그림은 절반 크기로 줄인 것이다. 도트는 낱장 파일로 본다.
7. 화구 · 대리석 판 · 쟁반의 보는 각도가 조금씩 다르다 (비스듬히 놓였다). 정식에서 맞춘다.
