## 흠

1. **S2 는 병을 줄이지 않았다.** 2배 병 그대로 8칸이 벽에 들어가서(폭 422) 1배로 줄일 까닭이 없었다. 1배 병은 폭이 24px 쯤이라 손가락으로 누르기 어렵다.
2. S1 · S2 의 셋째 줄과 S2 의 오른쪽 칸은 같은 병을 되풀이한 것이다. 정식 때는 재료마다 병을 따로 그린다.
3. 세 줄 선반은 윗벽장 바로 아래부터 조리대까지 벽을 꽉 채운다. 쪽 점(● ○)은 조리대 뒤쪽 가장자리에 얹혔다.
4. 전기 찜기는 닫힘과 열림을 따로 뽑아 본체 모양이 조금 다르다. 정식 때는 닫힌 그림을 고쳐서 열림을 만든다.
5. 스타일 참고 그림을 못 넣었다 (아래 함정). 글 낱말로만 색 · 선을 맞췄다. 믹서기 · 분쇄기는 v2 기구보다 옆에서 본 각도에 가깝다.
6. 칸2 벽 장식(화분 선반 · 도구 줄)은 번호로 고르는 것이 아니다. 빼거나 바꿔도 된다.
