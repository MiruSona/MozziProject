## 흠

1. **W1 · W3 은 등이 둘이다.** 보가 한 칸에 안쪽 둘뿐이라 「등은 보에 단다」를 지키면 120 · 270 · 420 자리를 못 쓴다.

   한 화면씩 볼 때는 안 보이고, 옆으로 넘기는 동안에만 보인다. W2 도 경계에서 널 줄이 꺾인다.
3. W1 은 받침과 줄이 짙은 보에 묻혀 거의 안 보인다. W2 도 바탕이 어두워 등이 약하다.
4. 천장은 3배, 벽 · 조리대는 1배라 도트 굵기가 다르다 (앞 판부터 있던 흠이다).
5. 정식 그림이 아니다. 고른 뒤 한 칸 폭(540)에 맞춰 다시 그려야 한다 — 그때 2번도 함께 푼다.
