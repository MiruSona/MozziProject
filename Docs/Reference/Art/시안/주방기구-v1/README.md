## 정식 판에서 조심할 것

- **크기** : pro_flash 는 캔버스 한 변이 256 까지라 **서랍장 238×284 를 한 장에 못 뽑는다.** 길 둘 — ① 238×256 쯤으로 뽑고 받침 줄을 PIL 로 이어 284 로 늘리기(`arttool extend`) ② 칸 앞면 50×80 + 몸 틀을 따로 뽑아 PIL 로 맞추기. 칸 자리(302+열×56, 480+줄×92)에 칸이 정확히 와야 하므로 **②가 안전하다.**
- 받은 그림은 캔버스보다 **10~40% 작게 온다** (「fills the whole canvas edge to edge」를 넣어도). 빚기판은 높이 49/80. 캔버스를 키워 뽑거나 `KitchenLayout` 의 자리 값을 그림에 맞춰 줄이는 쪽을 코드 갈래와 정한다.
- **색 수** : 찜기 · 그릇 A 가 48 을 넘었다. shading 을 끄고 「simple, no dithering」을 넣은 절구 C 는 49 → 43, 청록 바탕으로 받은 절구 B 는 32 였다. 정식 판에서는 이 글귀를 쓰고 `check --profile mozzi_prop` 으로 잰다.
- **절구 연출** : 쉼 자세가 「머리를 쌀 위에 얹음」이라 치기 동작은 「들어 올렸다 내려침」으로 뽑는다 (`animate_image`, first_frame = 고른 쉼 그림). 반죽이 단계마다 매끈해지는 것은 쌀 자리만 inpaint 로 3~4 단계를 뽑는 길을 권한다.
- **PixelLab 함정**
  - 흰 쌀처럼 밝은 면이 큰 그림은 `no_background=true` 에서 「바탕 지우기가 그림을 다 지웠다」로 **실패할 수 있다** (값은 안 빠진다). `false` + 바탕색 지시로 받으면 되는데, 바탕이 **한 색이 아니라 옅은 그러데이션**으로 온다 → `arttool cutout --key edge` 가 거의 못 지운다(관용 40 에도). 색상(파랑 − 빨강 > 12)으로 가장자리부터 번지게 지웠다.
  - 어림 회수(`estimated_generations`)와 실제 차감이 이번엔 같았다 (pro_flash 240×256 = 9, 152×140 · 152×80 · 112×36 = 6).
