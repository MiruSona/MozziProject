### 만든 법 (다시 뽑고 싶을 때)

- PixelLab `create_image_pixflux` · 360×400 · `view=low top-down` 또는 `side` · `outline=lineless` · `shading=basic shading` · `isometric=false`.
  씨앗 : 가판대 A 2003 · 가판대 B 1009 · 합성소 A 1013 · 합성소 B 2019.
- **`low top-down` 으로 실내를 부탁하면 아이소메트릭 방이 나왔다** (카페·솥 1판). 「straight-on front view · camera facing the back wall · no isometric angle」을 글로 넣고 `view=side` 로 다시 뽑으니 정면이 나왔다.
  정면판은 건물만 그리고 바깥을 회색으로 비워 둬서, 회색을 PIL 로 벽·바닥 색으로 메웠다.
- 합성 스크립트(PIL)는 세션 스크래치패드에서 돌렸다 — 배경 + Resources 그림 + UI 자리표시. 다시 필요하면 이 README 의 자리 설명대로 다시 짠다.

### 만든 법 (반복 02)

- 배경은 `create_image_pixflux` 360×400 · `view=side` · `lineless` · `basic shading`. 가판대 씨앗 2003, 합성소 씨앗 3212, 기계 씨앗 1013(208×224).
- **합성소는 「cozy back kitchen」으로 쓰면 또 아이소메트릭 방이 나왔다.** 글머리에 「flat 2D side-scroller game background, flat elevation of one back wall only, no side walls, no ceiling, no perspective」를 넣으니 정면이 나왔다.
- 「no bottles」를 적어도 선반에 병이 나왔다 → 선반 자리만 `inpaint_image` 로 「시루 · 그릇 · 떡 접시 · 쌀자루, no bottles」로 다시 그렸다 (한 번에 됨).
- 360×800 은 PIL 로 늘렸다 — 위는 맨 윗줄 색을 120px, 아래는 바닥을 280px 이어 붙였다. 가판대는 차양을 44px 올리고 칠판 윗부분·시계를 PIL 로 다시 그렸고, 유리 진열장을 가로로 늘려 모니터를 덮었고, 타일에 체크 무늬를 입혔다.
- 기계는 `no_background=true` 인데도 배경이 불투명 흰색으로 왔다 → 모서리에서 flood fill 로 뺐다.

### 만든 법 (가판대 주인)

- PixelLab `create_image_pixflux` · `view=side` · `direction=south` · `outline=single color black outline` · `no_background=true`. 이번에는 투명 배경이 제대로 왔다.
- 글머리 공통 : 「cute chibi girl cafe shopkeeper … long pastel pink hair, dark navy beret with a small pale pink cherry blossom ornament, big purple eyes, small red diamond mark on her cheek under one eye, black choker, white blouse, cream cafe apron, dark navy skirt」.
  - A : 48×64 · 씨앗 **4111** · `flat shading` · `low detail` · 앞에 「tiny super-deformed chibi, 2 heads tall, very big round head, tiny stubby body, simple dot eyes」.
  - B : 64×80 · 씨앗 **4201** · `basic shading` · 「full body, 2.5 heads tall chibi, light lavender boots」.
  - C : 64×64 · 씨앗 **4301** · `basic shading` · 「upper body bust only from the waist up」.
- **우리 손님 그림을 `init_image` 로 넣은 판(강도 120·200)은 손님이 거의 그대로 나왔다** (갈색 머리·빨간 옷). 강도 50 은 바뀌지만 등신이 손님과 달라졌다. 손님 화풍에 정확히 맞추려면 손님 겹(body·hair) 위에 PIL 로 그리는 쪽이 낫다.
- AI 는 볼 다이아를 못 그렸다 → PIL 로 `#FA6270` 5px 마름모를 찍고, 자줏빛 눈동자의 색상만 `#AE74DB` 쪽으로 돌렸다.
