### 만든 법 (다시 뽑고 싶을 때)

- PixelLab `create_image_pixflux` · 360×400 · `view=low top-down` 또는 `side` · `outline=lineless` · `shading=basic shading` · `isometric=false`.
  씨앗 : 가판대 A 2003 · 가판대 B 1009 · 합성소 A 1013 · 합성소 B 2019.
- **`low top-down` 으로 실내를 부탁하면 아이소메트릭 방이 나왔다** (카페·솥 1판). 「straight-on front view · camera facing the back wall · no isometric angle」을 글로 넣고 `view=side` 로 다시 뽑으니 정면이 나왔다.
  정면판은 건물만 그리고 바깥을 회색으로 비워 둬서, 회색을 PIL 로 벽·바닥 색으로 메웠다.
- 합성 스크립트(PIL)는 세션 스크래치패드에서 돌렸다 — 배경 + Resources 그림 + UI 자리표시. 다시 필요하면 이 README 의 자리 설명대로 다시 짠다.
