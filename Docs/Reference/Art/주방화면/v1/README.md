## 결론

- **새 레시피를 찾는 화면이다.** 가판대 화면의 「주방」 아이콘으로 들어온다 (사용자 확정).
- 작업대 위 재료 칸 여섯에서 1~3개를 골라 큰 절구에 넣고 떡메로 친다. 처음 만든 떡이면 「NEW!」 가 뜬다.
- **이미 찾은 떡은 여기서 안 만든다.** 가판대의 벽 차림표에서 바로 만든다.
- 새 기능은 없다. 지금 게임의 레시피 실험을 화면 하나로 옮긴 것이다.
