# 반 자른 떡 아이콘 레퍼런스 조사 (2026-09-21)

## 결론 먼저

- **웹에서 「작은 픽셀 아이콘의 떡 단면」을 바로 베낄 본보기는 못 찾았다.** 나온 것은 대부분 스톡 판매 페이지(미리보기만 보임)와
  일반 픽셀아트 입문 글이다. 그래서 아래 「가져올 것」은 **여러 단면 일러스트에서 공통으로 보이는 문법 + 작은 스프라이트 일반 원칙**을 합쳐 내가 정리한 것이다.
- 그래도 건진 것이 셋 있다.
  1. 단면 그림의 **정석 구도는 「온전한 한 알 + 잘린 반쪽」 짝**이다. 일본 쪽 대복(大福) 단면 소재가 거의 다 이 꼴이다.
  2. 16px 급 작은 그림은 **속을 색 층 2~3개로 줄여야** 읽힌다 — 피 / 떡살 / 소.
  3. 작은 스프라이트는 **실루엣만으로 알아볼 수 있어야** 하고, 색은 3~5개에서 시작한다.

## 우리 24px 에 가져올 것

| 본 것 | 우리 규칙으로 |
| --- | --- |
| 단면은 「온전한 한 알 + 잘린 반쪽」 짝이 정석 | 구도 후보 둘 중 하나(`setD_split`)를 이 꼴로 잡는다. 다른 하나(`setC_halfmoon`)는 **반쪽 하나만 크게** 보여 24px 에서 속이 넓게 나오는 쪽이다. 어느 쪽이 작은 크기에서 읽히는지를 견준다 |
| 피는 얇은 테두리, 속은 덩어리 하나 | 피 = 바깥 **2px 띠**. 그 안은 흰 떡살, 가운데에 소 덩어리 하나. 층을 3개(피·떡살·소)로 고정한다 |
| 콩은 겉, 팥은 속 | **재료마다 자리를 하나로 못 박는다** (피 / 소 / 고물). 같은 재료는 어느 떡에서나 같은 자리·같은 색으로 나온다 |
| 팥소는 알갱이 점 두엇 | 소 안에 밝은 점 2~3개만 찍어 알갱이를 낸다. 더 찍으면 24px 에서 지저분해진다 |
| 색은 3~5개로 시작 | 장당 3~6색 규칙 그대로. 색이 모자라면 **떡살 색을 피 하이라이트로 같이 쓴다** |
| 실루엣만으로 알아보게 | 반달(아래가 평평한) 실루엣 = 「잘린 떡」이라는 신호다. 통짜 한 알과 한눈에 갈린다 |

## 앞 판에서 이어받는 것

- 밝은 UI(#E8E0D0) 위에서 순백 몸이 묻혔다 → **피를 순백 대신 살짝 따뜻한 흰(#F2E9DC)**으로 하고 그늘을 한 톤 더 준다.
- 깨·잣·콩이 다 누런 계열이라 헷갈렸다 → **자리와 모양으로 가른다.** 콩은 겉 전체를 덮는 가루(피 색 자체가 노래진다), 깨는 겉에 성긴 점, 잣은 속에 박힌 낱알이다.
