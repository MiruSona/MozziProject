## 결론

- **고른 벌은 「가」다** — 256 풀밭 한 장 + 통나무 울타리. 건물과 가장 가까운 화풍이다 (메인 세션이 임시로 고름 · 사용자 미확정).
- v3 에서 바꾼 것은 잔디 · 울타리 · 볼 색(샛노랑)과 건물 사이 틈 · 보관함 자리뿐이다. 건물은 다시 안 뽑았다.

## 후보

| 벌 | 잔디 | 울타리 | 이음매 값 | 본 것 |
| --- | --- | --- | --- | --- |
| 지금 (v3) | 32 타일 3종 | 가는 울타리 | 0.86 | 민무늬라 건물과 화풍이 다르다 |
| **가** | 256 풀밭 한 장 되풀이 | 통나무 | 1.15 | 얼룩 · 풀포기 · 꽃이 손그림처럼 섞인다. 256 마다 되풀이된다 |
| 나 | `create_tiles_pro` 32 타일 | 판자 | 0.96 | 타일 가장자리가 어두워 격자가 보인다. 울타리가 굵다 |
| 다 | 가 의 풀밭을 32 로 잘라 섞기 | 통나무 | 2.02 | 타일 선에서 얼룩이 끊긴다 |
| 라 | v3 바탕 + 새 꾸밈 조각 | 통나무 | 0.24 | 타일 3종 방식과 맞지만 바탕이 여전히 밋밋하다 |

- 이음매 값 = 32 격자 선의 색 차 ÷ 다른 곳의 색 차. 1 에 가까우면 선이 안 보인다. **거친 값이다** — 「나」는 타일 양쪽 가장자리가 다 어두워 값이 낮게 나오지만 눈에는 격자가 보인다.

## 깨끗하지 않은 곳

- **풀색이 v3 의 민트보다 올리브 · 어두운 쪽이다.** 건물과는 맞지만 화면이 조금 가라앉는다.
- **게임은 32 타일 3종을 무게(0.82 / 0.10 / 0.08)로 섞는다. 「가」는 그 방식이 아니다** — 넣으려면 풀밭을 통짜 바탕으로 깔거나, 이음매 없는 32 타일을 다시 뽑아야 한다.
- 통나무 울타리의 기둥 간격은 가로 46 · 세로 37 이라 32 격자에 안 맞는다.
- 아래 울타리가 메뉴 버튼과 펼친 목록에 가린다.
- 판자 울타리는 굵고 모서리 기둥만 있다.
