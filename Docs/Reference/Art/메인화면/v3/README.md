## 뛰는 그림 4장 확인

| 장 | 윤곽 다른 픽셀 | 가장자리 픽셀 중 어두운 선 | 선 회색 (최소 · 가운데값) |
| --- | --- | --- | --- |
| hop0 | 0 | 108 / 114 | 141 · 156 |
| hop1 | 0 | 116 / 116 | 133 · 144 |
| hop2 | 0 | 118 / 118 | 157 · 164 |
| hop3 | 0 | 114 / 114 | 137 · 137 |

- 윤곽은 네 장 모두 지금 그림과 똑같고 선은 맨 바깥 1px 이다.
- **선 회색이 장마다 다르다** (137 ~ 164). 그대로 넣으면 뛸 때 선 밝기가 깜빡일 수 있다 — 넣기 전에 선 픽셀을 한 값으로 맞춘다.
- hop0 은 가장자리 6px 에 선이 안 들었다.

## 깨끗하지 않은 곳

- **울타리는 32 칸으로 「뽑힌」 것이 아니라 잘라 맞춘 것이다.** 136 폭에 기둥 다섯을 주문했는데 그림이 캔버스보다 작게 와 간격이 26px 이었다. 모서리는 겹쳐 놓기만 해서 가로대가 조금 삐져나오고, 세로 울타리는 가늘어 잘 안 보인다.
- 세로 울타리는 통나무 윗면이 보이고 가로 울타리는 앞면이 보여 짜임이 완전히 같지는 않다 (가로대 둘 · 나무색은 같다).
- 건물 둘(470px)과 상자를 540 폭에 넣느라 상자가 화면 오른쪽 끝에 붙고 건물 사이 틈이 없다.
- 합성소 건물이 기계로 바뀌어 v1·v2 의 「집」 모양과 다르다.
- 볼 색 둘은 색만 바꾼 미리보기다. 정식으로는 볼 그림 원본의 색을 바꿔 저장하면 된다 (그림을 새로 뽑을 필요 없음).
