- `create_image_pro_flash` 256 캔버스 · 화풍 그림 = v1 가게 · **「세부 따라 하기」(detail)를 끄고** 글로 「단순하게, 큰 면, 장식 2~3개」 를 시켰다.

## 깨끗하지 않은 곳

- 건물이 작아져 둘 사이 틈이 넓어졌다 (v4 는 10px). 가운데 x 는 v4 와 같다.
- 「가판대」 글자가 가게 가운데보다 왼쪽에 있다 (v4 자리 그대로).
- 왼쪽 손님이 기계 서랍을 조금 가린다.
- 기계 1 의 깔때기가 지금 기계보다 크다. 숲 지평선 위로 올라온다.
- 가게 1 은 지붕이 낮아 지금 가게보다 가벼워 보인다.
