## 찹쌀이 — 겹 구조를 지킨 채 외곽선을 넣을 수 있나

**넣을 수 있다.** 흰 몸 그림에 회색 선과 회색 명암을 넣어 두면, 게임이 종 색을 곱할 때 선이 「그 색의 어두운 선」이 된다.
곱한 결과는 `지난판/찹쌀이/2026-10-03-찹쌀이-새화풍.png` 에 여섯 종으로 계산해 두었다.

| 길 | 결과 | 얼굴·볼·왕관 |
| --- | --- | --- |
| (가) 지금 몸을 글로 고침 | 윤곽이 **한 픽셀도 안 바뀌고**(같은 42×35) 회색 선 1px + 아래·오른쪽 그늘이 들었다. 가장 낫다 | 그대로 맞는다 |
| (나) 새로 뽑음 | 선과 명암은 좋지만 몸이 36×26 으로 작고 납작해졌다 | 얼굴이 몸 밖으로 나가고 왕관이 뜬다 — 겹을 다 다시 맞춰야 한다 |
| (다) 기계적 외곽선 | 선만 생기고 명암이 없다. 뛰는 그림 4장에 한 번에 걸 수 있다 | 그대로 맞는다 |

- 선 회색은 (가) 148~156, (나) 110, (다) 150 이다. **흰 찹쌀이는 곱해도 회색 선으로 남는다** — 건물의 짙은 갈색 선보다 옅다.
  더 짙게 하려면 회색을 110 쯤으로 내리면 되지만 그러면 밝은 종(물)의 선도 같이 짙어진다.
- (가)는 **`body_hop0` 한 장만** 만들었다. `body_hop1~3` 은 아직이다.

## 깨끗하지 않은 곳

- **가로 울타리의 기둥 간격이 37px** 이라 32 칸 격자에 안 맞는다. 목업은 148px 띠를 그대로 이어 붙였다. 게임에 넣으려면 32 격자 조각(위 · 아래 · 옆 · 모서리)으로 다시 뽑아야 한다.
- 세로 울타리는 통나무를 쌓은 모양이라 가로 울타리(가로대 둘)와 짜임이 다르다. 모서리 조각이 없어 귀퉁이에서 그냥 겹친다.
- 풀 타일은 한 종류다. 지금 게임은 3종(무게 0.82 / 0.10 / 0.08)을 섞는다. 풀포기가 줄 맞춰 보인다.
- 밝은 패널의 모서리 장식(네모 못)은 자른 선에서 반쯤 잘렸다.
- 건물 · 숲 · 길 · 버튼은 v1 그대로다. 건물이 규격보다 작은 것도 그대로다.
- `create_topdown_tileset` 으로 풀 → 모래 길 묶음을 뽑았더니 「muted · low saturation」을 적어도 **형광 연두**로 왔다. 버리고 pro_flash 로 풀만 다시 뽑았다.
