## 결론

- **칸 수만큼 기계가 선다.** 자리 넷은 2×2 로 고정이고, 칸을 사면 그 자리에 기계가 들어온다.

## 깨끗하지 않은 곳

- **빈 받침이 기계보다 훨씬 작다** (80px 대 230px). 캔버스를 크게 줬는데 그림이 작게 왔다. 기계 발 크기로 다시 뽑아야 한다.
- 천 덮개 위로 김이 그대로 올라온다. 덮개 색이 밝아 「잠김」보다 「새 물건」처럼 보일 수 있다.
- 찹쌀이가 입구에 얕게 앉아 몸 절반이 위로 나온다. 왕관은 입구 밖으로 삐져나온다.
- 받침의 「?」 그림자는 찹쌀이 몸에 어두운 색을 곱한 미리보기다.
- 돌 마당은 한 장을 뒤집어 이었고 초록 점 잡티가 있다.
- 알림판 종이 면이 46×34 쯤이라 글 두 줄이 겨우 들어간다. 단축 값은 옆 나무 표에 따로 적었다.
- 4대일 때 9:16 은 꽉 찬다. 윗줄 기계 아래 팻말(확률)과 아랫줄 기계의 「+」 말풍선 사이가 좁다.
