- **실내 2×2 방향은 확정이다** (사용자 「이 방향 맞아」). 구도 · 칸 상태 · 대응표는 v3 그대로다 (`../v3/README.md`).
- **기계를 메인 화면과 같은 생김새(후보 2)로 바꿨다.** v3 기계는 후보 2 와 달랐다 (몸통 모양 · 깔때기 색). 그래서 후보 2 를 화풍 그림으로 줘서 전용 화면 크기로 새로 뽑았다.
