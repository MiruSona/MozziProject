## 결론

- **방앗간 안이다.** 나무 마루 위에 기계가 칸 수만큼 선다. 자리 넷은 2×2 고정이다 (v2 그대로).
- **기계를 단순하게 새로 뽑았다.** 깔때기 둘 · 둥근 몸통 · 창 하나 · 손잡이 하나다 (124×121 · 46색, v2 기계는 71색).
- **화면의 도트 굵기는 하나다.** 270×480 으로 짜서 ×2 했다.
- v2 의 흠 넷을 고쳤다 (아래 표).

## v2 흠을 어떻게 고쳤나

| v2 의 흠 | v3 |
| --- | --- |
| 빈 받침이 기계보다 작다 | 기계와 같은 폭의 받침 + 큰 간판으로 새로 뽑았다 (116×110) |
| 찹쌀이가 깔때기 위에 얹힌 것처럼 보인다 | 몸 아래가 입구 테두리보다 15px 아래로 들어간다. 눈 아래부터는 앞 테두리가 가린다 |
| 천 덮개 위에 김이 남았다 | 김 없는 덮개를 새로 뽑았다 |
| 4대일 때 팻말 글씨가 빽빽하다 | 기계마다 나무 표를 하나만 달았다. 표는 받침 앞에 붙는다 |

## 배치 (배경 원본 좌표 272×608)

- 천장 y 0~110 · 벽 110~215 (둥근 창 · 병 선반) · 징두리 215~270 · 마루 270~608.
- 기계 가운데 x 70 · 202, 바닥 y 404 · 562. 기계 하나가 화면에서 약 248×242px 이다.
- 깔때기 입구 하나는 화면에서 약 110×40px 이다 (누르는 자리 기준 48px 이상).
- 9:16 은 y 128~608, 9:20 은 y 8~608 을 쓴다. 남는 세로는 벽과 천장이 받는다.

## 깨끗하지 않은 곳

- **9:16 에서 둥근 창 위쪽이 윗줄 뒤로 잘린다.** 배경을 9:20 에 맞춰 뽑아서다.
- 윗줄 기계와 아랫줄 기계 사이가 좁다. 아랫줄의 「+」 말풍선이 윗줄 받침 바로 아래에 붙는다.
- 기계가 화면 폭을 거의 다 쓴다 (왼쪽 기계의 손잡이와 오른쪽 기계 사이 틈이 화면에서 약 16px).
- 왼쪽 위 기계가 벽 구석의 자루를 가린다.
- 찹쌀이는 지금 게임 그림(선 회색 110)이다. 기계보다 선이 옅다.
- 「다 됨」 의 그림자 찹쌀이는 몸 그림을 어두운 색으로 곱한 것이다.
