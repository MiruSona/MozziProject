## 깨끗하지 않은 곳

- 찹쌀이가 입구 **위에 얹힌** 것이지 속에 들어간 것이 아니다 (입구 앞 테두리를 따로 떼지 않았다). 게임에 넣으려면 입구 앞쪽 조각을 따로 잘라 찹쌀이 위에 덮어야 한다.
- 기계가 230×227 이 한계다 (캔버스 256). 화면 폭의 절반이 안 된다.
- 숫자(칸 사기 값 · 확률 · 대기)는 자리표시다. 「기계 입구를 눌러 찹쌀이를 넣는다」 안내 글은 지금 게임에 없는 글이다.
- 메인 화면 합성소 건물(v1)과 같은 집으로 읽히는지는 약하다 — 지붕 · 나무 틀은 닮았지만 모양이 다르다. 메인 화면 v3 에서 이 기계를 줄여 쓰는 쪽이 맞다.
