## 결론

- 손님 · 주인의 **둘레 검정 선을 짙은 갈색**(`#352E27`, 어두운 면 옆은 `#211D16`)으로 바꿨다. 눈 · 속눈썹은 그대로 검정이다.
- 손님 **귀**는 바깥 둘레를 머리통 선 색으로 닫았고, **볼**은 네모 덩이를 둥근 2단 덩이로 바꿨다. 머리통 겹 셋에서 이 둘 말고는 안 건드렸다.
- 계산대 · 꽃병의 남색 검정 · 붉은 검정 선을 같은 갈색으로 옮겼다.
- 진열장 **유리 판**과 주인 **안쪽 선까지 갈색 판**은 `out_alt/` 에 따로 뒀다 — 사용자가 고른다.
- 지붕 알림 표식(16×16)을 새로 그렸다. 말풍선 · 버튼 틀은 잡색을 합쳤다 (56 → 24색 · 34 → 20색).

## 검사 결과

| 묶음 | 고치기 전 | 고친 뒤 |
| --- | --- | --- |
| 사람 17장 `outline` 경고 | 17장 (검정 6 · 섞임 1 · 한 색 10) | **16장** (검정 0 · 섞임 1 `body` · 한 색 15). 주인은 통과 |
| 사람 `color_cap` | `face_03` 17색 | `face_03` 18색 (갈색 선 한 색이 늘었다. 한도 16) |
| 겹 `layers check` | ok | ok |
| 소품 · UI `max_colors` | **실패** — `ui_bubble_c` 56색 | 통과 (24색) |
| 소품 · UI `near_colors` | `ui_bubble_c` · `ui_button` | 없음 |
| 소품 · UI `isolated` | 꽃병 · `ui_bubble_c` | 꽃병만 |
| 소품 · UI `outline` | 계산대 · 꽃병 · `ui_bubble_c` | 계산대 · 꽃병 · `ui_bubble_c` · `ui_button` · 알림 표식 |
| 크기 · 반투명 · 투명 칸 꼴 | — | 26장 모두 원본과 같다 (어긋남 0) |

- **사람 `outline` 경고가 안 줄어든 까닭** : 프로필은 `selout`(면마다 제 색의 짙은 선)인데, 갈색 한 색 선은 툴이 「한 색 선(solid)」 으로 읽는다. 검정은 사라졌다. 프로필 값을 어떻게 둘지는 「넘긴 것」 에 적었다.
- 소품 `outline` 도 같은 까닭이다 (한 색 갈색 선). `color_cap` 넷은 `mozzi_prop` 의 64px 까지 16색 표 때문이다 (설계의 UI 한도는 32).
