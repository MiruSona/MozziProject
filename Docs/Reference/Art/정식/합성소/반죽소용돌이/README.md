# 합성 기계 창 속 「두 색 반죽 소용돌이」

합성 기계 둥근 창 안에서 **두 색 떡 반죽이 서로 꼬리를 물고 감겨 도는** 프레임 애니다 (반복 06, 2026-10-05).
얼굴은 없다. 색은 넣은 두 마리의 몸 색으로 코드가 물들인다.
**창 원을 빈틈 없이 꽉 채운다** (사용자 피드백으로 고침 — 아래 「판 셋」).
**정본은 다시 뽑은 판(regen)이다 — 사용자가 골랐다 (2026-10-05).**

## 한눈에

| 것 | 값 |
| --- | --- |
| 프레임 크기 | **60×60** (창 유리 안쪽과 같다. 창 원 밖은 이미 투명) |
| 도는 고리 | **8프레임**, 시계 방향 한 바퀴, 되풀이 |
| 겹 | 아래부터 `a` → `b` → `top` |
| 권장 프레임 시간 | 110ms (빠르게 보이려면 90ms) |
| 기계 그림 안 자리 | 왼쪽 위 (65, 86) — 가림 원 `fx_window_mask` 와 같은 자리 · 같은 크기 |

## 겹

| 겹 | 무엇 | 색 | 코드가 할 일 |
| --- | --- | --- | --- |
| `a` | 첫째 반죽 | 흰색 `255` · 회색 `220` · `180` 세 단계 | 첫째 찹쌀이 몸 색을 곱한다 |
| `b` | 둘째 반죽 | 같다 | 둘째 찹쌀이 몸 색을 곱한다 |
| `top` | 외곽선 `#3A2E25` + 반짝이 흰 점 | 그대로 | 색을 곱하지 않고 맨 위에 얹는다 |

- 창 원 안의 모든 칸이 세 겹 중 하나에 들어 있다 (빈 칸 0 · a 와 b 가 겹치는 칸 0 — 세어 봤다).
- 세 겹은 같은 크기 · 같은 자리라 그대로 포개면 된다.

## 판 셋

| 판 | 자리 | 무엇 |
| --- | --- | --- |
| **다시 뽑은 판 (정본)** | `out/Fx/` | 꽉 찬 밑그림(`base_fill_g`)으로 PixelLab 에서 새로 뽑았다. 매끈한 음양 꼴, 걸음이 고르다 |
| 빈틈 채운 판 | `out/alt/fill_near/` | 처음 판의 빈틈 칸을 가까운 쪽 반죽 겹에 그늘 회색 180 으로 붙였다. 빈틈이 접힌 그늘처럼 보인다 |
| 처음 판 | `out/alt/gap/` | 반죽 사이로 유리가 비친다. 사용자가 「꽉 채우면 좋겠다」고 한 판 |

- **정본은 사용자가 골랐다 (2026-10-05).** 빈틈 채운 판과 다시 뽑은 판을 나란히 보고 다시 뽑은 판(regen)을 골랐다.
  그 전에는 빈틈 채운 판이 정본이었다 (덩이 모양이 처음 판 그대로라서).
- `out/alt/regen/` 은 정본을 바꾸기 전에 만든 사본이다. 지금 `out/Fx/` 와 파일이 똑같다. 스크립트는 정본을 `out/Fx/` 에만 쓰므로 이 사본은 더 안 바뀐다.
- 정본을 바꾸려면 `scripts/build_swirl.py` 의 `CANON` 을 `'fill_near'` 나 `'regen'` 으로 고쳐 다시 돌린다. 파일 이름 · 크기 · 장수는 같다.
- 섞임 단계 그림은 안 쓴다 (「너무 공처럼 보인다」). 겹 파일은 `raw/mix_layers_v1/` 에 남겼다.

## 만든 길

1. PixelLab 으로 분홍 · 민트 두 반죽이 감긴 64×64 한 장을 뽑았다. 정본은 창 원을 꽉 채운 밑그림(`base_fill_g`)이다.
2. 그 한 장을 PixelLab 움직임 도구로 「시계 방향 한 바퀴」 16프레임으로 뽑았다. 프레임마다 새로 그려진 그림이다 — 한 장을 돌려서 만든 것이 아니다.
3. PIL 은 손질만 했다 : 60×60 자르기 → 색으로 겹 가르기(분홍 = a · 초록 = b · 어두운 갈색 · 흰 점 = top) → 밝기를 회색 세 단계로 → 외곽선 한 색 → 창 원 가림 → 빈 칸을 가까운 반죽 겹에 회색 180 한 색으로 채움.

## 모자란 점

- 정본 (다시 뽑은 판) : 꼬리가 늘어지는 맛이 적고 구슬처럼 반들거린다.
- 빈틈 채운 판 : 채운 자리가 한 색 그늘이라 넓은 곳은 밋밋한 어두운 덩이로 보인다. 한 빈틈이 두 반죽에 반씩 붙는 자리에는 두 색 사이 외곽선이 없다. 도는 걸음이 고르지 않다.
