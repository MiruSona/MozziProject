# 찜기2 — 1단 유리 전기 찜기 시안 (반복 09)

사용자 피드백 세 가지에 맞춘 시안이다.

1. 단을 하나로 줄였다. (지금 그림은 실제로는 2단이다)
2. 유리를 반투명 겹으로 나눠서 안에 든 떡이 보이게 했다.
3. 4초 동안 김 서림 · 김 · 뚜껑 덜컹 · 떡 색 바뀜으로 익는 모습을 보여 준다.

## 만든 방법

- **PixelLab 은 쓰지 않았다 (0 판, 크레딧 0).** 지금 찜기 그림(`kitchen_steamer_open_body` · `_closed` · `_open_lid`)의
  줄을 잘라 다시 쌓아 1단으로 만들었다. 시안의 생김새와 색을 그대로 이으려고 이렇게 했다.
- 만든 스크립트 : `raw/build_steamer2.py` (PIL, ArtTool `.venv` 의 python 으로 돌린다).
- 원본 줄 → 새 자리 (캔버스 y)
  - 손잡이 테 : 원본 86~104 → 68~86
  - 유리 늘린 부분 : 원본 104~122 복사 → 86~104 (떡 높이 44px 가 들어가게 늘렸다)
  - 유리 아래 · 받침 : 원본 104~199 → 그대로
  - 닫힌 뚜껑 : 원본 0~64 → +22 (28~86) · 열린 뚜껑 : +22

- 캔버스가 지금 찜기와 같으므로 `Steamer9X` · `Steamer9Bottom(805)` 은 **바꾸지 않는다.** 화면 1px = 캔버스 1px.
- 떡 : 캔버스 (61, 89) ~ (118, 133), 57×44. `kitchen_shape9_5` 와 같은 크기. 아래 끝 y 133 이 받침살 위다.
  화면 y 로는 위 695 · 아래 739 (805 − 199 + 캔버스 y).
- 뚜껑 윗끝 : 캔버스 y 28 (지금은 6) → 22px 내려갔다.

## 코드가 할 일 (다음 판)

- 찜기 그림을 겹 7개로 바꿔 끼운다 (`KitchenScreen` 찌기 부분, `KitchenLidView`).
- 떡 겹은 `Image.color` 로 물들인다. 그림이 흰색이라 color 가 그대로 떡 색이 된다.
- fog 는 `Image.type = Filled`, `fillMethod = Vertical`, `fillOrigin = Bottom` 으로 아래부터 차오르게 하고,
  `color.a` 로 0→1→0 을 준다.
- 상수 바꿀 것 : `Steam9ClosedBottom 634`, `Steam9Bottom 682`. 나머지 찜기 상수는 그대로.
