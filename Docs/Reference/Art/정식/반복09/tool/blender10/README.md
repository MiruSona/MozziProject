## 움직임 (9장)

| 장 | 모습 |
| --- | --- |
| 0 | 멈춤. 고슬고슬한 재료가 쌓여 있다 |
| 1 | 칼날이 돌며 가운데가 패이고 가장자리가 올라온다 |
| 2~4 | 통 벽을 타고 소용돌이친다. 알갱이가 위로 튄다 |
| 5~6 | 거의 고운 반죽. 윗면에 작은 소용돌이 |
| 7~8 | 매끈한 반죽이 잔잔히 돈다 |

- 권장 재생 : 장당 70ms. **0 → 1~8 을 한 번 → 5~8 을 되풀이** (8 에서 0 으로 바로 넘어가면 반죽이 다시 덩어리가 되어 튄다).
- 통 떨림은 코드가 한다. 그림의 몸통은 고정이다.

## 겹 순서

1. `blender9_body_0.png` (몸통, 통 안은 빈 유리색)
2. `blender10_fill_{장}.png` × 재료 색 (곱하기)

내용물은 통 안 영역 x15..78, y33..99 밖으로 나가지 않는다 (코드에서 잘라 둠).

## 색 방식

- **평균** : 넣은 재료 색의 평균 하나를 겹 전체에 곱한다. 색 표는 `../README.md` 「믹서기 내용물 겹 blender9」.
- **층** : 넣은 순서대로 아래부터 층을 쌓는다 (첫 재료 = L0 = 맨 아래).
  - 층 경계 : 열(x)마다 내용물 윗면 y(t)와 바닥 y(b)를 찾고, 그 사이를 층 수 n 으로 등분한다.
    칸 (x, y) 의 층 = `min(n-1, floor((b - y) * n / (b - t)))`. 윗면 꼴을 따라 경계가 울퉁불퉁해진다.
  - 장별 섞임 비율 : `t = clamp((장 - 1) / 5, 0, 1)` → 장 0·1 은 0 (층 그대로), 2=0.2, 3=0.4, 4=0.6, 5=0.8, 6~8 은 1 (평균색).
    칸 색 = 층색 × (1 - t) + 평균색 × t.
  - 게임에서 겹을 칸 단위로 나눠 칠할 수 없으면 `blender10_fill_{장}_n{n}_L{층}.png` 를 층마다 따로 깔고 각각 색을 곱한다.
    필요한 것은 장 0~5 × (n=2 이면 2장, n=3 이면 3장). 장 6~8 은 `blender10_fill_{장}.png` 하나에 평균색.
  - 5~8 을 되풀이하는 동안은 t 를 1 로 고정한다 (되풀이 때 층이 다시 생기지 않게).

## 만든 방법 · 크레딧

- 멈춘 장(몸통 + blender9 내용물 겹을 살구 #e8c496 로 물들인 것)의 통 부분 (8,24)-(86,106) 을 2배로 키워
  `animate_image_pixminimax` (8장, 1 generation) 에 넣었다. 프롬프트는 "유리 통 · 받침은 그대로, 안의 베이지 내용물만 갈리며 소용돌이치다 고운 반죽으로 가라앉음".
- 결과를 2배 최근접으로 줄이고, 붉은 기가 푸른 기보다 18 이상 큰 칸만 내용물로 가렸다 (유리 · 흰 반사 · 쇠 축이 빠진다).
  밝기는 9장 전체 최댓값을 255 로 맞췄다 (장마다 밝기가 튀지 않게).
- 쓴 것 : 이 일의 잡은 1 generation. 계정 잔량은 402 → 387 이었는데 같은 시간에 다른 세션의 잡 2개가 돌았다.
