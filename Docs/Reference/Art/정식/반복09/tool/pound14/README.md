# 떡메 치기 시안 pound14 (반복 09, 2026-10-07)

> **2026-10-18 정리** : 이 문서가 가리키던 그림 중 안 쓰는 시안·견줌판·옛 판은 저장소에서 지웠다 (`(정리함 2026-10-18)` 표시). 다시 보려면 git 기록에서 꺼낸다.

pound13 에 두 가지 말을 듣고 고친 판이다.

1. 「떡메는 보통 곡선으로 내리치는데 지금은 너무 일직선」 → 떡메가 **손 자리(축)를 중심으로 돌며** 호를 그린다.
2. 「반죽이 그릇 위에 붕 떠 보인다」 → 절구를 **뒷벽**과 **앞 테두리** 두 겹으로 갈라, 반죽이 그 사이에 앉는다.

세 겹 틀 · 자루 길이 · 넘침 단계 · 1단계 묻힘 깊이(48px)는 pound13 그대로다.
반죽 모양(PIL 타원)도 pound13 것을 아래로 8px 옮겨 썼을 뿐이다. 정식 때 PixelLab 으로 다시 뽑는다.
다시 만들려면 이 폴더에서 `python build_pound14.py` (pound13 의 `build_pound13.py` 를 읽어 쓴다).

## 절구 두 겹

- 입구 구멍 타원 : **가운데 (220,413) · 가로 반지름 81 · 세로 반지름 22** (구멍 위 끝 y391, 아래 끝 y435).
- **가르는 선** : 구멍 타원의 아래 호 `y = 413 + 22·√(1-((x-220)/81)²)` (|x-220|<81), 그 바깥은 `y = 413`.
  선보다 아래(큰 y)는 `mortar_front`, 선 위(선 포함)는 `mortar_back`.
- `mortar_back` bbox (120,384)-(320,436) — 뒤 테두리 + 구멍 안쪽.
  `mortar_front` bbox (118,414)-(322,560) — 앞 테두리 + 몸통.
- **반죽 밑 높이** (쉼 장) : 1단계 y446 · 2단계 y440 · 3단계 y442. 구멍 아래 끝(435)보다 5~11px 아래라 앞 테두리가 반죽 밑을 가린다.
  구멍 가운데 높이(413)보다 확실히 아래다. 413 바로 밑에 두면 앞 테두리가 아무것도 안 가려 다시 떠 보여서 이렇게 잡았다.

## 넘침 (1단계·2단계)

**넘친 부분만 따로 겹으로 뗐다** (`dough_spill_*`). 반죽 전체를 앞 테두리 위에 올리면 몸통이 다시 떠 보여서다.

- 규칙 : 반죽 타원 중 **가운데가 입구 타원(세로 반지름 +6) 밖이고 y>413 인 것**의 픽셀을 spill 로 옮긴다. 나머지는 `dough` 에 남는다.
- 그 결과 spill 이 있는 장 : `s1_5 · s1_6 · s1_7 · s2_5 · s2_6`. 앞 벽을 타고 흘러내린 방울로 보인다.
- 테두리 위로 튀는 방울(y<413)은 원래 앞 테두리보다 위라 `dough` 에 남아도 가려지지 않는다.

## 떡메 — 축 둘레 회전

- 원본 `raw/mallet_A_long.png` (87×49, pound13 과 같은 것). 머리는 왼쪽, 자루는 오른쪽.
- **축 = 손 자리 = 원본 (84, 24.5)** (자루 끝에서 3칸 안). 머리 가운데 = 원본 (11, 24.5).
- 머리 가운데 → 축 거리 **146px**, 머리 가운데 → 머리 아랫면 **49px**.
- 만드는 법 : 원본을 축이 가운데 오게 덧대고 → `rotate(각도, NEAREST)` → 2배(NEAREST) → 축을 아래 표의 축 좌표에 맞춰 붙인다.
- **각도** = 자루가 수평에서 기운 정도. **양수 = 손이 머리보다 위, 음수 = 머리가 손보다 위(어깨 뒤로 넘긴 자세).** PIL `rotate` 값과 같다(반시계 양수).
- 머리 가운데 = 축 − 146·(cos θ, −sin θ). 축은 늘 캔버스 안(x≤394)이라 자루가 캔버스 끝에서 잘리지 않는다.
