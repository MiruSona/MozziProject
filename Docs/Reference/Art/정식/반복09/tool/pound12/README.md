# 떡메 치기 시안 pound12 (반복 09, 2026-10-07)

pound11(P·Q)에 「옛 것이 낫다 · 둘 다 어색하다」는 말을 듣고 다시 만든 판이다.
고친 점은 세 가지다. 떡메를 높이 들었다 내리친다. 세 번 칠 때마다 넘침이 다르다. 자루가 짧아서 떡메 전체가 다 보인다.

## 세 단계

| 단계 | 반죽 (쉼) | 친 장 | 떡메가 박히는 깊이 |
| --- | --- | --- | --- |
| 1번째 | `dough_s1` 흩어진 가루 | 절구 밖으로 크게 넘친다. 흘러내리고 방울이 튄다 | 깊다(56px). 머리가 넘친 반죽에 묻힌다 |
| 2번째 | `dough_s2` 반쯤 뭉침 | 양쪽 가장자리로만 조금 솟는다. 방울 2개 | 반쯤(24px) |
| 3번째 | `dough_s3` 매끈한 덩어리 | 넘치지 않는다. 덩어리가 납작해졌다(1.2×0.68) 되돌아온다(0.94×1.1) | 거의 없음(4px). 위를 누른다 |

장마다 자세는 같다. 8장이다. 0 쉼(절구에 걸침) → 1 들기 → 2·3 높이 든 장(머리 가운데가 절구 입구에서 약 250px 위, 자루 48~50° 위로) → 4 내려오는 중간(흰 줄) → 5 친 장 → 6 튕김 → 7 쉼.
박자(ms)는 `110 80 90 140 45 160 90 140` 이다.

## 떡메

후보는 세 개다(견줌판 오른쪽 위). A·B 는 PixelLab `create_object_pro_flash`(side, 128×96)로, C 는 옛 꼴을 PIL 로 그렸다.
**움직임에는 B 를 썼다.** 머리가 굵은 통 모양이고 테가 있다. 결과 외곽선이 W1 절구와 가장 비슷하다. 2배로 키워 머리 높이는 114px 이다(절구 폭 204 의 약 0.56).
돌리기는 원래 크기에서 한 다음 2배로 키웠다. 그래서 계단이 도트 2칸 단위로 고르다.

## 기준점

캔버스는 **440×560** 이다. **캔버스 바닥 가운데(220,560) = 절구 바닥 가운데 = 화면 (270,815)** 이다. 캔버스 왼쪽 위는 화면으로 (50,255) 이다.

## 알려진 흠

- 든 자세는 머리가 왼쪽 아래를 향한 채 떠 있다. 손이 없어서 「누가 들었나」가 안 보인다. 내려오는 장도 한 장뿐이라 빠르긴 하지만 휙 지나간다.
- 넘친 반죽은 PIL 타원을 겹쳐 그렸다. 옛 것의 넘침보다 덩어리가 동글동글하고, 1번째 가루 결(점무늬)이 기계적이다.
- 1번째 튕김 장(s1_6)은 흘러내리는 반죽 띠가 머리 아래쪽을 가로질러 덮는다.
- 2번째 친 장의 솟음은 작은 혹 둘이라 「조금 넘침」이 약하게 읽힐 수 있다.
- 옛 것 칸은 견줌용으로 1.55배 키워 대충 맞췄다.
