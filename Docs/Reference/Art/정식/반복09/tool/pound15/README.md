# pound15 — 떡메 치기 시안 6차 (반죽만 PixelLab 그림으로 바꿈)

> **2026-10-18 정리** : 이 문서가 가리키던 그림 중 안 쓰는 시안·견줌판·옛 판은 저장소에서 지웠다 (`(정리함 2026-10-18)` 표시). 다시 보려면 git 기록에서 꺼낸다.

pound14 에서 **반죽 그림만** 바꿨다. 떡메 호 운동 · 절구 두 겹 · 박자는 pound14 그대로다 (mallet_* · mortar_* 는 pound14 복사본).

## 겹과 순서 (정식 배선이 읽는다)

- 캔버스 440×560. 모든 겹이 같은 크기라 같은 자리에 겹치면 된다.
- 순서 : `mortar_back` < `dough` < `mallet` < `mortar_front` < `dough_spill`
- 묻힘 장(단계 0·5·7, 넘어감 4장 전부)은 `dough` 가 `mallet` 위.
- 단계 8장 박자 110 80 90 140 45 160 90 140ms, 넘어감 4장 130 130 130 160ms.
- `dough_spill_*` 은 이름이 다 있다 (32장). 넘침이 없는 장(24장)은 빈 투명 그림이다.
- 반죽은 흰색(그늘은 회색 톤만)이다. 색은 코드가 물들인다.

- 넘어감 4장은 앞 단계 쉼 → 다음 단계 쉼을 t = 0.2 0.45 0.7 0.92 로 보간.

## 넘침 규칙 (10-07 셋째 고침 — 튀는 넘침 키움)

사용자 피드백 「넘침 표현 좀더 역동적이게」 로 가만히 붙은 흰 귀 두 개를 **터짐 → 내려옴 → 흘러내림** 세 장으로 바꿨다(둘째 고침).
셋째 고침에서 덩어리·방울을 크게 키우고 조각마다 윤곽을 둘러 크림 벽 위에서도 보이게 했다.
코드는 `splash_spill` (옛 `lobe_spill` 은 남아 있지만 안 쓴다).

- **넘침이 있는 장** : 1단계 5·6·7장 · 2단계 5·6·7장 · 넘어감 t12 0·1장(잔방울). 쉼(0) · 1~4장 · t12 2·3장 · t23 · 3단계 전체는 빈 투명.
- 기준 : 테두리 윗면 y412, 덩어리 뿌리 = 가운데 x220 ± 85 (x135 / x305), 바깥 벽 = 가운데 ± 97.
- 2단계는 크기 0.6 배 · 방울 3개 · 머리 위 방울 1개.

- 색 : 조각마다 윤곽 1px 205, 안쪽은 열별로 위 1~2줄 255 · 몸 240 · 아래 1줄 226.

## 반죽 윗면 맞추기 (10-07)

- 쉼 꼴 그대로면 머리가 반죽 위로 1~4px 떠 보였다. 단계마다 쉼 장(0)·복귀 장(7)에서 머리 가운데 ±28 열의
  (반죽 윗면 − 머리 밑면) 최솟값이 −5 가 되게 반죽 높이를 늘린다(밑은 그대로). 1~4·6장은 0장 높이를 쓴다.
- 맞는 장(5)은 −12/−10/−6 (1/2/3단계)보다 덜 묻혔으면 늘린다 — 실제로는 3단계만 늘었다.
- 넘어감 4장은 두 단계의 0장 늘림을 t 로 보간한다.
