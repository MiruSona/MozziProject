pound12 에 「반죽 애니만 따로 놀아 이상하다 · 절구 / 반죽 / 떡메 세 겹으로 나눠 달라 · A 가 낫지만 너무 짧다」는 말을 듣고 다시 만든 판이다.
그림을 **세 겹**으로 나눴다. 세 겹은 같은 캔버스를 쓰고, 그대로 겹치면 한 장면이 된다.

## 캔버스와 기준점

- 캔버스는 **440×560** 이다. 세 겹이 모두 같다.
- **캔버스 바닥 가운데 (220,560) = 절구 바닥 가운데 = 화면 (270,815)** 이다. 캔버스 왼쪽 위는 화면 (50,255) 이다.
- 지금 코드가 쓰는 옛 그림(`kitchen_pound_*.png`, 212×241 을 334×385 로 띄움)과 **크기가 다르다.** 배선할 때 칸 크기를 440×560 으로 바꾼다.

## 겹 순서

**절구 < 떡메 < 반죽** — 모든 장에서 같다. 장마다 순서를 바꾸지 않는다.

- 떡메 겹은 떡메를 통째로 그렸다. 묻히는 장에서는 반죽 겹이 떡메 머리 아랫부분을 덮어 「묻힌 것」처럼 보인다.
- 반죽이 넘쳐 절구 테두리에 걸치는 부분은 반죽 겹이 절구 위라서 테두리 위에 그려진다.

넘어감 장에서 떡메는 쉼 자세로 반죽 위에 걸쳐 있고, 반죽 높이를 따라 조금 오르내린다.

## 알려진 흠

- 반죽은 PIL 타원을 겹쳐 그렸다. 1단계 왕관은 끝이 둥근 귀 모양이라 만화 같다. 옛 것의 넘침보다 덩어리가 동글동글하다.
- 1단계 7번(가라앉음)에서 0번(쉼)으로 넘어갈 때 흘러내린 반죽이 한 번에 사라진다.
- 절구 안쪽 그림자는 따로 그리지 않았다. W1 그림의 어두운 입구를 그대로 쓴다.
- 든 자세에 손이 없어 「누가 들었나」가 안 보인다. pound12 와 같다.
- 넘어감 장은 타원 위치를 섞어 만든 것이라 「뭉치는」 움직임이 작고 미끄러지듯 보일 수 있다.
- 2단계 덩어리 결은 짧은 호 몇 개라 잘 안 보인다.
