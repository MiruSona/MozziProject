## 알려진 흠

- **반죽 반응이 옛 것보다 약하다.** 옛 것은 치는 장에서 반죽이 절구 밖으로 크게 넘쳐 나왔다. 지금은 납작 반죽을 옆으로 1.12배 늘리고 작은 방울 6개를 얹은 정도다. 옛 것이 자연스러웠던 큰 까닭이 이것이라 정식 때 넘치는 반죽 그림을 따로 그려야 한다.
- 떡메를 NEAREST 로 돌려서 비스듬한 장의 외곽선이 계단처럼 거칠다(특히 P 의 가는 자루).
- P 자루가 머리에 비해 가늘어 보인다. Q 는 PixelLab 그림이라 결이 더 곱지만 머리가 P 보다 작아 보인다(머리 폭은 같고 높이가 낮다).
- 옛 것 칸은 절구 폭을 W1 과 맞추려 1.55배 키웠는데, 옛 절구가 위로 더 높아 치는 장의 떡메가 칸 위에서 잘린다(견줌용이라 둠).
- 찹쌀이 손 없음(요청대로). 반죽 한 단계만.
