# 떡메 치기 시안 A · B (반복 09, 2026-10-07)

절구와 반죽은 그대로 두고 떡메와 그 움직임만 새로 그린 시안이다. 반죽은 s2(덜 친 반죽) 하나로만 만들었다.

## 겹 순서

절구 → (반죽 + 떡메를 한 겹으로) → 앞 테두리 가림. 입구 높이 가운데 줄 아래에서 절구 몸통과 겹치는 반죽·떡메 칸은 지운다.
그래서 떡메 머리가 절구 **안으로** 들어가 보인다. 떡메 그림은 돌리거나 늘리지 않았다. 자리 옮기기 · 바닥 먼지 칸(40칸 미만 덩어리) 지우기만 했다.

## 크레딧

PixelLab 생성 402 → 387, **15 회** 썼다. 첫 장 192×192 두 장(약 6씩) + pixminimax 8장 움직임 두 번(1씩).
같은 시간에 다른 세션 작업이 하나 돌고 있어서 1 정도는 그쪽 몫일 수 있다.

## 걸리는 점

- **자루 끝이 프레임 가장자리가 아니라 허공에서 잘린다.** 떡메 캔버스(192)의 오른쪽 끝이 프레임 x 261(A) · 294(B) 에 놓인다.
  친 장 머리를 절구 가운데에 맞추면 캔버스 오른쪽 끝이 프레임 끝(334)에 닿지 않는다. A 는 든 장에서 위쪽 끝(y 50)에서도 잘린다.
- 머리 폭이 절구 입 지름의 절반에 못 미친다 (약 3분의 1 남짓). 옛 것보다 굵어지기는 했다.
- 원본 움직임은 든 장에서 친 장으로 한 번에 건너뛴다. 잔상 장은 옮기기 + 겹치기로 만든 것이라 새로 그린 장이 아니다.

## 정식으로 갈 때 할 일

1. 고른 시안의 첫 장을 **256×256** 으로 다시 뽑는다. 캔버스 오른쪽 끝을 프레임 오른쪽 끝(334)에 맞추려면
   친 장의 머리 가운데가 캔버스 x 약 89 에 와야 한다 (334 − 256 = 78, 절구 가운데 167). 머리 폭 약 75칸으로 적는다.
2. pixminimax 를 **12장**으로 돌려 내려치는 사이 장을 새로 그리게 한다 (잔상 옮기기 대신).
3. 반죽 세 단계(s1 · s2 · s3)는 떡메 프레임을 같이 쓰고 반죽 겹만 바꾼다 → 3 × 9~12장. `build_pound10.py` 의 `dough_s2` 를 단계마다 바꾸면 된다.
4. 예상 크레딧 : 첫 장 약 12(256) + 움직임 1~2 = **15 안팎**, 다시 뽑기 한 번 넣으면 30.
