# 반복 09 주방 기구 정식 그림

현대 카페 주방(옆으로 세 칸)에 놓일 기구 그림이다. 모두 **화면에 1배로 놓는 크기**이고 투명 배경이다.
한눈에 보려면 `한눈판.png`, 치기 움직임은 `pound.gif` 를 연다.

## 파일

| 파일 | 크기 | 무엇 |
| --- | --- | --- |
| `blender_idle.png` | 105×176 | 믹서기 멈춤 (갈기, 칸1) |
| `blender_run_0..2.png` | 105×176 | 믹서기 도는 중 — 병 안 쌀가루만 소용돌이친다 |
| `pound_s{1..3}_{0..6}.png` | 334×389 | 흰 돌 절구(폭 249) + 떡메 치기 (칸2). s1 거친 반죽 · s2 덜 친 반죽 · s3 매끈한 반죽, 각 7장 |
| `shape_board.png` | 102×35 | 대리석 빚기 판 (칸3). 떡은 있는 떡 그림을 위에 얹는다 |
| `steamer_closed.png` | 114×123 | 전기 찜기 닫힘 (칸3) |
| `steamer_open.png` | 114×123 | 전기 찜기 열림 — 닫힘 그림에서 뚜껑만 고쳐 뽑아 본체 자리가 같다 |
| `steam_0..2.png` | 37×57 | 김 세 장 (찜기 위에 돌려 띄운다) |

치기 7장 차례 : 0 들기 → 1 더 들기 → 2 내리기 → 3 침(반죽 납작) → 4 튐(납작) → 5 올리기 → 6 들기.
절구는 모든 장에서 같은 자리에 고정이고 떡메·반죽만 바뀐다.

## 권하는 화면 자리 (한 칸 540 폭, 세로 1200 기준)

시안(`Docs/Reference/Art/시안/반복09-v3/`)의 자리를 그대로 옮겼다. 그림 아래 가운데를 기준점으로 둔다.

| 그림 | 칸 | 가운데 x | 아래 y |
| --- | --- | --- | --- |
| 믹서기 | 칸1 조리대 위 | 395 | 880 |
| 절구 치기 | 칸2 가운데 | 270 | 920 |
| 찜기 | 칸3 | 410 | 800 |
| 빚기 판 | 칸3 조리대 위 | 150 | 880 (짐작 — 시안에 자리 값 없음) |
| 김 | 찜기 뚜껑 위 | 410 | 690 |

## 옛 그림과 바꿔 끼우기

옛 그림(`ProjectMozziUnity/Assets/_Project/Resources/Art/Screen/kitchen_*`)은 고치지 않았다.

| 옛 그림 | 새 그림 |
| --- | --- |
| `kitchen_mill_0..4` (맷돌 5장) | `blender_idle` + `blender_run_0..1` (3장 — 장 수가 다르다) |
| `kitchen_pound_rough_0..6` | `pound_s1_0..6` |
| `kitchen_pound_0..6` | `pound_s2_0..6` |
| `kitchen_pound_smooth_0..6` | `pound_s3_0..6` |
| `kitchen_board`, `kitchen_shape_*` 의 판 | `shape_board` |
| `kitchen_steamer_body` + `kitchen_steamer_lid` | `steamer_closed` / `steamer_open` (뚜껑을 따로 움직이지 않고 두 장을 바꾼다) |

치기 프레임은 옛것(212×241)보다 크다(176×280). 떡메를 높이 드는 자리를 위에 더 둬서 그렇다.

## 알려진 흠

- (10-06 큰 판) 화면 자리: 한 칸 540 폭, 조리대 윗면 y 600~682 — 기구 바닥은 y 660 안팎. 옛 작은 판은 `old_small/`.
- 치기 프레임 폭 334 — 친 장(20도) 떡메 자루가 오른쪽으로 길어 300 을 넘는다.
- 믹서기 높이 176 (목표 160~170 보다 조금 큼).

- 떡메는 두 자세(든 장 45도·친 장 20도)를 바꿔 끼운다. 사이 각도 장은 없다.
- s3 매끈한 반죽은 색이 옅어 절구 안쪽 회색과의 차이가 s1 보다 작다.
- 김 세 장은 따로 뽑아 모양이 이어지지 않는다. 돌려 띄우면 깜빡이는 느낌이 날 수 있다.
