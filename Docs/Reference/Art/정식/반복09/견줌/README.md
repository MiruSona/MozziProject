## 눈에 띈 흠 (견줌판에서 본 것)

1. **조리대가 시안보다 얇고 색이 다르다.** 시안은 나무색 조리대가 약 600~900 줄(눈대중)을 차지하는데, 정식은 크림색 윗면 130줄(700~830)이다. 벽은 흰 벽돌로 시안에 가까워졌다.
2. **아랫장 색이 시안과 다르다.** 시안은 흰 문짝, 정식은 나무색 문짝이다 (윗벽장도 나무색).
3. 장식 크기는 시안과 비슷하다. 레일 251 폭 · 화분 선반 107 폭이 시안의 레일 · 화분 선반과 거의 같은 덩치로 보인다.
4. `칸2_치기_든` 은 떡메 맨 위(449)가 레일 아래 끝(453)보다 4px 위로 올라가 레일 줄과 높이가 겹친다(10-07 절구 키 155 → 176 탓). 불투명 픽셀 겹침은 0 이다. 떡메는 여전히 손 없이 떠 있다.
5. 큰 쟁반이 믹서기 왼쪽 조리대를 거의 채운다 (82px 틈만 남음).
6. 찜기는 크림빛 흰색 + 맑은 유리로 파란 기가 없다. 김이 들린 뚜껑 뒤 오른쪽에서 솟는다 (지난 판 흠 해결).
7. 꿀색 나무 판이 크림색 조리대와 잘 구분된다. 2배 떡은 판 위에서 떡으로 읽힌다.
8. 천장은 3배 도트라 아래 1배 그림보다 굵다 (지난 판과 같음). 돈 표시 판이 칸 왼쪽 등 윗부분을 가린다 (그대로 둠).
