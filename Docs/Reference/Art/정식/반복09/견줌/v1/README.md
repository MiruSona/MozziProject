## 눈에 띈 흠 (견줌판에서 본 것)

1. **믹서기가 선반과 겹친다.** 믹서기 키 176 이라 위 끝이 y 486 인데 선반은 x 40~500, y 400~591 이다. 둘째·셋째 줄 오른쪽 병과 선반 판을 가린다. x 를 어디로 옮겨도 칸 안에서는 피할 수 없다 — 선반을 5열로 줄이거나 믹서기를 앞으로 겹쳐 두는 것을 정해야 한다.
2. **크기 균형** : 절구(폭 249)가 화면 폭의 절반쯤이라 칸2 를 꽉 채운다. 찜기(114)·믹서기(105)는 절구 옆에서 작아 보이고, 찜기는 밥솥처럼 읽힌다. 빚기 판(102×35)과 떡(32)은 더 작아 칸3 이 비어 보인다.
3. 바닥 y : 믹서기 · 찜기 · 판은 조리대 윗면에 자연스럽게 얹힌다. 절구는 앞 모서리(668~682)에 4px 걸쳐 앞에 놓인 느낌이다.
4. **떡메 자루 끝이 윗벽장 앞에 겹친다.** 윗벽장은 화면 y 250~약 336 이다. 떡메 맨 위는 `s1_0` 이 y 298, `s1_1`(더 든 장)이 y 283, `s3_6` 이 y 306 이라 자루 끝 30~50px 이 벽장 앞에 그려진다. 가까이 보면 「벽장 앞으로 들어 올린」 것처럼 읽혀 아주 어색하진 않다. 칠 때(`s2_5` 위 끝 y 333)는 거의 안 겹친다. 화면 밖으로는 안 나간다. 피하려면 절구 바닥을 약 50px 내려야 하는데 그러면 조리대를 벗어난다.
5. 아래 버튼 줄은 반복 08 캡처를 그대로 써서 옛 안내 글 「서랍에서 재료를 1~3개 고르세요」가 남아 있다. 새 안내 판과 두 줄이 겹친다.
6. 돈 표시 판(10~170)이 칸 왼쪽 등(x 120)의 줄과 갓을 가린다.
7. 배경은 y 1050 까지라 긴띠의 1050~1200 은 검다 (화면에서는 UI 가 덮는 자리).
8. 결과 떡 자리 점선 원은 흰 타일 위라 아주 옅다.
