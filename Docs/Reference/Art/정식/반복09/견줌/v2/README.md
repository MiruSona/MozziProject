## 눈에 띈 흠 (견줌판에서 본 것)

1. **김이 들린 뚜껑 앞에 그려진다.** 뚜껑이 오른쪽 위로 기울어 들려 있어서, 찜 칸 위에 세운 김이 뚜껑 왼쪽 절반을 덮는다. 「김이 뚜껑 틈으로 솟는다」로도 읽히지만, 김을 뚜껑 뒤에 두려면 찜기 열림을 몸통 · 뚜껑 두 장으로 나눠야 한다.
2. **빚기 판 위 떡(32px)이 작다.** 판(208×95)이 넓어 떡이 판 가운데 작은 흰 점처럼 보인다.
3. 크기 균형은 지난 판보다 좋다. 절구(188) · 찜기(172) 가 비슷한 덩치이고 믹서기(105)는 가늘지만 키(176)가 있어 작아 보이지 않는다. 기구 바닥이 모두 조리대 윗면 안(800~822)이라 앞 모서리에 걸치지 않고 얹혀 보인다.
4. 천장은 3배 도트라 아래 1배 그림보다 굵다. 어둡고 결이 단순해 크게 튀지는 않는다. 긴띠에서 칸 경계마다 널이 「^」 꼴로 만난다 (칸마다 소실점이 있는 시안 그대로).
5. 돈 표시 판(10~170)이 칸 왼쪽 등(x 120) 줄 윗부분을 가린다 (그대로 둠).
6. `칸2_치기_든` 은 떡메가 절구 위에 홀로 떠 있다 (쥐는 손이 없는 프레임 그대로).
