# 화풍 통일 C 갈래 — 농장 · 합성소 (2026-10-05)

> 설계 : `Docs/Design/화풍통일/2026-10-05-그림화풍통일설계.md` 7절 C-1 ~ C-4.
> **찹쌀이 몸 선 색은 `#5E5048` 로 확정했다 (2026-10-05, 후보 2).** `out/` 의 몸 4장이 이 색이다.
> 이 폴더는 `out/` 까지만 낸다. `Resources/Art/` 로 옮기는 것은 코드 갈래 몫이다.

## 결론

- **C-1 시안** : 선 색 셋(지금 회색 · 따뜻한 후보 둘)을 농장 잔디 위에 놓은 판을 만들었다. **고르는 것은 사용자다.**
- **C-2 색 합치기** : `body_hop1` 9 → 5색 · `body_hop3` 32 → 8색. 네 장이 같은 색 값만 쓴다. 이때 선은 `#6E6E6E` 그대로 뒀고, 뒤에 C-1 확정으로 `#5E5048` 이 됐다.
- **C-3 장식** : 풀 장식 4 · 꽃 장식 3 의 풀색 12가지를 잔디 쪽(노란 연두)으로 옮겼다. 꽃잎 색은 안 바꿨다.
- **C-4 결과 판** : `synthesis_plate` 45 → 26색. 나무 면의 비슷한 갈색을 합쳤다.
- 모든 그림이 원본과 **캔버스 크기 · 실루엣(알파)이 한 칸도 안 다르고 반투명 0** 이다 (`scripts/verify.py`).

**선 색을 볼 때 알아 둘 것**

- **원작 그늘은 무채색 회색이다** (`#DEDEDE` · `#CCCCCC` · `#AEAEAE`, 원본에는 선이 없다). 「회색 그대로」 쪽의 근거다.
- 건물 · 울타리 선은 따뜻한 짙은 갈색 `#352E27` 계열이다. 후보 둘은 그쪽으로 한 걸음 · 두 걸음 간 색이다.
- **게임은 몸 그림에 종 색을 곱한다. 선도 같이 물든다.** 그래서 색 있는 종(풀 · 화산)에서는 세 후보 차이가 거의 안 보이고, **흰찹쌀이에서만 갈린다.**
- 볼 `#FBD701` 은 지키기로 한 값이라 그대로 뒀다.
- 판의 찹쌀이는 64 캔버스 그대로(×1)다. 게임 농장은 ×1.143 ~ 1.6 으로 키워 찍는다.
- 뜀 장면(hop1 ~ 3)의 볼 · 표정 자리는 **어림**이다 (게임은 애니메이션 클립이 옮긴다). hop0 자리는 코드 값 그대로다.

## 무엇을 어떻게 고쳤나

| 그림 | 고친 것 | 값 |
| --- | --- | --- |
| `body_hop1` · `hop3` | 칠 색을 `hop0` · `hop2` 가 쓰는 색으로 보냄 (가장 가까운 색) | 갈 수 있는 색 7 : `#FDFDFD` `#DFDFDF` `#D4D4D4` `#CCCBCB` `#C4C4C4` `#B8B7B7` `#A4A4A4` |

| `synthesis_plate` | 채널 차이 5 안인 색을 칸 수 많은 쪽으로 합침 + 홀로 남은 1 ~ 2칸 점 20칸 메움 | 못 · 둘레선 색은 그대로 |

- 장식 값은 설계 출발점(색상 −10° · 밝기 +0.08 · 채도 ×2.4)에서 **밝기를 덜 올렸다.** 그대로 올리면 밝은 잎이 바탕(`#C0CF7D`)보다 밝아져 덩이가 풀밭에 녹았다.
- 장식 풀색은 `#31502B`(둘레) ~ `#BBD76E`(잎 끝)이 됐다. 잔디 풀잎 획(`#698F58` 근처)과 바탕 사이 색이다.
