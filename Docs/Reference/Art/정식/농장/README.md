## 결론

- **잔디 = 무늬 약한 바탕 256×256 한 장(네 변 이어짐) + 장식 조각 11개를 32 칸에 따로 놓는다.** 바탕에 얼룩 · 꽃 · 풀포기를 안 그렸다.
- **울타리 = 「가」 벌 통나무를 32 격자에 잘라 맞춘 마디 셋** (가로 · 세로 · 모서리 기둥). 새로 안 뽑았다.
- **찹쌀이 몸 4장 = 맨 바깥 1px 를 회색 110 한 값으로.** 윤곽은 지금 게임 그림과 픽셀 하나 안 다르다.
- **찹쌀이 크기 주의** : 지금 게임의 1단계 「40px」 은 캔버스가 아니라 **몸 높이**다. 그래서 실제로는 64 캔버스를 **73px(×1.143)** 로 키워 찍는다 (`LayoutConst.MozziTier1Px` · `MozziObject.DivisorOf`). 「64 를 40 으로 줄여 보인다」는 틀린 전제다. 견주기 그림에 ② 칸으로 넣었다.

## 깨끗하지 않은 곳

- **바탕 가운데 십자(x · y 120~136)가 조금 밝다** (밝기 +2 안팎 · 풀잎 획이 조금 성글다). 2×2 로 깔아 ×2 로 봐서는 안 보였다.
- **새 바탕은 「가」보다 어둡고 밋밋하다** (평균 밝기 155 대 162). 얼룩을 빼라는 결정대로지만, 벽지처럼 고른 무늬로 보일 수 있다 — 판정 그림에서 사용자가 본다.
- **가로 울타리 기둥 간격이 원본 46 → 32 로 좁아졌다.** 가로대를 14px 잘라 냈다. 기둥이 빽빽해 보이면 64 마디(가로대를 늘림)로 바꿀 수 있다.
- **아래 울타리도 위와 같은 `fence_h` 를 쓴다.** 원본 한 바퀴 그림의 아래 줄은 기둥 앞면이 더 크게 보이는데 그 짜임은 안 썼다.
- 오른쪽 세로 줄은 왼쪽 그림을 그대로 쓴다 (뒤집지 않음). 빛이 왼쪽 위라 큰 차이는 없다.
- 몸 hop0 은 PixelLab 이 다시 그린 것이라 안쪽 명암 색이 v3 시안과 조금 다르다 (윤곽은 같다).

## 코드에 넘길 것

1. **바탕 까는 법** : `grass_base` 한 장을 PPU 32 · Point 로 넣고 `SpriteRenderer` 의 Draw Mode **Tiled** (Wrap Mode Repeat) 로 농장 넓이만큼 깐다. Tilemap 은 걷어 낸다 (결정 2026-10-03). 256 마다 같은 그림이 되풀이된다.
2. **장식 칸 크기 제안 : 32.** 울타리 안쪽 32 칸마다 확률(시안은 22%)로 하나 놓는다. 무게 시안 값 : 풀포기 0.55 · 흰꽃 0.15 · 분홍꽃 0.08 · 돌 0.17 · 버섯 0.05. 반은 좌우 뒤집기. 씨앗을 고정해 날마다 같은 자리에 둔다. 장식은 바닥 바로 위 겹이고 찹쌀이보다 뒤다 (y 정렬 안 해도 된다).
3. **울타리 짜임** : 가로 n 칸 · 세로 m 칸 격자 (칸 32).
   - 위 줄 : 칸 0 = `fence_post`, 칸 1 ~ n-1 = `fence_h`, 그리고 **칸 n-1 위에 `fence_post` 를 한 번 더 덮는다** (마지막 마디 기둥을 모서리 기둥으로 가림).
   - 아래 줄 : 위 줄과 같다.
   - 양옆 : 칸 0 과 칸 n-1 의 줄 1 ~ m-2 = `fence_v`.
   - `fence_h` · `fence_post` 는 높이 36 이라 칸 위로 4px 솟는다 (칸 바닥에 맞춘다).
   - **겹 순서** : 바탕 → 장식 → 위 줄 · 양옆 (찹쌀이보다 뒤, `FenceBackSortOrder`) → 찹쌀이 (y 정렬) → 아래 줄 (찹쌀이보다 앞, `FenceFrontSortOrder`). 양옆을 y 정렬에 넣으면 더 자연스럽다.
   - 시안 농장은 540×480 안에 16×14 칸(512×452)을 가운데 놓았다.
4. **찹쌀이 몸** : `화풍통일/out/body_hop0~3.png` (2026-10-05 부터의 정본) 를 `Resources/Art/Mozzi/` 의 같은 이름 파일에 덮어 쓴다. 윤곽이 같아 볼 · 표정 · 왕관 자리는 그대로다.
5. **찹쌀이 크기** : 단계 통일 값은 판정 대기. 지금 코드의 40/48/56 은 몸 높이(35px 기준)라 1단계도 ×1.143 으로 커진다. ×1(64 그대로)로 하려면 몸 높이 35 로 두면 된다.
