## 두 꼴이 같은 것

- **바닥 붙임** : 그림 아래끝이 캔버스 바닥에서 1줄 위다 (떡 y 30 · 재료 y 26). 가로는 가운데다.
- **선 색** : 제 색을 짙게 한 따뜻한 색 둘이다. 그늘 쪽(아래 · 오른쪽)은 짙고, 빛 쪽(위 · 왼쪽)은 한 단 옅다. 순검정은 없다.
  흰 떡의 짙은 선은 공용 팔레트 `line` 의 `#3A2E25`, 대추는 `#4A2622` 다.
- **색 수** : 장마다 2색이 늘어 5 ~ 8색이다 (상한 8).
- 24px 자리는 32 그림을 줄여 찍어서 선이 군데군데 빠진다. 두 꼴 다 그렇다 (설계 9-4 의 물을 거리).
- 쑥 잎의 막힌 구멍 둘은 선을 두르면 눈처럼 보여 메웠다.
