## 알고 있는 흠

- 떡메 가루 3~4장은 떡메를 든 채 가루가 먼저 튄다. 순서가 살짝 어색하다. 거슬리면 3~4장을 건너뛰고 0,1,2,5,6 으로 돌려도 된다.
- 수집기 v2 의 빨림 줄(4~6장)은 알갱이보다 막대 줄처럼 보인다. 공급기 v2 는 알갱이가 떨어지는 장이 셋뿐이고 통은 거의 안 움직인다.
- 맷돌 자리는 아직 정하지 않았다. 견줌판 자리는 임시다.
- 가판대 장식 자리도 임시다. 화분이 계산대 오른쪽 끝과 붙어 보인다.
