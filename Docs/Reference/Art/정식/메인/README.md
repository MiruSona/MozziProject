## 깨끗하지 않은 곳

- **먼 숲 띠가 v7(69 줄)보다 높다** (약 90 줄). 기계 깔때기 뒤로 숲이 더 보인다. 거슬리면 하늘을 다시 뽑기보다 `sky.png` 를 코드에서 몇 줄 내려 놓으면 된다 (잔디가 덮는다).
- 하늘 위쪽(9:20 에서만 보이는 곳)의 구름은 **같은 원본 구름 조각을 옮겨 놓은 것**이라 자세히 보면 같은 구름이 두 번 나온다 (뒤집어 놓아 덜 띈다).
- 하늘 그림 좌우 끝에 잘린 구름이 하나씩 있다 (원본 576 을 540 으로 자른 자리).
- 길은 v1 부품을 뒤집어 이은 것이라 x≈280 에 좌우 대칭 이음매가 있다 (v7 과 같다). 정식 길을 따로 뽑지 않았다.
- 도감 책이 조금 비뚤게 기울었다. 강화 화살표 옆 반짝이가 틀 안쪽 선에 붙어 있다.
- 보관함은 정면 그림이고 가게 · 기계보다 픽셀 굵기가 같지만 명암이 단순하다 (원래 후보 그대로).
- 건물 셋의 빛 방향은 모두 왼쪽 위로 보인다 (눈으로만 봄). 가게 바닥선은 몸체 y 200 · 문턱 y 202 로 2px 층이 있다 — 피벗은 문턱(맨 아랫줄) 기준이다.
