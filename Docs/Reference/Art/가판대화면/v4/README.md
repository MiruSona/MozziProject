## 결론

- **v3 구도 그대로다.** 카메라는 계산대 안쪽에 있고 손님이 계산대 너머에 선다.
- **주인은 계산대 안(카메라 쪽)에 선다.** 큰 그림 10차 A 를 그대로 쓴다. 뒷모습은 안 만든다 (사용자 확정).
- **떡 만들기 작업대를 뺐다.** 대신 아래 왼쪽에 「주방」 작은 아이콘이 있다. 누르면 주방 화면으로 간다.
- **이미 찾은 떡은 벽 차림표를 눌러 바로 만든다.** 목록이 뜨는 것은 UI 느낌이 나지만 받아들인다 (사용자 확정).
- **줄은 큰 손님이 겹치지 않고 순서대로 선다.** 문 쪽에서 계산대 쪽으로 2명만 보이고 나머지는 문밖이다.

- 겹 순서 : 벽 → 손님 → 계산대 → 진열장 → 주인. 계산대 윗면이 주인 뒤에 온다.

## 차림표를 「오늘의 떡」 칠판과 합친 까닭

- **벽에 칠판이 하나만 있는 쪽이 덜 복잡하다.** 따로 두면 벽의 절반이 판이 되고 손님 머리 위 자리가 준다.
- 칠판 위쪽은 「차림표」(떡 그림 셋), 아래 한 줄은 「오늘의 떡 : 팥떡」 이다. 칠판 어디를 눌러도 목록이 뜬다.

## 차림표 목록 (곁그림)

- 밝은 종이 패널 한 장이다. 2열 × 6줄에 떡 11종이 다 들어간다 (스크롤 없음).
- 찾은 떡 : 떡 그림 · 이름 · 값 「15G」 · 「만들기」 버튼. 못 찾은 떡 : 「? 아직 못 찾은 떡」.
- **떡 이름과 값은 자리표시다.** 이름은 그림 파일 이름에서 지었고 값은 전부 15G 로 적었다.

## 깨끗하지 않은 곳

- **둘째 손님이 문을 거의 가린다.** 문 위쪽만 보인다. 정식 그림에서는 문을 왼쪽 끝으로 옮기거나 줄 간격을 넓힌다.
- 주인이 둘째 손님의 다리 쪽과 조금 겹친다.
- 주인 뒤 아래쪽 판(계산대 안쪽)이 비어 있다. 정식 그림에서 선반 · 서랍을 그린다.
- 주인(10차 A)은 도트 굵기가 배경보다 가늘다. 큰 판을 화면 굵기에 맞춰 다시 뽑아야 한다.
- 목록이 뜨면 뒤 화면이 그대로 보인다 (어둡게 덮지 않았다).
- 안 그린 것 : 문 여닫는 그림 · 손님이 걸어 들어오는 그림 · 만들기 누른 뒤 연출.
