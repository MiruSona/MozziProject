## 깨끗하지 않은 곳

- **가게가 240×200 이 한계다.** pro_flash 캔버스가 256 까지라 540 폭 화면의 절반쯤만 찬다. ×2 로 키우면 손님·찹쌀이와 도트 굵기가 달라져 안 키웠다. 그래서 9:16 에서도 하늘이 넓다.
- **주인이 손님의 두 배 크기다.** 주인 128×160 을 절반으로 줄이면 얼굴이 뭉개진다. 맞는 길은 주인을 손님 크기(64×80)로 **새로 뽑는 것**이다 — 손님을 2배로 키우는 것은 답이 아니다.
- 넓은 버튼의 모서리 잎 장식이 버튼마다 되풀이돼 시끄럽다. 꺼진 버튼은 글자 색만 흐리게 했다 (꺼진 버튼 그림이 없다).
- 말풍선 속 떡 아이콘이 말풍선에 꽉 찬다.
