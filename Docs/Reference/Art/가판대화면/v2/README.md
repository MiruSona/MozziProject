> 시안 그림 : `Docs/Reference/Art/시안/2026-10-03-가판대화면-v2.png` (왼쪽 v1 · 가운데 9:16 · 오른쪽 9:20)

## 결론

- **가게가 화면 폭을 채운다.** 가게 그림 508×428 한 장을 540 폭 화면에 ×1 로 세웠다.
- **아래 종이 패널을 없앴다.** 기능은 전부 화면 속 물건으로 옮겼다 (아래 대응표). 새 기능은 없다.
- 남은 UI 는 윗줄(골드 · 이름 · 닫기 · 오늘 손님)과 오른쪽 아래 아이콘 버튼 둘뿐이다.

## 큰 가게를 어떤 길로 뽑았나

| 길 | 결과 | 고름 |
| --- | --- | --- |
| ① 256 조각을 나눠 뽑아 잇기 | 안 해 봤다. 조각마다 지붕 · 기둥 선이 달라 이음새가 보일 위험이 크다 | 버림 |
| ② 더 큰 캔버스 도구 (`create_image_pro` 512×448) | 한 장에 508×428 로 왔다. 40회 | **고름** |
| ③ 240 가게를 ×2 로 키우기 | 도트 한 칸이 2px 이 돼 손님 · 찹쌀이(×1)와 굵기가 달라진다 | 버림 |

- ② 의 흠 : v1 가게보다 면이 넓고 깔끔하다. 덩굴 · 자잘한 무늬가 적어 조금 「새 건물」 같다.
- 화풍 그림은 v1 가게의 112×112 조각을 넣었다 (내가 뽑은 그림이다).

## 깨끗하지 않은 곳

- **주인 v11 은 아직 미확정이다.** 스크립트가 구울 때 그 파일이 있어서 썼다. 사용자가 다른 번호를 고르면 바뀐다.
- 모래 마당은 한 장을 좌우로 뒤집어 이었다. 초록 싹과 흰 잡티가 줄지어 보인다.
- 바구니 아래 숫자와 「담음」 글은 물건 밖에 뜬 글이다. 바구니에 달린 꼬리표 그림은 안 뽑았다.
- 앞치마 아이콘이 작고 자루처럼 보인다. 다시 뽑아야 한다.
- 절구는 화풍 그림 없이 뽑아 가게보다 선이 굵고 진하다.
- 칠판 · 문패 · 접시 자리는 눈으로 잰 좌표다. 가게를 다시 뽑으면 다시 재야 한다.
- 안 그린 것 : 떡메 치기 연출 · 밤 · 닫힘 상태 · 레시피가 여럿일 때 팻말 줄 · 진열 떡이 여러 종일 때.
