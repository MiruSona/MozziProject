## 결론

- **카메라가 손님 쪽(가게 홀)에 있다.** v4 에서 「안 고른 안」 으로 작게 붙였던 구도를 본 그림 크기로 만들었다.
- **주인은 계산대 뒤에서 이쪽을 본다.** 큰 그림 10차 A 그대로다. 허리 아래는 계산대에 가려진다. 뒷모습은 없다.
- **손님은 새 그림 없이 앞 보는 그림 그대로 계산대 앞 마루에 섰다.** 그래서 손님이 주인에게 등을 돌리고 이쪽을 본다.
- 들어간 기능은 v4 와 같다. 빠진 것은 없다.

## 깨끗하지 않은 곳

- **손님이 주인을 등지고 이쪽을 본다.** 옆모습 · 뒷모습 그림이 없어서다. 어색하면 손님 옆모습을 새로 뽑아야 한다.
- **주인 베레모가 칠판 오른쪽 아래 귀퉁이를 조금 가린다.** 주인을 더 내리면 얼굴만 남아서 이 높이로 뒀다.
- **9:20 에서 들보가 위에서 끊긴다.** 위 60 줄이 한 가지 색이라서다. 정식 그림은 9:20 높이로 뽑는다.
- 둘째 손님 머리가 계산대 오른쪽 끝과 문 아래 귀퉁이에 조금 걸친다.
- 주인이 진열장과 조금 겹친다 (진열장이 앞).
- 왼쪽 선반이 화면 가장자리에서 잘려 있다 (배경 그림이 그렇게 왔다).
- 목록이 뜨면 윗줄(골드 · 닫기)도 같이 어두워진다.
- 안 그린 것 : 문 여닫는 그림 · 손님이 걸어 들어오는 그림 · 화살표(글자 표로 대신함).
