# 손님 그림 레퍼런스 조사 2 — 흰 사람

> 앞 조사(`2026-09-21-손님그림레퍼런스조사.md`)의 「헤어·모자·옷으로 가른다」가 물러났다.
> 손님은 **특징 없는 흰 사람 덩어리 + 표정 + 볼터치**로 간다 (찹쌀이와 같은 식).
> 날짜 2026-09-21 · 조사만 했다 · 상태 **제안 단계, 결정은 사용자**

## 1. 결론 먼저

- **비율은 안 A(2등신 큰머리 콩몸)를 권한다.** 캔버스 48×64 · 키 56px · **머리 28×26 · 어깨 22 · 팔 3px · 다리 5px.**
  어깨가 머리보다 좁은 것은 이 비율에서 **저절로 따라온다.**
- **겹은 3~4장뿐이다** — 몸 1(흰색, 색 곱하기) + 표정 3~5 + 볼 1 (+ 선택 소품 1). 앞 안의 12장에서 크게 준다.
- **찹쌀이 표정 10장은 그대로 못 쓴다.** 실측했다 — `face_01` 은 **가로 16px**, 찹쌀이 몸통은 42px 이다.
  손님 머리를 28px 로 잡으면 얼굴은 12~14px 이어야 해서 **같은 화풍으로 다시 찍어야** 한다.
- **흰 몸의 명암·색값은 찹쌀이 몸에서 그대로 베낀다** (`#FEFDFC` + 회색 4단). 이미 풀린 문제다.
- **「메챠 카멜레온」은 찾았다** — 2026년 6월 10일에 나온 일본 인디 멀티 게임이고, **흰 백지 상태의 두 발 캐릭터**가 맞다 (4절).

## 3. 시안 v1 이 왜 안 맞았나

`Docs/Reference/Art/손님/preview_layers.png` 를 보고 스크립트 숫자를 읽었다. 문제는 셋이다.

| 무엇 | v1 값 | 왜 문제인가 |
| --- | --- | --- |
| 몸통이 네모 상자 | `TORSO_X0..X1 = 16..32` — **폭 16px 이 어깨부터 허리까지 그대로** | 어깨에서 허리로 흐르는 선이 없다. 사람이 아니라 상자로 읽힌다 |
| 어깨가 머리보다 넓다 | 어깨 16 + 소매 2 = **18**, 머리 폭 **18** | 같거나 넓다. SD 관례는 어깨를 머리보다 좁게(또는 같게) 두고 **둥글게 기울인다** |
| 팔이 1px | `ARM_XL/XR` 폭 1 | 앞 조사에서 「16px 짜리는 1px」을 읽고 그대로 옮겼는데, **48px 짜리는 2~3px 이 맞다.** 1px 은 막대기로 보인다 |

머리·얼굴 자리(`HEAD_CY 25` · `EYE_Y 27` · `MOUTH_Y 31`)와 볼터치 자리는 **쓸 만했다.**

## 4. 레퍼런스에서 알아낸 것

### (1) 휴먼 폴 플랫의 밥 (Bob)

- **왜 특징이 없나** — 「완전한 백지 상태로 시작해 아무 특징도 없다」가 의도다. 플레이어가 **자기를 투영하고 꾸며 넣게** 하려는 것이다.
  얼굴·손가락·발가락이 **아예 없고** 흰 피부에 모자 하나만 얹혀 있다.
- **모양** — 「반죽 인형 같은 체형」으로 묘사된다. 각이 없고 **끝이 뭉툭한 팔다리**에 말랑한 실루엣이다.
- 비율 자체는 SD 가 아니라 **거의 사람 비율(4~5등신)**이다. 그래서 **비율이 아니라 「말랑함」만 가져오는 게** 맞다.

### (2) 메챠 카멜레온 — 찾았다

- 2026-06-10 출시, 개발 `Lemorion_1224` · `Haganeiro`, 윈도우/스팀. 술래잡기 캐주얼 멀티.
- **「흰색의 두 발로 걷는 캐릭터」**가 맞다. **순백의 백지 상태**로 시작해 **플레이어가 제 몸에 색을 칠해** 배경에 숨는다.
- 눈·표정에 대한 서술은 문서에 **없다.** 「몸 크기 조정」과 「온몸을 정사각형으로」 같은 꾸미기 기능이 있다.
- **뜻하는 바** : 흰 몸은 **꾸밈의 바탕**이지 완성이 아니다. 손님도 **몸 색 곱하기**로 개성을 주는 쪽이 이 갈래와 맞는다.

### (3) 같은 갈래 — 빈 흰 사람

- 같은 갈래의 파티 게임들은 **두 발로 걷는 덩어리(blob)**에 옷·색만 갈아입힌다. 얼굴이 없거나 점 두 개다.
- 공통점은 **① 각이 없다 ② 손발이 뭉툭하다 ③ 기본 상태는 무채색이다** 셋이다.

### (4) SD(슈퍼 데포르메) 비율 — 숫자로

- **등신은 1.75~3등신** 범위다. 2등신이면 **머리와 몸이 거의 같은 크기**, 3등신이면 몸통·상체·하체가 비슷한 비율로 나뉜다.
- **몸통은 상자가 아니라 콩(bean)·배(pear)·달걀 모양**이다. **엉덩이가 가장 넓고 어깨는 작게** 둔다.
- **어깨** — 「머리보다 살짝 넓되 각지지 않고 둥글게」와 「어깨와 목은 작게」가 같이 나온다.
  즉 **핵심은 폭보다 「각이 없고 기울어진 어깨선」**이다. 픽셀 48px 에서는 **어깨를 머리보다 좁게** 두는 쪽이 읽기 쉽다.
- **팔다리** — 「부드러운 원통 또는 선 + 벙어리장갑」으로 줄인다. 팔꿈치·무릎은 고무호스처럼 흐물흐물하게, **팔다리는 좀 두껍게** 둔다.
  **팔이 다리보다 두꺼우면 안 된다.**
- **목** — 「없애지는 말고 **머리 높이의 1/4 이하**로 짧게」다. 48px 짜리면 **1~2px** 이거나 아예 생략이다.

### (5) 흰 몸을 픽셀로 — 이미 저장소에 답이 있다

찹쌀이 몸(`Resources/Art/Mozzi/body_hop0.png`)을 실측했다.

| 무엇 | 값 |
| --- | --- |
| 몸 불투명 크기 | 42×35 (64×64 캔버스 안) |
| 색 | `#FEFDFC`(1066px) + `#E0DFDD` · `#C7C6C4` · `#B6B5B4` · `#A6A5A2` |
| 외곽선 | **없다** |

- 즉 **흰색 하나가 아니라 흰색 + 회색 4단**이다. 아래·오른쪽으로 갈수록 어두워져 덩어리로 읽힌다.
  **손님도 이 다섯 색을 그대로 쓰면 찹쌀이와 한 벌로 붙는다.**
- 밝은 바닥에서 흰 몸이 묻히는 문제의 표준 대처는 셋이다 — **① 자리마다 색이 다른 외곽선(selective outline)
  ② 뒤에서 오는 빛처럼 한쪽 가장자리만 밝게(rim) ③ 발밑에 옅은 바닥 그림자**.
  이 게임은 「외곽선 없음」이 규칙이므로 **③ 바닥 그림자**가 가장 싸고 규칙과 안 부딪친다.

### (6) 흰 사람 다섯을 어떻게 가르나

효과가 큰 순서다.

| 순위 | 수단 | 비용 | 실루엣이 바뀌나 |
| --- | --- | --- | --- |
| 1 | **몸 색 곱하기** (옅은 파스텔 5색) | **0장** — 코드 숫자 하나 | 아니오 (그래도 가장 잘 구별된다) |
| 2 | **키·통통함 2~3단계** | 0장 — 그릴 때 값만 바꿔 몸을 2~3벌 뽑는다 | **예** |
| 3 | 표정 | 장당 1장 | 아니오 |
| 4 | 소품 1점 (가방·목도리) | 장당 1장 | 예 (작게) |

찹쌀이는 `MozziVisual`·`MozziArtKeys` 에서 **몸 색 곱하기 + 표정 + 악세사리** 셋으로 12종을 가른다.
**손님도 이 틀을 그대로 쓸 수 있다** — 폴더만 `Art/Customer/` 로 새로 만들면 된다.

## 5. 비율안 셋 — px 숫자와 격자 그림

셋 다 **캔버스 48×64 · 가로 한가운데 `CX=24` · 발바닥 `y=64`** 다 (v1 과 같다).
아래 격자는 **한 칸이 2px**인 대략 그림이다. 정확한 값은 표를 본다.

### 안 A — 2등신 큰머리 콩몸 (권함)

| 부위 | 값 (px) | 자리 (y) |
| --- | --- | --- |
| 전체 키 | **56** | y8~64 |
| 머리 | **28 넓이 × 26 높이** (타원) | y8~34 |
| 목 | **없다** (머리 아래가 곧장 어깨) | — |
| 어깨 폭 | **22** (머리 28보다 **6 좁다**) · 둥글게 기울인다 | y34 |
| 허리 폭 | **17** | y42 |
| 엉덩이 폭 | **20** (여기가 가장 넓다) | y50 |
| 팔 | **폭 3 · 길이 14** · 끝 둥글게 | y36~50 |
| 다리 | **폭 5 · 길이 14** · 사이 틈 2 | y50~64 |
| 얼굴(눈·입) 들어갈 넓이 | **12~14** | 눈 y20 · 입 y26 |
| 볼터치 | **5×5** 두 개 | y23 |

```
      ########        머리 28 - 몸에서 가장 넓다
    ############
    ##.##..##.##      눈 두 점 + 볼터치
    ####.__.####      입
      ########
       ######         어깨 22 - 머리보다 좁고 둥글다
     # ######  #      팔 3px, 몸통과 1px 띄운다
     # #####   #      허리 17 - 여기서 좁아진다
     # ######  #      엉덩이 20 - 다시 넓어진다
       ###  ###       다리 5px, 틈 2px
       ###  ###
```

- **왜 권하나** — ① 표정·볼터치만으로 가르려면 얼굴이 커야 하는데, 찹쌀이 얼굴은 몸통 42px 에 16px(38%)이다.
  머리 28 에 얼굴 13 이면 **46%** 로 눈금이 비슷하다. ② 어깨 22 < 머리 28 이라 **「어깨 좁게」가 저절로 된다.**
  ③ 몸이 22px 밖에 안 돼 **상자가 될 여지가 없다.** ④ 찹쌀이(몸 35px) 대비 키 56 = **1.6배**로 나란히 세워도 자연스럽다.
- **휴먼 폴 플랫의 말랑함은 여기서 가져온다** — 각 없는 어깨 · **끝이 둥근 3px 팔** · 몸통보다 살짝 긴 팔.

| 팔 | 폭 3 · 길이 15 |

  표정으로 가르는 이번 방향과 어긋난다.

## 6. 겹 구성안

| 겹 | 파일 | 캔버스 | 몇 장 | 무엇 |
| --- | --- | --- | --- | --- |
| 몸 | `body` (또는 `body_s`·`body_m`·`body_l`) | 48×64 | **1~3** | 흰색 `#FEFDFC` + 회색 4단. **색은 코드가 곱한다.** 키·통통함을 2~3단계로 뽑으면 실루엣까지 갈린다 |

### 찹쌀이 표정 10장을 그대로 쓸 수 있나 — 못 쓴다

실측한 숫자다.

| 무엇 | 값 |
| --- | --- |
| `face_01` 실제 크기 | **16×8** (64×64 캔버스 안, 눈·입만) |
| `face_02` 실제 크기 | 20×10 |
| 찹쌀이 몸통 넓이 | 42 → 얼굴이 몸의 **38%** |
| 안 A 의 머리 넓이 | 28 → 얼굴은 **12~14** 여야 한다 |

- 16px 짜리를 13px 로 줄이면 **정수배가 아니라 눈 모양이 뭉개진다.** 눈이 2px 인데 줄이면 1px 이 돼 모양이 사라진다.
- **다시 찍는다.** 다만 **화풍은 그대로 베낀다** — 눈은 검정 `#12110F` 한 색, 안티에일리어싱 없음.
- **볼터치도 다시 그린다.** 찹쌀이 `cheek.png` 는 11×11 에 **노랑 계열(`#FBD701`)**이라 사람 볼로는 안 맞는다
  (이건 실측값이다 — 왜 노랑인지는 못 알아봤다. 9절 물음 5번).

## 7. 시안 v1 에서 살릴 것 · 버릴 것

`Docs/Reference/Art/손님/draw_customer_v1.py` 얘기다.

| | 무엇 |
| --- | --- |
| **살린다** | 스크립트 뼈대 — `ellipse` · `rect` 도우미, `Layer` 클래스, `paint`(그늘·하이라이트 자동), `compose` |
| **살린다** | 미리보기 넷 — `preview_layers`(겹 따로) · `preview_cell`(칸에 넣어 보기) · `preview_scale`(키 비교) · `preview_tint`(색 곱하기). **판정에 그대로 쓴다** |
| **살린다** | 캔버스 값 `W,H = 48,64` · `CX = 24` · `GROUND_Y = 64` · 칸 `68×80` · 떡을 머리 위에 얹는 자리 |
| **살린다** | 머리·눈·입·볼 y 자리 감각 (값은 안 A 로 다시 잡는다) |
| **버린다** | `layer_cloth_apron`(옷) · `layer_hair_bob`(머리카락) — 방향이 바뀌었다 |
| **버린다** | 살색 몸 — 흰색 `#FEFDFC` + 회색 4단으로 바꾼다 |
| **버린다** | `TORSO_X0..X1` 네모 몸통 — 어깨→허리→엉덩이로 흐르는 폭 표로 바꾼다 |
| **버린다** | 1px 팔 (`ARM_XL/XR`) — 3px 둥근 끝으로 |
| **버린다** | 목 (`NECK_Y0..Y1 = 33..37`) — 안 A 는 목이 없다 |

## 8. 다음 판이 바로 그릴 수 있게 — 할 일 차례

1. `draw_customer_v2.py` 를 만든다. v1 을 복사해 **5절 안 A 표의 숫자**를 위쪽 상수로 박는다.
2. 몸을 **폭 표**로 그린다 — y34 에서 22, y42 에서 17, y50 에서 20 으로 **줄마다 폭을 보간**하면 콩 모양이 나온다.
   (네모를 쌓지 않는다. 이게 v1 이 실패한 자리다)
3. 색은 찹쌀이 몸의 다섯 색(`#FEFDFC` `#E0DFDD` `#C7C6C4` `#B6B5B4` `#A6A5A2`)을 그대로 쓴다. 빛은 왼쪽 위.
4. 표정 3장(기본·웃음·시무룩)을 얼굴 넓이 13px 안에 찍는다. 눈은 `#12110F` 한 색.
5. 볼터치 5×5 분홍 1장 + 바닥 그림자 1장.
6. `preview_tint` 로 **몸 색 5개**, `preview_scale` 로 **찹쌀이 35px · 건물 64px 과 나란히** 뽑아 사용자에게 보인다.
7. **안 A 가 아니라고 나오면 상수만 안 B·C 값으로 바꿔 다시 돌린다.** 그래서 상수를 위에 모은다.

## 9. 못 정한 것 · 사용자에게 물을 것

| # | 물음 | 왜 |
| --- | --- | --- |
| 1 | **안 A(2등신 큰머리)로 갈까?** | 5절 표에서 하나를 고르는 일이다. 나머지가 다 따라온다 |
| 2 | **몸을 2~3벌(키·통통함) 그릴까, 한 벌에 색만 바꿀까?** | 한 벌이면 5명이 실루엣으로는 똑같다. 세 벌이면 그릴 것이 2장 는다 |
| 3 | **발밑 바닥 그림자를 넣을까?** | 흰 몸이 밝은 바닥에 묻히는 것을 막는 가장 싼 수단이다. 대신 찹쌀이에는 없어서 손님만 있으면 어색할 수 있다 |
| 4 | **표정을 몇 가지 그릴까 (3 · 5)** | 기다린 시간에 따라 바꿀 생각이 있으면 5, 아니면 3 |
| 5 | **찹쌀이 `cheek.png` 가 노란색인 것이 맞나?** | 실측이 `#FBD701` 이다. 손님 볼을 분홍으로 하면 둘이 안 맞는다 |
| 6 | **소품(가방·목도리)을 넣을까?** | 없어도 5명은 갈린다. 넣으면 「손님마다 사연이 있다」는 느낌이 는다 |
| 7 | **손을 뭉툭한 덩어리로 둘까, 아예 없앨까?** | 참고한 게임의 밥은 손가락이 없다. 3px 팔이면 손을 따로 안 그려도 된다 |
