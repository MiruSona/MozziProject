## 2. 임시 숫자 (프로토에 박힌 것)

| 항목 | 값 |
| --- | --- |
| 찹쌀가루 생산 | 1마리당 15초에 1개 |
| 부재료 생산 | 1마리당 30초에 1개, 단계 배수 ×1 / ×1.5 / ×2 |

| 떡 값 | 부재료 단계별 10 / 30 / 90 골드 |

| 잉여 찹쌀이 팔기 | 20 골드 |
| 부재료 이름 (자리표시) | 잔디=풀 · 물=물풀 · 용암=숯 · 늪=이끼 → 계열당 1종 = 총 4종 |
| 떡 이름 규칙 | 부재료 이름 + 단계 (부재료 1종 = 떡 1종) |
| 판매 | 「팔기 1개 / 팔기 전부」 즉시. 판매 대기·속도 개념 없음 |
| 시작 | 골드 0 · 찹쌀이 2마리 |

## 5. 빈 구멍 (어디에도 값·규칙이 없는 것)

| 구멍 | 왜 |
| --- | --- |
| 떡 종류 수 | 레시피 도감이 몇 칸인지 없다. q1-2 는 6개, q2 는 12종 |
| 부재료 종류표 | 어느 찹쌀이가 어느 부재료를 뱉는지 표가 없다 |
| 레시피가 부재료 몇 개짜리인가 | q1-2 는 1~3개, q2 는 1개 |
| 판매 대기 시간 · 판매 속도 | 둘 다 즉시. 가판대 강화의 「판매 속도」 정의도 없다 |
| 손님 수 · 줄 길이 · 주문 간격 · 보너스 배율 | 숫자가 하나도 없다 |
| 떡 보관 상한 | 재료 상한은 있는데 떡 상한은 없다 |
| 떡 값을 무엇이 정하나 | 부재료 단계로만 갈린다. 레시피 떡 vs 평범한 떡 차이 없음 |
| 제작 시간 | 둘 다 즉시. 「빠른 시계 15~30초」가 생산 주기인지 제작 시간인지 안 갈렸다 |
| 자동화 설비 값·처리량 | 없음 |
| 가판대 강화 축·값 | 낱말뿐 |
| 가판대가 화면 어디인가 | 별도 화면인지 농장 위 건물인지 안 정했다 |
| 찹쌀가루 남는 문제 | 가루 15초·부재료 30초라 가루가 구조적으로 남는다 |
| 방치 중 판매 | 설비 사기 전에도 방치 판매가 되는지 미정 |

## 6. 다음 세션이 답할 물음 8개

순서대로, 하나씩 답한다.

1. 부재료를 몇 종으로, 어느 찹쌀이에 붙일까 — 아래 안 셋
2. 레시피는 부재료 몇 개짜리인가, 레시피 도감은 몇 칸인가
3. 판매 속도·대기 시간 개념 (손님 주문 부드러운 안과 같은 자리)
4. 떡 값 규칙 (레시피 떡 vs 평범한 떡, 단계)
5. 제작 시간
6. 손님 수·줄 길이·주문 간격·보너스 배율
7. 자동화 설비 값·시점, 설비 전 방치 판매 여부
8. 가판대가 화면 어디인가
