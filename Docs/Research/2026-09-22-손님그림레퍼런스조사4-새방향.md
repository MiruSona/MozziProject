# 손님 그림 레퍼런스 조사 4 — 카페 운영 게임의 손님

> 시안 v1~v6 이 전부 물러난 뒤 사용자가 레퍼런스 방향을 직접 정했다 —
> **「카페 운영 게임류에서 손님을 참고. 2D·픽셀 위주. 카이로소프트 게임도 참고.」**
> 그 초점으로 다시 조사했다.
> 날짜 2026-09-22 · 조사만 했다 · 상태 **제안 단계, 결정은 사용자**

**베끼지 않는다.** 아래 게임들은 **화풍과 수치를 재는 자**로만 쓴다. 남의 캐릭터를 옮겨 그리지 않고,
그림은 저장소에 한 장도 안 넣었다 (카이로소프트 낱장 넷은 임시 폴더에서 재고 버렸다).
기획서(`Docs/Design/`)로 옮길 때는 게임 이름을 「같은 갈래의 경영 게임」처럼 바꿔 쓴다.

## 1. 결론 먼저

- **카이로소프트 손님은 실측했다.** 몸 **12×20px · 2~2.2등신 · 검정 외곽선 · 재질마다 2단 명암 ·
  낱장 22~31색**이다 (3절). 손님을 가르는 것은 몸 모양이 아니라 **머리색 · 머리 모양 · 옷 색**이다.
- **이 방식이 v1~v6 의 막힌 곳을 정확히 푼다.** 우리가 막힌 까닭은 「맨몸을 단순하게 그리려 했다」인데,
  카이로소프트는 **살색을 얼굴에만 쓰고 나머지를 옷으로 덮는다.** 그리면 그릴수록 사람다워진다.
- **후보를 셋으로 좁혔다** (5절) — **가 카이로식 SD 사람(권함)** · 나 스타듀식 마을 사람 · 다 동물 손님.
- **가(카이로식)를 권한다.** 사용자가 직접 고른 레퍼런스이고, 「얼굴이 너무 크다(v5)」와
  「어른 몸이라 기괴하다(v6)」 사이를 **머리카락 덩어리**로 메운다 (6절).
- **안전판은 다(동물 손님)다.** 사람을 그리는 길이 또 막히면 사람을 버리는 쪽이 가장 확실하다.

## 2. v6 이 왜 기괴했나 (짧게)

`v6/preview_v5_v6.png` 를 v5 와 나란히 보고 세운 가설 셋이다. **사용자 판정이 필요하다.**

1. **머리를 22px 로 줄인 순간 아기 비율이 어른 비율이 됐는데, 옷도 머리카락도 없는 맨몸이라
   「옷 안 입은 작은 사람」으로 읽힌다.** (가장 크다)
2. **외곽선이 몸을 속 빈 껍질로 만들었다.** 크림 바탕에서 속색과 바탕색이 같아 선만 남고, 다리 틈이 해부도처럼 보인다.
3. **한 단 명암이 3px 팔을 고무관으로 만들었다.** 굵기의 3분의 1이 그늘이면 마네킹 팔이 된다.

**셋이 겹치는 자리는 「사람 꼴인데 사람 정보가 없다」이다.** 3절의 카이로소프트가 이 자리를 어떻게
피하는지가 이번 조사의 핵심이다.

## 3. 카이로소프트 손님 — 실측

`kairosoft.wiki.gg` 의 인물 낱장 넷(`Chef`·`Chess Master` = 봉봉 케이크 가게,
`Cheerleader`·`Chemist` = 세계 일주 이야기, `Chairprsn` = 온천 이야기)을 임시 폴더에 받아
**원본 격자(3배 확대본이었다)로 되돌려 쟀다.**

### 잰 값

| 항목 | 값 | 어떻게 알았나 |
| --- | --- | --- |
| 캔버스 | **16 × 24 px** (일부 16×23) | 3배 확대본 50×70·50×72 를 되돌렸다 |
| 실제 몸 | **12 × 19 ~ 14 × 22 px** | 투명 아닌 칸의 테두리 |
| 등신 | **약 2 ~ 2.2** | 머리(머리카락 포함) 9~10px ÷ 전체 20~22px ≈ 45% |
| 머리 폭 | **10 ~ 11 px** | 어깨 폭(12px)과 **거의 같다** |
| 몸 폭 | **12 px** (어깨) · 허리도 거의 안 좁아진다 | 줄마다 폭을 세어 봤다 |
| 팔 | **몸에 붙어 있다. 폭 2px.** 손은 살색 점 1~2px | 팔과 몸 사이에 빈 칸이 없다 |
| 다리 | **짧다.** 3~4px 두 개, 맨 아래 1~2줄은 어두운 신발 | |
| 외곽선 | **있다. 거의 검정** (`#212421` · `#290C08`) | **낱장에서 가장 많이 쓰인 색이다** — 12×20 안에서 31~51칸 |
| 명암 | **재질마다 2단** (밝은 면 + 그늘 한 단). 평면에 가깝다 | 살색이 `#FFDB9C` + `#E6BA7B` 두 개뿐 |
| 눈 | **1 × 2px 세로 막대 두 개**, 검정 | |
| 입 | **1~2px 점** (붉은 기) | |
| 볼 | 주황·분홍 점이 있는 인물이 있다 (전원은 아니다) | 체스 선수에 있다 |
| 색 수 | **낱장 22 ~ 31색** | 투명 뺀 낱색 세기 |
| 걷기 프레임 | **못 쟀다** — 낱장만 받았고 시트를 못 구했다 | |

### 읽은 것 다섯

1. **살색은 얼굴에만 쓴다.** 나머지는 전부 옷·신발·모자다. **그래서 맨몸 문제가 원천에서 없다.**
2. **머리카락이 머리 덩어리를 키운다.** 얼굴(살색 타원)은 7~8px 로 작은데, 머리카락이 위와 옆을
   덮어 머리 전체가 10px 이 된다. **얼굴은 작고 머리는 크다** — v5 「얼굴이 너무 크다」와
   v6 「머리가 작아 어른 같다」 사이가 바로 여기다.
3. **검정 외곽선이 가장 많이 쓰인 색이다.** 우리 v6 은 「몸 색을 어둡게 한 선」이라 약했다.
   카이로소프트는 아예 검정에 가깝게 둬서 **어떤 바탕에서도 안 묻힌다.**
4. **몸 폭이 위아래로 거의 안 변한다.** 허리를 안 좁힌다 — 그래서 「사람 몸매」가 아니라
   **「네모난 덩어리에 얼굴이 붙은 것」**으로 읽힌다. 사용자가 싫어한 마네킹·페그돌은
   오히려 **허리가 잘록하고 팔이 떨어져 있을 때** 나온다.
5. **손님을 가르는 것은 실루엣이 아니라 색이다.** 머리색 · 머리 모양 · 옷 색 · 모자 넷으로 가른다.
   **몸 뼈대는 전부 같은 한 장을 쓴다.** 그래서 손님을 100명 만들어도 그릴 것이 안 는다.

## 5. 후보 방향 셋

우리 제약 : **캔버스 48×64 안팎 · 손님 칸 68×80 · 찹쌀이 몸 35px 옆 · 가판대는 분홍 카페풍 ·
남녀 구분 없음 · 주문은 말풍선 · 빛은 왼쪽 위.**

### 안 가 — 카이로식 SD 사람 (권함)

> **한 줄 분위기** : 머리카락과 옷을 갖춘, 손바닥만 한 동네 사람. 얼굴은 점 둘과 점 하나.

| 요소 | 값 | 카이로소프트 실측에서 어떻게 왔나 |
| --- | --- | --- |
| 캔버스 | **48 × 64** (그대로) | 16×24 의 **두 배 조금 넘는다.** 더 그릴 자리가 있다 |
| 키 | **44 px** (찹쌀이 35px 의 1.26배 — 주인공이 안 밀린다) | |
| 등신 | **2.2** | 실측 그대로 |
| 머리 덩어리 | **높이 20 · 폭 24** | 머리 폭 ≒ 어깨 폭 (실측) |
| 얼굴(살색) | **폭 14 · 높이 12.** 나머지는 머리카락이 덮는다 | 얼굴 7~8px 를 두 배로. **v5 의 13px 보다 넓다** |
| 몸 | **높이 24 · 폭 26.** 허리를 안 좁힌다 | 실측 그대로 — 잘록하면 마네킹이 된다 |
| 팔 | **몸에 붙인다. 폭 4px.** 손은 살색 점 2×2 | 실측 그대로. 띄우지 않는다 |
| 다리 | **짧게 8px 두 개**, 아래 3px 는 어두운 신발 | |
| 외곽선 | **거의 검정 1px** (`#2A2420` 쯤) | **몸 색 기준 선은 약했다.** 검정으로 바꾸는 것이 이번 판의 핵심 |
| 명암 | **재질마다 2단**(밝은 면 + 그늘 한 단). 가는 팔에는 안 넣는다 | 실측 그대로 |
| 눈 | **2 × 4px 세로 막대 두 개**, 검정 | |
| 입 | **2 × 2px 점** (붉은 기) | |
| 볼 | 분홍 4×4 (넣는 손님만) | |
| 색 수 | **낱장 10 ~ 14색** | 실측 22~31색보다 줄인다 (우리 화풍이 더 평평하다) |
| 손님 가르기 | **머리색 4 · 머리 모양 3 · 옷 색 5.** 몸 뼈대는 한 장을 같이 쓴다 | 실측 그대로 |

- **맨몸 문제를 푼다** — 살색은 얼굴에만 있다. 2절 가설 1이 통째로 사라진다.
- **껍질 문제를 푼다** — 옷 색이 진해 크림 바탕에서도 속이 차 보인다. 가설 2가 사라진다.
- **고무관 문제를 푼다** — 팔이 몸에 붙어 있어 가는 부위가 없다. 가설 3이 사라진다.
- **얼굴 크기 다툼을 푼다** — 얼굴은 14px 로 작게 두되 **머리카락으로 머리를 24px 로 키운다.**
- 위험 : **「작게 줄인 사람」이 또 안 통할 수 있다** (v2 가 그랬다). 다만 v2 는 머리카락도 옷도 없었다.
  **머리카락과 옷이 들어가면 다른 그림이다.**

### 안 나 — 스타듀식 마을 사람

> **한 줄 분위기** : 조금 더 키가 크고 사람다운 마을 사람. 얼굴 그림을 따로 둔다.

| 요소 | 값 |
| --- | --- |
| 캔버스 | **32 × 64** (세로로 길다) |
| 키 | **56 px** |
| 등신 | **3 ~ 3.5** |
| 머리 | 높이 16 · 폭 16 |
| 몸 | 어깨 20 → 허리 16 으로 **좁아진다** |
| 팔 | 몸에 붙인다. 폭 4px |
| 다리 | 16px 두 개 |
| 외곽선 | 어두운 색 1px |
| 명암 | 재질마다 2단 |
| 얼굴 | **전신에는 눈 점만.** 표정은 **말풍선 옆 얼굴 그림 32×32** 로 따로 보여 준다 |
| 손님 가르기 | 머리 모양 · 옷 · 키 |

- 장점 : **얼굴 그림을 따로 두면 표정이 확 커진다.** 말풍선과 나란히 놓기도 좋다.
- 단점 : **3등신이 되면 몸이 사람 몸매가 된다.** 허리가 좁아지고 다리가 길어져
  2절 가설 1이 다시 살아날 위험이 있다. **찹쌀이(35px) 옆에 56px 이면 손님이 주인공보다 커 보인다.**
- **그릴 것이 두 배다** (전신 + 얼굴 그림).

| 요소 | 값 |
| --- | --- |
| 캔버스 | **48 × 64** |
| 키 | **40 px** (귀 포함 46) |
| 등신 | **1.5 ~ 2.** 머리와 몸이 이어진 한 덩어리 |
| 머리 | 폭 26 · 높이 20. **귀가 실루엣의 개성을 전부 맡는다** |
| 몸 | 폭 24 · 높이 20. 위아래 폭이 거의 같다 |
| 팔 | 짧은 앞발 6×8, 몸에 붙인다 |
| 다리 | 없거나 발끝만 6×4 |
| 외곽선 | 몸 색을 어둡게 한 1px (동물은 색이 진해 검정까지 안 가도 된다) |
| 명암 | 그늘 한 단 (아이콘·건물과 같은 화풍) |
| 얼굴 | 점눈 2×4 · 코 점 · 입. 볼 분홍 |
| 손님 가르기 | **귀 모양 + 몸 색** |

- 장점 : **사람을 안 그리니 2절 가설 셋이 통째로 사라진다.** 늘리는 값도 가장 싸다(귀+색).
  찹쌀이(매끈한 떡)와 귀 하나로 한눈에 갈린다.
- 단점 : 사용자가 고른 레퍼런스(카페 운영 게임 · 카이로소프트)에서 가장 멀다.
  「귀여운 동물」은 흔한 길이라 개성이 약할 수 있다.

## 6. 셋 비교와 권하는 것

| | **가 카이로식** 권함 | 나 스타듀식 | 다 동물 |
| --- | --- | --- | --- |
| 사용자가 고른 레퍼런스에 맞나 | **정확히 맞는다** | 맞는다 | 멀다 |
| 키 (찹쌀이 35 대비) | **44 (1.26배)** | 56 (1.6배 — 크다) | 40 (1.14배) |
| 등신 | 2.2 | 3~3.5 | 1.5~2 |
| 맨몸 문제 (가설 1) | **옷으로 푼다** | 옷으로 푼다 | 사람이 아니라 없다 |
| 껍질 문제 (가설 2) | **검정 선 + 진한 옷으로 푼다** | 푼다 | 푼다 |
| 고무관 문제 (가설 3) | **팔을 붙여 푼다** | 푼다 | 푼다 |
| 마네킹으로 보일 위험 | 낮다 (허리를 안 좁힌다) | **있다** (허리가 좁아진다) | 없다 |
| 얼굴 넓이 | 14px | 전신 8px + 얼굴 그림 32px | 16px |
| 손님 늘리기 | **머리색 × 머리 모양 × 옷 색** | 머리 + 옷 + 얼굴 그림 | 귀 + 색 |
| 그릴 양 | 보통 (몸 한 장 + 겹) | **가장 많다** | 적다 |
| 찹쌀이와 구별 | 강하다 | 강하다 | 강하다 |

**가(카이로식)를 권하는 까닭**

1. **사용자가 직접 고른 레퍼런스다.** 조사의 출발점이 여기였다.
2. **우리가 여섯 판 막힌 자리를 정확히 푼다.** 살색을 얼굴에만 쓰고, 검정 선을 두르고,
   팔을 몸에 붙이고, 허리를 안 좁힌다 — 2절 가설 셋이 하나씩 다 지워진다.
3. **「얼굴이 너무 크다」와 「머리가 작아 기괴하다」 사이를 머리카락이 메운다.**
   얼굴은 14px 로 작게, 머리 덩어리는 24px 로 크게. 이건 v1~v6 에서 한 번도 안 해 본 수다.
4. **손님을 늘리는 값이 싸다.** 몸 뼈대 한 장 + 머리색 4 × 머리 모양 3 × 옷 색 5.
5. **말랑함도 죽지 않는다** — 허리를 안 좁히고 모서리를 둥글게 두면 v5 에서 좋아했던
   「한 몸 덩어리」 느낌이 남는다. 카이로소프트 인물도 뼈대가 아니라 네모 덩어리다.

**안전판은 다(동물)** 다. 가로 한 판 그려 보고 또 「사람이 기괴하다」가 나오면 사람을 버린다.

## 7. 사용자에게 물을 것

| # | 물음 | 왜 |
| --- | --- | --- |
| 1 | **가 · 나 · 다 중 어느 쪽인가?** | 나머지 수치가 다 따라온다. AI 는 **가(카이로식)**를 권하고 안전판으로 **다(동물)**를 둔다 |
| 2 | **손님에게 머리카락과 옷을 넣어도 되나?** | 이번 판의 핵심 바꿈이다. v1 이 옷·헤어로 갔다가 「어깨가 넓다」로 물러난 적이 있어 한 번 더 확인한다 |
| 3 | **외곽선을 「거의 검정」으로 바꿔도 되나?** | 지금 아트 규칙은 손님만 「몸 색을 어둡게 한 1px」이다 (`Docs/Design/06-아트규칙.md` 2절 7번). 검정으로 가면 그 줄을 고쳐야 한다 |
| 4 | **손님 키를 44px 로 할까?** | 찹쌀이 35px 의 1.26배다. v2 는 1.6배라 손님이 주인공보다 커 보였다 |
| 5 | **손님을 몇 명 만들 셈인가?** | 4~6명이면 머리색·옷 색만으로 되고, 20명 넘으면 모자·소품이 필요하다 |
| 6 | **표정을 전신에 넣을까, 말풍선 옆 얼굴 그림으로 뺄까?** | 안 나(스타듀식)의 방식이다. 얼굴 그림을 따로 두면 표정이 커지지만 그릴 것이 두 배다 |
| 7 | 2절의 기괴함 진단이 맞나? | 틀렸다면 안 가의 근거가 흔들린다. 특히 **「맨몸」이 문제였는지** |
