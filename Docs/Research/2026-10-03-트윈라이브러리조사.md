# 트윈 라이브러리 조사 — DOTween Pro 를 대신할 것

> 2026-10-03 · 조사 AI · **조사만. 코드·설계는 쓰지 않았고 패키지도 설치하지 않았다.**
> 까닭 : DOTween Pro(유료 에셋)를 git 저장소에 넣을 수 없어 지우고 대체제를 찾는다.
> 대상 : Unity 6000.3.23f1 · 2D URP · **PC(Windows) + 안드로이드(IL2CPP · ARM64)**. WebGL 은 안 쓴다.
> 표기 : `[확인]` 라이선스 원문·공식 저장소·소스를 직접 엶 · `[전언]` 제작자 글·요약만 봄 · `[추측]` 근거 있는 내 판단.
> 앞선 조사 : `Docs/Research/2026-10-03-서비스코드조사.md` (PrimeTween 을 `[전언]` 으로 후보에 올렸다).

## 결론 먼저

- **권장 : LitMotion** (MIT). 공개 저장소에 소스를 넣어도, UPM git 주소로 참조해도 된다. 조건은 저작권 글 남기기뿐이다.
  **수동 갱신(`ManualMotionDispatcher.Update(dt)`)** 이 있어 우리 `GameRunner` 의 `Process(dt)` 와 그대로 맞는다.
  Burst · Collections · Mathematics 에 기대지만 **셋 다 이미 `packages-lock.json` 에 들어 있다** — 새로 딸려 오는 Unity 패키지가 없다.
- **차선 : DOTween 무료판.** 기능은 가장 넉넉하다(경로 `DOPath` · 시퀀스 콜백 · `ManualUpdate`). **고치지 않은 원본 그대로**면 공개 저장소에 넣어도 된다.
  다만 UPM 이 없어 파일이 `Assets/Plugins/Demigiant/` 에 통째로 들어가고, 「고친 판은 배포 금지」 조건이 붙고, 트윈마다 GC 할당이 있다.
- **PrimeTween 은 조건부다.** 공개 저장소에서는 **NPM 패키지(scoped registry)로 설치할 때만** 허락된다. 소스·tgz 를 저장소에 넣으면 위반이다.
  수동 갱신도 없다 — 우리 게임 시계(`GameMaster.TimeScale`)와 맞추려면 트윈마다 `timeScale` 을 손으로 맞춰야 한다.
- **DOTween Pro 는 안 된다.** 「프로젝트에서 일하는 사람 모두가 라이선스를 가져야」 하고 배포가 막혀 있다. 공개 저장소에 못 넣는다.
- **경로(스플라인) 이동은 LitMotion · PrimeTween 둘 다 없다.** 꺾은선은 시퀀스로 이어 붙이면 되고, 곡선은 0→1 트윈 + 보간 함수를 직접 둔다.
- **DOTween 흔적은 조사하는 동안 사용자가 이미 지웠다.** 남은 것은 문서·기억 속 「트윈은 DOTween」 글귀뿐이다 (6절).

## 3. 권장과 까닭

| | 고른 것 | 까닭 |
| --- | --- | --- |
| **권장** | **LitMotion** | ① MIT — 조건이 가장 가볍고 저장소가 공개돼도 그대로다. ② 수동 갱신이 있어 게임 시계와 맞추기 쉽다. ③ 딸린 패키지 셋이 이미 프로젝트에 있다. ④ 올해 9월까지 손이 가고 있다 |
| **차선** | **DOTween 무료판** | 경로 · 시퀀스 콜백 · 수동 갱신이 다 있어 **컷씬에 필요한 기능은 가장 많다.** 원본 그대로 넣는 조건이면 라이선스도 통과한다. 사용자가 이미 써 본 API 다 |
| 뺀 것 | PrimeTween | 공개 저장소 조건이 「NPM 설치만」으로 좁고, 수동 tick 이 없다 |
| 뺀 것 | 직접 | 쓸 자리가 다섯 갈래(팝업 · 찹쌀이 연출 · 발견 · 컷씬 · 카운트업)라 「이동·크기·투명 셋뿐」이던 앞선 조사의 전제를 넘는다 |

LitMotion 을 고르면 **안고 가는 것** 셋 :

1. **경로 이동이 없다.** 컷씬의 「대역을 경로대로 이동」은 꺾은선이면 `Append` 로 잇고, 곡선이면 0→1 모션에 보간 함수를 묶는다. (앞선 조사가 이미 `PathMoveAgent` 를 직접 두기로 적었다 — 그 길과 부딪히지 않는다.)
2. **시퀀스 중간 콜백이 없다.** 컷씬은 단계 JSON 실행기가 차례를 쥐므로 단계 끝은 `WithOnComplete` 로 받는다. 한 시퀀스 안에 소리를 끼우는 식은 「값 없는 모션 + `WithOnComplete`」 로 돌려 쓴다 (제작자 FAQ 의 길 `[확인]`).
3. **Burst 에 기댄다.** 안드로이드 빌드에서 Burst AOT 가 돈다. 이미 프로젝트에 깔려 있지만 **APK 로 한 번 돌려 봐야 안다.**

## 5. 게임 시계와 맞추기

지금 코드 `[확인]` : `GameRunner` 가 `dt = Time.deltaTime * GameMaster.TimeScale` 을 만들어 `Process(dt)` 로 내려보낸다. **Unity 의 `Time.timeScale` 은 안 건드린다.** 그래서 라이브러리의 기본 스케줄러(`Update`)에 맡기면 **디버그 배속이 트윈에 안 먹는다.**

| 트윈이 쓰이는 곳 | 어느 시계 | LitMotion 에서 |
| --- | --- | --- |
| 농장 안 연출 (찹쌀이 점프·들림 · 떡 발견 · 줍기) | **게임 시계** — 배속을 따르고, 컷씬 중엔 멈춘다 | **수동 tick.** `ManualMotionDispatcher` 하나를 두고 `GameRunner` 가 주는 `dt` 로 `Update(dt)` 를 부른다. 농장 시계를 멈추면 같이 멈춘다 |
| UI 팝업 열림/닫힘 · 수치 카운트업 | **실제 시간** — 배속 0 이어도 움직여야 한다 | `MotionScheduler.UpdateIgnoreTimeScale` (또는 배속 안 곱한 `dt` 를 먹는 두 번째 dispatcher) |
| 컷씬 (레터박스 · 대역 이동 · 페이드) | **컷씬 시계** — 농장이 멈춰도 돈다. 스킵은 「끝 상태 즉시 적용」 | 따로 둔 dispatcher 를 컷씬 실행기가 tick. 스킵은 `handle.Complete()` |

- 정리하면 **「unscaled」 하나로는 모자라고 수동 tick 이 필요하다.** 우리 배속이 Unity 것이 아니라 자체 값이기 때문이다.
- 도메인 리로드를 끄면 `ManualMotionDispatcher.Default` 의 상태가 안 지워진다 — 시작 때 `Reset()` 을 부르라고 문서가 적는다 `[확인]`. 직접 `new` 한 dispatcher 를 쓰면 이 걱정이 없다.
- DOTween 무료판으로 가도 같은 꼴이다 : `SetUpdate(UpdateType.Manual)` + `DOTween.ManualUpdate(…)`.
- 어느 Manager/Service 가 dispatcher 를 쥐나는 **설계에서 정한다** (여기서는 안 정했다).

## 7. 사용자에게 물을 것

1. **LitMotion 으로 갈까, DOTween 무료판으로 갈까.** 가르는 물음은 하나다 — 컷씬에서 **곡선 경로**와 **시퀀스 중간 콜백**을 라이브러리가 해 주길 바라는가. 바라면 DOTween 무료판, 직접 조금 얹어도 되면 LitMotion.
2. LitMotion 이면 판을 `#v2.0.2` 로 **못 박을까.** (권장 : 박는다)

- **아무것도 설치·실행하지 않았다.** LitMotion 이 Unity 6000.3 + 안드로이드 IL2CPP(ARM64) 에서 도는지는 `[추측]` 이다 — 설치 뒤 APK 한 판으로 봐야 한다.
- 「할당 0」 「2~20배 빠름」 은 제작자 글 `[전언]` 이다. 우리 기기에서 안 쟀다.
- DOTween 무료판의 최신 판 번호 · `DOPath` 가 무료판에 든다는 것 · IL2CPP 상태, LeanTween 의 기능 칸은 원문에서 못 짚어 `[전언]` 이다.
- DOTween 의 설치 도구가 만드는 모듈 파일·asmdef 가 「고친 판(Modified Version)」 에 드는지는 원문에 없다 — `[확인 못 함]`.
- Unity 에셋 스토어 EULA 는 따로 안 열었다. PrimeTween · DOTween 을 **에셋 스토어에서** 받으면 그 EULA 가 겹칠 수 있다 `[추측]`. 그래서 PrimeTween 은 NPM, DOTween 은 공식 사이트 zip 이 더 깨끗하다.
- 꼬리표 `v2.0.2` 는 GitHub 릴리스 목록에서 봤다. `#v2.0.2` 를 붙인 주소로 실제 받아 보지는 않았다.
- 라이선스 풀이는 법률 자문이 아니다. 원문 글귀를 그대로 읽은 것이다.
