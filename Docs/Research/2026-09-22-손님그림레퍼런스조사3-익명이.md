# 손님 그림 레퍼런스 조사 3 — 익명이 쪽으로

> 시안 v1(살색 몸 + 옷·헤어)과 v2(흰 사람 2등신)가 둘 다 물러났다.
> 사용자가 새 방향을 냈다 — **카카오 이모티콘 「익명이」와 지금 우리 캐릭터의 중간쯤 되는 중성적인 모습.**
> 날짜 2026-09-22 · 조사만 했다 · 상태 **제안 단계, 결정은 사용자**

## 1. 결론 먼저

- **익명이는 찾았다.** 작가 **라부**가 그리는 카카오 이모티콘 캐릭터이고, 「안녕! 나는 익명이고 …」 시리즈로
  **12판 넘게** 나왔다. 흰 달걀 덩어리 + 가는 손그림 윤곽선 + 점눈 + 분홍 볼이다. 그림도 눈으로 확인했다(6절).
- **익명이와 우리 v2 의 진짜 차이는 「등신」이 아니라 「덩어리가 몇 개냐」다.**
  익명이는 **머리와 몸이 한 덩어리**(달걀 하나)이고, v2 는 **머리 · 몸통 · 팔 · 다리 네 덩어리**다.
  v2 가 어색했던 까닭이 여기 있다 — 사람 뼈대를 줄여 놓으니 「작은 사람」이지 「말랑한 무엇」이 아니다.
- **그러므로 중간을 잡는 손잡이는 「덩어리를 몇 개로 나누나」 하나다.** 후보 셋을 7절에 뒀다.
  **안 가(달걀 한 덩어리 + 혹 팔)를 권한다** — 찹쌀이와 가장 잘 붙고 그릴 것이 가장 적다.
- **윤곽선은 넣지 않는다.** 익명이의 손그림 선이 매력의 절반이지만 우리 아트 규칙 7번이 「외곽선 없음」이고,
  48px 안에 1px 선을 두르면 흰 속이 너무 좁아진다. 선 대신 **찹쌀이의 회색 4단 명암**으로 덩어리를 세운다.
- **중성성은 이미 풀렸다.** 익명이도 v2 도 성별 표시가 아예 없다. 새로 할 일이 아니다.

## 2. 익명이가 어떤 캐릭터인가

| 항목 | 내용 |
| --- | --- |
| 무엇 | 카카오톡 이모티콘 캐릭터. 「안녕! 나는 익명이고 너를 조아해」가 첫 판 |
| 작가 | **라부** (카카오 작가 페이지 `W0R685`) |
| 몇 판 | **12판 이상**. 「너를 조아해」 · 「쪼금 엉뚱해」 등으로 이어진다. 한 판에 24~30컷 |
| 컨셉 | 「나도 익명, 너도 익명, 우리는 모두 익명」 — **이름도 정체도 없는 존재**가 컨셉이다 |
| 바깥 | 굿즈 상점(익명상점)이 따로 있고, 카드사 캐릭터 카드로도 나갔다 |
| 인기 까닭 | 2019년 이모티콘 디자인 분석 논문에 10~20대 인기 캐릭터로 이름이 오른다 |

**왜 인기인가 — 그림에서 읽은 것**

1. **투영하기 쉽다.** 얼굴에 눈·입·볼뿐이라 누구든 자기로 읽는다. 「익명」이라는 이름이 그걸 못 박는다.
2. **감정이 크다.** 몸은 단순한데 눈물·하트·땀·효과선이 크게 붙는다. 작은 화면에서 감정만 또렷하다.
3. **선이 손맛이다.** 굵기가 들쭉날쭉한 손그림 선이라 「대충 그린 듯 귀엽다」는 느낌을 준다.
4. **변형이 싸다.** 몸이 달걀 하나라 고양이 귀를 붙이거나 이불을 덮으면 바로 새 컷이 된다.

## 3. 익명이 생김새 — 그림에서 뽑은 것

이모티콘 미리보기 12장을 받아 눈으로 보고 픽셀을 쟀다. **그림은 저장소에 안 넣었다** (임시 폴더에서 보고 버렸다).

| 무엇 | 익명이 |
| --- | --- |
| 몸 색 | **흰색 한 색**. 명암이 거의 없다. 접힌 자리에만 가는 선 하나 |
| 실루엣 | **달걀 한 덩어리**. 머리와 몸이 안 나뉜다. 목도 어깨도 없다 |
| 가로세로 | 재 보니 대략 **156 × 186** (가로가 세로의 0.84) — 조금 긴 달걀이다 |
| 등신 | **1~1.3등신**. 「머리가 곧 몸」이라 등신을 세는 것이 의미가 없다 |
| 윤곽선 | **있다.** 검정 손그림 선, 굵기가 고르지 않고 군데군데 끊긴다 |
| 눈 | **작은 점 두 개**. 사이가 좁다(얼굴 폭의 1/4쯤). 감정에 따라 선·반달·`><` 로 바뀐다 |
| 입 | **작게 벌린 입 하나**. 눈 바로 아래에 붙어 있다. 코는 없다 |
| 볼 | **분홍 타원 두 개**. 거의 모든 컷에 있다 |
| 팔 | **짧은 혹**. 손가락 없음. 뻗을 때만 가는 국수처럼 길어진다 |
| 다리 | **거의 없다.** 몸 아래가 바닥에 닿는다. 걸을 때만 짧은 발이 나온다 |
| 표정 내는 법 | **눈 모양 + 입 모양 + 바깥 효과**(눈물·하트·땀·떨림선) 셋을 겹친다 |
| 중성성 | **완전히 없다.** 머리카락·옷·몸매 표시가 하나도 없다 |

## 4. 찹쌀이 · 손님 v2 · 익명이 비교

| | **익명이** | **찹쌀이** (지금 게임) | **손님 v2** (물러남) |
| --- | --- | --- | --- |
| 몸 색 | 흰색 한 색 | `#FEFDFC` + 회색 4단 | 찹쌀이와 같은 5색 |
| 크기 | 이모티콘 210px | 몸 42×35 (64 캔버스) | 키 56 (48×64 캔버스) |
| 등신 | **1~1.3** | **1** (몸 하나가 전부) | **2** |
| 덩어리 수 | **1** (+ 혹 팔) | **1** (팔다리 없음) | **4** (머리·몸통·팔·다리) |
| 윤곽선 | **있다** (손그림 검정) | **없다** | **없다** |
| 눈 | 검정 점 두 개, 좁게 | 검정 `#12110F` 점 두 개 | 검정 2×4 두 개 |
| 입 | 작게 벌린 입 | 작은 선 하나 | 작은 선 하나 |
| 볼 | **분홍** 타원 | **노랑** `#FBD701` 원 (11×11) | 분홍 5×5 |
| 코 | 없다 | 없다 | 없다 |
| 팔 | 짧은 혹 | **없다** | 3px 막대 |
| 다리 | 거의 없다 | **없다** | 5px 두 개 |
| 표정 내는 법 | 눈 + 입 + 바깥 효과 | 표정 10장 갈아끼우기 | 표정 3장 갈아끼우기 |
| 중성성 | 완전 | 완전 (사람이 아니다) | 완전 |
| 분위기 한 줄 | 말랑한 익명의 존재 | 동그란 떡 | **작게 줄인 사람** |

**읽히는 것 셋**

1. **익명이와 찹쌀이는 같은 편이다.** 둘 다 덩어리 하나에 얼굴만 찍는다. v2 만 혼자 「사람」이었다.
2. **차이는 윤곽선과 볼 색뿐이다.** 익명이는 선이 있고 볼이 분홍, 찹쌀이는 선이 없고 볼이 노랑이다.
3. **손님을 익명이 쪽으로 당기면 찹쌀이와 너무 닮는다.** 그래서 **「어디서 갈라지나」를 하나 정해야 한다**
   — 그게 7절 후보를 가르는 축이다.

## 5. 「중간」을 잡는 축 넷

사용자 말의 「중간」을 숫자로 풀면 손잡이가 넷이다.

| 축 | 익명이 끝 | v2 끝 | 중간이란 |
| --- | --- | --- | --- |
| **덩어리 수** | 1 | 4 | **2~3** — 머리+몸 한 덩어리에 팔만 붙이거나, 머리와 몸을 살짝 잘록하게 나눈다 |
| **등신** | 1.2 | 2.0 | **1.4~1.7** — 머리가 몸보다 크되 경계가 흐리다 |
| **팔다리** | 혹 · 없음 | 막대 3px · 5px | **혹 팔 + 짧은 발** 또는 **가는 팔 + 발만** |
| **윤곽선** | 있다 | 없다 | **없음 유지**. 대신 명암 4단으로 덩어리를 세운다 (아트 규칙 7번) |

윤곽선은 사실 「중간」이 없다. 규칙이 정해져 있으니 **없음으로 간다.** 남은 셋만 고르면 된다.

## 7. 후보 방향 셋

셋 다 **캔버스 48×64 · 전신 · 외곽선 없음 · 손님 칸 68×80** 안에 든다.
빛은 왼쪽 위, 색은 찹쌀이 5색(`#FEFDFC` `#E0DFDD` `#C7C6C4` `#B6B5B4` `#A6A5A2`)을 그대로 쓴다.

### 안 가 — 달걀 한 덩어리 + 혹 팔 (권함)

> **한 줄 분위기** : 찹쌀이가 일어서서 걸어온 것 같은, 이름 없는 말랑한 손님.

| 부위 | 값 (px) |
| --- | --- |
| 전체 키 | **48** (y16~64) — v2 의 56보다 8 낮다 |
| 몸 | **달걀 하나 34 넓이 × 48 높이.** 머리와 몸이 안 나뉜다 |
| 잘록한 곳 | y40 언저리에서 폭이 **2px 만** 들어간다. 「여기가 목이구나」 싶은 정도 |
| 팔 | **혹 6×8 두 개**, 몸 옆면에 붙인다. 끝은 둥글다 |
| 다리 | **발만 8×4 두 개.** 다리는 없다 |
| 얼굴 넓이 | **16~18** (v2 의 13보다 넓다 — 표정이 훨씬 잘 보인다) |
| 눈 | 2×4 검정, 사이 6 |
| 입 | 눈 아래 4px, 작게 벌린 입 3×3 |
| 볼 | 분홍 5×5 두 개 |

```
       ##########
     ##############      달걀 하나 - 머리와 몸이 한 덩어리
    ################
    ##..###..###..##     볼 · 눈 · 볼
    ####...##...####     입
    ################
   ###############       y40 에서 2px 만 잘록
  ##################      혹 팔이 옆구리에 붙는다
  ##################
    ##############
      ####  ####          발만 있다
```

- **왜 권하나** — ① 얼굴이 16~18px 이라 표정 세 가지가 확실히 갈린다(v2 는 13px 이라 빠듯했다).
  ② 덩어리가 하나라 「작은 사람」으로 안 읽힌다. ③ **그릴 것이 가장 적다.**
  ④ 키 48 은 찹쌀이(35) 대비 **1.37배**라 나란히 놓아도 주인공이 안 밀린다 (v2 는 1.6배였다).
- **찹쌀이와 어떻게 가르나** — 찹쌀이는 **가로로 넓은 떡**(42×35, 가로가 넓다),
  손님은 **세로로 긴 달걀**(34×48). 같은 화풍인데 실루엣 방향이 반대라 한눈에 갈린다.
  볼 색도 찹쌀이 노랑 · 손님 분홍으로 갈라 둔다.
- **v2 뼈대에서 그대로 쓰는 것** :
  `superellipse`(머리에 쓰던 것 — 이번엔 몸 전체에 쓴다) · `paint`(회색 4단 자동 명암) ·
  `Layer` · `compose` · 미리보기 넷(`preview_ab` · `preview_cell` · `preview_scale` · `preview_variants`) ·
  캔버스 상수 `W,H=48,64` `CX=24` `GROUND_Y=64` `CELL_W,CELL_H=68,80` · 색 상수 `WHITE5` `INK` `CHEEK_PINK` ·
  그림자 `shadow.png` · 얼굴 그리는 부분(자리만 옮긴다).
- **버리는 것** : `torso` 폭 표 · `arm` · `leg` 세 묶음. 달걀 하나 + 혹 + 발로 바꾼다.

### 안 나 — 눈사람 두 덩어리

> **한 줄 분위기** : 머리와 몸이 살짝 나뉜, 조금 더 사람 같은 말랑이.

| 부위 | 값 (px) |
| --- | --- |
| 전체 키 | **52** (y12~64) |
| 머리 | 30 × 28 (y12~40) |
| 몸 | 26 넓이 × 24 높이 (y40~64). **머리와 1px 겹쳐** 붙인다 |
| 목 | 없다 |
| 팔 | 혹 5×9, 몸 옆에 붙인다 |
| 다리 | 발만 7×4 두 개 |
| 얼굴 넓이 | 14~16 |

```
      ############
    ################       머리 30 - 위 덩어리
    ##..####..####.##
    #####...###...###
    ################
     ##############        1px 겹쳐 붙인다
   ################        몸 26 - 아래 덩어리
   ################
     ############
       ###  ###            발
```

- **장점** : 「머리」와 「몸」이 있어 떡을 건네는 손동작을 나중에 붙이기 쉽다.
  익명이와 v2 사이 딱 절반이다.
- **단점** : **눈사람으로 읽힐 위험**이 있다. 두 덩어리 크기 차이를 잘못 잡으면 바로 눈사람이다.
  얼굴도 안 가보다 2px 좁다.
- **v2 뼈대에서 쓰는 것** : 안 가와 같고, **`torso` 폭 표를 살려서** 아래 덩어리에 쓴다
  (어깨 26 → 허리 24 → 바닥 26 처럼 거의 안 변하게). `arm` 은 혹으로, `leg` 는 버린다.

### 안 다 — 물방울 한 덩어리 + 가는 팔

> **한 줄 분위기** : 아래로 갈수록 퍼지는 물방울. 서 있는 느낌이 가장 또렷하다.

| 부위 | 값 (px) |
| --- | --- |
| 전체 키 | **50** (y14~64) |
| 몸 | 위 28 → 아래 36 으로 퍼지는 물방울 (y14~64) |
| 팔 | **가는 팔 3×12**, 몸에서 1px 띄운다 |
| 다리 | 없다. 몸이 바닥에 닿는다 |
| 얼굴 넓이 | 15~17 |

```
        ########
      ############        위가 좁다
     ##############
     ##..###..##.##
     ####...##.####
     ##############
   # ################  #   가는 팔 - 띄운다
   # ##################  #
   # ####################
     ######################  아래로 퍼진다
     ######################
```

- **장점** : 위가 좁고 아래가 넓어 **서 있는 안정감**이 가장 크다. 실루엣이 찹쌀이·안 가와 또 다르다.
- **단점** : 아래가 36px 이라 **떡 든 손님 여럿을 좁은 칸에 세우면 답답하다.**
  v2 에서 팔을 띄우면 막대로 보였던 문제가 다시 올 수 있다.
- **v2 뼈대에서 쓰는 것** : **`torso` 폭 표를 거의 그대로 쓴다** (값만 위 28 → 아래 36 으로 뒤집는다).
  `arm` 도 그대로 쓰되 `gap` 을 1 로 둔다. `leg` 와 `head` 는 버린다(몸에 흡수).

## 8. 사용자에게 물을 것

| # | 물음 | 왜 |
| --- | --- | --- |
| 1 | **6절 링크의 익명이가 맞나?** | 카카오 작가 「라부」의 그 캐릭터다. 다른 익명이를 떠올렸다면 여기서 갈린다 |
| 2 | **안 가 · 나 · 다 중 어느 쪽인가?** | 나머지 숫자가 다 따라온다 |
| 3 | **윤곽선 없음을 유지할까?** | 익명이 매력의 절반이 손그림 선이다. 넣으려면 아트 규칙 7번을 뒤집어야 한다 (뒤집는 조건은 이미 달려 있다) |
| 4 | **볼을 분홍으로 할까 노랑으로 할까?** | 찹쌀이는 노랑이다. 분홍으로 하면 손님과 갈리고, 노랑이면 한 벌로 붙는다 |
| 5 | **손님이 찹쌀이와 닮아도 되나?** | 익명이 쪽으로 갈수록 찹쌀이와 닮는다. 「손님도 떡 같은 존재」로 봐도 되는지가 갈림길이다 |
| 6 | **다음 판이 바로 시안을 그려도 되나?** | 안 하나만 고르면 `draw_customer_v3.py` 로 바로 뽑을 수 있다 |

## 9. 다음 판이 할 일

1. `draw_customer_v3.py` 를 만든다. `draw_customer_v2.py` 를 복사해 **7절 표 숫자**를 위쪽 상수로 박는다.
2. 몸을 **달걀 하나**(`superellipse`, n=2.3~2.6)로 그린다. 네모를 쌓지 않는다.
3. 혹 팔 · 발을 붙이고 `paint` 로 회색 4단 명암을 얹는다. 빛은 왼쪽 위.
4. 표정 3장(기본 · 웃음 · 시무룩)을 얼굴 넓이 17px 안에 찍는다. 눈은 `#12110F` 한 색.
5. `preview_scale` 로 **찹쌀이 35px · 가판대 62px 과 나란히**, `preview_variants` 로 **몸 색 5개**를 뽑는다.
6. 고른 안이 아니면 **상수만 바꿔 다시 돌린다.**
