# 골드 소비처와 합성 병목 조사

> 왜 조사했나 : 5단계 q1-1 「골드 고리」가 **닫히는데 돌릴 이유가 없어** 불통이라 3단계 코어 루프 2판으로 되돌렸다. 골드가 남고, 합성소 1칸이 곧 정지고, 새 종이 1마리라 번식이 막힌다. 다른 방치·합성 게임이 이 셋을 어떻게 푸는지 보고 2판 안을 고른다.
> 날짜 2026-09-08 · 조사한 사람 AI (웹 조사 + q1-1 기록) · 상태 조사 — 설계는 사용자 승인 뒤 `Docs/Design/01-코어루프.md` 2판에서

> 이 문서는 참고용이다. 기획서에는 여기 나오는 게임 이름을 그대로 옮기지 않는다.

## 1. 한 줄 결론

**「합성소 칸 늘리기 + 영구 시간 단축 + 도감 짝 구매」 셋을 골드 소비처로 묶은 안 가를 추천한다.** 셋 다 「계속 사는」 물건이고 값이 지수로 오르니 골드가 안 고이며, 짝 구매가 3번째 병목(새 종 1마리)까지 같이 푼다. 즉시 완료는 넣지 않는다 (기둥 1·3 지킴).

## 2. q1-1 에서 본 숫자

| 항목 | 값 | 읽는 법 |
| --- | --- | --- |
| 번 골드 / 쓴 골드 / 남은 골드 | 15,180 / 9,050 / 6,130 | 40% 가 고였다. 배수구가 합성 21회 · 구매 15회뿐 |
| 5분 건너뛰기 | 70회 (실제 16분) | 대기 = 할 일 없음. 합성소 1칸이라 기다림이 곧 정지 |
| 마릿수 / 번식 | 462 / 466 | 1단계 잔디는 넘치는데 새 종은 1마리라 못 불린다 |
| 질린 시점 | 10분 | 30분 기준을 못 채웠다 |

## 3. A. 골드 소비처 구조 — 다른 게임은 어디에 계속 쓰게 하나

| 종류 | 한 번 / 계속 | 값 오르는 꼴 | 어느 게임 | 이 게임에 맞나 |
| --- | --- | --- | --- | --- |
| 시간 단축 (즉시 완료) | 계속 | 남은 시간 비례 | 합성·육성 게임 대부분 (보석) | **안 맞음.** 「골드로 시간을 못 산다」가 이미 결정. 과금 없는 게임에서 시간이 진짜 비용 |
| 시간 단축 (영구 업그레이드) | 계속, 상한 있음 | 단계마다 지수 | 드래곤 육성 게임의 「번식 시간 -20%」 건물 · 몬스터 육성 게임의 「-25%」 구조물 강화 | **맞음.** 03 문서의 75%·50% 두 단계를 5~8단계로 잘게 나누면 계속 사는 물건이 된다 |
| 칸 확장 (동시 진행 슬롯) | 계속, 상한 있음 | 칸마다 지수 (×2~3) | 드래곤 육성 게임의 부화장 슬롯(5칸까지) · 몬스터 육성 게임의 번식 구조물 추가 | **맞음.** 사용자가 직접 짚은 것 |
| 생산 강화 (뱉는 속도·상한) | 계속 | 1.15^n (쿠키 게임) · 티어별 곱 | 방치 클리커류 전부 | 맞음. 재료 상한 · 생산 주기를 골드로 올린다. 다만 골드 유입도 같이 늘어 배수구가 되려면 값이 지수여야 한다 |
| 자동화 설비 (수집기·제작·판매) | 한 번 | 설비마다 고정, 뒤로 갈수록 비쌈 | 자본가 게임의 「매니저」 | 맞음 (이미 결정). 큰 덩어리 배수구지만 **한 번 사면 끝**이라 이것만으로는 못 버틴다 |
| 영구 업그레이드 트리 (연구) | 계속, 트리 끝까지 | 티어마다 10배 | 달걀 농장 게임의 「연구」 | 반만. 트리를 크게 만들면 그림·UI 가 는다. 위 항목들을 「합성소·농장·가판대」 세 건물 안의 단계로 묶는 편이 싸다 |
| 소모품 (부스터·먹이) | 계속 | 고정 | 달걀 농장 게임의 부스트 | **안 맞음.** 「먹이는 자원이 아니다」 결정과 부딪히고, 축 셋 밖의 새 시스템이다 |
| 짝·기본 개체 구매 | 계속 | 고정 또는 종마다 다름 | 몬스터 육성 게임의 「단일 원소 마켓 판매」 | **맞음.** C 절에서 자세히 |

- 값 오르는 꼴은 **지수**가 표준이다. 쿠키 게임은 같은 건물 n번째가 1.15^n 이라 5개마다 값이 두 배. 지수는 「살 때마다 다음 목표까지의 시간이 비슷하게 유지」되게 만든다. 선형이면 골드 유입이 지수로 늘 때 금방 다 사 버린다.
- 방치 게임 소비처 글은 소비처를 「영구 힘을 주는 진행 소비처」와 「행동 허가를 파는 소비처」로 가른다. 이 게임은 과금이 없으니 **진행 소비처만** 쓴다. 실패 꼴은 「원천이 상한 찬 소비처를 앞지른다」 — q1-1 이 정확히 이것이었다.

## 4. B. 합성 여러 칸과 대기 중 할 일

### 칸을 늘리는 방식

| 방식 | 어느 게임 | 이 게임에 옮기면 |
| --- | --- | --- |
| 건물 단계 올리면 칸 +1 | 드래곤 육성 부화장 (1→5칸, 뒤 칸은 보석) | 합성소 단계 1~5, 칸 1~5. 값은 300 · 1,000 · 3,000 · 10,000 골드 꼴 (×3) |
| 건물을 하나 더 짓는다 | 몬스터 육성의 두 번째 번식 구조물 | 합성소 건물 하나로 두기로 했으니 안 씀 |
| 칸마다 따로 산다 | 드래곤 육성 5번째 칸 120보석 | 위와 같은 뜻. UI 는 「칸에 자물쇠」가 알아보기 쉽다 |

- 칸 상한은 3~5가 보통이다. 이 게임은 종 12개 · 도감 24칸이라 **4칸**이면 「1단계 짝 두 쌍 + 2단계 한 쌍 + 여유」로 한 접속에서 걸 만한 수를 다 건다.
- 칸이 늘면 골드 배수구도 같이 는다 (합성 비용 × 칸). 골드 고임이 저절로 줄어드는 방향이다.

### 대기 시간을 줄이는 방식

| 방식 | 판단 |
| --- | --- |
| 골드 즉시 완료 | 안 씀 (3절) |
| 광고 시청 | 안 씀 (컨셉 「유료 판매·광고 안 함」) |
| 재료(찹쌀떡·부재료)로 단축 | 가능하지만 새 변환 한 칸이 는다. 2판엔 안 넣고 후보로만 |
| 영구 단축 단계 | **씀.** 100% → 90% → … → 50% 까지 5단계, 값 지수 |

### 기다리는 동안 할 일 — 시계 겹치기

「항상 작은 할 일 하나가 있게 시계를 겹쳐 놓으라」는 것이 방치 게임 설계 글의 공통 조언이다. 빠른 시계 · 느린 시계 · 하루 시계를 어긋나게 두면 「동시에 다 비는 순간」이 거의 안 생긴다.

| 시계 | 이 게임에서 | 주기 (임시) | q1-1 에 있었나 |
| --- | --- | --- | --- |
| 빠른 | 재료 줍기 → 떡 만들기 → 팔기 | 15~30초 | 있었다. 다만 「전부 만들기 · 전부 팔기」 두 번 눌러 끝이라 1초짜리 |
| 중간 | 합성 완료 · 번식 | 3~5분 | 있었다. 합성소 1칸이라 하나뿐 |
| 느린 | 떡 레시피 찾기 (새 부재료가 생길 때) | 새 종마다 | **없었다** (q1-2 에 따로 있었다) |
| 목표 | 도감 24칸 · 레시피 도감 | 며칠 | 있었다 |

- q1-1 에서 비어 있던 것은 **중간 시계가 하나뿐**이고 **느린 시계(레시피 찾기)가 아예 없던** 점이다. 2판은 합성소 칸(중간 시계 여러 개)과 레시피 찾기(느린 시계)를 같은 판에 넣어야 「대기 = 정지」가 풀린다.
- 가판대 손 판매는 빠른 시계지만 「전부」 버튼이 있으면 1초로 끝난다. 손 판매를 할 일로 남기려면 「손님이 하나씩 온다」 꼴이어야 하는데, 이는 가판대 설계 몫이고 이번 조사 밖이다.

## 5. C. 새 종 짝 문제 — 1마리를 어떻게 불리나

| 후보 | 장점 | 단점 | 수집 재미에 주는 영향 | 판단 |
| --- | --- | --- | --- | --- |
| ① 도감에서 짝 구매를 **모든 일반 종**으로 넓힌다 (지금은 1단계 150골드만) | 골드 소비처와 병목을 한 번에 푼다. 몬스터 육성 게임이 쓰는 방식 | 03 문서 「2단계 이상 안 판다」 결정을 뒤집어야 한다. 값이 싸면 합성이 의미 없어진다 | 「처음 얻기」는 여전히 합성뿐이라 도감 재미는 그대로. 변종은 안 팔아 값을 지킨다 | **채택** |
| ② 같은 계열끼리 번식 허용 (낮은 단계가 나옴) | 골드 없이 자연스럽다 | 상위 종은 여전히 1마리다 — 병목이 안 풀린다. 번식 규칙이 복잡해진다 | 없음 | 안 씀 |
| ③ 합성 결과를 2마리로 | 짝이 바로 생긴다 | 마릿수가 폭증한다 (이미 462). 합성이 2→2 라 배수구가 사라지고 찹쌀이가 고인다 | 「새 종 한 마리」의 무게가 반으로 준다 | 안 씀 |
| ④ 합성 재료를 소모 안 함 | 재료 걱정이 없다 | ③과 같이 배수구가 사라진다. 「마지막 2마리 경고」 같은 긴장도 없어져 밋밋하다 | 없음 | 안 씀 |
| ⑤ 합성 결과에 「같은 종 한 마리 더」 갈래를 준다 (예 : 정해진 종 나올 때 30% 로 쌍둥이) | 뽑기 재미가 하나 는다 | 운에 걸려 병목이 안 풀릴 때가 있다. 확률표가 넷으로 는다 | 살짝 좋아진다 | 후보로만 (①이 부족하면) |

- ① 값 눈금(임시) : **그 단계 합성 비용 × 1.5** — 1단계 150 · 2단계 750 · 3단계 3,000. 「번식·합성이 사는 것보다 싸다」를 지키면서, 2·3단계 짝 구매가 골드 큰 배수구가 된다.
- ① 조건 : 도감에 열린 종만 · 일반만 (변종 없음) · 늪 계열도 열리면 같이.

## 6. D. 고리 2판 안 셋 비교

| | 안 가 「합성소 성장 + 짝 구매」 | 안 나 「농장·설비 트리」 | 안 다 「합성 결과 2마리」 |
| --- | --- | --- | --- |
| 무엇 | 합성소 칸 1→4 · 영구 단축 5단계 · 도감 짝 구매(모든 일반 종). 값 지수 | 재료 상한 · 생산 속도 · 농장 칸 · 자동화 설비를 1.15^n 꼴로 계속 산다. 합성소는 2칸 고정 | 합성 결과 2마리, 재료 소모 유지. 골드는 설비에만 |
| 고리가 닫히나 | 닫힌다. 골드 → 칸·단축 → 합성 더 → 새 종 → 짝 구매 → 번식 → 재료 | 닫힌다. 골드 → 생산 강화 → 골드 더 (그러나 합성 쪽으로 안 흐른다) | 닫힌다. 다만 찹쌀이 배수구가 약해 마릿수가 고인다 |
| 골드 유입·유출 균형 | 칸이 늘면 합성 비용이 칸 수만큼 나간다. 짝 구매 750·3,000 이 큰 배수구 | 생산 강화가 유입도 같이 키워 균형이 어렵다. 지수 값으로만 버틴다 | 유출이 설비뿐이라 q1-1 과 같은 고임 |
| 병목 셋 | 1 소비처 ○ · 2 칸 ○ · 3 짝 ○ | 1 ○ · 2 △ · 3 × | 1 × · 2 × · 3 ○ |
| 기둥 (힐링·방치) | 즉시 완료 없음 · 벌칙 없음. 맞는다 | 맞는다. 다만 「강화 안 하면 손해」 느낌이 커질 수 있다 | 맞는다 |
| 만들 것 | 합성소 UI 단계 하나 · 도감 구매 버튼 | 설비 트리 UI · 값표. 그림이 는다 | 거의 없음 |
| 위험 | 짝 구매가 싸면 합성이 시시해진다 — 값을 잰다 | 합성 대기 정지는 그대로 남는다 | 마릿수 폭증 · 도감 무게 감소 |

**추천 : 안 가.** 안 나의 자동화 설비(이미 결정)는 그대로 큰 덩어리 배수구로 두되, 계속 사는 소비처는 합성소 쪽에 몬다. 안 다는 문제 하나만 풀고 둘을 새로 만든다.

### 안 가 한 눈 흐름

```
켠다 → 재료 줍기 → 떡 만들어 팔기 → 골드
 ├→ 합성 걸기 (칸 1~4 동시)  → 새 종 → 도감 칸 → 새 재료 → 레시피 찾기
 ├→ 짝 구매 (도감 · 일반 종) → 번식 시작 → 마릿수 → 재료
 └→ 합성소 강화 (칸 · 단축)   → 다음 접속에 합성이 더 돈다
```

### 5단계에서 다시 잴 물음 · 기준 초안

| 물음 | 기준 초안 (기록으로 재는 것) |
| --- | --- |
| 골드가 고이지 않나 | 30분 뒤 「남은 골드 ÷ 번 골드」 20% 이하 (q1-1 은 40%) |
| 대기가 정지가 아닌가 | 30분에 5분 건너뛰기 20회 이하 (q1-1 은 16분에 70회) · 합성 2칸 이상 동시에 돈 시간 비율 50% 이상 |
| 새 종이 병목이 아닌가 | 새 종을 얻고 짝(2마리째)까지 게임 시간 10분 이하 · 짝 구매가 골드 유출의 20~40% |
| 짝 구매가 합성을 시시하게 만들지 않나 | 구매 횟수 ≤ 합성 횟수 |
| 한 판 더 | 예/아니오 · 질린 시점(분) |

## 7. 이 조사에서 정한 것 · 안 정한 것

| 정한 것 (조사 판단, 설계 승인 전) | 안 정한 것 |
| --- | --- |
| 즉시 완료·광고·소모품은 안 쓴다 | 칸·단축·짝 구매의 값 눈금 확정 (가판대 눈금 뒤) |
| 계속 사는 소비처는 합성소(칸·영구 단축)와 도감 짝 구매다 | 「2단계 이상 안 판다」 결정(03 문서 6절)을 뒤집을지 — **사용자 승인 필요** |
| 값은 지수(×2~3)로 오른다 | 손 판매를 할 일로 남길지 (가판대 설계) · 재료로 단축(후보) |
