# 고차비 원작 조사

> 이 게임이 팬게임으로 삼는 방송인 **고차비**와, 주인공이 될 팬 캐릭터 **찹쌀이**를 조사한 문서.
> 날짜 2026-09-07 · 상태 조사 — 게임에 무엇을 넣을지 확정은 사용자가 한다.
> 대부분 나무위키와 검색 결과에서 모았다. **치지직 채널은 도구가 막혀서 못 봤다.** 팬카페 공지는 사용자가 직접 읽었다.

## 한 줄 결론

**찹쌀이는 「왕관 쓴 찹쌀떡」이다.** 고차비 님이 좋아하는 음식 찹쌀떡에서 나왔고,
구독 이모티콘·구독 뱃지로 태어나 지금은 자캐 옆에 늘 붙어 다니는 짝꿍이 됐다.
길게 구독한 사람은 빨간 마름모가 붙은 **대왕찹쌀이**를 단다.
대표 색은 **코랄 `#F29886`**, 팬은 **호군단(고구마들·찹쌀이들)** 이다.
**팬카페 공지에 팬게임 규정은 없다 (2026-09-07 사용자 확인). 카페 글 외부 공유 금지만 있다.**

## 2. 캐릭터들

### 2-1. 본인 자캐

- **살구빛 머리**가 제일 큰 특징이다.
- **오른쪽 눈 밑에 다이아몬드 모양 점(문신처럼 보이는 것)** 이 있다.
  실제로는 (신상 뺌)이고, 초기에는 고구마를 형상화한 보라색이었다가 지금은 실제 점에 가깝게 바뀌었다.
- 옆에 늘 **찹쌀이**가 붙어 다닌다.

### 2-2. 마스코트 고슴도치 — 「찹슴도치」

- 고슴도치 모습의 변형이고 이름은 **찹슴도치**다.
- **살구빛 머리색이 등의 가시 색에 그대로 들어간다.**
- VR 방송에서 자주 쓰고, 다시보기 썸네일에 자주 나온다.

### 2-3. 팬 캐릭터 「찹쌀이」 — 이 게임의 주인공

| 항목 | 내용 |
| --- | --- |
| 생김새 | **왕관을 쓴 찹쌀떡.** 동그랗고 말랑한 떡 몸에 머리 위 왕관 하나 |
| 크기 | 자캐 옆에 붙어 다니는 **작은 짝꿍** 크기. 이모티콘·뱃지로 쓰이니 아주 작게 그려도 알아보게 생겼다 |
| 색 | 떡이라 **흰색~미색 몸**으로 보이고, 왕관과 포인트는 노랑·빨강 계열. 대표 색 코랄 `#F29886` 이 원작 톤이다. **정확한 색값은 확인 못 함** |
| 왜 찹쌀이인가 | 고차비 님이 **좋아하는 음식이 찹쌀떡**이라, 새 구독 이모티콘을 만들 때 나온 캐릭터에 본인이 「찹쌀이」라고 이름 붙였다 |
| 팬이 쓰는 법 | **구독 6개월~3년 미만 구독 뱃지**이자 이모티콘. 채팅창에서 매일 보는 얼굴이다. 팬을 부를 때 「찹쌀이들」이라고도 한다 |
| 변형 | **대왕찹쌀이** — 3년 넘게 구독한 사람용. 다이아와 왕관으로 표시하고, 치지직으로 옮긴 뒤 **빨간 마름모**를 더해 구분한다 |
| 다른 변형 | 이모티콘 갈래로 **삼지창 든 찹쌀이**(딜러용), **반창고 든 찹쌀이**(힐러용) 가 있다. 「이쑤시개 든 호군단」 이모티콘도 같이 있다 |

> **게임에 쓸 때 핵심** : 찹쌀이는 「원래 하나뿐인 캐릭터」가 아니라 **여럿이고 변형이 붙는 캐릭터**다.
> 무기·소품을 들려 갈래를 나누는 것이 원작에 이미 있다. 합성으로 종을 늘리는 지금 기획과 잘 맞는다.

## 4. 원작 색과 그림 톤

- **대표 색 : 코랄 `#F29886`** — 연한 주황빛 분홍이다. 게임의 기본 색으로 그대로 써도 된다.
- **살구빛** 이 자캐 머리색이자 찹슴도치 가시색이다. 코랄과 한 계열이라 같이 쓰기 좋다.
- 찹쌀이는 **떡**이라 흰색·미색이 몸이고, 왕관이 유일한 강한 색이다.
- 그림 톤은 **작게 줄여도 알아보는 둥글고 귀여운 이모티콘 그림체**다.
  실제 쓰임(채팅 뱃지·이모티콘)이 그렇기 때문이다.
  → 게임 아트도 **파스텔·둥근 형태·굵은 외곽선**이 원작에 가깝다. 도트로 가도 형태만 지키면 알아본다.
- **확인 못 함** : 로고 그림 원본, 공식 팔레트 전체(코랄 말고 다른 색값).

## 5. 팬게임·2차 창작 규정

**확인함 (2026-09-07, 사용자가 팬카페 공지를 직접 읽음) — 팬게임 규정은 없다.**

- 나무위키 문서에는 2차 창작 허용 범위·상업 이용·표기 요청에 대한 내용이 **없다.**
- 팬카페 `cafe.naver.com/chabii` 공지는 **사용자가 직접 읽었다.**
  공지에 있는 관련 규정은 **카페 글 외부 공유 금지** 하나뿐이다. (카페 글이라 캡처는 저장소에 안 넣었다)
- 나무위키에 적힌 것 중 관련 있는 한 줄 : **신상 관련 이야기를 좋아하지 않는다.**
- 굿즈는 소속사 **픽셀네트워크**가 판다. 즉 **상업적 권리는 회사 쪽에 있다** — 상업 이용은 안 한다고 못 박는 게 안전하다.

**확인 결과**
1. 팬카페 공지에 2차 창작·팬게임 규정이 있나 → **없다.**
2. 무료 배포도 허락을 받아야 하나 → **허락 절차가 없다.** 무료 배포로 가되, 만드는 과정과 게임 공유는 **카페 안에서** 한다.
3. 표기 문구를 정해 준 게 있나 → **없다.** 우리가 「고차비 님 팬게임입니다」 식 표기를 붙인다 (안, 확정 아님).
4. 공식 이모티콘을 쓸 수 있나 → **규정이 없으니 안전하게 새로 그린다.**

문제가 생기면 사용자가 감수하기로 했다.

| --- | --- |
| 찹쌀이 = 왕관 쓴 흰 떡 | 원작 그대로. 이게 없으면 팬게임이 아니다 |
| 색은 코랄 `#F29886` 중심 | 원작 대표 색이라 첫 화면부터 「아, 고차비다」가 된다 |
| 변형에 **소품**을 쓴다 (삼지창·반창고 같은) | 원작 이모티콘이 이미 그 방식이다. 합성으로 종을 늘리는 기획과 딱 맞는다 |
| **대왕찹쌀이**를 최종 단계나 희귀 종으로 | 원작에서도 「오래 본 사람만 아는」 자리다. 빨간 마름모가 표식 |

| 말버릇 몇 개를 UI 문구에 (「오호라」·「타란~」) | 짧아서 버튼·알림에 넣기 쉽다 |
| 고구마·찹쌀떡 같은 먹을거리 소재 | 이름 유래라 설명이 필요 없다 |

| 무엇 | 왜 |

| 공식 이모티콘 그림을 그대로 넣기 | 저작권이 본인·소속사에 있다. **새로 그린다** |
| 본인 자캐를 조작 캐릭터로 | 실존 인물 아바타다. 주인공은 찹쌀이로 충분하다 |
