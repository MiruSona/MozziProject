# 서비스 코드 조사 — 미리 깔아 둘 공통 층

> 반복 01 피드백 10 「기본 서비스 코드(에셋·데이터·리소스·VFX·SFX/BGM·컷씬)를 미리 파악·조사」 의 답이다.
> 2026-10-03 · 조사 AI · **조사만. 코드·설계는 쓰지 않았다.** 사용자가 「이번엔 조사만」으로 정했다 (`Docs/History/반복/01-2026-10-03.md`).
> 대상 : Unity 6000.3.23f1 · 2D URP · **WebGL(Web) 빌드** · 세로 한 화면. 지금 코드 13,672줄 · 씬 1개(`Farm`).
> 표기 : `[확인]` 공식 문서나 코드를 직접 봄 · `[전언]` 검색 요약만 봄 · `[추측]` 근거 있는 내 판단.
> **2026-10-03 덧붙임** — 트윈은 LitMotion v2.0.2 로 정했다 (`2026-10-03-트윈라이브러리조사.md`). 목표 플랫폼이 PC + 안드로이드로 바뀌어 아래 WebGL 제약 절은 참고용이다. 데이터 표는 DataTool 로 갈아탔다.

## 결론 먼저

- **뼈대는 이미 있다.** 서비스 층(`GameMaster` → `GlobalHub`) · 씬 Manager 층(`InGameMaster` → `InGameHub`) · 풀링 로더(`ResourceService`) · 이벤트 버스 · 세이브 · 데이터 표 · 디버그 패널까지 돌아간다. **새로 「틀」을 만들 일은 없고, 그 틀에 칸을 더하는 일이다.**
- **당장 비어 있는 칸은 넷** : 소리(SFX/BGM) · VFX(파티클·트윈 풀링) · 세이브 판 올리기(migration) · 컷씬. 이 가운데 **소리와 VFX 가 먼저다** — Should 38 「떡 만들기·새 떡 발견 연출」 이 둘 없이는 못 붙는다.
- **방식은 거의 전부 「Unity 기본 기능 + 직접 짜기」다.** WebGL 이 외부 패키지를 많이 깎는다 : VFX Graph 는 아예 안 돌고, AudioMixer 는 볼륨만 되고, Addressables 는 비동기만 된다. 지금 규모(빌드 12.6MB · 표 7장 · 씬 1개)에서는 Addressables · Localization 패키지 · DI 컨테이너가 전부 과투자다.
- **외부 패키지 「후보」는 둘뿐** : 트윈 라이브러리 **PrimeTween**(무료 · 무할당 · WebGL 확인) 과 **DataTool**(이미 서브모듈로 붙어 있는 우리 툴 — JSON 검증·MessagePack 내보내기). 둘 다 지금 당장은 없어도 된다.
- **컷씬은 Timeline 이 아니라 「단계 목록(JSON) + 코드 실행기」를 권한다.** Timeline 은 이미 패키지에 들어 있지만 배선이 에셋 인스펙터에 남아 「흐름 배선은 코드에」 규칙과 부딪히고, AI 가 읽고 고치기 어렵다.

## 1. 지금 있는 것

### 1-1. 층 구조 `[확인]`

| 층 | 자리 | 만드는 이 | 등록되는 Hub | 수명 |
| --- | --- | --- | --- | --- |
| Service | `Scripts/Core/IService` · `ServiceBase` | `GameMaster.RegisterServices()` (앱 부팅 때 한 번) | `GlobalHub` | 앱 내내 (`DontDestroyOnLoad`) |
| Master | `Scripts/Core/MasterBase` → `Game/InGameMaster` | 씬에 놓인 MonoBehaviour | — | 씬 하나 |
| Manager | `Scripts/Core/IManager` (+ `IProcess`) | `InGameMaster.CreateManagers()` | `InGameHub` | 씬 하나 |
| Agent | `Core/AgentBase<TOwner>` | Manager·Object 가 소유 | — | 주인 따라 |
| Object | `Core/ObjectBase` (= `IPooledObject`) | `ResourceService.Rent` | — | 풀 |

- `Update` 는 `GameRunner` 하나뿐이다. Service → Master 순으로 `Process(dt)` 를 돌리고 `dt` 에 `GameMaster.TimeScale` 을 곱한다. **코루틴·async 는 코드 어디에도 없다.** 새 서비스도 `Process(dt)` 로 도는 꼴이 맞다.
- Manager 끼리는 `EventBus`(동기 · readonly struct)로만 알린다. 재진입(알리는 중 같은 이벤트 다시 알림)은 예외로 막는다.
- `GameMaster.RequestScene` 로 씬 전환 예약만 있고, 페이드·로딩 화면은 없다.

## 3. 방식 비교

판정 기준 셋 : **WebGL(Web) 에서 되나** · **Unity 6000.3 에서 되나** · **「흐름 배선은 코드에 · SO 는 수치 통만」 과 맞나**.

### 3-1. WebGL 이 깎는 것 (전부 `[확인]` 공식 문서)

| 기능 | WebGL 에서 | 뜻 | 출처 |
| --- | --- | --- | --- |
| 오디오 자동 재생 | **사용자 입력(클릭·터치·키) 전에는 소리가 안 난다** | 첫 탭을 받고 BGM 을 시작한다. 지금 게임은 어차피 탭으로 시작하니 자리가 있다 | [Unity 6 Web Audio](https://docs.unity3d.com/6000.3/Documentation/Manual/webgl-audio.html) |
| AudioMixer | **볼륨(`SetFloat`)만 된다.** 다른 효과는 안 됨 | 믹서 대신 `AudioSource.volume` 을 서비스가 직접 곱한다 | 같은 문서 |
| AudioClip Streaming | 안 됨 (브라우저가 스트리밍 미지원). `Stream=false` | BGM 도 메모리에 올린다. **CompressedInMemory** 로 둬 메모리를 아낀다 | 같은 문서 |
| `SetData/GetData` | DecompressOnLoad 만 | 짧은 SFX 는 DecompressOnLoad, 긴 BGM 은 CompressedInMemory | 같은 문서 |
| pitch | 양수만 | 역재생 효과는 못 쓴다 | 같은 문서 |
| iOS 무음 모드 | DecompressOnLoad 클립이 안 들림 | 모바일 WebGL 에서 「소리 안 남」 문의가 올 수 있다 — 알고만 둔다 | 같은 문서 |
| C# 스레드 | 안 됨. `Task` 대신 `Awaitable` 권장 | 우리는 둘 다 안 쓰고 `Process(dt)` 로 간다 | [Web 기술 제한](https://docs.unity3d.com/6000.3/Documentation/Manual/webgl-technical-overview.html) |
| `Reflection.Emit` | 안 됨 (AOT) | 런타임 코드 생성 라이브러리 금지 | 같은 문서 |
| Addressables 동기 로드 | 안 됨. 비동기 API 만 | 지금 `ResourceService` 는 전부 동기 → Addressables 로 바꾸면 `Rent` 꼴이 바뀐다 | [Unity Discussions](https://discussions.unity.com/t/webgl-addressables-and-local-loadpaths/883118) `[전언]` |
| VFX Graph | **아예 안 돈다** (compute shader 필요) | 파티클은 **ParticleSystem(Shuriken)** 만 | [dev.to](https://dev.to/furic/unity-webgl-particles-invisible-causes-and-how-to-fix-it-358a) `[전언]` |
| Soft Particles | depth texture 없어 투명해짐 | URP 2D 라 어차피 끔 | 같은 글 `[전언]` |

### 3-3. 컷씬 — Timeline 과 직접 짜기 견주기

| 보는 것 | Timeline (PlayableDirector) | 단계 목록 JSON + `CutsceneManager` |
| --- | --- | --- |
| WebGL · Unity 6 | 된다 `[확인]` 패키지 설치돼 있음 | 된다 (순수 C#) |
| 배선이 어디에 | **`.playable` 에셋 + 씬의 PlayableDirector 바인딩.** 코드로 `SetGenericBinding(key, value)` 를 쓰면 코드 배선은 가능 `[확인]` 하지만 트랙 내용(누가 언제 어디로)은 에셋 안이다 | **전부 코드 + JSON.** diff 로 읽힌다 |
| AI 가 쓰고 고치기 | 어렵다. `.playable` YAML 을 손으로 쓰는 셈 | 쉽다. JSON 한 줄 = 단계 하나 |
| 대사 · 선택지 | 트랙으로 억지로 넣어야 함 (Signal + 코드) | `say` 단계 하나 |
| 대역 이동 | Animation 트랙(절대 좌표) — 농장 크기·해상도 바뀌면(피드백 8) 전부 다시 찍음 | `move(actor, 경로 점들, 초)` — 점은 타일 좌표라 바뀌어도 산다 |
| 스킵 | `director.time = duration` 로 끝으로 점프. 트랙 밖 코드 상태는 따로 맞춰야 함 | 남은 단계의 `ApplyEnd()` 를 차례로 부른다 — 단계마다 「끝 상태」를 정의하는 규칙만 지키면 자동 |
| 배속 · 멈춤 | 자기 시계. `GameMaster.TimeScale` 과 따로 논다 | `Process(dt)` 라 같은 시계 |
| 카메라 연출 · 복잡한 타이밍 | **강점.** 키프레임 편집기 | 약함. 숫자로 적는다 |
| 판정 | 카메라 워크 중심 영상이 필요해지면 그때 후보 | **권장.** 세로 한 화면 · 대사 중심 · 대역 몇 걸음이면 충분 |

컷씬이 가져야 할 단계 종류 (조사 결과 · 설계 아님) : `letterbox on/off` · `say(화자, 글)` · `spawn(대역 key, 자리)` · `move(대역, 점들, 초)` · `emote(대역, 표정)` · `wait(초)` · `sfx/bgm(key)` · `focus(자리)`(카메라 살짝 이동) · `end`. 대사 글은 H 가 들어오면 key 로 바뀐다.

## 6. 못 본 것 · 확인 못 한 것
