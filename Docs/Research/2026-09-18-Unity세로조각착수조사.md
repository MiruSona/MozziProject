# Unity 세로 조각 착수 조사

> 8단계 「세로 조각」을 Unity 로 만들기 전에, 기획서 · 프로토 · 코드 구조 문서 · Unity 프로젝트 상태를 대조한 조사다.
> 2026-09-18 · 조사 AI · 상태 조사 끝, 9절 물음은 설계 단계에서 정한다
> 관련 결정 : mem `20260918-c65f70f0`(8단계로 되돌림) · `20260918-7850afb8`(판정은 사용자가 직접) · `20260917-c90b6fca` · `20260913-77f8c41d` · `20260912-83c75f55` · `20260909-84384f61` · `20260906-97b15e5e` · `20260913-188b52e6`

## 결론 먼저

- **기획서는 세 시스템 중 둘(합성소·가판대)만 문서가 있고, 농장은 없다.** 세로 조각은 농장 화면에서 시작하므로 `03-시스템-농장.md` 가 첫 빈 자리다. 시스템 문서 없이 코드를 쓰면 `stage lint` 가 막는다.
- **「게임 속 하루」의 뜻이 둘이다.** 코어루프의 「접속 3~4번」과 가판대의 「열기 → N명 → 밤 → 다음날로」. 세로 조각 범위는 뒤쪽(가게 한 바퀴)으로 잡는 것이 자연스럽지만, 설계 단계에서 못 박아야 한다.
- **수치표는 「확정」이 셋뿐이고, 프로토(q3·q2)에만 있는 값·규칙이 스무 개 넘는다.** 코드가 어느 값을 읽을지, 수치표를 어떤 장치(md 파서 · SO · JSON)로 읽을지가 미정이다.
- **CodeTool 은 문서만 있고 실물 템플릿이 없다.** 7층 구조 · 폴더 · asmdef 규칙은 정해져 있으니 뼈대는 첫 판에서 직접 세워야 한다.
- **Unity 프로젝트는 빈 상태다.** 6000.3.23f1 2D URP, 씬은 SampleScene 뿐, `Assets/Scripts` 비어 있음. CLI(`unity status`)로 에디터 연결은 확인됐다.
- 배경 : 2026-09-18 에 사용자가 9단계에서 8단계로 되돌리고 Unity 로 세로 조각(게임 속 하루 한 번)을 만들기로 정했다. 판정은 「남이 켜서」가 아니라 **사용자가 직접 켜서 하루치 끝까지 해 본다.**

### 1-3. 시스템 문서의 핵심 규칙

**합성소** (`Docs/Design/03-시스템-합성소.md`) : 재료 2마리 · 실패 없음 · 결과 1마리. 슬롯 순서는 계열이 다를 때 첫 슬롯 계열. 결과 ① 정해진 종 65% ② 다른 계열 1단계 20% ③ 변종 15%. 3단계끼리는 ② 60 / ③ 40. 교차 잔디 + 물(둘 다 2단계↑) → 늪 1단계. 비용은 재료 단계 기준, 골드 + 대기, 즉시 완료 없음. 시작 흰찹쌀이 2마리 · 잔디 농장 1 · 합성소 처음부터 열림. 번식은 같은 농장 같은 종 2마리↑ → 1마리, 변종끼리 없음, 담장 상한(10~20)에서 멈춤. 짝 구매는 1 · 2단계 일반 종만 ×1.5(150/750). 화면 : 건물 → 슬롯 2 → 확률 미리보기(미획득 ???) → 골드 → 알림 → 결과 연출 → 보관함(상한 · UI 미정). 레어 확률 업그레이드 없음(단 「다시 볼 것」 남음).

**가판대** (`Docs/Design/03-시스템-가판대.md`) : 찹쌀가루(무한 · 값 0) / 수수가루(늪 3단계) / 부재료 11종(재료별 상한). 변종 12종은 「특제판」. 레시피 = 가루 1 + 부재료 1~3, 도감 24칸(찹쌀 18 = 11/5/2, 수수 6 = 3/2/1). 2 · 3개짜리 10칸 조합 미정. 실패 = 평범한 떡(절반 값). 힌트 셋 필수(해 본 조합 표시 · 3재료 하나 공개 · 5명 중 1명이 못 찾은 떡 주문). 제작 대기 없음, 미발견 조합만 떡메 3~4탭(약 3초, 판정 없음). 판매 : 열기 → 손님 5초 간격 → 주문 맞으면 ×1.5 → 떡 없으면 줄(5명) → N명 다 사면 밤 → 다음날로. 진열 상한 30. 떡 값 = 부재료 값 합 × (개수 · 특제 · 주문), 수수는 덧셈. 설비 점원 200 → 찜기 500, 설비 전 방치 판매 없음. 강화 축은 N 하나. 화면 : 농장 화면 / 가판대 화면 하나. 열림/닫힘은 상태.

**농장** : 정식 시스템 문서 없음. 규칙 조각이 `Docs/Design/01-코어루프.md` 3절 · `Docs/Design/03-시스템-합성소.md` 6절 · 옛 `Docs/Design/농장기획/농장 시스템.md` 에 흩어져 있다.

### 하루 한 번의 화면과 행동 사슬

화면 : 농장 화면(자원바 · 배치 · 줍기 · 건물 둘 · 번식) / 가판대 화면(진열대 · 줄 · 만들기 · 실험 · 도감 · 열기 · 다음날로) / 합성소 화면(슬롯 2 · 확률 · 시계 · 결과 연출 · 보관함) / 도감 둘 / 보관함.

행동 사슬 : 켠다 → 줍기 → (합성 결과 → 보관함 → 배치) → 실험/만들기 → 열기 → 손님 N명(주문 · 힌트로 발견 → 도감 칸 연출) → 밤 → 골드 쓰기 → 다음날로.
