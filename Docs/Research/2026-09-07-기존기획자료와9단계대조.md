# 기존 기획 자료와 9단계 대조

> 저장소에 이미 있는 기획 자료를 다 훑고, 기획절차 9단계 가운데 **어디가 차 있고 어디가 비었나**를 대조한 문서.
> 날짜 2026-09-07 · 상태 조사 — 단계 판정·다음 할 일 확정은 사용자가 한다.
> 9단계 내용 자체는 여기 안 옮긴다. 정본은 `Tools/GamedesignTool/Docs/Guide/기획절차.md`.

## 한 줄 결론

**위(컨셉·기둥)가 비어 있고 아래(시스템 문서)가 먼저 나와 있다.**
1단계 컨셉과 3단계 코어 루프는 조각만 있고, 2단계 기둥과 4단계 물음 묶음은 아예 없다.
반면 8단계 것인 `03-시스템-합성소.md` 는 이미 1차 설계까지 나와 있다.
그래서 다음 세션은 **컨셉 물음 8개에 사용자 답을 받는 것**부터 시작한다.

## 2. 9단계 대조

| 단계 | 상태 | 근거 |
| --- | --- | --- |
| **1 컨셉** | **반쯤** | 합성소 문서 2절 첫 줄 「2D 도트 방치형 농장 게임. 찹쌀이 슬라임을 키워 재료를 얻고 가판대에서 찹쌀떡을 팔아 골드를 번다」가 **한 줄 컨셉 초안** 노릇을 한다. 대상 · 남는 기분 · 「왜 재밌나」 · 안 할 것 목록은 없다. `00-컨셉.md` 파일 자체가 없다 |
| **2 기둥** | **없음** | 어디에도 없다. **사용자만 정하는 자리**다 |
| **3 코어 루프** | **반쯤** | 조각은 흩어져 있다. 원천(농장 재료 생성 · 번식), 변환(합성 2→1, 재료→찹쌀떡), 배수구(합성 골드·시간, 설비 업그레이드, 농장 확장). 하지만 **3층 루프 표**도, **가판대 골드 눈금**도, **하루/며칠 고리**도 없다. `01-코어루프.md` 없음 |
| **4 물음 묶음** | **없음** | 후보만 있다 — 합성소 9절의 「20% 가 너무 잦지 않나」 「3단계까지 평균 몇 번 합성하나」. `Docs/Research/2026-09-06-필요프로토타입가늠.md` 의 물음 17개가 재료가 될 수 있다 |

## 3. 정리 제안 (다음 세션에 할 일)

1. **`Docs/Design/00-컨셉.md` 작성** — 아래 4장 물음에 답을 받은 뒤에 쓴다.
   컨셉 초안 문장 예 : 「찹쌀이 슬라임을 농장에서 키우고 둘씩 합성해 새 종을 만들어, 24칸 도감을 채우는 2D 도트 방치형 농장 게임」
2. **같은 문서 `## 기둥` 절** — 사용자가 고른 것만 적는다. AI 가 채우지 않는다.
3. **`Docs/Design/01-코어루프.md` 초안** — 3층 루프 표로 쓴다. 사용자 확인 뒤 `stage ask` 로 물음을 등록한다.
4. **`Docs/Guide/프로젝트개요.md` 고치기** — 「지금 정해진 것은 2D 라는 것 하나다」 줄이 진행상황과 어긋난다. 같이 고친다.
5. **농장기획 폴더와 합성소 문서는 그대로 둔다.** 농장 수치·그림은 8단계 `03-시스템-농장.md` 때, 임시 수치는 `04-수치표.md` 때, 자른 것은 `02-기능목록.md` Won't 칸 때 쓴다.

## 4. 사용자에게 물을 것 (컨셉 확정용)

1. **누가 하는 게임인가** — 나이와 노는 상황 (자기 전 5분 / 출퇴근길 / PC 앞에 오래)
2. **끄고 나서 남는 기분 한 단어** — 뿌듯함 · 편안함 · 모으는 재미 · 구경하는 재미
3. **가장 재밌어야 할 순간 하나** — 합성 결과가 열릴 때 / 농장이 꽉 차 저절로 굴러갈 때 / 찹쌀떡 팔아 돈이 들어올 때
4. **방치의 세기** — 껐다 켜면 쌓여 있는 쪽인가, 켜 놓고 계속 누르는 쪽인가
5. **가판대의 무게** — 골드 나오는 수도꼭지인가, 요리 타이쿤 한 축인가
6. **플랫폼** — 그림은 모바일 세로로 보이나 확정된 적이 없다
7. **한 판 길이** — 한 번 켜면 몇 분인가
8. **안 할 것에 더 넣을 것** — 전투 · 스토리 · 멀티 · 랭킹

그리고 **기둥 3~4개는 사용자가 직접 고른다.**

## 5. 주의

- **`Docs/Design/농장기획/` 은 옛 프로젝트 자료다.** 필드에서 잡아 온다는 전제는 이미 폐기됐다. 참고로만 쓰고 그대로 승격하지 않는다.
- **컨셉·기둥이 위, 시스템이 아래다.** 합성소 문서가 먼저 있다고 해서 거기에 맞춰 컨셉을 거꾸로 짜맞추지 않는다.
- 컨셉 작업 전에 조사 둘을 읽는다 : `Docs/Research/2026-09-06-기획순서와기법조사.md` · `Docs/Research/2026-09-06-필요프로토타입가늠.md` (진행상황 37줄이 지목한다).
