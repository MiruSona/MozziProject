# 몬스터 합성 조사 — 믹스마스터를 중심으로

> 왜 조사했나 : 찹쌀이를 「잡아오기」 대신 「합성 기계」로 얻기로 정해서, 몬스터 합성을 오래 굴린 게임의 규칙을 참고하려고
> 날짜 : 2026-09-06
> 조사한 사람 : AI (웹 조사)

> 이 문서는 참고용이다. 기획서에는 여기 나오는 게임 이름들을 그대로 옮기지 않는다.

## 1. 왜 조사했나

우리 게임은 2D 도트 방치형 농장 게임이고 「찹쌀이」라는 슬라임을 키운다.
옛 기획은 찹쌀이를 「필드에서 잡아온다」였는데, 필드 파트를 통째로 빼기로 정했다 (mem 결정 `20260906-e112b4d7`).
대신 찹쌀이 2~3마리를 합성 기계에 넣으면 새 찹쌀이가 나오게 한다 (정해진 결과 + 낮은 확률의 레어).
그 참고로 몬스터 합성을 게임의 뼈대로 삼은 믹스마스터를 조사하고, 비슷한 게임 셋과 견줬다.

## 2. 한 줄 결론

**「결과는 고정 레시피, 확률은 레어 여부에만」은 가져오고, 「실패하면 재료를 잃는다」와 「10단계 깊이·850종 규모」는 버린다.**

## 3. 믹스마스터 합성 규칙

### 3-1. 기본 규칙

| 항목 | 내용 |
| --- | --- |
| 재료 수 | 딱 2마리. 「주(Main) 헨치」 1 + 「부(Sub) 헨치」 1 을 순서대로 올린다 |
| 조건 | ① 두 마리 다 살아 있어야 한다 (코어 상태면 안 됨) ② 반드시 암·수 한 쌍 ③ 두 마리 다 정해진 기본 레벨에 도달 |
| 장소 | 각 마을의 「믹스빌더」 NPC 에서만. 이 NPC 가 코어 회복(부활)도 맡는다 |
| 비용 | 골드 수수료 유무는 공식 가이드에 없음(불확실). 진짜 비용은 「믹스 아이템」 |
| 결과 | 성공하면 재료 두 마리는 사라지고 완전히 새 종 한 마리가 생긴다 |

- 헨치 = 데리고 다니는 몬스터. 죽으면 「코어」라는 알 상태로 돌아간다.
- 믹스 아이템 : 일정 단계부터는 계열별(드래곤·악마·짐승·곤충·식물·미스터리·메탈·새) 믹스 아이템을 헨치에 붙여야 믹스가 된다.
  1~5단계 아이템이 있고, 던전 드랍·암시장 NPC·이벤트로 구한다.
- 보조 캐시 아이템

| 아이템 | 효과 |
| --- | --- |
| 믹스 전용 옷 | 성공률 1.2배, 실패 시 레벨 하락 3 고정 |
| 엘리시온 목걸이 | 성공률 상승 |
| (축복의) 생명의 열매 | 실패해도 레벨 안 떨어짐, 1회용 |

### 3-2. 결과가 정해지는 방식 — 레시피 고정 + 성공/실패 확률

- **결과 종은 100% 고정 레시피.** 주 A + 부 B = 결과 C. 같은 조합이면 항상 같은 결과.
  랜덤으로 결과가 갈리는 레시피는 없다. (팬 DB 기준, 한 결과에 레시피가 2~40개씩 있어도 한 조합 → 한 결과)
- **순서가 중요하다.** 앞(주)에 올린 헨치가 결과의 계열을 정한다. 뒤집으면 다른 결과거나 안 된다.
- 팬 앱 DB 구조도 `결과 ← (왼쪽 헨치, 왼쪽 아이템, 오른쪽 헨치, 오른쪽 아이템)` 고정 표다.
- **확률은 「되냐 안 되냐」에만 걸린다.** 성공률은 결과 헨치의 레벨 구간(= 믹스 스킬 레벨)로 정해진다.

| 믹스 스킬 레벨 | 결과 헨치 레벨 | 기본 시작 성공률(공식) |
| --- | --- | --- |
| 1 | 1~20 | 40% |
| 2 | 21~40 | 30% |
| 3 | 41~60 | 24% |
| 4 | 61~80 | 15% |
| 5 | 81~100 | 10% |
| 6 | 101~120 | 7% |
| 7 | 121~140 | 3% |
| 8 | 141~160 | 2% |
| 9 | 161~180 | 1% |
| 10 | 180~ | 1% |

- 나무위키는 「1~20 은 90%, 21~40 은 80%, 41~60 은 70%, 구간마다 10%씩 내려간다」고 적는다.
  공식 표는 「시작」 성공률이고, 믹스 포인트(성공 2점·실패 1점)를 쌓아 구간을 「마스터」하면 확률이 오른다.
  나무위키 수치가 최대치인지는 불확실하다.
- **실패하면** : 헨치 레벨이 3~6 떨어지고 코어(알) 상태로 돌아가 회복비를 내야 다시 쓴다.
  기본 레벨 아래로 떨어지면 소멸한다. 그래서 미리 레벨을 올려 두면 실패해도 살아남는다(「렙업빵」).
  싼 재료는 그냥 날리며 시도한다(「날림빵」).
- 믹스가 아예 안 되는 헨치도 있다 (돌연변이 등).

### 3-3. 레벨 조건

- 재료 두 마리는 각자 「기본 레벨」에 도달해야 한다. 그 이상 올린 레벨은 결과 종을 바꾸지 않는다.
- 레벨이 영향을 주는 곳은 둘이다.

| 어디에 | 어떻게 |
| --- | --- |
| 성공률 | 결과 레벨 구간이 믹스 스킬 레벨을 정한다. 같은 레벨대끼리 할수록 성공률이 오른다 |
| 실패 시 보험 | 레벨이 높을수록 실패해도 소멸하지 않는다 |

- 모든 헨치는 기본 레벨에서 시작해 기본 +25 까지만 자란다. 더 강해지려면 믹스로 상위종을 만들어야 한다.
  게임 전체를 믹스로 끌고 가는 장치다.
- 따로 「재료 등급」 개념은 없다. 레벨 구간과 믹스 아이템 단계(1~5)가 그 역할을 한다.

### 3-4. 등급·희귀도 체계

- 정식 등급(레어·에픽) 표기는 없다. 희귀도를 만드는 것은 셋이다.

| 축 | 내용 |
| --- | --- |
| 레벨 구간 | 기본 1 ~ 351+ |
| 계열 8종 | 드래곤·악마·짐승·곤충·식물·미스터리·메탈·새 (한국 공식은 7종, 해외 자료는 새 포함 8종) |
| 성향 접두사 5종 | 힘쎈·날쎈·정확한·운좋은·속성강한. 획득 시 랜덤. 같은 종인데 다른 개체를 만드는 유일한 랜덤 요소 |

- 레어가 나오는 길

| 길 | 내용 |
| --- | --- |
| 사냥 드랍 불가 종 | 믹스로만 얻는 종 |
| 돌연변이 헨치 | 레시피 없음, 사냥으로만 |
| 알려지지 않은 레시피 발견 | 해외 뉴스에 Flame Rhino = BlazeRhino + Neo Mad 소개 |

- **랜덤 확률로 레어 종이 튀어나오는 구조는 확인된 자료에는 없다.**

### 3-5. 합성 트리 구조

- 아래→위 피라미드. 사냥 드랍 코어 둘 → 1단계 → 결과끼리 또 → 2단계 … 커뮤니티는 「1~10단계」로 부른다.

| 단계 | 예 |
| --- | --- |
| 3단계 | 몽크 + 보어 = 와일드보어 |
| 6단계 | 고쿠마 + 아야야 = 뉴고쿠마 |
| 10단계 | 침묵의 탑 보스 코어 + 종족별 고대 코어(3단계 아이템) |

- 초보 필독서는 「5~6단계쯤에서 멈추는 게 보통」이라고 한다. 위로 갈수록 재료·아이템 비용이 급하게 오른다.
- 옆으로 바꾸는 구조는 없다. 한 결과에 여러 레시피(2~40개)가 있어 「어느 길로 올라갈지」는 고를 수 있다.
- 규모 : 헨치 약 850종(팬덤 위키) / 코어 1,000종 이상(해외 공식). 레시피 수천 개. 플레이어는 외부 DB·계산기를 쓴다.

## 4. 플레이어 반응

| 구분 | 내용 |
| --- | --- |
| 재미 | 목표 헨치를 정하고 거꾸로 레시피를 짜는 역산 퍼즐 |
| 재미 | 믹스한 헨치 거래·대리 믹스 경제 |
| 재미 | 남이 못 본 레시피 발견 자랑 |
| 불만 | 후반 성공률 1~3%, 실패 시 레벨 하락·소멸. 캐시 옷 없이는 사실상 못 함 |
| 불만 | 코어 드랍률 극악, 상위 단계는 던전 전용 아이템 필요 |
| 불만 | 직접 믹스보다 완성품 사는 게 싸다 |
| 불만 | 대리 믹스 사기, 색만 바꾼 몬스터 남발로 850종 체감 가치 낮음 |
| 불만 | 정보가 게임 밖에만 있어 신규 진입 어려움 |

## 6. 우리 게임에 가져올 것 / 안 가져올 것

### 가져올 만한 것

| 무엇 | 왜 |
| --- | --- |
| 결과 종은 고정 레시피, 확률은 레어 여부에만 | 고정 레시피가 역산 퍼즐 재미를 준다. 우리 결정과 맞는다. 단 「성공/실패」 확률은 두지 말고 「일반 결과 / 레어 결과」 확률만 둔다 |
| 주 재료가 계열(색·타입)을 정한다 | 첫 슬롯이 결과 계열을 정하면 레시피를 크게 늘리지 않고도 「순서 바꿔 보기」 재미가 생긴다 |
| 레벨은 결과 종이 아니라 조건에만 | 재료 레벨은 합성 가능 여부만 정한다. 데이터 표가 단순해지고 「키워서 합성」 방치 루프가 생긴다 |

### 가져오면 안 될 것

| 무엇 | 왜 |
| --- | --- |
| 실패 시 재료 소멸·레벨 하락 | 가장 큰 불만이자 캐시 유도 장치. 「뭔가는 반드시 나온다」로 간다 |
| 10단계 깊이·850종 규모 | 혼자 도트 그리는 규모로는 불가능. 3~4단계, 수십 종 안에서 레시피가 게임 안 도감에 다 보이게 한다 |
| 계열별 소모 아이템 같은 별도 재료 축 | 재료 노가다의 뿌리. 재료는 찹쌀이 자체(+ 농장 산물 정도)로만 |

## 7. 불확실한 것 · 신뢰도

### 불확실한 것

- 골드 수수료 유무·액수
- 나무위키의 90/80/70% 가 최대 성공률인지
- 한국판 계열 7종 vs 8종
- 믹스 옷 가격 (갤러리 글 1건 근거)

### 신뢰도

| 항목 | 신뢰도 | 근거 |
| --- | --- | --- |
| 믹스 규칙·성공률 표·실패 규칙 | 90% | 공식 가이드 원문 |
| 트리 구조·규모·레어 방식 | 70% | 팬 DB·커뮤니티 여러 건이 일치. 공식 표는 없음 |
| 플레이어 반응 | 65% | 나무위키 영문 미러·갤러리 글 3건 |
| 비교 게임 | 60% | 나무위키 1~2페이지 |
