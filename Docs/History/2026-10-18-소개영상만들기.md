## 다시 만드는 법

1. **자동 플레이** : `ProjectMozziUnity/Assets/Editor/VideoCapture/DemoDriverIntro.cs` 를 쓴다. 장면마다 `[DemoIntro] 장면 N 시작 frame=` 로그를 남긴다. 데움은 `Warmup = 60` 이라 Arm 에도 60 을 넘긴다.
2. **캡처** : `VideoCapture.cs` 를 Bash 에서 `unity command eval` 로 부른다. 순서는 Farm 씬 열기 → `SetGameViewSize(540,1200)` → `TouchSaveTime` → `Arm("Captures/intro",30,1900,60,"VideoCaptureTool.DemoDriverIntro")` 이고, 절차는 howto 기억 `20261011-f825a5c2` 에 있다.
3. **묶기** : 미니PC 의 ffmpeg 8 로 `nice -n 19` 를 붙여 한 번 돈다. 그림을 490×1090 으로 줄여 띠를 붙이고, 자막은 `drawtext textfile` 에 `enable='between(n,a,b)'` 를 건다. 그다음 카드와 concat 한다. 보내기·묶기 스크립트는 세션 스크래치에만 있었고 저장소에는 없다.
