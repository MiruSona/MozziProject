## 피드백

사용자 말 그대로 적는다. 줄 끝에 갈래를 붙인다 — `[코드]` `[그림]` `[소리]` `[VFX]` `[기획]`.

### 먼저 온 스크린샷 두 장

「이 이미지들은 버그 같아보여서 일단 보고 잠시만 마저 피드백 적을게」

(스크린샷 설명 : 합성소 — 바닥 그림이 세로로 늘어남 · 흰찹쌀이 골랐는데 깔때기에 초록 찹쌀이 / 가판대 — 위 막대·아래 패널이 반투명이라 배경이 비침 · 바닥 타일 늘어남)

### 플레이 피드백

1. 합성소, 가판대를 위로 붙이면서 아래쪽이 늘려서 보이는데 아래로 붙이고 비는 부분은 하늘? 처럼 배경이 보이면 좋겠어
2. 농장도 마찬가지로 중앙에 붙일 필요없이 아래로 붙이고 하늘이 보이면 좋겠어
3. 합성소 이상한게 흰찹쌀이를 선택하는데 초록 찹쌀이를 나와 -> 이걸보니까 클로드 코드 리뷰로 전체 작업한거 코드 리뷰 한번 돌려서 버그 잡는게 좋을듯
4. 합성소 내가원한건 이체 합성소 기계가 있으니까 기계 입구 양쪽을 각각 선택해서 찹쌀이 선택하는게 좋을 것같아
5. UI 프로토타입 만든것들을 정식 UI이미지로 하는게 좋을 것 같아 -> 그리고 지금처럼 위아래 배치가 아니라 우측에 배치하고 그.. 햄버거?메뉴 처럼 누르면 목록나오던가 주요메뉴는 항시 표시하는게 좋을 것 같아
6. 합성소랑 가판대도 바뀐 가판대와 합성소를 참고해서 정식 이미지로 만들고(굳이 높이를 작게할 필요없어) 뭐라해야하지.. 농장이 내가 원하는 이미지가 위에는 하늘이 보이고 아래 카페/합성소 건물이 배치되어있고, 그 아래 농장이 있고 배치를 원했었어. 카페/합성소 건물 옆에는 보관함 창고상자 같은 이미지를 두고 이걸 보관함으로 사용하길 원했고
7. 그래 솔직히 말하면 지금은 게임이라기보다 너무 프로토타입 UI로 정말 기능만 돌아가게 만든 수준으로 보여서 전체적으로 그림체 통일, 게임처럼 보이게 만드는 작업을 하고싶어 `[그림]`
