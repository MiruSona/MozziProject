## 다시 만드는 법

캡처 도우미 절차는 howto 기억 `20261011-f825a5c2` 에 있다. 핵심만 적는다.

1. **캡처 도우미** : `ProjectMozziUnity/Assets/Editor/VideoCapture/VideoCapture.cs`.
   게임 코드를 참조하지 않는다. `Time.captureFramerate` 로 30fps 를 맞추고 PlayerLoop 의 PostLateUpdate 에서 `ScreenCapture` 로 찍는다.
   부르는 것은 `SetGameViewSize` → `TouchSaveTime` → `Arm` 순서 (`Stop` · `Status` 도 있다).
2. **부르는 길** : `unity command eval` 로 부른다. **Bash 에서만 친다** — PowerShell 5.1 은 따옴표를 깨뜨린다.
3. **v17 자동 플레이** : `DemoDriverV17.cs` (v17 전용). 옛 판 worktree 에는 `VideoCapture.cs` 만 복사한다.
4. **결과 폴더** : `ProjectMozziUnity/Captures/` (`.gitignore` 에 넣었다).
5. **묶기** : 미니PC 의 ffmpeg 8 로 `nice -n 19` 를 붙여 돌린다 (1판 12초).
   보내기·묶기·받기 스크립트는 세션 스크래치에만 있었고 저장소에는 없다.
6. **뒷정리** : 옛 판 worktree 넷 · 캡처 프레임 · 미니PC `~/mozzi-video` 는 다 지웠다. 캡처 도우미와 이 문서만 남았다. 다시 만들려면 worktree 부터 다시 꺼낸다.
