# 2026-10-17 피드백 — 저장소를 다른 드라이브로 옮긴 뒤 (`Tools/setup.ps1`)

> 2026-10-17 · 게임 저장소를 C: 드라이브에서 D: 드라이브로 옮긴 뒷정리 중.
> `Tools/setup.ps1` 은 툴 저장소가 아니라 이 저장소에서 만든 파일이라(커밋 `3b17b79`) 여기에 남긴다.

## 막힌 것 — `-Check` 가 옛 경로 venv 를 못 잡는다

- **증상** : venv 가 다른 드라이브에서 만들어져 런처 shebang · editable 설치 · activate 가 옛 경로인데도
  `setup.ps1 -Check` 가 「모두 최신」(종료 0)을 낸다. 실제로는 툴 exe 가 안 돈다.
- **재현** : 저장소를 C: 에서 D: 로 옮긴 뒤 `powershell -File Tools\setup.ps1 -Check`.
- **바라는 것** : `.venv\Scripts\python.exe -c "import sys; print(sys.prefix)"` 결과가 그 `.venv` 자리와 같은지,
  또는 `<툴>.exe --help` 가 종료 0 인지도 같이 본다. 다르면 「다시 만들어야 함」으로 표시한다.
