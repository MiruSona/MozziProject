- 무료 레퍼런스는 거의 픽셀이다. 벡터로 가면 캐릭터·용암·늪 타일을 직접 정의해야 한다. 떡·한옥 같은 한국 전통 에셋은 무료로 없어 어느 쪽이든 자체 제작 자리다.
- PixelLab 의 몸 유형은 사람형·네발형뿐이라 덩어리 찹쌀이가 잘 나올지는 **써 봐야 안다** (추측).
- 합성 연출·빛나는 변종·먹기/자기 애니 레퍼런스는 못 찾았다. 필요하면 머지류 모바일 게임 스크린샷을 따로 본다.
- mem 표준 태그에 `reference` · `background` 를 더했다 (`Memory/vocab.toml`). 원치 않으면 빼도 된다.
- 기획 세션과 아트 세션이 같이 돌 때 : 기획은 `Docs/Design/` · `Prototypes/`, 아트는 `Docs/Reference/Art/` · `Docs/Research/*아트*`. `Memory/log.md` 는 둘이 같이 쓰니 한쪽이 커밋한다.

## 못 정한 것

| 무엇 | 왜 아직 못 정했나 |
| --- | --- |
| 장르 | **방치형 농장 + 합성 수집** 으로 잡혔다. 가판대(요리 타이쿤 비중)를 얼마나 둘지는 ⑥(가판대 설계)에서 정한다 |
| 규모 | 혼자 만들 수 있는 크기가 어디까지인지 기획이 나와야 잡힌다 |
| 다음 골드 소비처 | 봇 실측에서 60분 뒤 골드가 다시 고인다(남은÷번 30%). 다음 소비처(농장 확장·설비)는 가판대 설계(⑥) 뒤에 정한다 |

## 그 밖의 것은 mem 에 있다

- 결정 : `mem search --type decision --scope game`
- 아직 못 정한 것 : `mem search --type todo`
- 공수 눈금과 지난 기록 : `mem search 공수 눈금`

툴 자체의 할 일은 여기 적지 않는다 — 그 툴 저장소의 `Docs/Todo/` 를 본다.
